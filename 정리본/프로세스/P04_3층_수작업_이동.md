# [프로세스] 3층 수작업 이동

> 키워드: INB-MAN · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「입고 오더」, 「운반 설비」, 「작업지시 체계」, 「W/T」
> **이름만 쓰는 묶음**: 「시스템」, 「AS/RS」, 「단말」, 「재고 수량」, 「팔레트」, 「입고 업무 용어」, 「WCS 위치」
> **이어지는 프로세스**: 앞 → P01 EWMS 작업정보 수신, 뒤 → 없음(3층 도착 뒤 이동은 WCS 처리 범위 밖), 관련 → P02 일반입고(1층 AS/RS 경로), P10 AS/RS Bypass 이송(EWMS가 Bypass를 지시할 때)

## 1. 범위

1층에서 하역하거나 수작업 팔레타이징한 팔레트(국내OEM·해외OEM 등)를 3층·4층으로 옮긴다. 〔K28-OV01〕 EWMS가 PDA 선행작업 후 생성한 W/T를 받아 이동 작업을 만들고, 도착하면 도착 정보를 EWMS에 보내 W/T를 확정한다. 〔K28-OV04〕

**진입 조건**

| 조건 | 처리 | 출처 |
|---|---|---|
| (EWMS) 입고 오더 → 유형별 경로 결정 | 3층 이동 | 〔K16-F01.00〕 |
| 입고 유형 = 국내OEM / 해외OEM | 3층으로 이동한 뒤 팔레트로 보관한다 | 〔BR-MST-ORD-002〕 |
| 입고 유형 = OEM | 이 경로로 3층 이동 | 〔BR-INB-MAN-002〕 |
| 구분자로 식별한 국내OEM·해외OEM 입고 | 3층 수작업 이동 경로로 처리한다 | 〔REQ-MST-ORD-008〕 |
| 국내OEM 입고 | 1층 하역장 하차 → 3층 이동 | 〔K16-F06.00〕 |
| 해외OEM(역수입) 입고 | 1층 하역장 하차 → 3층 이동 | 〔K16-F07.00〕 |
| W/T 행선지 = 3층 | 이 경로 적용 | 〔BR-INB-MAN-001, K28-OV02〕 |

- 1층 AS/RS로 가는 입고 유형은 → P02 일반입고.
- ⚠ 원문 불일치: 대상을 「W/T상 행선지가 3층인 입고」로 적는다. 〔BR-INB-MAN-001, K28-OV02〕
- ⚠ 원문 불일치: 대상을 「1층 → 3층·4층 이동」으로 적는다. 〔K28-OV01, BR-INB-MAN-010〕
  - 행선지 4층 W/T가 이 프로세스 대상인지 표현이 다르다.

## 2. 흐름

1. (작업자) EWMS PDA로 선행작업을 한다. 〔K28-F01.00, BR-INB-MAN-015〕
2. (EWMS→WCS) EWMS가 W/T를 생성해 WCS에 알린다. 〔K28-F01.00, BR-INB-MAN-015, REQ-INB-MAN-016, K28-OV04〕
3. (WCS) W/T를 받은 뒤 이동 작업(AMR·수직반송기 작업지시)을 만든다. WCS는 W/T 생성을 요청하지 않는다. 〔BR-INB-MAN-015, REQ-INB-MAN-016, K28-F01.00, K28-OV04〕
4. (WCS) 이동 수단은 Workflow 설정(기본·대체)으로 정하고, AMR 가동 불가 시 대체 수단으로 바꾼다 → 3. 조건·규칙. 〔K28-F02.00〕
5. 이동 방식은 두 가지다. 〔K28-F02.00〕
   - AMR 라인: AMR 호출 → 수직반송기까지 이동 → 3층. 〔K28-F02.01〕
   - 유인지게차: 지게차가 직접 수직반송기로 이동 → 3층. 〔K28-F02.02〕
6. (WCS→수직반송기) 투입 시 출발 위치(1층)와 도착 위치(3층·4층)를 지시한다. 〔K28-IF02〕
7. (수직반송기→WCS) 출발 신호를 보낸다. 〔K28-IF03, REQ-INB-MAN-010〕
8. (수직반송기 ECS→WCS) 목적층(3층·4층) 도착 신호를 보낸다. (WCS) 이동 작업을 완료 처리한다. WCS 재고로는 등록하지 않는다. 〔K28-F03.01, K28-IF04, REQ-INB-MAN-010〕
9. (WCS→EWMS) 도착 정보를 보내고 W/T를 확정한다. 〔K28-F03.01, BR-INB-MAN-012, REQ-INB-MAN-013, K28-OV04, K28-IF06〕
10. (작업자) 3층 도착 팔레트를 유인지게차로 옮긴다. 이 이동은 WCS 처리 범위 밖이다. WCS는 이 이동에 작업지시를 내리지 않고, 수직반송기 출발 신호와 3층 도착 신호만 받는다. 〔K28-F03.02, REQ-INB-MAN-010〕

## 3. 조건·규칙

### W/T와 재고

| 조건 | 처리 | 출처 |
|---|---|---|
| 1층 → 3층·4층 수작업 이동 | W/T는 만들지만(EWMS 생성) WCS 재고로 등록하지 않는다. WCS는 이동 작업지시(AMR 이동·수직반송기 이송)와 완료 수신만 처리하고, 이동 중·도착 팔레트를 WCS 재고로 등록하지 않는다 | 〔BR-INB-MAN-010, REQ-INB-MAN-011, K28-OV03, BR-INV-WT-001〕 |

### 경로

| 조건 | 처리 | 출처 |
|---|---|---|
| OEM 3층 이동건(WCS가 만드는 3층 수작업 이동) | AS/RS를 통하지 않는다. AS/RS Bypass 경로를 쓰지 않고 AMR 또는 유인지게차 → 수직반송기로만 3층(4층)에 이동 작업을 만든다 | 〔BR-INB-MAN-013, BR-INB-PLT-019, REQ-INB-MAN-014, K28-F02.00〕 |
| EWMS가 Bypass를 지시함 | 업무 구분 없이 따른다(1층 → 3층 적치 W/T / 4층 → 3층 이동 W/T). EQP-ASRS 처리다 → P10 AS/RS Bypass 이송 | 〔BR-INB-PLT-019, BR-INB-MAN-013〕 |

- ⚠ 원문 불일치: WCS는 W/T 행선지가 3층인 OEM 입고를 AS/RS 투입·Bypass로 처리하지 않고, 3층 수작업 이동으로만 처리한다. 〔REQ-INB-PLT-019〕
- ⚠ 원문 불일치: EWMS가 Bypass를 지시하면 WCS는 업무 구분 없이 따른다. 〔BR-INB-PLT-019, BR-INB-MAN-013〕
  - EWMS가 OEM 건에 Bypass를 지시할 때 앞 기록은 Bypass로 처리하지 않는다고 읽히고, 뒤 기록은 따른다고 적는다.

### 이동 수단

| 조건 | 처리 | 출처 |
|---|---|---|
| 이동 수단 설정 | 기본 수단(예: AMR)과 대체 수단(유인지게차), 대체 허용 여부를 Workflow에 설정한다. 기본값·대체 여부는 운영자가 화면에서 바꾼다 | 〔BR-INB-MAN-014, REQ-INB-MAN-015〕 |
| 이동 작업 생성 시 AMR 장애·가동 불가(설비 운영 상태) | 대체 수단(유인지게차)으로 바꾼다 | 〔BR-INB-MAN-014, REQ-INB-MAN-015, K28-F02.00〕 |
| 유인지게차로 전환함 | AMR 작업지시를 내지 않고 수직반송기 이송부터 이어간다 | 〔REQ-INB-MAN-015〕 |
| 수단을 적용·전환함 | 적용·전환한 수단과 사유를 전략 이력으로 남긴다 | 〔BR-INB-MAN-014, REQ-INB-MAN-015〕 |

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 | 출처 |
|---|---|---|---|
| EWMS→WCS | EWMS PDA 선행작업 후 W/T 생성 시 | W/T: W/T 번호, 팔레트 ID, 제품, LOT, 수량, 출발지, 목적층 | 〔K28-IF05〕 |
| WCS→AMR | AMR 호출 시 | 출발지, 목적지(수직반송기), 팔레트 ID | 〔K28-IF01〕 |
| WCS→수직반송기 | 투입 시 | 팔레트 ID, 출발 위치(1층), 도착 위치(3층·4층) | 〔K28-IF02〕 |
| 수직반송기→WCS | 출발 시(출발 신호, 센싱) | 팔레트 ID, 출발 위치(층), 도착 위치(층) | 〔K28-IF03〕 |
| 수직반송기→WCS | 3층(4층) 도착 시(도착 신호, 센싱) | 팔레트 ID, 출발 위치(층), 도착 위치(층) | 〔K28-IF04〕 |
| WCS→EWMS | 3층(4층) 도착 시 | 도착 정보·W/T 확정: W/T 번호, 팔레트 ID, 도착층, 도착 시각 | 〔K28-IF06〕 |

## 5. 예외

- AMR 장애·가동 불가 때의 수단 전환은 3. 조건·규칙 「이동 수단」을 따른다. 그 밖의 예외는 원문에 없다.

## 6. 기능·화면

- [확인필요] WCS는 AMR 호출과 수직반송기까지의 이동 지시를 지원한다. 〔REQ-INB-MAN-001〕
- [확인필요] WCS는 유인지게차로 수직반송기에 투입된 팔레트를 3층으로 이송한다. 〔REQ-INB-MAN-002〕
- 운영자가 이동 수단(기본·대체, 대체 허용 여부)을 화면에서 바꾼다. 〔REQ-INB-MAN-015〕

## 7. 미결

- [추가 협의] [미결 Q-165] 쉽백 WCS 프로세스 제외 범위 — EWMS가 쉽백에 Bypass를 지시하면 WCS는 업무 구분 없이 처리한다(1층 → 3층 적치 W/T / 4층 → 3층 이동 W/T). 남은 것은 쉽백도 OEM처럼 3층 수작업 이동을 위한 설비 작업지시(AMR·수직반송기)가 필요한지다. 〔Q-165, BR-MST-ORD-015, K16-F08.00, REQ-MST-ORD-016, BR-INB-MAN-002, K28-OV01〕
