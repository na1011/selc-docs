# [프로세스] 제조번호 수신·추적

> 키워드: MST-SN · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「LOT·제조번호」(제조번호·시리얼 마스터·시리얼 이력 로그·변경 TASK번호), 「HU」(HU 내역 조회·HU 시리얼 정보)
> **이름만 쓰는 묶음**: 「제품」(Product Code·제품코드), 「로지스올 입고 설비」(BCR), 「입고 업무 용어」(디베닝입고·일반입고), 「팔레트」(팔레트 ID), 「재고 이력·관리단위」(관리단위 전환), 「재고 수량」, 「WCS 위치」(수작업 영역), 「W/T」(피킹 W/T), 「단말」(WCS PDA·파워유저), 「재고 운영 용어」(재고대사), 「시스템」(EWMS·ECS)
> **이어지는 프로세스**: 앞 → P02 일반입고, → P03 디베닝입고, → P05 HU 확인·생성 / 함께 → P34 재고 반영·보정 / 뒤 → P39 재고대사 / 관련 → P31 출고완료 확정(출고 검수 실적)

## 1. 범위
- 입고에서 제조번호를 처음 받을 때 시작해, 설비 실적·출고 검수·HU 시리얼 통보마다 시리얼 이력 로그를 쌓고 조회하는 데까지다

## 2. 흐름

### 2-1. 제조번호 수신
- 디베닝입고: (BCR) 스캔 → (WCS) BCR 스캔 정보로 제조번호를 받는다
- 일반입고:
  1. (EWMS) 제조번호를 만든다
  2. (WCS→EWMS) 입고장 투입 때 HU 내역을 조회한다
  3. (EWMS→WCS) HU 내역 조회 응답으로 제조번호(S/N)를 함께 받는다
- (WCS) 바코드를 스캔하면 제조번호 앞자리가 Product Code와 같은지 정합성을 체크한다
- (WCS) Product Code 불일치 결과를 시리얼 이력 로그에 남긴다

### 2-2. 시리얼 마스터 생성과 이력 로그 적재
시리얼 이력 로그가 쌓이는 세 이벤트는 「LOT·제조번호」 묶음에 있다. 이벤트별 처리는 아래와 같다

1. 입고 최초 생성: (WCS) 시리얼번호가 입고되어 처음 수신(확인)되면 시리얼 마스터를 만들고 이력 로그(입고 생성)를 쌓는다
2. 설비 결과 실적: (ECS→WCS) 시리얼번호 단위 결과 실적을 받으면 즉시 이력 로그를 쌓는다
3. 출고 검수: (WCS) 출고 때 시리얼번호 단위 검수 결과를 받으면(검수 실적 발생 즉시) 이력 로그를 쌓는다
- 시리얼번호 단위 변경이 생기면 변경 TASK번호로 시리얼 이력 로그를 쌓는다
- 관리단위 전환 때는 시리얼 이력 로그에도 전환 시점을 남긴다(→ P34 재고 반영·보정)

### 2-3. HU 시리얼정보 통보 반영
1. (EWMS→WCS) HU의 시리얼 정보가 바뀌면 EWMS가 자기 내역을 HU 단위 전체 목록(시리얼당 수량 1)으로 통보한다
2. (WCS) 해당 HU의 시리얼 정보를 EWMS 내역 기준으로 갱신한다. 시리얼 마스터·이력 로그에 반영한다
3. (WCS) 반영 방식은 3-2를 따른다

## 3. 조건·규칙

### 3-1. 이력 로그 적재
- 시리얼번호 단위 변경 작업(설비 실적, 출고 검수 실적)이 생기면 설비 구분 없이 모든 실적을 실시간으로 이력 로그에 적용한다. 특정 설비로 한정하지 않는다
- 같은 TASK번호·제조번호·이벤트의 실적이 다시 들어오면 로그를 중복으로 쌓지 않는다

### 3-2. HU 시리얼정보 통보 반영 방식

| 경우 | 처리 |
|---|---|
| 통보받은 HU가 WCS 재고(자동화 설비)에 있다 | HU 단위 전체 목록으로 시리얼 마스터를 맞춘다(시리얼당 수량 1). 시리얼 이력 로그에 변경 전·후를 변경 TASK번호와 함께 남긴다 |
| 시리얼 수가 WCS 재고 수량과 달라진다 | WCS 재고는 바꾸지 않는다. 재고대사 대상으로 등록해 파워유저에게 알린다(→ P39 재고대사) |
| WCS 재고에 없는 HU(수작업 영역 등) | 이력만 남기고 무시한다 |
| 같은 통보를 두 번 받는다 | 한 번만 반영한다 |

## 5. 예외
- 제조번호 누락·중복: 프로세스를 막지 않는다는 것은 「LOT·제조번호」 묶음에 있다. 처리는 아래 두 줄이다
- 제조번호가 중복으로 들어오면 기존 시리얼 마스터에 이력 로그를 더한다
- 제조번호가 누락되면 로그 없이 진행한다. 누락·중복 건은 조회할 수 있어야 한다
- Product Code 불일치: 시리얼 이력 로그에 기록한다(2-1)

## 6. 기능·화면
- 시리얼 이력 로그로 제조번호별 입고 → 설비 실적 → 출고 검수 이력을 추적(조회)할 수 있다
- 시리얼 이력 조회 화면
  1. 조회 조건: 제조번호, 제품, 기간, TASK번호, 피킹 W/T, 입고번호 중 하나 이상
  2. 타임라인: 제조번호별 이력 유형, 시각, 위치, 설비, 작업(TASK·W/T)
  3. 누락 목록
  4. 중복 목록
  5. 엑셀 다운로드
- ⚠ 원문 불일치: 「누락」의 뜻이 기록마다 다르다. 제조번호 수신 쪽 기록의 누락은 제조번호가 수신되지 않은 것이다. 시리얼 이력 조회 화면 쪽 기록의 누락 목록은 입고됐으나 출고 검수 이력이 없는 제조번호다

## 7. 미결
- [추가 협의] Q-174: HU 시리얼정보 통보에 신규·변경·삭제 등의 구분을 붙일지
- Q-174에서 이미 정한 것: EWMS 내역을 HU 단위 전체 목록으로 통보한다, 시리얼당 수량은 1이다, 반영 방식은 HU 시리얼정보 통보 반영 요구(3-2)를 채택한다
