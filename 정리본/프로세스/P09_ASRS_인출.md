# [프로세스] AS/RS 인출

> 키워드: EQP-ASRS · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「AS/RS」, 「W/T」, 「EWMS BIN 코드」
> **이름만 쓰는 묶음**: 「시스템」, 「작업지시 체계」, 「팔레트」, 「TRASH BIN」, 「출고 업무 용어」, 「재고 이력·관리단위」, 「에러·사유코드」, 「입고 업무 용어」, 「재고 수량」
> **이어지는 프로세스**: 앞 → AS/RS에서 팔레트를 꺼내는 모든 프로세스(P24 FULL 팔레트 출고, P29 수작업 GTP 출고, P30 직송 이적, P28 3층 출고 구성, P22 GANTRY 사전·긴급 보충, P27 3층 사전·긴급 보충, P14 공팔레트 공급, P15 TRASH BIN 공급) / 뒤 → P11 3층 출고대 도착 팔레트 처리, P13 설비 출고 불가 재할당(출고 불가 시) / 관련 → P08 AS/RS 적치·P12 AS/RS 용량 부족 배출(토출건 DEST BIN 변경), P29 수작업 GTP 출고·P30 직송 이적(재고 차감·W/T 확정 예외)

## 1. 범위
AS/RS에서 팔레트를 꺼내는 모든 작업이 함께 쓰는 공통 단계다. WCS가 피킹셀과 배출 목적지를 지시할 때 시작해, 배출 완료를 받아 재고 차감과 W/T 반영을 마칠 때 끝난다.
무엇을 왜 꺼내는지는 부르는 쪽 프로세스가 정한다. 출고 작업을 할 수 없을 때는 → P13 설비 출고 불가 재할당.

## 2. 흐름
1. (WCS→ECS) 피킹셀을 지정해 피킹 작업지시를 보낸다(팔레트 ID, 피킹 위치).
   - [확인필요] WCS가 출고 시 피킹셀을 지정해 팔레트 ID와 피킹 위치를 ECS에 전달하는 요구사항은 확인필요다.
2. [확인필요] (WCS→ECS) 층별(1·3·4층) 입고대·배출구를 구분해 배출 목적지를 지시한다.
   - 3층 배출이면 배출라인을 지정한다(3절).
3. (ECS) 팔레트를 인출해 배출 위치로 이송한다.
4. (ECS→WCS) 피킹 완료 결과를 통보한다.
   - [확인필요] ECS가 피킹 완료 결과를 WCS에 통보하는 요구사항은 확인필요다.
5. (WCS) 3층·4층으로 배출되면(배출 완료 수신) 배출 이력으로 해당 팔레트를 WCS 재고에서 차감한다.
6. (WCS→EWMS) 그 팔레트에 W/T가 있었으면 배출 완료 시 W/T를 확정해 EWMS에 반영한다.
7. (WCS→EWMS) W/T 없이 나간 배출은 3절의 「W/T 없는 배출」 규칙으로 맞춘다.
8. 3층 출고대에 도착한 뒤는 → P11 3층 출고대 도착 팔레트 처리.

## 3. 조건·규칙

### 3층 배출라인 지정
WCS는 3층 배출을 지시할 때 배출라인을 지정한다. 작업 유형별 배출라인은 Workflow로 설정한다.

| 작업 | 3층 배출라인 |
|---|---|
| 디팔레타이징(3층 출고 구성 2순위 할당분) | 3층 디팔레타이징 배출라인 |
| GTP 출고 | 3층 출고대 |
| 직송 이적 | 3층 출고대 |
| 설비 공급(TRASH BIN, 3층 MIXED 팔레타이징용 공팔레트) | 3층 출고대 |
| 그 밖에 팔레트 그대로 나가는 건 | 3층 출고대 |

- 3층 출고대로 배출을 지시할 때는 「3층 출고대」까지만 지정하고, 2개 중 어느 출고대인지는 지정하지 않는다.

### 재고 차감
- 3층·4층으로 배출되면 WCS 재고에서 차감한다(배출 이력).
- 3층 디팔레타이징 배출라인으로 나가는 팔레트는 이 차감에서 뺀다.
- ⚠ 원문 불일치: AS/RS 쪽 규칙은 GTP 출고분·직송 이적분도 예외 없이 3·4층 전달 완료 시 출고확정으로 차감한다고 적는다.
- ⚠ 원문 불일치: AS/RS 쪽 요구는 GTP 출고분·직송 이적분은 예외로 W/T 확정까지 WCS 재고를 유지한다고 적는다.
  - 두 갈래의 처리는 → P29 수작업 GTP 출고, → P30 직송 이적이 갖는다. 아래 「W/T 확정」에서 GTP·직송 이적을 빼는 것과도 함께 확인한다.

### W/T 확정
- 3층(4층)으로 배출할 때 W/T가 있었던 건은 배출 완료 시 W/T 확정으로 EWMS에 반영한다.
- 이 확정에서 GTP·직송 이적은 뺀다.
- 토출건(Reject·용량 부족 배출)은 DEST BIN을 실제 도착 위치(3층 출고대 9013·RCV3 / 4층 입고장 9014·RCV4)로 바꿔 확정한다(→ P08 AS/RS 적치, P12 AS/RS 용량 부족 배출).

### W/T 없는 배출
- W/T 없는 배출(WCS 자체 판단)은 자동화구역(0050)에서 입고장으로 BIN이 바뀐다. 그래서 이동 W/T 생성·확정을 함께 처리해 맞춘다. GTP 잔량과 같은 방식이다.
- 단, WCS 판단 Reject는 여기서 빼고 W/T 확정·DEST BIN 9013·RCV3로 처리한다.

### 4층 배출
- 4층 배출도 3층 배출과 같은 규칙을 적용한다.
- W/T 없는 4층 배출은 4층 입고장 Stock Type·BIN으로 같은 규칙을 쓴다.

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→ECS | 출고 지시 시 | 팔레트 ID, 피킹셀, 배출구 |
| ECS→WCS | 피킹 완료 시 | 팔레트 ID, 완료 결과 |
| WCS→EWMS | 3·4층 배출 완료 시(W/T가 있었던 건, GTP·직송 이적 제외) | W/T 확정 — W/T 번호, 팔레트 ID, DEST BIN(토출건은 실제 도착 위치로 바꿈) |

## 5. 예외
- 설비가 지시받은 재고를 출고할 수 없으면 → P13 설비 출고 불가 재할당.
