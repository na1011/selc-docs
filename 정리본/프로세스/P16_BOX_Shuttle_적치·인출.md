# [프로세스] BOX Shuttle 적치·인출

> 키워드: EQP-BSH · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「BOX Shuttle」, 「W/T」, 「3층 디팔레타이징·MIXED」
> **이름만 쓰는 묶음**: 「설비 공통·설비사」, 「시스템」, 「에러·사유코드」, 「재고 운영 용어」, 「WCS 위치」, 「단말」, 「창고 기초속성」, 「AS/RS」, 「재고 이력·관리단위」, 「LOT·제조번호」, 「제품」, 「출고 업무 용어」, 「출고 오더」, 「EWMS BIN 코드」
> **이어지는 프로세스**: 앞 → P03 디베닝입고(경로 A), P28 3층 출고 구성(경로 B 잔량), P27 3층 사전·긴급 보충 / 뒤 → P28 3층 출고 구성(BOX 출고), P13 설비 출고 불가 재할당, P39 재고대사, P44 설비 에러·Reject 처리

## 1. 범위
WCS가 BOX Shuttle에 BOX 투입(적치)을 지시해 적치 완료를 받는 일과, BOX 출고(인출)를 지시해 3층 MIXED 팔레타이징로봇까지 보내는 일이다. BOX Shuttle 용량 관리(적치율 알림·공간 확보)도 다룬다(6절).
어떤 BOX가 어느 경로로 들어오는지는 → P03 디베닝입고, P27 3층 사전·긴급 보충, P28 3층 출고 구성.

## 2. 흐름

### 2-1. 적치
1. [확인필요] (WCS→ECS) 경로 A/B 각각에 대해 BOX Shuttle 입고 지시를 내린다.
2. (WCS→ECS) 투입 시 BOX 식별자와 수량을 보낸다. 적치 위치는 지정하지 않는다.
3. (ECS) BOX Shuttle이 적치셀을 자동 할당해 적치한다.
4. (ECS→WCS) 적치 완료를 통보한다(BOX 식별자, 자동 할당 적치셀). WCS는 이 적치셀을 받아 관리한다.
5. (WCS) 3층 해체 실적 때 원팔레트에서 3층 디팔레타이징 스테이징 셀로 전환한 재고를, BOX Shuttle 적치 실적 때 스테이징 셀에서 BOX Shuttle 셀로 옮긴다.
6. ⚠ 원문 불일치: (WCS→EWMS) BOX Shuttle의 적치 완료 통보를 EWMS에 전달해 적치 W/T를 확정한다.
   - 3층 사전 보충 BOX는 자동화구역 안 이동이라 W/T가 없다는 기록과, 모든 적치에 W/T 확정이 따른다는 기록이 함께 있다. 경로 B의 W/T 필요 여부는 [추가 협의] Q-016이다. 어느 적치에 W/T가 따르는지는 → P03 디베닝입고, P27 3층 사전·긴급 보충, P28 3층 출고 구성에서 함께 확인한다.

### 2-2. 인출(출고)
1. (WCS→ECS) BOX 단위 출고 작업지시를 보낸다(BOX 식별자, 목적지 = 3층 MIXED 팔레타이징로봇).
2. (ECS) BOX를 인출해 WCS에 통보한다(BOX 식별자, 결과).
3. (ECS) 출고 구성 위치(3층 MIXED 팔레타이징로봇)로 이송한다. 이 인계가 현대무벡스 내부 인계라는 것은 「설비 공통·설비사」 묶음 3.4에 있다(⚠ 원문 불일치 포함).
4. (ECS→WCS) 출고완료 결과를 통보한다.

## 3. 조건·규칙

| 조건 | 처리 |
|---|---|
| 적치 위치 | 누가 정하는지는 「BOX Shuttle」 묶음 3.3에 있다. WCS는 적치 완료 통보로 받은 적치셀을 관리한다 |
| BOX Shuttle 적치 실적 | 3층 디팔레타이징 스테이징 셀에서 BOX Shuttle 셀로 재고를 옮긴다 |

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→ECS | 투입 시 | BOX 식별자(제조번호 또는 제품코드), 수량(적치 위치 미지정) |
| ECS→WCS | 적치 완료 시 | BOX 식별자, 자동 할당 적치셀 |
| WCS→EWMS | 적치 완료 통보 후 | 적치 W/T 확정(2-1의 6 ⚠) |
| WCS→ECS | 출고 지시 시 | BOX 식별자, 목적지(3층 MIXED 팔레타이징로봇) |
| ECS→WCS | 인출/출고 완료 시 | BOX 식별자, 결과 |

## 5. 예외
BOX Shuttle 예외의 기본 연결(예시)은 다음과 같다.

| 예외 | 처리 |
|---|---|
| 투입 거부 | 통합 Reject 등록. 재고는 이동 직전 위치를 유지한다. 작업자 확인 후 재투입·보류한다(경로 A는 BOX 단위 W/T를 만들지 않음) |
| 적치 실패 | 설비 내부 재시도 후 실패를 보고하면 「적치 실패」 표시·알람. 재고는 투입구 위치다. 이후 적치 완료 통보를 받으면 정상 처리한다 |
| 인출 실패(셀에 BOX 없음) | 재고 처리 오류 표시·재고대사 등록 후 다른 셀로 재할당한다(→ P13 설비 출고 불가 재할당). 없으면 긴급 보충, 마감 내 불가하면 알람·파워유저 판단 |
| 인출 BOX 불일치 | 인출 실패와 같이 처리하고, 나온 BOX는 통합 Reject에 등록한다 |

- [미결 Q-211] 위 연결은 예시이며, 실제 연결은 설비사 에러코드 정리 때 확정한다.

## 6. 용량 관리 (적치율 알림·공간 확보)

### 6-1. 용량 부족
- 용량이 부족할 때 설비가 어떻게 되는지(3층 설비 자체 멈춤, WCS 멈춤 처리 없음)는 「BOX Shuttle」 묶음 3.6에 있다.
- 설비가 용량 부족으로 멈춘 상태는 설비 운영 상태 수신으로 반영해 대시보드에 표시한다.

### 6-2. 적치율 알림
- BOX Shuttle 적치율이 80% 임계치에 도달하면 알림을 준다.
- 임계치 기준값은 「창고 기초속성」 묶음의 변수 목록에 있다.
- 알림은 대시보드와 파워유저에게 보내고, 임계치 도달·해소 시점을 이력으로 남긴다.

### 6-3. 공간 확보
- 공간 확보는 기본은 운영 관리로 한다.
- [미결 Q-131] BOX Shuttle 재고를 3층 팔레타이징 작업지시로 팔레트화한 뒤 AS/RS로 옮겨 공간을 확보하는 방안은 협의가 필요하다. 설비 경로가 확인되면 추가한다.

## 7. 미결
- [추가 협의] Q-131: 팔레트화 공간 확보의 설비 경로, 대상 BOX 기준(입고월 오래됨·출고예정 없음)·사용자 지시 시점. 정해진 것: 기본은 사전 보충 상한·BOX Shuttle 우선 소진 운영 관리다.
- [미결 Q-211] BOX Shuttle 예외 연결의 확정(5절).
