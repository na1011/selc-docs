# [프로세스] 출고 배치 편성

> 키워드: OUB-BAT · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「출고 배치」, 「출고 오더」, 「거래처·인도처」
> **이름만 쓰는 묶음**: 「작업지시 체계」, 「단말」, 「시스템」, 「출고 업무 용어」, 「W/T」, 「WCS 위치」, 「조직·재고관리체계」
> **이어지는 프로세스**: 앞 → P01 EWMS 작업정보 수신 / 뒤(확정된 배치의 할당·작업지시) → P23 GANTRY 출고, → P28 3층 출고 구성, → P29 수작업 GTP 출고, → P32 재고 할당, → P42 작업지시 생성·실행 / 마감시간을 쓰는 곳 → P22 GANTRY 사전·긴급 보충, → P23 GANTRY 출고
> 출고 스케줄 수립(마감시간·시간대 Type으로 우선순위 정하기)이 이 문서에 합쳐졌다(§3-3).

## 1. 범위
- WCS는 출고배치관리 화면에서 출고 오더를 출고 배치로 묶는다 〔K30-OV01〕
- 피킹 W/T를 받으면 시작하고, 사용자가 배치를 확정해 그 차수의 피킹 W/T에 할당·작업지시가 생기면 끝난다.

## 2. 흐름
1. (EWMS→WCS) 출고 오더(피킹 W/T)를 받는다 — 인도처(거래처), 출고 오더 유형(STO·직송), 출고예정일, 시간대별 출고 Type. 출고예정이 배치 대상이 아니라는 것은 「출고 배치」 묶음, 출고예정의 용도는 「출고 오더」 묶음에 있다 〔K30-F00.01, REQ-OUB-BAT-016〕
2. (WCS 사용자) 배치 차수를 만들고 차수 속성을 정한다. 차수 속성의 항목은 「출고 배치」 묶음에 있다 〔K30-F00.02, REQ-OUB-BAT-010〕
3. (WCS) 출고예정일이 당일인 미배치 오더(전일 잔여건 포함) 중 차수 속성에 맞는 오더를 해당 차수에 묶는다 〔K30-F00.03, G222, G223, REQ-OUB-BAT-010〕
4. (WCS 사용자) 출고배치관리 화면에서 배치에 오더를 추가하고, 오더를 수작업으로 포함·제외한다. 현재 차수의 포함 오더를 조회해 골라 제거하고, 당일자 오더를 팝업으로 조회해 골라 포함한다(드래그앤드롭 등). 화면은 §6 〔K30-F00.04〕
5. (WCS 사용자) 배치를 확정한다 → (WCS) 확정된 차수의 피킹 W/T를 할당하고 작업지시(Work·Task)를 만든다 〔K30-F00.05〕
   - 배치 확정이 할당·작업지시의 관문이라는 것은 「출고 배치」 묶음에 있다 〔K30-F00.05, K30-EX04〕

## 3. 조건·규칙

### 3-1. 차수 속성과 묶는 기준
- 배치를 자동으로 만들지 않고 차수마다 정한 속성 기준으로 오더를 묶는다는 것(출고 배치의 뜻)은 「출고 배치」 묶음에 있다 〔BR-OUB-BAT-006, REQ-OUB-BAT-010〕
- 거래처의 거리유형(값은 「거래처·인도처」 묶음)에 따라 배치에 포함할지 정한다 〔BR-OUB-BAT-002, BR-MST-CUS-009, REQ-OUB-BAT-002〕
- 거리유형별로 배치에 포함할 오더타입(A~D)을 정한다 〔BR-OUB-BAT-003, BR-MST-CUS-009, REQ-OUB-BAT-003〕
- 거리유형 조건은 TC 오더에만 적용한다. 직송 오더는 오더유형(직송)과 오더타입(A~D)으로만 묶는다 〔BR-OUB-BAT-009, REQ-OUB-BAT-015, K30-EX01〕
  - 이유: 직송 거래처는 관리하지 않으므로 직송 오더에는 거리유형이 없다. 직송에도 거리유형 조건을 적용하면 직송 오더가 어떤 차수에도 들어가지 못한다 〔BR-OUB-BAT-009, REQ-OUB-BAT-015〕

### 3-2. 차수 대상 오더
- 차수는 출고예정일이 당일인 출고 오더만 묶는다 〔BR-OUB-BAT-007, K30-OV03, REQ-OUB-BAT-012〕
- 전일 잔여건은 없도록 운영한다. 있으면 당일 오더에 포함한다 〔BR-OUB-BAT-007, K30-OV03, REQ-OUB-BAT-012〕
- 당일 오더인지는 EWMS가 W/T에 내려준 출고예정일로 판단한다 〔BR-OUB-BAT-012, REQ-OUB-BAT-016〕

### 3-3. 출고 스케줄 — 마감시간과 시간대별 출고 Type
- [협의필요] 출고 유형별 마감시간을 출고 스케줄의 기준으로 쓴다. 출고 스케줄은 사전 보충 시간 배치, 출고 작업 우선순위, 긴급 보충 우선순위, 마감 내 해소 불가 판정이다. 구체 마감시간이 정해지지 않으면 스케줄을 작성할 수 없으므로 협의로 확정한다(Q-123) 〔REQ-MST-ORD-009〕
- [확인필요] WCS는 시간대별 출고 Type(A~D)을 출고 작업 우선순위에 반영한다 〔REQ-MST-ORD-005〕
- [확인필요] EWMS가 W/T에 마감 시각을 내려주면 그 값을 우선하고, 없으면 마스터 값을 쓴다 〔REQ-MST-ORD-010〕

### 3-4. 편성 중·확정 뒤 변경
- 차수 속성은 해당 차수의 전략 이력으로 남긴다 〔REQ-OUB-BAT-011〕
- 편성 중 속성을 바꾸면 다시 묶되, 수작업으로 포함·제외한 오더는 유지한다 〔REQ-OUB-BAT-011〕
- [확인필요] 차수 속성에 맞지 않는 오더를 수작업으로 포함하거나 속성 대상 오더를 제외하면, 사용자·시각·사유를 해당 차수의 전략 이력에 남긴다 〔REQ-OUB-BAT-008〕
- [확인필요] 확정 이후에는 작업지시가 시작되지 않은 오더만 추가·제외할 수 있다. 진행 중인 오더를 빼려면 작업 취소 절차를 거친다 〔REQ-OUB-BAT-007〕

## 4. 주고받는 정보
| 송신→수신 | 시점 | 업무 항목 | 출처 |
|---|---|---|---|
| EWMS→WCS | 피킹 W/T 생성 시 | W/T 번호, 제품, 수량, 인도처, 출고 오더 유형(STO·직송), 출고예정일(EWMS 제공), FO, 출고 DOCK, 시간대 Type, 작업지시 단위(직송 = FO / STO = ORG DO) | 〔K30-IF01〕 |

## 5. 예외
- 거리유형이 「미지정」인 TC센터 거래처의 오더는 어떤 차수 속성에도 맞지 않아 묶이지 않는다. 미배치 목록에 남고, 사용자가 수작업으로 포함한다 〔K30-EX02〕
- 미등록 거래처의 피킹 W/T는 작업지시를 만들지 않으므로 배치 대상에서도 제외한다 〔K30-EX03〕
- [확인필요] 시간대 Type 마감에서 역산한 리드타임 안에 배치되지 않았거나 배치가 확정되지 않은 피킹 W/T가 있으면 대시보드·파워유저에게 알람한다 〔K30-EX04, REQ-OUB-BAT-017〕

## 6. 기능·화면
- 출고배치관리 화면에서 출고 오더를 배치(차수)별로 묶고, 생성된 배치에 오더를 추가할 수 있다 〔BR-OUB-BAT-001, REQ-OUB-BAT-001〕
- 사용자가 오더를 배치에 수작업으로 포함하거나 제외할 수 있다 〔BR-OUB-BAT-004, REQ-OUB-BAT-004, G222, K30-OV04〕
- 제외: 현재 배치 차수에 포함된 오더를 조회하고, 고른 오더를 차수에서 제거한다. 제거한 오더는 미배치 상태로 돌아간다 〔BR-OUB-BAT-004, REQ-OUB-BAT-013〕
- 포함: 현재 배치 차수에서 당일자(출고예정일 당일) 오더(전일 잔여건 포함)를 팝업으로 조회하고, 고른 오더를 차수에 포함한다. 팝업에는 다른 차수에 속하지 않은 오더만 보인다 〔BR-OUB-BAT-004, REQ-OUB-BAT-014〕
- 배치 편성 화면은 드래그앤드롭 등 사용자 편의 기능을 제공한다 〔BR-OUB-BAT-005, REQ-OUB-BAT-005, K30-OV04〕
- 자주 쓰는 차수 속성은 이름을 붙여 저장하고 다음 차수에서 불러온다 〔REQ-OUB-BAT-011〕
- [확인필요] 화면 편의 기능: 미배치 오더 목록과 배치 목록을 나란히 두고 드래그앤드롭으로 옮기기, 다중 선택, 거래처·오더유형(TC/직송)·거리유형·오더타입·마감 시각 필터, 배치별 오더 수·물량(BOX·팔레트) 합계 즉시 표시, 확정 전 변경 되돌리기 〔REQ-OUB-BAT-009〕
- [확인필요] 미배치 W/T 마감 관리: 미배치 W/T 목록을 마감 시각순으로 보여 수작업 포함을 돕는다. 배치 확정이 관문이므로, 거리유형 「미지정」 오더처럼 자동으로 묶이지 않는 W/T는 사람이 넣지 않으면 작업지시가 생기지 않는다. 이를 마감 전에 알리려는 것이다 〔REQ-OUB-BAT-017〕

## 7. 미결
- [미결 Q-150] 출고 배치 정의 — (3) 하루 차수 수, 배치 구분 단위(창고·화주·출고 DOCK·설비 등) (4) 추천 항목(REQ-OUB-BAT-007~009·017) 채택 여부, 할당(예약) 시점도 배치 확정으로 본 해석 〔Q-150〕
- [미결 Q-123] 출고 유형별 마감시간이 정해지지 않으면 출고 스케줄(사전 보충·우선순위·마감 판정)을 작성할 수 없다. 추가 협의 대상이다 〔K16-EX01〕

## 8. 변경 이력
- 배치 패턴을 자동 취합하던 방식에서 차수 개념으로 바뀌었고, 차수 속성에 오더유형이 추가됐다 〔BR-OUB-BAT-006, REQ-OUB-BAT-010〕
- 차수 대상에 전일 잔여건 포함이 추가됐다 〔REQ-OUB-BAT-012〕
