# [프로세스] 작업지시 생성·실행

> 키워드: SYS-JOB · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「작업지시 체계」, 「시스템」, 「조직·재고관리체계」, 「LOT·제조번호」, 「EWMS BIN 코드」, 「W/T」, 「설비 공통·설비사」
> **이름만 쓰는 묶음**: 「출고 오더」, 「할당 전략」, 「운반 설비」, 「단말」, 「재고 수량」, 「WCS 위치」, 「출고 업무 용어」, 「AS/RS」, 「창고 기초속성」, 「거래처·인도처」, 「입고 오더」, 「제품」
> **이어지는 프로세스**: 앞 → P01 EWMS 작업정보 수신, P47 기준정보 관리 · 뒤 → P32 재고 할당, P43 팔레트 작업 상태 추적, P44 설비 에러·Reject 처리, P45 네트워크 단절 대응 · 화면 → P46 단말 화면·알림 · 관련 → P36 LOT 채번·속성 변경(Work의 화주로 채번), P41 자동화 전환(경계 이동의 W/T 맵핑 Work)

## 1. 범위
EWMS 오더·W/T를 받아 Batch → Work → Task → Action을 만들고, 설비 실적을 받아 Workflow·Task를 끝낼 때까지다.
누가 무엇을 만드나(Planning이 Task, Execution이 Action)는 「시스템」 묶음에 있다. 이 문서는 그 순서를 2절에 적는다

## 2. 흐름
1. (EWMS→WCS) 오더·W/T를 받는다. PLANT로 화주를 식별하고, 화주별 제품·LOT로 처리한다
2. (WCS) 프로세스(입고·출고·이동 등)별로 Batch를 만든다
3. (WCS) Batch 아래 Work를 만든다
4. (WCS) Work 생성 시점에 맵핑을 WCS 기준으로 적용한다: PLANT → 화주, EWMS Storage Location → WCS Storage Location
   - Work 가공 규칙(화주 확정, LOT 속성 기준값, Work 통합)은 3-1에 있다.
5. (WCS Planning) EWMS 오더·W/T와 기준정보를 바탕으로 Work 아래 Task를 만든다
6. (WCS Planning→WCS Execution) Task를 전달한다 (잠정 §9-7)
7. (WCS Execution) Task를 받아 Workflow에 따라 설비 단위 작업지시인 Action을 만든다
8. (WCS Execution→통신표준화 솔루션→ECS) Action을 전달한다
   - [미결 Q-111] 통신표준화 솔루션과의 접점(주고받는 항목·전달 방식)은 설계 중이다
9. (ECS→통신표준화 솔루션→WCS Execution) 설비 실적(Action 실적)을 받아 Workflow·Task 진행·완료에 반영한다
10. (WCS Execution) 설정된 Workflow의 단계 순서대로 다음 작업을 이어서 만들고 지시한다
11. (WCS Execution→WCS Planning) Workflow·Task 진행·완료를 보고한다 (잠정 §9-7)

## 3. 조건·규칙

### 3-1. Work 가공 (화주·LOT 속성·통합)
- PLANT–화주 맵핑은 Work 생성 시점에 적용한다
- 맵핑은 WCS 기준으로 적용해 Work에 화주를 확정한다
- 이후 프로세스(LOT 채번, 출고 할당 시 화주 체크, 출고)는 Work에 적용된 화주로 진행한다
- LOT 속성 기준값: LOT 생성 전략에서 출고 체크를 켠 속성마다 기준값을 만든다

| 순서 | 기준값 |
|---|---|
| 1 | 원본에 해당 항목이 있으면 그 값(예: Valuation Type) |
| 2 | 없으면 창고 기초속성의 기본값 |
| 3 | 기본값도 없으면 「조건 없음」 — 그 속성은 비교하지 않는다 |

- Work 통합: 가공 속성이 같은 원본 행은 한 Work로 합친다(여러 원본 행 → 한 Work)
- 한 Work로 합치는 것은 창고, 화주(맵핑 후), 제품, LOT 속성 기준값, 프로세스 유형, 출고 유형, 작업지시 단위(직송 FO / STO ORG DO), 인도처, 시간대 Type이 모두 같은 원본 행이다
- 수신 PLANT는 합치는 기준에서 뺀다. 화주 맵핑으로 통합된 PLANT끼리 합칠 수 있게 하기 위해서다

### 3-2. W/T와 Work의 연결
| 경우 | 처리 |
|---|---|
| BIN을 넘는 이동 — 층간 이동, 수작업 영역에서 시작하는 이동(1층 → 3·4층 수작업 이동, 출고확정 후 운반 등) | EWMS가 생성해 보낸 W/T를 받아 W/T 맵핑 Work로 만든다. WCS는 W/T 생성을 요청하지 않는다 |
| WCS 처리 결과로 BIN이 바뀌는 경우(GTP 잔량, W/T 없는 AS/RS 배출) | 이동 W/T 생성·확정을 함께 처리하고, 그 Work를 W/T 맵핑으로 연결한다 |
| 위 두 종류 공통 | 화주 맵핑·LOT 속성 기준값·할당 전략 적용은 같게 한다 |
| 출고예정으로 만든 사전 보충 Work | W/T 무관 Work다. 이후 받은 피킹 W/T는 별도의 W/T 맵핑 Work로 만든다. 사전 보충 BOX는 출고예정에 예약하지 않는다 |

### 3-3. Workflow(경로) 결정
- W/T 경로는 W/T DEST(Stock Type·BIN)로 정한다
- ⚠ 원문 불일치: WCS 경로는 제품마스터 속성이 아니라, 디베닝 입고정보(디베닝 하역 대상)와 주고받는 W/T의 DEST Stock Type·BIN으로 정한다. DEST 값별 행선은 「EWMS BIN 코드」 묶음에 있다 (상대: 제품마스터 개요 「제품마스터 속성은 입고 경로·보관설비·출고설비를 결정한다」 — 「제품」 묶음 3절의 ⚠)
- ⚠ 원문 불일치: 입고 경로는 제품마스터 속성으로 정하지 않는다 (상대: 제품마스터 개요, 위와 같음)
- 수신한 디베닝 입고정보와 W/T의 DEST Stock Type·BIN을 BIN 마스터의 구역과 대조해 Workflow(경로)를 정한다. 구역별 DEST 값(3층 수작업·4층 수작업·AS/RS 보관·디베닝)은 「EWMS BIN 코드」 묶음의 「W/T DEST가 가리키는 WCS 행선」 표에 있다

### 3-4. 작업지시 없이 진행하는 단계
- 유인지게차·수작업 단계는 WCS 작업지시 없이 PDA 완료 스캔으로 위치를 이동 이력에 반영한다

### 3-5. 설비 운영 상태와 작업 배정
- [확인필요] WCS는 수신한 설비 운영 상태를 작업 배정에 반영한다
- ⚠ 원문 불일치: [확인필요] 설비 운영 상태가 가동이 아니면 작업 배정 대상에서 제외한다
- ⚠ 원문 불일치: [확인필요] 설비 운영 상태에 따라 배정에서 제외하거나 우회한다

## 4. 주고받는 정보
| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS Planning→WCS Execution | Task 생성 시 | Task ID, 예약 재고(관리단위)·LOT·수량, 목적 셀. WCS 구성 쪽 기록은 「Task 정보(항목 미정)」로 적었다 (잠정 §9-7) |
| WCS Execution→WCS Planning | Workflow·Task 진행·완료 시 | Task 번호, 진행 상태, 실적 (항목 미정) (잠정 §9-7) |
| WCS Execution→WCS Planning | Action 실적 수신 시 | Task ID, Action ID, 실적 수량, 부족·불가 사유 (잠정 §9-7) |
| WCS Execution→통신표준화 솔루션→ECS | Action 생성 시 | [미결 Q-111] Action ID, Task 번호, 설비 ID, 작업 구분, 대상(팔레트/BOX), 출발·도착 위치 (항목 추후 구체화, 접점 설계 중) |
| ECS→통신표준화 솔루션→WCS Execution | Action 실적 발생 시 | [미결 Q-111] Action ID, Task 번호, 결과(실적), 시각 (항목 추후 구체화, 접점 설계 중) |

## 5. 예외
- 원본(오더·W/T)이 변경·취소되면 원본은 새 이력으로 쌓고, 해당 원본 행 단위로 반영한다
  - 진행 전 Work: 해당 행 수량을 빼거나 다시 가공한다
  - 진행 중 Work: 변경 대상으로 표시한다
- [미결 Q-081] Action 실패·재지시 처리는 정해지지 않았다(7절)
- 설비 에러가 들어온 뒤의 처리(Task 보류·재지시·취소 포함)는 → P44 설비 에러·Reject 처리

## 6. 기능·화면
- Task 화면에서 해당 Task의 예약 재고를 볼 수 있게 한다
- Task 진행 이력(Task → Workflow → Action) 조회는 → P43 팔레트 작업 상태 추적, P46 단말 화면·알림

## 7. 미결
- [미결 Q-081] [추후 정리] Action 실패·재지시 처리
