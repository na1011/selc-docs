# [프로세스] 설비 출고 불가 재할당

> 키워드: EQP-ASRS · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「출고 업무 용어」, 「할당 전략」, 「WCS 위치」
> **이름만 쓰는 묶음**: 「설비 공통·설비사」, 「AS/RS」, 「BOX Shuttle」, 「GANTRY」, 「작업지시 체계」, 「재고 운영 용어」, 「W/T」, 「단말」, 「LOT·제조번호」, 「조직·재고관리체계」, 「재고 수량」, 「에러·사유코드」, 「팔레트」
> **이어지는 프로세스**: 앞 → P09 AS/RS 인출, P23 GANTRY 출고, P28 3층 출고 구성, P08 AS/RS 적치(셀 이상), P16 BOX Shuttle 적치·인출(인출 실패), P30 직송 이적, P34 재고 반영·보정(보정 감소), P44 설비 에러·Reject 처리 / 뒤 → P09 AS/RS 인출(새 피킹 작업지시), P39 재고대사 / 함께 → P32 재고 할당(전략 조회·필터·예약 등 모든 할당에 공통인 단계)

## 1. 범위
현대무벡스 설비가 지시받은 재고를 출고할 수 없다고 알려 올 때 시작해, WCS가 대체 재고를 골라 다시 할당하고 새 피킹 작업지시를 낼 때(또는 출고 불가 알람을 낼 때) 끝난다.
적용 범위는 현대무벡스 설비 전체(AS/RS·BOX Shuttle·GANTRY)다. GANTRY 설비 출고 불가와 BOX Shuttle 출고 불가도 같은 처리를 쓴다.

## 2. 흐름
1. (현대무벡스 ECS→WCS) 출고 작업을 수행할 수 없으면 대상 작업과 불가 사유를 전달한다.
2. (WCS) 원 할당을 해제한다.
3. (WCS) 원 재고·셀은 사유에 따라 셀 상태를 할당불가로 바꾸거나 보류해 다시 할당되지 않게 한다.
4. (WCS) 같은 출고 조건(화주·제품·LOT 조건·수량)을 만족하는 대체 재고를 선정한다. 원 재고는 뺀다.
5. (WCS) 재할당하고 새 피킹 작업지시를 내린다(→ P09 AS/RS 인출).
6. (WCS) 재할당 이력(원 재고, 대체 재고, 사유, 시각)을 남긴다.

## 3. 조건·규칙

| 조건 | 처리 |
|---|---|
| 재할당의 초기 전략 값 | 원 할당과 같은 조건(화주·제품·LOT 조건·수량)에서 원 재고를 뺀다 |
| 불가 사유가 재고 불일치 | 재고대사 대상으로 등록한다(→ P39 재고대사) |
| 대체 재고가 없거나 일부만 있음 | 가능한 수량만 재할당하고, 부족분은 출고 불가로 모니터링·알람한다 |
| 같은 작업의 재할당 반복 | 횟수를 제한한다 |
| 반복 한도를 넘음 | 출고 불가 알람을 내고, 파워유저가 부분 출고 / 출고 대기 중 처리를 고른다(GANTRY 출고와 같은 선택지). 이 처리가 없으면 한도에 걸린 W/T가 멈춘다 |
| 적용 설비 | 현대무벡스 설비 전체(AS/RS·BOX Shuttle·GANTRY) |

## 5. 예외
- 대체 재고 부족과 반복 한도 초과는 3절 표를 따른다.

## 6. 기능·화면
