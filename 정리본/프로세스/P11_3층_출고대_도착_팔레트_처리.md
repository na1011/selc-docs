# [프로세스] 3층 출고대 도착 팔레트 처리

> 키워드: EQP-ASRS · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「AS/RS」, 「단말」, 「에러·사유코드」, 「WCS 위치」
> **이름만 쓰는 묶음**: 「설비 공통·설비사」, 「운반 설비」, 「작업지시 체계」, 「W/T」, 「LOT·제조번호」, 「출고 업무 용어」, 「TRASH BIN」, 「팔레트」, 「거래처·인도처」, 「3층 디팔레타이징·MIXED」
> **이어지는 프로세스**: 앞 → P09 AS/RS 인출, P08 AS/RS 적치(Reject 배출), P10 AS/RS Bypass 이송, P12 AS/RS 용량 부족 배출 / 뒤 → P08 AS/RS 적치(3층 입고대 재투입), P29 수작업 GTP 출고, P30 직송 이적, P14 공팔레트 공급, P15 TRASH BIN 공급, P33 재고 예약·보류(보류)

## 1. 범위
AS/RS에서 3층 출고대로 배출된 팔레트(모든 배출 유형)의 도착 보고를 받는 때부터, 작업자가 WCS PDA로 행선지를 확인하거나 처리를 판단해 유인지게차로 옮길 때까지다.
행선지가 이미 정해진 건(GTP 출고·직송 이적·설비 공급 등)은 행선지를 보여 주고, 정해지지 않은 건(용량 부족 배출·Reject 등)은 작업자의 처리 판단을 받는다.

## 2. 흐름
1. (현대무벡스 ECS→WCS) 3층 출고대 배출 완료를 보고한다. 모든 배출 유형에 대해 도착 출고대(2개 중 어느 것, 포트 코드)를 담아 보낸다. 〔BR-EQP-ASRS-051, K21-IF13, REQ-EQP-ASRS-047〕
2. (현대무벡스 ECS→WCS) 용량 부족 배출·Reject 팔레트이면 배출 사유를 함께 제공하고, 현대무벡스 상황판에도 표시한다. 〔BR-EQP-ASRS-007, K21-IF12, REQ-EQP-ASRS-011〕
3. (WCS) 받은 배출 사유를 팔레트별로 저장해 사유를 추적·조회할 수 있게 한다. 〔REQ-EQP-ASRS-011〕
4. (WCS) 팔레트 위치를 도착한 출고대 셀로 반영한다. 〔REQ-EQP-ASRS-037, REQ-EQP-ASRS-047, REQ-EQP-ASRS-042〕
5. (WCS) 도착 출고대를 PDA 조회·팔레트 작업 추적·상황판의 출고대별 대기 목록에 표시한다. 〔REQ-EQP-ASRS-047, REQ-EQP-ASRS-042〕
6. (작업자→WCS PDA) 유인지게차 작업자가 배출 팔레트 ID를 스캔한다. 〔BR-EQP-ASRS-016, REQ-EQP-ASRS-018〕
7. (WCS PDA→작업자) 행선지를 보여 준다. 행선지가 정해지지 않은 건은 「행선지 판단 필요」로 표시하고, 도착 작업 추적 정보와 함께 처리 판단 입력으로 넘긴다. 〔BR-EQP-ASRS-016, REQ-EQP-ASRS-018, REQ-EQP-ASRS-019〕
8. (작업자→WCS PDA) 행선지가 정해지지 않은 건은 처리 판단을 입력한다: 출고 수작업 영역 이동 / 용량 확보 후 AS/RS 재투입 / 보류. 〔REQ-EQP-ASRS-016〕
9. (WCS) 판단 결과에 따라 재고를 처리하고 목적지를 표시한다: 위치 이동 이력, 재투입 작업 생성(→ P08 AS/RS 적치), 보류 처리. 〔REQ-EQP-ASRS-016〕
10. (WCS) 판단자·사유·시각을 전략 이력으로 남긴다. 〔REQ-EQP-ASRS-016〕
11. (작업자) 사용자가 판단해 유인지게차로 팔레트를 옮긴다. WCS는 이동 작업지시를 내리지 않는다. 〔BR-EQP-ASRS-011, REQ-EQP-ASRS-014, REQ-EQP-ASRS-016, REQ-EQP-ASRS-019〕

## 3. 조건·규칙

| 조건 | 처리 | 출처 |
|---|---|---|
| 3층 출고대 도착 팔레트의 위치 | 도착한 출고대로 관리한다 | 〔REQ-EQP-ASRS-037〕 |
| 3층 배출라인에 나온 팔레트(용량 부족 배출·Reject·Bypass 등) | 어떤 작업으로 그 위치까지 왔는지 작업자가 추적할 수 있어야 한다 | 〔BR-EQP-ASRS-017, REQ-EQP-ASRS-020〕 |
| 행선지를 정하는 출처 | 배출을 만든 작업(Task)의 Workflow 목적지에서 가져온다 | 〔REQ-EQP-ASRS-019〕 |
| 행선지가 정해지지 않은 건(용량 부족 배출·Reject 등) | 「행선지 판단 필요」로 표시하고 처리 판단 입력으로 넘긴다 | 〔REQ-EQP-ASRS-019〕 |
| 출고대 → 다음 위치 이동 | 유인지게차로 옮기고 WCS 작업지시는 없다 | 〔BR-EQP-ASRS-011, REQ-EQP-ASRS-014, REQ-EQP-ASRS-019〕 |

## 5. 예외
- 스캔한 팔레트가 배출 작업에 없거나 이미 처리된 건이면 경고한다. 〔REQ-EQP-ASRS-019〕

## 6. 기능·화면
3층 배출라인에 도착한 팔레트의 판단과 재고 처리를 위한 WCS PDA 기능을 둔다. 3층 배출라인은 행선지가 여러 곳이라 복잡하기 때문이다. 〔BR-EQP-ASRS-013, REQ-EQP-ASRS-015, BR-EQP-ASRS-016〕

| 기능 | 내용 | 출처 |
|---|---|---|
| 팔레트 조회 | 팔레트 ID 스캔 → 배출 사유(Reject: 사유코드 — 용량 부족 포함, ECS 또는 WCS 사유코드 / Bypass), W/T 상태, 제품·LOT·수량 | 〔REQ-EQP-ASRS-016〕 |
| 행선지 표시 | 배출 목적(GTP 출고 / 직송 이적 / TRASH BIN 공급 / 공팔레트 공급 / Bypass 등), 행선지 로케이션(출고 수작업 영역 로케이션, TRASH BIN 요청 위치, 3층 MIXED 팔레타이징로봇 공팔레트 투입 위치 등), 인도처·출고 차량(해당 시), 제품·LOT·수량 | 〔REQ-EQP-ASRS-019〕 |
| 작업 추적 | 그 팔레트가 어떤 작업으로 그 위치까지 왔는지 — 작업 유형·작업 번호·발생 사유·이동 경로 이력 | 〔REQ-EQP-ASRS-020, BR-EQP-ASRS-017〕 |
| 처리 판단 입력 | 출고 수작업 영역 이동 / 용량 확보 후 AS/RS 재투입 / 보류 | 〔REQ-EQP-ASRS-016〕 |
| 재고 처리 | 판단 결과에 따라 위치 이동 이력, 재투입 작업 생성, 보류 처리, 목적지 표시 | 〔REQ-EQP-ASRS-016〕 |
| 이력 | 판단자·사유·시각을 전략 이력으로, 스캔자·시각을 작업 이력으로 남긴다 | 〔REQ-EQP-ASRS-016, REQ-EQP-ASRS-019〕 |
| 대기 목록 | 출고대 대기 팔레트 목록 조회. 상황판에 출고대별로 표시 | 〔REQ-EQP-ASRS-016, REQ-EQP-ASRS-047〕 |
