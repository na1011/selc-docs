# [프로세스] GANTRY 출고

> 키워드: OUB-GNT · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「GANTRY」, 「출고 오더」, 「출고 업무 용어」, 「W/T」, 「재고 수량」, 「거래처·인도처」, 「LOT·제조번호」, 「작업지시 체계」, 「제품」(OUT EQUIPMENT = GANTRY가 진입 조건), 「할당 전략」(후보 범위·정렬·초기 값 ①)
> **이름만 쓰는 묶음**: 「시스템」, 「AS/RS」, 「WCS 위치」, 「출고 배치」, 「조직·재고관리체계」, 「EWMS BIN 코드」, 「팔레트」, 「HU」, 「설비 공통·설비사」, 「단말」, 「에러·사유코드」, 「재고 이력·관리단위」, 「재고 운영 용어」, 「창고 기초속성」, 「3층 디팔레타이징·MIXED」
> **이어지는 프로세스**: 앞 → P20 출고 배치 편성, → P21 직송 GANTRY 호기 임시 할당, → P22 GANTRY 사전·긴급 보충 / 뒤 → P25 출고 DOCK 이송, → P31 출고완료 확정 / 갈래 → P24 FULL 팔레트 출고, → P29 수작업 GTP 출고, → P13 설비 출고 불가 재할당, → P26 W/T 취소 요청 / 함께 → P18 GANTRY 호기 운영(2-1 ④⑤의 보관호기 재고 순서·잔량 보관) / 관련 → P14 공팔레트 공급(출고 팔레트가 되는 공팔레트를 1층 MIXED 공급라인에 댐), → P05 HU 확인·생성(출고 팔레트 HU 생성·PACK 항목)
> **다른 문서에 한 번만 둔 규칙**: 피킹호기 보충원 순서, 보관호기 재고를 쓰는 순서, GANTRY 진입 잔량을 보관호기에 두는 규칙, 인도처 매핑 변경은 → P18 GANTRY 호기 운영에 있다. 긴급 보충을 만드는 방법(수량·우선순위)은 → P22 GANTRY 사전·긴급 보충에 있다. GANTRY 출고대 → 출고 DOCK 이송과 1층 MIXED 출고 팔레트의 팔레트갈이(3층 유도)는 → P25 출고 DOCK 이송에 있다.

## 1. 범위
- 대형제품 출고 중 FULL 팔레트로 출고할 수 없는 건을 GANTRY에서 BOX 단위로 출고 구성(MIXED 팔레타이징)한다 〔K31-OV01〕
- 확정된 배치의 피킹 W/T를 할당하면서 시작한다. 출고 구성을 마친 팔레트가 GANTRY 출고대로 배출되고 출고 구성 완료를 통보받으면 끝난다. GANTRY 출고대에서 출고 DOCK까지 옮기는 일은 → P25 출고 DOCK 이송이다.

## 2. 흐름

### 2-1. 피킹 W/T 수신부터 피킹호기 채우기까지
1. (EWMS→WCS) 피킹 W/T를 받는다 → (WCS 사용자) 배치를 편성·확정한다(→ P20) → (WCS) 확정된 배치의 W/T를 할당하고 출고 작업지시를 만든다 〔K31-F00.02〕
2. (WCS) [확인필요] 피킹 W/T 기준으로 FULL 팔레트 출고와 GANTRY 경유 출고 중 어느 쪽인지 판단한다. 판단 기준은 §3-1이다 〔REQ-OUB-GNT-001〕
3. (WCS) GANTRY 경유 출고분을 피킹호기에 할당한다. 어느 피킹호기인지는 §3-2, 무엇을 할당 후보로 쓰는지는 §3-3이다.
4. (WCS→ECS) 보관호기에 해당 제품 재고가 있으면 먼저 피킹호기로 이동시킨 뒤 출고 구성한다. 보관호기 재고를 고르는 순서는 → P18 〔K31-F00.03, BR-EQP-GNT-005, REQ-EQP-GNT-007, G022〕
5. (WCS→ECS) 부족분만 AS/RS 팔레트 배출을 지시한다 → 보충 컨베이어로 GANTRY 입구까지 이송 → 디팔레타이징(팔레트 → BOX) → 인도처 매핑 피킹호기로 이송. 피킹호기로 보내고 남은 잔량 BOX는 보관호기로 옮겨 보관한다(GANTRY 진입 시점에만. 보관호기 선택 → P18) 〔K31-F00.04, REQ-OUB-GNT-005, K31-OV02, K31-OV03〕
   - [확인필요] WCS는 디팔레타이징된 BOX를 인도처 매핑 기준으로 피킹호기에 할당한다 〔REQ-OUB-GNT-003〕

### 2-2. 적재 계획과 출고 구성
6. (WCS) 출고 구성 지시 전에 로딩 옵티마이저로 적재 계획을 세운다. 로딩 옵티마이저가 무엇인지, 두 수행 방식과 수행 주체를 고르는 법은 「출고 업무 용어」 묶음에 있다. 방식별 규칙은 §3-5 〔K31-F00.05, G195〕
   - SDS 방식: (SDS→WCS) 결과를 받는다 → (WCS→현대무벡스 ECS) 출고 구성 지시와 함께 결과를 전달한다 〔K31-F00.05, BR-EQP-GNT-009, REQ-OUB-GNT-020, G195, G197〕
   - 현대무벡스 방식: 설비사가 자체 처리한다. WCS는 결과를 전달하지 않고 출고 구성만 지시한다 〔K31-F00.05, BR-EQP-GNT-009, REQ-OUB-GNT-020, G195〕
7. (WCS→ECS) 출고 주문 단위로 출고 구성(MIXED 팔레타이징) 작업을 지시한다 → (ECS) 피킹호기에서 1층 MIXED 팔레타이징로봇이 출고 구성한다 〔REQ-OUB-GNT-004, K23-F05.03, K31-F01.00〕
8. (ECS) 출고 구성을 마친 팔레트를 GANTRY 출고대로 배출한다. MIXED 팔레타이징 후 피킹호기에 남은 BOX는 그대로 둔다(→ P18). GANTRY 출고대에서 출고 DOCK까지 옮기는 일은 → P25 출고 DOCK 이송이다 〔K31-F01.01, K23-F05.03〕
   - 1층 MIXED 출고 팔레트의 유형이 직송 배송 팔레트 유형과 다를 때 팔레트갈이를 위해 3층으로 보내는 경로도 → P25 §3에 있다 〔BR-OUB-GNT-024〕
9. (ECS→WCS) 출고 구성 완료를 통보한다 → (WCS) 완료 결과를 받아 출고 팔레트 위치를 GANTRY 출고대로 반영한다 → 출고완료 확정(→ P31) 〔K31-F01.02, REQ-OUB-GNT-004, REQ-EQP-GNT-032〕
10. (WCS) 출고 구성 인출 실적을 받으면 셀 출고 이력과 출고 팔레트 입고 이력을 쌓고 셀을 비운다 〔REQ-EQP-GNT-011〕
    - 출고 팔레트는 팔레트 ID이자 HU다. 두 이력은 같은 변경 TASK번호로 묶고, LOT·화주를 유지하며, W/T를 만들지 않는다 〔BR-OUB-GNT-015〕
11. (WCS→EWMS) 출고 팔레트의 HU 생성·PACK을 보낸다(항목은 §4) 〔K31-IF04〕

## 3. 조건·규칙

### 3-1. 출고 경로
- 진입 조건: 1층 GANTRY 출고 구성 대상은 제품마스터 OUT EQUIPMENT = GANTRY인 제품이다(값의 뜻은 「제품」 묶음) 〔BR-OUB-GNT-027〕

| 조건 | 처리 | 출처 |
|---|---|---|
| AS/RS에서 FULL 팔레트로 출고 가능 | GANTRY를 거치지 않고 팔레트 그대로 출고한다(→ P24) | 〔BR-OUB-GNT-001〕 |
| FULL 팔레트 출고 불가(잔여 수량) | GANTRY를 거쳐 출고 구성(MIXED 팔레타이징)한다 | 〔BR-OUB-GNT-002〕 |
| GANTRY 출고 불가(설비 제약 등) | ⚠ 원문 불일치: 수작업 GTP 출고로 보낸다(→ P29) | 〔BR-OUB-GNT-005〕 |

- ⚠ 원문 불일치: WCS는 자체 기준으로 GANTRY 출고 불가를 판단하지 않는다. GTP 여부는 피킹 W/T의 DEST BIN으로 정한다(→ P29 §3) 〔BR-OUB-MAN-026〕
- 차이: 위 표 셋째 줄은 「GANTRY 출고 불가」를 GTP로 가는 조건으로 적었고 누가 판단하는지 밝히지 않았다. 아래 줄은 WCS가 그런 판단을 하지 않고 W/T DEST BIN만 본다고 정한다.

### 3-2. 피킹호기 정하기
- 출고분은 해당 인도처에 매핑된 피킹호기로 할당한다 〔BR-EQP-GNT-002, K09-F00.04, K09-OV06〕
- 직송은 FO 기준으로 임시 할당한 호기로 할당한다(→ P21) 〔BR-EQP-GNT-002, K09-F00.04〕
- 인도처 매핑의 관리·변경은 → P18이다.

### 3-3. 할당 후보와 쓰는 순서
- WCS는 GANTRY 피킹 W/T를 할당할 때 피킹호기 재고만 후보로 쓴다 〔REQ-EQP-GNT-038, REQ-MST-ALC-004〕
- 부족분은 긴급 보충(보관호기 → 피킹호기 이동, 그래도 부족하면 AS/RS 팔레트)을 먼저 지시하고, 피킹호기에 도착한 BOX로 할당한다(긴급 보충 → P22) 〔REQ-EQP-GNT-038, BR-EQP-GNT-048, REQ-MST-ALC-004, BR-EQP-GNT-019〕
- 피킹호기 안 BOX는 입고월 FIFO를 우선하고, 같은 입고월 안에서는 셀 피킹 우선순위(셀 마스터 값) 순으로 출고 구성에 할당한다 〔BR-MST-ALC-006, BR-INV-UNT-017, BR-EQP-GNT-037, REQ-EQP-GNT-031, REQ-MST-ALC-004, BR-MST-LOC-030〕
- 이 할당 후보·순서는 할당 전략의 초기 값 ①(1층 GANTRY 출고·보충)이다 〔REQ-MST-ALC-004〕

### 3-4. 출고 팔레트 구성
- 팔레트는 인도처(FO) 단위로 구성한다(인도처가 다르면 합적하지 않는다는 것은 「거래처·인도처」 묶음) 〔REQ-EQP-GNT-027〕
- WCS는 1층 MIXED 팔레타이징 작업지시(출고 구성 지시)에 현대무벡스 ECS가 인쇄물을 출력하는 데 필요한 항목을 포함해 보낸다. 항목은 협의 중이다(§7) 〔BR-EQP-GNT-030, REQ-EQP-GNT-025〕

### 3-5. 로딩 옵티마이저
- MIXED 팔레타이징 전에 로딩 옵티마이저로 적재 계획을 세운다. 로딩 옵티마이저의 뜻, 두 수행 방식(SDS / 현대무벡스), 층별 수행 주체를 창고 기초속성 옵션으로 고르는 것은 「출고 업무 용어」 묶음에 있다 〔BR-OUB-GNT-012〕
- 두 방식과 아래 입력 규칙은 1층 GANTRY MIXED와 3층 MIXED에 같게 적용한다(3층에서 다른 점은 → P28 3-7) 〔REQ-OUB-GNT-033〕
- SDS 방식: WCS는 인도처별 피킹 W/T 할당을 마치면(출고 구성 지시 전) SDS에 입력을 보낸다 〔REQ-OUB-GNT-033〕
- SDS 방식: 결과를 받기 전에는 해당 인도처의 출고 구성 지시를 보류한다 〔REQ-OUB-GNT-021〕
- SDS 방식: 결과 항목은 출고 팔레트 수, 팔레트별 BOX 목록·적재 순서·적재 위치, 분할 여부다 〔REQ-OUB-GNT-021〕
- SDS 방식: 출고 구성 완료 실적의 출고 팔레트는 결과의 팔레트 번호와 연결한다 〔REQ-OUB-GNT-021〕
- 현대무벡스 방식: SDS 입력과 같은 항목을 출고 구성 지시에 담아 현대무벡스 ECS에 보낸다 〔REQ-OUB-GNT-033〕

### 3-6. 부족 감지
- 사전 보충을 해 두어도 실제 피킹지시 시점에 피킹호기 재고가 부족할 수 있다. 부족 유형(S1~S8)마다 원인·감지 시점·처리를 정해 대응한다(§5-1) 〔BR-OUB-GNT-008〕
- WCS는 세 시점에서 GANTRY 재고 부족을 판정한다 〔REQ-OUB-GNT-013〕
  1. 피킹 W/T 할당 시(배치 확정) — 전산 부족: 피킹호기 가용 재고 < W/T 수량
  2. 피킹지시 전 보충 진행 상태 확인 시 — 보충 미완료·지연
  3. 출고 구성 중 설비 보고 시 — 실물 부족
- 부족 건은 유형 코드(S1~S8)와 부족 수량을 기록한다 〔REQ-OUB-GNT-013〕

### 5-2. 실물 부족과 마감 내 해소 불가
- 설비가 BOX 부족을 보고하면 WCS는 해당 호기 재고를 재고 처리 오류로 표시해 재고대사 대상으로 등록하고(→ P39 재고대사), 부족분을 긴급 보충 또는 재할당으로 채운다 〔REQ-OUB-GNT-015〕
- GANTRY 실물 부족·설비 이상은 수작업 GTP 출고가 아니라 재할당·긴급 보충으로 처리한다 〔BR-OUB-MAN-026〕
- 마감 내 채울 수 없으면 대시보드·파워유저에게 알람을 보낸다 〔REQ-OUB-GNT-015〕
- 마감 내 GANTRY 재고 부족을 해소할 수 없으면 부분 출고 / 출고 대기 두 가지 중 파워유저가 고른다 〔BR-OUB-GNT-010, REQ-OUB-GNT-015〕
- 이 경우에는 수작업 GTP 출고를 쓰지 않는다 〔BR-OUB-GNT-010〕
- 부분 출고: 확보된 수량만 출고 구성을 지시하고, 남은 수량은 W/T 취소로 처리한다(→ P26). 취소 요청은 작업을 모두 마친 뒤 업무 마감 시점에 한다 〔REQ-OUB-GNT-018, BR-OUB-GNT-010, G216〕
- 출고 대기: 긴급 보충이 끝난 뒤 출고 구성을 이어서 지시한다 〔REQ-OUB-GNT-018〕

### 5-3. 인도처 매핑이 없는 출고분
- 인도처 매핑이 없는 W/T는 거래처 정보 오류로 보류하고, 매핑이 등록되면 자동으로 다시 처리한다 〔K23-EX01, REQ-EQP-GNT-039〕

## 6. 기능·화면
- WCS는 마감 내 GANTRY 재고 부족을 해소할 수 없는 출고 건을 파워유저에게 보여 준다(부족 유형·부족 수량·마감 시각). 파워유저는 건별로 부분 출고 또는 출고 대기를 골라 처리한다 〔REQ-OUB-GNT-017〕

## 7. 미결
- [미결 Q-162] 1층 MIXED 팔레타이징 작업지시에 넣을 현대무벡스 ECS 인쇄물 출력 항목은 협의 중이다. 항목 후보는 FULL 팔레트 출고지시와 공통이다(→ P24) 〔K31-IF10, K23-IF04〕
- [미결 Q-107] 디팔레타이징 전 DeWrapping 체적정보 요청은 미결 과제다. GANTRY 디팔레타이징에도 걸리는지는 원문만으로 분명하지 않다 〔K31-EX01〕
- [추가 협의] 출고 유형별 마감시간이 구체화되지 않았다. 그래서 긴급 보충 우선순위와 마감 내 해소 불가 판정의 기준이 정해지지 않았다(Q-123) 〔K31-EX03〕

## 8. 변경 이력
- 마감 내 해소 불가 처리는 3가지였으나 수작업 GTP 출고를 빼고 2가지(부분 출고 / 출고 대기)로 바뀌었다 〔BR-OUB-GNT-010〕
