# [프로세스] 3층 출고 구성

> 키워드: OUB-MIX · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「BOX Shuttle」, 「3층 디팔레타이징·MIXED」(디랩핑기·3층 MIXED 팔레타이징로봇·3층 디팔레타이징 스테이징 셀·3층 디팔레타이징 범위), 「AS/RS」(3층 디팔레타이징 배출라인·AS/RS 재투입라인·사이즈 체크), 「출고 업무 용어」(MIXED 팔레타이징·디팔레타이징·긴급 보충·재할당·로딩 옵티마이저·SDS·출고 팔레트 분할), 「재고 수량」(잔량·가용재고·작업중 재고), 「재고 이력·관리단위」, 「작업지시 체계」(Workflow·Task·Action), 「운반 설비」(수직반송기·AMR·유인지게차), 「설비 공통·설비사」(P-14·P-10, 현대무벡스 내부 인계), 「제품」(OUT EQUIPMENT = BOX가 진입 조건), 「할당 전략」(1·2순위 보충원 순위·정렬·초기 전략 값 ②), 「W/T」(적치 W/T 확정 = 가용), 「LOT·제조번호」(입고월 FIFO)
> **이름만 쓰는 묶음**: 「시스템」, 「TRASH BIN」, 「팔레트」, 「HU」, 「거래처·인도처」, 「출고 오더」, 「출고 배치」, 「WCS 위치」, 「단말」, 「에러·사유코드」, 「재고 운영 용어」, 「GANTRY」, 「조직·재고관리체계」, 「EWMS BIN 코드」
> **이어지는 프로세스**: 앞 → P20 출고 배치 편성, → P27 3층 사전·긴급 보충 · 뒤 → P31 출고완료 확정, → P30 직송 이적(팔레트갈이 대상) · 함께 → P27 3층 사전·긴급 보충(2순위 = 긴급 보충: 부족 W/T 연결·MIXED 지시 시점), → P23 GANTRY 출고 3-5(로딩 옵티마이저 방식별 규칙 — 1층과 같음), → P16 BOX Shuttle 적치·인출, → P13 설비 출고 불가 재할당, → P26 W/T 취소 요청, → P39 재고대사, → P15 TRASH BIN 공급 · 관련 → P05 HU 확인·생성(출고 팔레트 HU 생성·PACK 항목), → P34 재고 반영·보정(원팔레트 잔량 공통 규칙)

## 1. 범위

- 배치 확정된 3층 피킹 W/T에 재고를 할당하면서 시작한다.
- BOX Shuttle 재고와 AS/RS 팔레트를 3층에서 해체한 BOX로 3층 MIXED 팔레타이징로봇이 출고 팔레트를 구성한다. 남은 BOX는 BOX Shuttle에 되돌린다.
- 출고 팔레트를 1층 출고 DOCK까지 옮기면 끝난다. 출고확정은 → P31 출고완료 확정에 있다.

## 2. 흐름

### 2-1. 시작과 할당

1. (EWMS→WCS) 피킹 W/T를 받는다 → (WCS 사용자) 배치를 편성·확정한다. 이후 단계는 배치 확정 후에 진행한다
2. (WCS) BOX Shuttle 재고를 우선 할당한다(할당 순서 3-1)
3. 부족분만 AS/RS 팔레트를 3층 배출·디팔레타이징해 쓴다(2-3)

### 2-2. BOX Shuttle 1순위 인출

1. (WCS→BOX Shuttle ECS) BOX 인출을 지시한다 → BOX가 3층 MIXED 팔레타이징로봇으로 이송된다(현대무벡스 내부 인계)
2. (BOX Shuttle ECS→WCS) 인출 완료 또는 출고 불가를 알린다(4절)

### 2-3. AS/RS 배출 → 랩핑 제거 → 디팔레타이징 → BOX Shuttle → MIXED (2순위)

- 이 경로의 설비 사이 인계는 현대무벡스 내부 인계다(「설비 공통·설비사」 묶음). WCS가 단계마다 작업을 지시한다
- 3층 출고 구성용 AS/RS 팔레트는 유인지게차 구간이 없으므로 WCS가 배출·랩핑 제거·디팔레타이징을 순서대로 지시한다

1. (WCS→현대무벡스 ECS) AS/RS 보관 팔레트를 3층 디팔레타이징 배출라인으로 배출하도록 지시한다
2. (WCS→현대무벡스 ECS) 3층 디랩핑기에 팔레트별 랩핑 제거를 지시한다
3. (3층 디랩핑기) 3층 디팔레타이징 전 팔레트의 랩핑 비닐을 제거해 TRASH BIN에 담는다
4. (현대무벡스 ECS→WCS) 랩핑 제거 완료를 보고한다
5. WCS는 랩핑 제거 완료를 받은 뒤에 디팔레타이징을 지시한다(실패 시 5절)
6. (WCS→현대무벡스 ECS) 3층 디팔레타이징을 지시한다 → (현대무벡스 ECS→WCS) BOX 단위 해체 결과를 받는다
7. 전량 해체(기본): 팔레트를 전부 해체한다 → (WCS→현대무벡스 ECS) 해체 BOX 전량의 BOX Shuttle 투입을 지시한다 → BOX Shuttle이 자동 할당해 적치하고 WCS에 통보한다. 공팔레트는 매거진으로 보낸다
8. 적치가 끝나면 피킹 W/T에 할당한다 → BOX Shuttle에서 인출한다 → 3층 MIXED 팔레타이징로봇으로 보낸다. MIXED 직투입은 하지 않는다
   - [확인필요] 2순위로 해체·적치한 BOX를 어느 W/T에 먼저 붙이고 MIXED 출고 구성을 언제 지시하나(긴급 보충 Task–부족 W/T 연결, 필요 BOX 전량 적치·할당 후 지시)는 → P27 3-2 「우선순위·대상 W/T」에 있다
9. 부분 해체: 디팔레타이징하지 않고 작업자가 피킹량만 작업한다 → 피킹 BOX를 BOX Shuttle에 적치 → 인출 → MIXED. 남은 팔레트는 AS/RS 재투입라인으로 재입고한다
   - [미결 Q-207] 작업자가 피킹하는 위치(재투입라인 상세)는 정해지지 않았다(§7)
10. 부분 해체 피킹 실적은 (작업자) 설비 HMI에 입력 → (현대무벡스 ECS→WCS) 보고로 받는다
11. (WCS) 피킹 실적을 받아 원팔레트 출고 이력·BOX 입고 이력을 남기고, 피킹 BOX의 BOX Shuttle 적치 작업과 남은 팔레트의 AS/RS 재투입라인 재입고 작업을 이어서 지시한다

### 2-4. 적재 계획과 MIXED 출고 구성

1. (WCS) 출고 구성 지시 전에 로딩 옵티마이저(「출고 업무 용어」 묶음)로 적재 계획을 세운다. SDS가 수행하면 (SDS→WCS) 결과를 받아 출고 구성 지시와 함께 전달하고, 설비사가 수행하면 설비사가 자체 처리한다(규칙 3-7)
2. (WCS→현대무벡스 ECS(3층 MIXED 팔레타이징)) 출고 구성을 지시한다 → 출고분을 MIXED 팔레타이징한다
3. (현대무벡스 ECS→WCS) 3층 MIXED 출고 구성 완료(팔레트 출고 완료)와 잔량 BOX 정보를 통보한다

### 2-5. 잔량 처리 (경로 B)

1. (WCS) 잔량 BOX 정보를 받아 BOX Shuttle 투입 작업으로 변환한다
2. (WCS→BOX Shuttle ECS) 잔량 BOX 투입을 지시한다. 현대무벡스 내부 인계이고, WCS가 작업지시한다
3. BOX Shuttle이 자동 할당해 적치하고 WCS에 통보한다
   - [미결 Q-016] 이 이동에 W/T가 필요한지는 정해지지 않았다
4. (BOX Shuttle ECS→WCS) 투입·적치 완료를 알린다 → WCS가 MIXED 팔레타이징 설비 쪽 인계 완료로 처리한다

### 2-6. 출고 구성 완료 팔레트 이송 (수직반송기 P-14 → AMR P-10 → 출고 DOCK)

1. (WCS→수직반송기 ECS) 출고 구성 완료를 받은 뒤 출고 팔레트를 수직반송기로 1층에 이동하도록 지시한다. 설비 접점 P-14이고 WCS가 중간 처리한다
2. (수직반송기 ECS→WCS) 3층 출발 신호와 1층 도착 신호를 따로 통보한다(출발 위치·도착 위치·팔레트 ID)
3. (WCS→생기연 ECS) 도착 정보를 받아 AMR에 1층 출고 DOCK까지 이송을 지시한다. 설비 접점 P-10이고 WCS가 중간 처리한다
4. AMR 또는 유인지게차(Workflow 설정)가 1층 출고 DOCK으로 이송한다. AMR은 (생기연 ECS→WCS) 이송 완료를 통보하고, 유인지게차는 작업지시 없이 WCS PDA 스캔으로 처리한다
5. 이어서 출고완료 확정을 한다(→ P31 출고완료 확정)

## 3. 조건·규칙

### 3-1. 재고 사용 순서 (할당 우선순위)

- 진입 조건: 3층 출고 구성 대상은 제품마스터 OUT EQUIPMENT = BOX인 제품(중소형 제품)이다(값의 뜻은 「제품」 묶음)
- 3층 출고 구성은 BOX Shuttle 가용 재고를 먼저 할당하고, 부족분만 AS/RS 팔레트 3층 배출·3층 디팔레타이징을 지시한다. 피킹 W/T 할당 때는 할당 우선순위로 쓴다: 1순위 BOX Shuttle 재고, 2순위 AS/RS 팔레트(3층 배출 → 디팔레타이징 → BOX Shuttle 적치 후 인출)
- 2순위 AS/RS 팔레트 할당은 긴급 보충과 같다(→ P27 3층 사전·긴급 보충)
- 부족이 감지되면 긴급 보충을 하고, 출고예정 기반 사전 보충도 한다(→ P27)
- BOX Shuttle 재고는 입고월 FIFO를 우선하고, 같은 입고월 안에서 셀 마스터의 셀 피킹 우선순위 순으로 인출 대상을 정한다
- ⚠ 원문 불일치: 초기 전략 값 ② 3층 출고 구성의 2순위 AS/RS 팔레트 정렬은 잔량 최소 → 부분 팔레트 → 입고월 FIFO다
- ⚠ 원문 불일치: 2순위 팔레트 선택은 입고월 FIFO를 우선하고, 같은 입고월 안에서 남는 BOX 수가 적은 팔레트(부분 팔레트 포함)를 우선해 BOX Shuttle 적치량을 줄인다
- BOX Shuttle 적치율이 임계치에 도달하면 3층 출고 할당 때 BOX Shuttle 재고를 우선 소진한다(할당 우선순위 1순위 유지)
- 3층 출고 구성 지시에는 인도처 기준 스테이션 할당·매핑을 쓰지 않는다
- 한 인도처 오더에 GANTRY 제품과 BOX 제품이 섞이면 층별로 각각 출고 팔레트를 구성한다

### 3-2. 해체 BOX는 BOX Shuttle을 거친다

- AS/RS 팔레트를 3층에서 해체한 BOX는 MIXED에 바로 투입하지 않는다. 할당 우선순위 2순위·사전 보충·긴급 보충 모두, 전량·부분 해체 공통으로 BOX Shuttle에 적치한 뒤 인출해 MIXED에 투입한다(Q-185 결정)
- 해체 범위(전량/부분)는 「3층 디팔레타이징·MIXED」 묶음의 3층 디팔레타이징 범위 옵션 값을 따른다
- 전량 해체면 남은 BOX는 모두 BOX Shuttle에 보관하고(필요 BOX는 인출해 MIXED로) 공팔레트는 매거진으로 보낸다. 부분 해체면 남은 팔레트는 AS/RS 재투입라인으로 AS/RS에 재입고한다
- 3층 디팔레타이징 배출라인 배출은 해체 실적으로 처리한다. 자동화구역 안 이동이라 배출 때 W/T 확정이 없다. 피킹 W/T는 3층 출고 구성 후 출고완료 확정 때 확정한다

### 3-3. 전량 해체

- WCS는 디팔레타이징 지시에 팔레트 전체 해체를 지정하고, 해체 실적(BOX별 제품·LOT·수량)을 받는다
- 해체한 BOX는 모두 BOX Shuttle 투입을 지시한다. 출고에 필요한 BOX는 적치 완료 후 해당 W/T에 할당해 인출 → MIXED 투입한다
- 공팔레트는 매거진으로 보낸다. 전량 해체로 없어진 원팔레트 HU 정보는 EWMS에 알리지 않는다
- AS/RS → BOX Shuttle은 자동화구역(0050) 안 이동이라 W/T를 만들지 않는다(자동화구역은 「EWMS BIN 코드」 묶음)
- BOX Shuttle 적치 완료 전까지 남은 BOX는 가용재고가 아니다

### 3-4. 부분 해체

- 부분 해체 적용 여부와 피킹 수량(필요 BOX 수)·대상 팔레트는 사용자 판단으로 지정한다
- WCS는 현대무벡스 ECS가 보고하는 부분 해체 피킹 실적(설비 HMI 입력)을 받는다
- 작업자가 부분 해체로 피킹한 BOX는 BOX Shuttle에 적치한 뒤 인출해 MIXED에 투입한다
- 남은 팔레트는 AS/RS 재투입라인(현대무벡스)으로 재입고한다. HU 확인은 하지 않는다
- ⚠ 원문 불일치: 재입고 때 사이즈 체크를 한다 / 재입고 때 사이즈 체크를 기본으로 한다
- [미결 Q-207] 재투입라인 상세(작업자가 피킹하는 위치)는 정해지지 않았다(§7)
- 해체부터 재입고 완료까지 남은 팔레트 재고는 작업중 재고로 보고 가용재고에서 뺀다

### 3-5. 재고 이력·관리단위 전환

- 디팔레타이징: 해체 실적 때 원팔레트 출고 이력 + 3층 디팔레타이징 스테이징 셀 입고 이력을 남긴다
- 이후 BOX Shuttle 적치 실적 때 스테이징 셀 → BOX Shuttle 셀 이동 이력을 남긴다(MIXED 직투입 없음)
- 원팔레트 잔량 처리(원팔레트에 남김, 0이면 종료)는 관리단위 전환 공통 규칙이다 → P34 재고 반영·보정 3-3
- MIXED: BOX 출고 이력 + 출고 팔레트(= 팔레트 ID·HU) 입고 이력을 남긴다
- 같은 변경 TASK번호로 묶는다(→ P34 3-3). LOT·화주를 그대로 두는 것은 「재고 이력·관리단위」 묶음에 있다. W/T는 만들지 않는다
- ⚠ 원문 불일치: 전량 해체의 재고 이력은 원팔레트 전량 출고 이력(원팔레트 재고 종료) + BOX Shuttle 적치 BOX 입고 이력이고, 같은 변경 TASK번호로 묶는다. 이 이력에는 스테이징 셀 단계가 없다
- 부분 해체의 재고 이력은 원팔레트에서 해체 수량만 출고 이력 + BOX 입고 이력이다. 원팔레트는 남은 수량으로 유지되고, 재입고 위치는 이동 이력으로 반영한다(적치셀이 바뀌어도 수용)

### 3-6. 잔량 처리

- GANTRY 외에는 잔량을 BOX Shuttle에 보관하거나 W/T를 생성해 이동한다. W/T를 생성해 이동하는 경우는 → P29 수작업 GTP 출고, → P30 직송 이적을 본다
- 3층 출고 구성(MIXED 팔레타이징) 후 잔량이 생기면 WCS가 잔량 정보를 받아 경로 B로 BOX Shuttle에 투입·보관한다
- BOX Shuttle에 보관한 잔량은 다음 출고 때 먼저 쓴다
- 3층 BOX Shuttle의 잔량 보관은 1층 GANTRY 보관호기와 같은 역할이다

### 3-7. 적재 계획 (로딩 옵티마이저)

- MIXED 팔레타이징 전에 1층과 같이 로딩 옵티마이저(「출고 업무 용어」 묶음)로 적재 계획을 세운다
- SDS 방식이면 WCS가 결과를 출고 구성 지시와 함께 현대무벡스 ECS(3층 MIXED 팔레타이징)에 전달한다
- 그 밖의 방식별 규칙(SDS 입력 송신 시점, 결과 전 출고 구성 지시 보류, 결과 항목, 현대무벡스 방식은 결과 없이 지시)과 수행 주체 변수는 1층과 같다 → P23 GANTRY 출고 3-5

### 3-8. 랩핑 제거 단계

- 랩핑 제거는 3층 배출 Workflow(AS/RS 3층 배출 → 디랩핑기 → 3층 디팔레타이징 로봇)의 한 단계로 설정한다
- 완료 보고를 받은 뒤에 다음 단계(디팔레타이징 지시)를 진행한다
- 랩핑 제거 지시·보고 내역은 작업 이력으로 남긴다

### 3-9. 출고 팔레트 이송 Workflow

- WCS는 3층 출고 구성 팔레트를 MIXED 팔레타이징 → 수직반송기(P-14) → 1층 AMR(P-10) 또는 유인지게차 → 1층 출고 DOCK으로 잇는 팔레트 단위 Workflow로 실행한다. 수직반송기 센싱 결과를 받으면 다음 단계를 이어 간다
- 현재 팔레트 유형과 배송 팔레트 유형이 다르면 경로가 달라진다. 팔레트갈이 대상이면 → P30 직송 이적의 경로를 따른다
- 3층 MIXED로 만든 출고 팔레트의 유형(「3층 디팔레타이징·MIXED」 묶음)이 직송 배송 팔레트 유형과 다르면 팔레트갈이 대상이다(3층 안에서 이적)

## 5. 예외

### 5-1. 설비 쪽 예외

- 랩핑 제거 실패를 보고받으면 알람을 띄우고 해당 팔레트 작업을 보류한다
- 전량 해체 때 남은 BOX를 BOX Shuttle에 넣을 수 없는 경우(용량 부족)의 설비 동작은 「BOX Shuttle」 묶음 3.6에 있다. 80% 임계치 알림과 공간 확보 방안은 → P16 BOX Shuttle 적치·인출에 있다

### 5-2. 3층 재고 부족

- GANTRY와 마찬가지로 피킹지시 시점에 재고가 부족할 수 있다. 부족 유형별 원인·감지 시점·처리를 정의해 대응한다
- 부족 감지: WCS는 ① 피킹 W/T 할당 때(배치 확정)(전산 부족) ② 피킹지시 전 확인 때(적치·확정 진행 중, 처리능력 부족) ③ 출고 구성 중 설비 보고 때(실물 부족·인계 손실) 3층 재고 부족을 판정하고, 유형 코드와 부족 수량을 기록한다
- 부족이 생기면(할당 우선순위 2순위 = 긴급 보충) 감지(W/T 할당 / 피킹지시 전 / 출고 구성 중 설비 보고) → 긴급 보충(MIXED 직투입 안 함, → P27) → 마감 내 해소 불가면 파워유저가 부분 출고·출고 대기를 고른다
- ⚠ 원문 불일치: 아래 부족 유형 표의 「재할당」은 긴급 보충으로 수행한다. 보충 BOX는 BOX Shuttle에 적치한 뒤 쓴다. 이 「재할당」은 「출고 업무 용어」 묶음의 재할당(설비 불가 사유를 받아 대체 재고를 다시 할당)과 뜻이 다르다

| 유형 | 원인 | 감지 시점 | 처리 |
|---|---|---|---|
| S1 수량 증가·신규 | W/T 수량이 출고예정보다 많거나 출고예정 없이 W/T가 들어옴 | W/T 할당(배치 확정) | ⚠ AS/RS 팔레트로 재할당 |
| S2 인도처·호기 불일치 | 해당 없음(인도처별 스테이션 매핑 없음) | — | — |
| S3 선점 | BOX Shuttle 재고를 마감이 더 빠른 다른 W/T가 먼저 할당받음 | W/T 할당(배치 확정) | 마감이 빠른 W/T 우선, 밀린 W/T는 ⚠ AS/RS 팔레트로 재할당 |
| S4 LOT·화주 조건 불일치 | W/T 지정 LOT·Storage Location·V/T 또는 Work 생성 시점 화주가 BOX Shuttle 재고와 다름 | W/T 할당(배치 확정) | ⚠ 조건 맞는 재고로 재할당 |
| S5 재고 상태 변경 | 보류 전환, LOT 속성 변경(파손 등), 셀 상태 할당불가 | W/T 할당(배치 확정) | 가용 재고에서 제외 후 ⚠ 재할당 |
| S6 보충 미완료 | 사전 보충분이 아직 BOX Shuttle에 적치·확정되지 않음(디팔레타이징·적치 진행 중·지연) | 피킹지시 전 확인 | 적치 완료 대기 또는 ⚠ AS/RS 팔레트로 재할당 |
| S7 실물 수량 차이 | BOX Shuttle 적치·인출 수량 차이, BOX 파손·Reject, 디팔레타이징 실적 부족 | 출고 구성 중 설비 보고 | 재고 처리 오류 표시·재고대사 등록, ⚠ 재할당 |
| S8 설비 출고 불가 | BOX Shuttle 이상으로 BOX를 인출할 수 없음 | 설비 보고 | 불가 사유 수신 후 재할당(→ P13 설비 출고 불가 재할당) |
| B1 적치 진행 중 | 경로 B 잔량 BOX가 BOX Shuttle로 인계 중이라 아직 적치 완료 전 | W/T 할당(배치 확정) | 가용에서 제외, 적치 완료 대기 또는 ⚠ 재할당 |
| B2 W/T 미확정 | 경로 A(디베닝)로 적치했으나 BOX 단위 적치 W/T 확정 전이라 가용재고 아님. [미결 Q-016] 경로 B에 W/T가 필요한지는 정해지지 않았다 | W/T 할당(배치 확정) | 확정 대기 또는 ⚠ 재할당 |
| B3 인계 손실 | BOX Shuttle → 3층 MIXED 팔레타이징로봇 이송 중 BOX 누락·Reject | 출고 구성 중 설비 보고 | 재고 처리 오류 표시·재고대사 등록, ⚠ 재할당 |
| B4 처리능력 부족 | 재고는 있으나 BOX Shuttle 인출 처리량 때문에 마감 내 인출 불가 | 피킹지시 전 확인 | 인출 우선순위 재조정, 불가 시 마감 내 해소 불가 처리 |

- ⚠ 원문 불일치: 실물 부족 — 설비가 BOX 부족이나 인계 손실을 보고하면 WCS는 해당 재고를 재고 처리 오류로 표시해 재고대사 대상으로 등록하고(→ P39 재고대사), 할당 우선순위에 따라 재할당한다(이 「재할당」은 위 표와 같은 뜻)
- 출고 불가 — BOX Shuttle(현대무벡스)이 출고 불가 사유를 보내면 대체 재고를 선정해 재할당한다

### 5-3. 마감 내 해소 불가

- WCS는 해당 출고 건을 파워유저에게 보여 주고(부족 유형·수량·마감 시각) 부분 출고 / 출고 대기 중 하나를 고르게 한다
- 부분 출고면 남은 수량은 EWMS에 W/T 취소를 요청한다(작업을 모두 마친 뒤 업무 마감 시점, → P26 W/T 취소 요청)
- 출고 대기면 재할당분이 도착한 뒤 출고 구성을 이어서 지시한다
- 수작업 GTP 출고는 쓰지 않는다. GANTRY 출고(OUB-GNT)와 같다

## 6. 기능·화면

- WCS는 3층 부족 이력(유형·수량·제품·시간대)을 집계해 모니터링·대시보드에 제공한다
- 마감 내 해소 불가 건의 부분 출고 / 출고 대기 선택 화면(파워유저)은 5-3에 있다.

## 7. 미결

- [추가 협의] [미결 Q-207] 3층 부분 해체 때 작업자가 피킹하는 위치는 협의가 필요하다. 이미 정한 것: 재투입라인 설비사는 현대무벡스, 피킹 BOX는 BOX Shuttle 적치, 재투입 때 사이즈 체크, 피킹 실적은 설비 HMI 입력 후 현대무벡스 ECS 보고
- [추가 협의] [미결 Q-016] 경로 B(3층 MIXED 잔량 → BOX Shuttle)에 W/T가 필요한지 — 자동화구역 안 이동이라 W/T 없음으로 볼지
- [추가 협의] [미결 Q-107] 디랩핑기 전달 항목 확정(제품마스터 치수 등 적재 정보 외 필요 항목) — 현대무벡스 확인. 체적은 현대무벡스 내부 처리이고, WCS는 제품마스터 치수 등 적재 정보를 전달한다
- [미결 Q-162] 출고 구성 지시에 넣을 인쇄물 출력 항목(4절 표)
- [추가 협의] 출고 유형별 마감시간이 구체화되지 않아 마감 내 해소 불가 판정의 기준이 정해지지 않았다(Q-123)
