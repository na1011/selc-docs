# [프로세스] HU 확인·생성

> 키워드: HU-VAL · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「HU」, 「팔레트」
> **이름만 쓰는 묶음**: 「시스템」, 「W/T」, 「AS/RS」, 「GANTRY」, 「3층 디팔레타이징·MIXED」, 「입고 업무 용어」, 「출고 업무 용어」
> **이어지는 프로세스**: 앞 → P03 디베닝입고, P23 GANTRY 출고, P28 3층 출고 구성, P29 수작업 GTP 출고, P19 GANTRY 장기 보관 재고 AS/RS 투입, 뒤 → P31 출고완료 확정, 관련 → P02 일반입고, P06 HU PACK·UNPACK·SWAP

## 1. 범위

팔레트 ID를 WCS가 쓸 수 있는지 판단하려고 EWMS HU를 확인·생성한다. 〔K29-OV01〕 팔레타이징 유형별로 HU 확인/생성 주체를 정한다. 〔K29-OV03〕 HU 확인은 HU 스캔 시 쓴다. 〔G118〕

- 일반입고 투입 때의 HU(EWMS 선행, WCS는 확인·생성 안 함)와 HU 사용 불가 팔레트 처리는 → P02 일반입고.
- 셀 재고에 대한 PACK·UNPACK·SWAP은 → P06 HU PACK·UNPACK·SWAP.

## 2. 흐름

### 2-1. EWMS 팔레타이징(검증) 순서

1. (EWMS) HU 확인: 사용하려는 HU가 EWMS에 채번되어 있는지 확인한다. 〔K29-F01.01〕
2. (EWMS) HU 생성: 없으면 새로 만든다. 〔K29-F01.02〕
3. (EWMS) W/T HU 매핑/확정: EWMS에서 HU와 W/T를 매핑한다. 〔K29-F01.03〕

### 2-2. WCS 팔레타이징 결과 연동

4. [확인필요] (WCS→EWMS) WCS는 팔레타이징 결과를 EWMS 처리 순서(HU 확인 → 생성 → W/T 매핑)대로, 실시간 또는 배치로 연동한다. 〔BR-HU-VAL-002, K29-F02.00, REQ-HU-VAL-003〕
   - 디베닝 팔레타이징 결과의 HU 생성·PACK 요청은 → P03 디베닝입고.

### 2-3. MIXED 출고 팔레트

5. (설비→WCS) 출고 구성 완료 보고(출고 팔레트 ID, 적재 내역)를 받는다. 〔REQ-HU-VAL-024, BR-HU-VAL-022〕
6. (WCS→EWMS) EWMS에 HU 생성·PACK을 요청한다(팔레트 ID, 제품, LOT, 수량, 시리얼번호 목록). 〔REQ-HU-VAL-024, BR-HU-VAL-022〕
7. (WCS→EWMS) 출고확정 때 그 HU 기준으로 피킹 W/T를 확정한다. → P31 출고완료 확정 〔BR-HU-VAL-022〕
   - 1층 GANTRY MIXED와 3층 MIXED에 같게 적용한다. → P23 GANTRY 출고, P28 3층 출고 구성 〔REQ-HU-VAL-024〕

## 3. 조건·규칙

| 조건 | 처리 | 출처 |
|---|---|---|
| 디베닝입고 / 1층 자동화 팔레타이징 / MIXED 팔레타이징 | 공팔레트 보관(또는 AS/RS 입고) 전에 HU 확인을 선행한다. 그래서 WCS는 HU 확인을 하지 않는다. 디베닝 팔레타이징에 쓰는 팔레트 ID도 같다 | 〔BR-HU-VAL-006, BR-INB-DVN-006〕 |
| [확인필요] 팔레타이징 유형별 주체 | WCS는 팔레타이징 유형별 HU 확인/생성 주체 규칙에 따라 처리한다. 이 요구가 가리키는 BR-HU-VAL-003·005는 원문에 없다 | 〔REQ-HU-VAL-001〕 |
| 분할 팔레트 잔량 | 다음 일련번호 팔레트 ID로 HU 확인한다. → P29 수작업 GTP 출고 | 〔BR-HU-VAL-007〕 |
| MIXED 출고 팔레트의 HU 생성 | HU 생성이 성공해야 그 팔레트의 출고확정을 할 수 있다 | 〔REQ-HU-VAL-024〕 |

- ⚠ 원문 불일치: 디베닝입고·1층 자동화 팔레타이징·MIXED 팔레타이징은 HU 확인을 선행하므로 WCS는 HU 확인이 필요 없다. 〔BR-HU-VAL-006〕
- ⚠ 원문 불일치: 같은 유형에서 WCS가 EWMS에 HU 생성·PACK을 요청한다 — MIXED 출고 구성 완료 때 〔BR-HU-VAL-022, REQ-HU-VAL-024〕, 디베닝 팔레타이징 결과로(→ P03의 BR-INB-DVN-018).
  - 「WCS는 HU 처리가 필요 없다」와 「WCS가 HU 생성을 요청한다」가 함께 있다. 확인(존재 여부)과 생성은 다른 단계이나, 원문은 둘의 관계를 적지 않았다.

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 | 출처 |
|---|---|---|---|
| WCS→EWMS | HU 생성(실시간/배치) | 팔레트 ID, 적재 내역 | 〔K29-IF02〕 |
| WCS→EWMS | HU 조회(장기 보관 재고·GTP 잔량 HU 확인) | HU(팔레트 ID) → 존재 여부·내역. → P19, P29 | 〔K29-IF03〕 |

## 5. 예외

- MIXED 출고 팔레트: EWMS 실패·단절 때도 설비는 멈추지 않는다. HU 생성이 성공해야 해당 팔레트의 출고확정을 할 수 있다. 〔REQ-HU-VAL-024〕
