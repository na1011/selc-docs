# [프로세스] 3층 사전·긴급 보충

> 키워드: OUB-MIX · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「출고 업무 용어」(사전 보충·긴급 보충·재할당), 「BOX Shuttle」, 「재고 수량」(도착예정 수량·가용재고·미예약 재고), 「출고 오더」(출고예정·시간대별 출고 Type), 「작업지시 체계」(Task·Action·전략 이력), 「창고 기초속성」(BOX Shuttle 적치율 임계치), 「제품」(OUT EQUIPMENT = BOX로 중소형 판단), 「할당 전략」(2순위 보충원·팔레트 정렬·초기 전략 값 ②③), 「LOT·제조번호」(입고월 FIFO)
> **이름만 쓰는 묶음**: 「AS/RS」, 「3층 디팔레타이징·MIXED」, 「W/T」, 「시스템」, 「설비 공통·설비사」, 「단말」, 「EWMS BIN 코드」, 「조직·재고관리체계」
> **이어지는 프로세스**: 앞 → P01 EWMS 작업정보 수신(출고예정), → P20 출고 배치 편성(W/T 할당) · 뒤 → P28 3층 출고 구성 · 함께 → P16 BOX Shuttle 적치·인출, → P22 GANTRY 사전·긴급 보충(1층 대칭. 층 공통 규칙 — 사전 보충 대상 범위, 긴급·사전 보충 우선순위, 긴급 보충량 식 — 은 P22에 둠), → P32 재고 할당

## 1. 범위

- 새벽에 받은 출고예정으로 3층 사전 보충을 만들 때, 또는 3층 출고 구성 재고 부족을 감지해 긴급 보충을 만들 때 시작한다.
- AS/RS 팔레트를 3층에서 디팔레타이징한 BOX가 BOX Shuttle에 적치되면 끝난다.
- 적치한 BOX를 인출해 MIXED 팔레타이징하는 일은 → P28 3층 출고 구성에 있다.

## 2. 흐름

### 2-1. 사전 보충

1. (EWMS→WCS) 새벽 시간에 출고예정을 1회 받는다 〔K32-F01.01, BR-OUB-MIX-019, REQ-OUB-MIX-021, K32-OV03, G214〕
2. (WCS) 당일 출고예정 대상이면서 시간대 A타입인 오더만 추려 보충 대상 자료를 생성한다(대상 규칙 3-1) 〔K32-F01.01〕
3. (WCS) 3층 사전 보충 수요와 보충 소요량을 계산한다(계산 규칙 3-1) 〔K32-F01.01〕
4. (WCS→현대무벡스 ECS) 피킹 W/T 수신 전에 AS/RS 팔레트 3층 배출 → 랩핑 제거 → 3층 디팔레타이징을 지시하고, 해체 BOX를 BOX Shuttle에 적치한다 〔K32-F01.02, K22-F03.01〕
   - 경로는 3층 디팔레타이징 배출라인 → 랩핑 제거 → 3층 디팔레타이징(전량 해체) → BOX Shuttle 적치다. 인계는 경로 B와 같다 〔REQ-OUB-MIX-014〕
5. (WCS→BOX Shuttle ECS) 보충 BOX 투입을 지시한다. BOX Shuttle이 자동 할당해 적치하고 (BOX Shuttle ECS→WCS) 통보한다 〔K22-F03.02, REQ-EQP-BSH-009〕
6. 이 이동은 자동화구역 안 이동이라 W/T가 없다 〔K22-F03.02, REQ-EQP-BSH-009〕
7. BOX Shuttle 적치율이 임계치에 도달하면 (WCS→대시보드·파워유저) 알람을 보내고, 사용자가 사전 조치한다(규칙 3-3) 〔K32-F01.03〕

### 2-2. 긴급 보충

1. [확인필요] (WCS) 3층 출고 구성 재고 부족을 감지한다. 감지 시점은 W/T 할당(배치 확정), 피킹지시 전 확인(사전 보충 실패 포함), 출고 구성 중 설비 실물 부족 보고다 〔REQ-OUB-MIX-017(확인필요)〕
2. [확인필요] (WCS→현대무벡스 ECS) AS/RS 팔레트를 3층 디팔레타이징 배출라인으로 배출 → 랩핑 제거 → 3층 디팔레타이징(전량 해체) → 해체 BOX 전량을 BOX Shuttle에 적치한다. MIXED에 바로 넣지 않는다 〔K22-F05.01, REQ-OUB-MIX-017(확인필요)〕
3. [확인필요] 적치가 끝나면 대상 W/T에 할당 → BOX Shuttle 인출 → 3층 MIXED 팔레타이징으로 이어진다(→ P28 3층 출고 구성). 할당 우선순위 2순위 할당과 같은 경로다 〔K22-F05.02, REQ-OUB-MIX-017(확인필요)〕
4. [확인필요] 해당 W/T에 필요한 BOX가 모두 BOX Shuttle에 적치되어 할당된 뒤에 MIXED 출고 구성을 지시한다. 일부만 확보한 채 시작해 MIXED가 대기하지 않게 한다 〔REQ-OUB-MIX-017(확인필요)〕

## 3. 조건·규칙

### 3-1. 사전 보충 — 대상과 수요

- 3층은 중소형 BOX 낱개 오더의 출고 처리를 위해 출고예정으로 사전 보충 작업을 만든다 〔G214, BR-EQP-BSH-007, BR-OUB-MIX-013, K32-OV01, REQ-OUB-MIX-013〕
- 대상은 새벽에 1회 받은 출고예정 중 당일 출고예정 대상이면서 시간대 A타입인 오더다 〔BR-OUB-MIX-019, REQ-OUB-MIX-021, K32-OV03, REQ-OUB-MIX-014, REQ-MST-ALC-004〕
- 이 대상 범위가 층 구분 없이 같다는 규칙은 → P22 §3에 있다 〔BR-OUB-MIX-023〕
- 보충 대상 자료는 새벽 출고예정 수신 후 1회 생성한다 〔REQ-OUB-MIX-014〕
- 「중소형 제품」은 OUT EQUIPMENT 값(= BOX)으로 판단한다 〔BR-OUB-MIX-029, REQ-OUB-MIX-014〕
- 3층 사전 보충 수요는 중소형 제품의 출고예정 수량 중 AS/RS FULL 팔레트로 출고할 수 있는 수량을 팔레트로 출고하고, 남은 수량으로 계산한다 〔G214, BR-OUB-MIX-014, REQ-OUB-MIX-015, K32-OV02, REQ-OUB-MIX-014〕
- FULL 팔레트 출고분은 GANTRY 수요와 같이 AS/RS 실제 팔레트 수량 기준으로 (인도처, 화주, 제품)별로 뺀다 〔REQ-OUB-MIX-014〕
- 보충 소요량 = 제품(화주·LOT 조건)별 3층 수요(W/T 미할당분) − BOX Shuttle 미예약 현재고 − 도착예정 수량(진행 중 보충량) 〔REQ-OUB-MIX-014〕
- 보충 소요량은 출고예정과 개별로 짝짓지 않고 제품 단위 합계로 계산한다. 출고예정에 예약하지 않는다 〔REQ-OUB-MIX-014〕
- 보충 BOX는 적치 완료 전까지 도착예정 수량으로 관리한다. 가용재고가 아니다 〔REQ-EQP-BSH-009〕
- 사전 보충으로 디팔레타이징해 BOX Shuttle에 적치한 BOX는 피킹 W/T 할당 때 1순위 재고로 쓴다 〔BR-EQP-BSH-012〕
- 사전 보충 전략은 교체할 수 있고, 전략 이력을 기록한다 〔REQ-OUB-MIX-014〕
- 시간대 A타입이 아닌 오더는 사전 보충하지 않는다. 긴급 보충(= 할당 우선순위 2순위)으로 BOX Shuttle을 채운다 〔BR-OUB-MIX-025〕
- A타입이 아닌 오더의 3층 수요는 피킹 W/T 수신 후 1순위 BOX Shuttle 재고로 할당하고, 부족분은 긴급 보충으로 BOX Shuttle을 채운다 〔REQ-OUB-MIX-025〕

**보충원 팔레트 고르는 순서**
- ⚠ 원문 불일치: 사전 보충의 보충원은 AS/RS 팔레트다. 입고월 FIFO를 우선하고, 같은 입고월 안에서 잔량 최소·부분 팔레트를 우선해 고른다 〔REQ-OUB-MIX-014〕
- ⚠ 원문 불일치: 초기 전략 값 ③ 사전 보충의 보충원은 3층 출고 구성(초기 전략 값 ②) 순서를 쓴다. ②의 AS/RS 팔레트 정렬은 잔량 최소 → 부분 팔레트 → 입고월 FIFO다(→ P28 3층 출고 구성 3-1) 〔REQ-MST-ALC-004〕

### 3-2. 긴급 보충

- 3층도 피킹 W/T 할당·피킹지시 때 출고 구성 재고가 부족하면 긴급 보충 작업을 만든다 〔BR-OUB-MIX-015, K32-OV04, REQ-OUB-MIX-016, REQ-OUB-MIX-014〕
- 할당 우선순위 2순위(AS/RS 팔레트 3층 배출·디팔레타이징 → BOX Shuttle 적치 후 인출)와 긴급 보충은 같은 개념이다. 피킹 W/T 할당 때 BOX Shuttle 재고가 부족해 2순위로 가는 것이 곧 긴급 보충이다 〔G217, BR-OUB-MIX-022〕
- 할당 우선순위 2순위 할당과 긴급 보충은 같은 처리(같은 Task 유형·경로·우선순위 규칙)로 한다 〔REQ-OUB-MIX-024〕
- 긴급 보충으로 해체한 BOX도 MIXED에 바로 넣지 않고 BOX Shuttle을 거친다. 해체 BOX 공통 규칙은 → P28 3층 출고 구성 3-2 〔G217, BR-EQP-BSH-012, BR-OUB-MIX-017, REQ-OUB-MIX-019〕
  - 긴급 보충에서 그렇게 하는 이유: 해체·이송 시점이 출고 구성과 맞지 않아 MIXED 대기 시간이 길어진다 〔BR-OUB-MIX-017〕
- ⚠ 원문 불일치: 재할당(= 긴급 보충) — 전산 부족이 감지되면 WCS는 할당 우선순위에 따라 다음 순위 재고(AS/RS 팔레트 3층 배출 → 3층 디팔레타이징 → BOX Shuttle 적치 → 인출 → MIXED 팔레타이징)로 재할당한다. 부족분 처리는 긴급 보충으로 한다. 여기서 「재할당」은 「출고 업무 용어」 묶음의 재할당(설비 불가 사유를 받아 대체 재고를 다시 할당)과 뜻이 다르다 〔REQ-OUB-MIX-005〕
- 긴급 보충과 사전 보충 사이, 예약 간 우선순위는 1층과 같다 → P22 §3. 3층에서는 REQ-OUB-MIX-005·REQ-OUB-MIX-014 ⑦(확정)이 정하고, REQ-OUB-MIX-017 ⑤(확인필요)도 같은 내용이다 〔REQ-OUB-MIX-005, REQ-OUB-MIX-014, REQ-OUB-MIX-017〕
- 3층은 설비 접점과 층간 이동 때문에 1층보다 리드타임이 길다. 마감 역산 리드타임을 3층용으로 따로 관리한다. 리드타임 상세는 정리 대상에서 일단 제외했다 〔REQ-OUB-MIX-005〕

**소요량**
- 긴급 보충량을 구하는 식은 1층과 같다 → P22 2-3 ②. 보충이 이중으로 생기지 않게 하기 위해서다 〔BR-OUB-MIX-030, REQ-OUB-MIX-027〕
- 같은 제품의 시작 전 사전 보충 작업이 있으면 새 작업을 만들지 않는다. 그 작업을 긴급으로 전환(우선순위 상향)하고, 모자라는 양만 새 긴급 보충으로 만든다 〔REQ-OUB-MIX-027〕

**우선순위·대상 W/T** (REQ-OUB-MIX-017 전체가 확인필요)
- [확인필요] 긴급 보충끼리는 시간대 Type 마감이 빠른 W/T를 우선한다. AS/RS 배출·랩핑 제거·디팔레타이징·BOX Shuttle 투입 순서에도 같은 우선순위를 적용한다 〔REQ-OUB-MIX-017(확인필요)〕
- [확인필요] 긴급 보충 Task에 부족 W/T를 연결해 두고, 적치 완료된 BOX를 그 W/T에 먼저 할당한다 〔REQ-OUB-MIX-017(확인필요)〕
- [확인필요] 마감이 더 빠른 W/T의 선점은 Action 전송 전까지만 허용한다 〔REQ-OUB-MIX-017(확인필요)〕
- [확인필요] 3층 마감 역산 리드타임에는 디팔레타이징 → BOX Shuttle 적치 → 인출 시간을 넣는다. 마감 안에 확보할 수 없으면 마감 내 해소 불가로 처리한다(→ P28 3층 출고 구성 5절) 〔REQ-OUB-MIX-017(확인필요)〕
- [확인필요] 부족 유형·수량과 긴급 보충 Task를 부족 이력과 전략 이력에 남긴다 〔REQ-OUB-MIX-017(확인필요)〕
- [확인필요] 할당 우선순위 2순위 할당도 이 방식으로 처리한다 〔REQ-OUB-MIX-017(확인필요)〕

**보충원 팔레트 고르는 순서**
- ⚠ 원문 불일치: [확인필요] 긴급 보충의 팔레트 선택은 사전 보충 기준(REQ-OUB-MIX-014 ③ — 입고월 FIFO 우선, 같은 입고월 안에서 잔량 최소·부분 팔레트 우선)을 따른다 〔REQ-OUB-MIX-017(확인필요)〕
- ⚠ 원문 불일치: 긴급 보충 AS/RS 팔레트는 잔량 최소(조합) → 부분 팔레트 → 입고월 FIFO 순으로 고른다. FIFO와 충돌하면 잔량 최소를 우선한다 〔BR-MST-ALC-009〕

### 3-3. BOX Shuttle 적치율 임계치

- BOX Shuttle 적치율이 임계치에 도달하면 (WCS→대시보드·파워유저) 사용자 알람을 보내 사전 조치하게 한다 〔K32-OV05, BR-OUB-MIX-018, REQ-OUB-MIX-020, K32-F01.03, BR-EQP-BSH-012, REQ-OUB-MIX-014〕
- 적치율이 임계치(「창고 기초속성」) 이상이면 3층 사전 보충 소요량을 여유 용량(임계치까지 남은 수용량) 안으로 줄인다. 사전 보충은 여유 용량 상한 안에서만 만든다 〔BR-EQP-BSH-018, REQ-EQP-BSH-014, BR-OUB-MIX-018, REQ-OUB-MIX-014〕
- 적치율 임계치로 긴급 보충을 막거나 줄이지 않는다(REQ-OUB-MIX-017 ⑦(확인필요)도 같은 내용이다) 〔BR-OUB-MIX-018, REQ-EQP-BSH-014, REQ-OUB-MIX-017〕
- 줄어든 사전 보충분은 이후 긴급 보충으로 채워진다 〔REQ-EQP-BSH-014〕
- 상한을 적용·해제한 시점과 줄인 수량을 전략 이력으로 남긴다 〔REQ-EQP-BSH-014〕
- ⚠ 원문 불일치: 3층 보충 중 적치율이 임계치에 도달해도 보충을 막지 않는다(사전·긴급을 나누지 않고 「보충」 전체로 적음). 위의 「사전 보충은 여유 용량 상한 안에서만 만든다」와 적용 범위가 다르게 읽힌다 〔BR-EQP-BSH-012, REQ-OUB-MIX-020〕

### 3-4. 수요가 줄었을 때

- 출고예정이 변경·취소되어도 이미 BOX Shuttle에 보충한 BOX는 되돌리지 않는다. BOX Shuttle 재고로 두고 이후 출고에 할당 우선순위 1순위로 쓴다 〔BR-OUB-MIX-020, REQ-OUB-MIX-022〕
- ⚠ 원문 불일치: 3층 사전 보충의 대상 범위는 새벽 생성분으로 고정한다. W/T 수신·설비 실적 수신 때 보충 소요량(W/T 할당분·진행 중 보충량 반영)만 갱신한다 〔REQ-OUB-MIX-014〕
- ⚠ 원문 불일치: 출고예정 취소·수량 변경, W/T 할당 반영 등으로 3층 사전 보충 소요량이 갱신된다(출고예정 변경도 재계산 계기로 적음) 〔BR-OUB-MIX-031〕
- 보충 소요량 갱신 결과 제품 단위 소요량이 0 이하가 되면, Action 전송 전 사전 보충 작업은 취소하고 보충원 AS/RS 팔레트 예약을 해제한다. 취소 경계는 Action 전송 전이다 〔BR-OUB-MIX-031, K32-EX05, REQ-OUB-MIX-028〕
- Action을 이미 보낸 작업(AS/RS 배출·디팔레타이징 시작)은 끝까지 수행한다 〔BR-OUB-MIX-031, K32-EX05, REQ-OUB-MIX-028〕
  - 이유: 전량 해체가 시작되면 해체 BOX를 받을 Task가 없어 라인에 남는다 〔REQ-OUB-MIX-028〕
- 남는 BOX는 BOX Shuttle 미예약 재고로 두고, 다음 소요량 계산·할당에서 먼저 쓴다 〔BR-OUB-MIX-031, K32-EX05, REQ-OUB-MIX-028〕
