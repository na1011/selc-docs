# [프로세스] 팔레트 작업 상태 추적

> 키워드: SYS-ARC · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「작업지시 체계」(팔레트 작업 상태 값), 「운반 설비」, 「단말」, 「설비 공통·설비사」(도착 지연 기준 시간)
> **이름만 쓰는 묶음**: 「팔레트」, 「WCS 위치」, 「재고 수량」, 「시스템」, 「W/T」, 「출고 오더」
> **이어지는 프로세스**: 앞 → P42 작업지시 생성·실행 · 뒤 → P44 설비 에러·Reject 처리(오류 긴급 조치), P11 3층 출고대 도착 팔레트 처리(행선지 표시)

## 1. 범위
팔레트가 Workflow로 이어지는 이동을 하는 동안, 받은 신호로 팔레트 작업 상태(현재 위치·작업 상태·다음 위치)를 갱신하고 보여 주는 일이다.
1층에 한정하지 않고 Workflow로 이어지는 모든 팔레트 이동에 적용한다 〔REQ-SYS-ARC-016〕

## 2. 흐름
1. (설비·운반 수단·작업자→WCS Execution) 신호가 들어온다: 설비 실적, 수직반송기 출발·도착 신호, AMR 결과, WCS PDA 스캔 〔K01-F01.00, REQ-SYS-ARC-015〕
   - AFL 단계: (WCS→생기연 ECS) 이송 작업지시(팔레트 ID, 출발 위치, 도착 위치)를 보내고, (생기연 ECS→WCS) 출발·완료 결과를 받는다 〔REQ-EQP-VND-013〕
2. (WCS Execution) WCS 작업 상태(Task·Workflow·Action)와 받은 신호를 합쳐 팔레트 작업 상태(현재 위치·작업 상태·다음 위치)를 갱신한다 〔K01-F01.00, REQ-SYS-ARC-015, BR-SYS-UI-008, REQ-EQP-VND-013〕 (잠정 §9-7)
3. (WCS Execution) Workflow 다음 단계로 진행한다 〔K01-F01.00〕
4. (작업자, WCS PDA·PC) 팔레트 ID로 현재 위치·작업 상태·다음 위치를 조회한다 〔G096, BR-SYS-UI-007, REQ-SYS-UI-015〕 — 화면은 6절

## 3. 조건·규칙

### 3-1. 근거 신호
- 작업지시가 없는 유인지게차 단계는 PDA 스캔을 신호로 본다. 도착 스캔은 필수, 출발 스캔은 선택이다 〔REQ-SYS-ARC-016〕
- 수직반송기도 작업지시 대상으로 포함한다 〔BR-SYS-UI-008〕

### 3-2. 현재 위치
- 현재 위치는 마지막으로 받은 신호의 위치다. 출발 신호면 이송 중 셀, 도착 신호면 도착 포트·셀이다 〔REQ-SYS-ARC-016〕
- WCS 재고 팔레트는 현재 위치가 재고 위치와 같아야 한다. 다르면 오류로 표시한다 〔REQ-SYS-ARC-016〕
- WCS 재고가 아닌 이동(1층 → 3·4층 수작업 이동, 수작업 영역 운반)은 작업 기준으로만 관리한다 〔REQ-SYS-ARC-016〕

### 3-3. 다음 위치
- 다음 위치는 Workflow 다음 단계의 목적지다 〔REQ-SYS-ARC-016〕
- 팔레트갈이 대상이면 바뀐 경로의 다음 단계가 다음 위치다 〔REQ-SYS-ARC-016〕

## 4. 주고받는 정보
| 송신→수신 | 시점 | 업무 항목 | 출처 |
|---|---|---|---|
| WCS→생기연 ECS | AFL 단계 이송 지시 시 | 팔레트 ID, 출발 위치, 도착 위치 | 〔REQ-EQP-VND-013〕 |
| 생기연 ECS→WCS | AFL 출발·완료 시 | 출발·완료 결과 | 〔REQ-EQP-VND-013〕 |

## 5. 예외
| 경우 | 처리 | 출처 |
|---|---|---|
| 출발 신호 없이 도착 신호가 온다 | 출발도 함께 처리하고 이력에 표시한다 | 〔REQ-SYS-ARC-016〕 |
| 같은 신호가 중복해 온다 | 한 번만 반영한다 | 〔REQ-SYS-ARC-016〕 |
| 작업지시가 없는 팔레트의 신호가 온다 | 미지시 신호로 기록하고 알람한다 | 〔REQ-SYS-ARC-016〕 |
| 출발 후 기준 시간 안에 도착이 없다 | 오류로 판단한다 | 〔REQ-SYS-ARC-016, BR-MST-EQP-028〕 |

- 위 기준 시간은 설비 기준정보에 설비별로 둔 도착 지연 기준 시간이다 〔REQ-SYS-ARC-016〕
- 오류 상태(도착 지연·신호 불일치·위치 불일치)는 사유를 함께 보여 주고 긴급 조치로 연결한다 〔REQ-SYS-UI-016〕

## 6. 기능·화면

### 6-1. WCS PDA 팔레트 조회
- WCS PDA로 팔레트 ID를 스캔하면 현재 위치·작업 상태·다음 위치(목적지)를 조회한다 〔G096, BR-SYS-UI-007, REQ-SYS-UI-015〕
- 유인지게차 작업을 고려한 기능이다 〔BR-SYS-UI-007〕
- 대상은 1층에 한정하지 않고 WCS가 작업지시·추적하는 전체 프로세스다 〔BR-SYS-UI-007, REQ-SYS-UI-015〕

### 6-2. 팔레트 작업 추적 화면 〔REQ-SYS-UI-016〕
- 조회 결과: 팔레트 ID, 현재 위치(셀·층·구역), 팔레트 작업 상태, 현재 Task·Action과 이송 수단(설비·AMR·수직반송기·유인지게차), 마지막 수신 신호와 시각, 다음 위치(Workflow 다음 단계 목적지), Workflow 진행 단계(n/N), 관련 W/T·오더·출고 DOCK 〔REQ-SYS-UI-016〕
- 대상: WCS 재고 팔레트와 WCS 재고가 아닌 이동(1층 → 3·4층 수작업 이동, 수작업 영역 팔레트 운반) 모두 〔REQ-SYS-UI-016〕
- 유인지게차 단계는 같은 화면에서 도착 스캔으로 이동 완료를 입력해 다음 단계로 넘긴다 〔REQ-SYS-UI-016〕
- 3층 출고대 행선지 표시는 이 기능을 쓴다 〔REQ-SYS-UI-016〕 → P46 단말 화면·알림, P11 3층 출고대 도착 팔레트 처리
- PC에서도 팔레트 ID로 같은 내용과 진행 이력(Task → Workflow → Action, 수신 신호 이벤트)을 조회한다 〔G096, REQ-SYS-UI-016〕
- 이 화면에서 해당 Task의 전략 이력으로 바로 이동한다 〔REQ-SYS-ARC-017〕 → P46 단말 화면·알림(전략 이력 조회)
