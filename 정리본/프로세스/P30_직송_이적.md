# [프로세스] 직송 이적

> 키워드: OUB-TRF · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「팔레트」(팔레트 유형·팔레트갈이·팔레트 ID), 「거래처·인도처」(배송 팔레트 유형), 「출고 업무 용어」(이적), 「작업지시 체계」(Workflow·Work·Task), 「W/T」(피킹 W/T·W/T 확정), 「운반 설비」(AMR·수직반송기·유인지게차), 「할당 전략」(정렬 기준·초기 전략 값 — 회피·팔레트 고르는 순서), 「LOT·제조번호」(입고월 FIFO)
> **이름만 쓰는 묶음**: 「출고 오더」, 「AS/RS」, 「GANTRY」, 「3층 디팔레타이징·MIXED」, 「HU」, 「단말」, 「WCS 위치」, 「시스템」, 「재고 수량」(잔량), 「재고 이력·관리단위」(출고 이력)
> **이어지는 프로세스**: 앞 → P20 출고 배치 편성, → P24 FULL 팔레트 출고, → P23 GANTRY 출고(1층 MIXED), → P28 3층 출고 구성(3층 MIXED) · 뒤 → P31 출고완료 확정(전달 완료 자동 출고확정·인도처별 실적·PARTIAL 규칙의 주인) · 함께 → P29 수작업 GTP 출고(잔량·1층 이동 규칙의 주인), → P13 설비 출고 불가 재할당 · 관련 → P32 재고 할당(할당 공통 단계)

## 1. 범위

- 직송 피킹 W/T를 받아 출고 팔레트 유형과 배송 팔레트 유형을 비교할 때 시작한다.
- 유형이 다르면 팔레트를 3층으로 유도하고, 전달 완료 때 출고확정한다. 3층에서 작업자가 이적한 뒤, 새 팔레트를 1층 출고 DOCK으로 옮긴다.
- 유형이 같으면 이적 없이 출고 DOCK으로 바로 간다(3-4).

## 2. 흐름

1. (EWMS→WCS) 직송 피킹 W/T를 받는다. FO, 인도처, 출고 DOCK, 배송 팔레트 유형이 들어 있다
2. (WCS) 출고 팔레트 유형과 배송 팔레트 유형을 비교한다. AS/RS FULL 팔레트는 할당 팔레트의 유형을, MIXED 팔레트는 출고 구성 설비의 팔레트 유형을 쓴다
3. 유형이 다르면 팔레트갈이 대상으로 보고 3층으로 유도한다(Workflow 가변)
   - AS/RS FULL 팔레트는 3층 AS/RS 출고대로 배출한다
   - 1층 GANTRY MIXED 팔레트는 GANTRY 출고대 → (AMR) → 수직반송기 → 3층으로 옮긴다
   - 3층 MIXED 팔레트는 유인지게차로 3층 안 이적 위치로 옮긴다. WCS 작업지시는 없다
4. (WCS) 3층 전달 완료 때 출고확정한다 → (WCS→EWMS) 피킹 W/T 실적을 보낸다. 한 팔레트에 인도처가 여럿이면 원팔레트ID-n으로 나눠 보낸다 → WCS 재고에서 뺀다(3-3)
   - 전달 완료 시점: AS/RS FULL 팔레트는 3층 배출 완료, 1층 GANTRY MIXED는 수직반송기 3층 도착 신호, 3층 MIXED는 구성 완료 보고다
5. (작업자) 3층에서 이적한다. 새 팔레트 ID·HU는 EWMS가 처리한다(WCS 재고 밖)
6. 이후 이적한 팔레트를 W/T의 출고 DOCK으로 옮긴다. EWMS가 PDA 선행작업 후 생성한 W/T를 받아 WCS가 작업지시한다(→ P29 수작업 GTP 출고 2-3과 같은 흐름)

## 3. 조건·규칙

### 3-1. 이적 대상 판정

- 출고 유형이 직송이고 보관 팔레트 유형이 W/T 팔레트 유형과 다르면 이적 대상이다
- AS/RS FULL 팔레트 배출 또는 MIXED(1층 GANTRY·3층)로 만든 팔레트의 유형이 배송 팔레트 유형과 다르면 팔레트갈이(이적)가 필요하므로 3층으로 유도한다. 이적은 3층에서 한다
- 직송 출고 때 팔레트 유형을 비교해 이적 대상을 판별하고 3층으로 배출을 지시한다
- 팔레트갈이 판정 시점은 Task 생성 시점이다(잠정 §9-7)
  - Work에는 W/T의 배송 팔레트 유형만 담고, 팔레트갈이 여부는 작업지시가 나가는 Task를 만들 때 판정해 Task에 표시한다
  - 이유: FULL은 실제 팔레트가 할당·예약될 때 정해지고, MIXED는 출고 구성 설비(1층 GANTRY / 3층)가 Task를 만들 때 정해진다. 그래서 Work 시점에는 비교할 팔레트 유형을 알 수 없다
  - 판정 결과로 Task의 Workflow 목적지를 정한다. 갈이 필요 = 3층 출고대·이적 위치, 불필요 = W/T 출고 DOCK
  - 설비 출고 불가로 재할당되면 새 Task에서 다시 판정한다(→ P13 설비 출고 불가 재할당)
  - 사전 보충 계획·대시보드용으로 Work 시점에 「갈이 예상」(MIXED 설비 유형 ≠ 배송 팔레트 유형)을 참고로 보여 줄 수 있다. 확정 판정은 Task 시점이다

### 3-2. 배출 층·경로

- 이적 대상은 AS/RS 출고대로 배출한다
- ⚠ 원문 불일치: 이적 대상은 무조건 3층으로 배출한다
- ⚠ 원문 불일치: 직송 이적이 필요한 팔레트는 「3층(4층)」 전달 완료 시점에 출고확정한다(4층도 적음)
- 팔레트갈이 이동 흐름(이송 단계·수단·출고확정을 일으키는 단계 = 전달 완료 시점)은 Workflow 설정으로 바꿀 수 있게 한다. 예: AS/RS Bypass 경로로 전환

**회피**
- AS/RS FULL 팔레트는 할당 전략 정렬에서 배송 팔레트 유형과 같은 AS/RS 팔레트를 먼저 고른다
- MIXED는 설비 팔레트 유형이 고정이라 팔레트갈이를 피할 수 없다

**팔레트 고르는 순서**
- ⚠ 원문 불일치: 직송 이적은 수량 일치 팔레트를 먼저 고르고, 그다음 잔량 최소 → 부분 팔레트 → 입고월 FIFO 순을 쓴다
- ⚠ 원문 불일치: 초기 전략 값 ⑤ 직송 이적 — AS/RS 팔레트(수량 일치 팔레트 → 잔량 최소 → 입고월 FIFO). 「부분 팔레트」 단계가 없다

### 3-3. 출고확정과 재고

- ⚠ 원문 불일치: 직송 이적이 필요한 팔레트는 3층 전달 완료(AS/RS 배출 완료) 시점에 WCS가 출고확정 처리하고, 결과를 EWMS에 피킹 W/T 실적으로 보낸다. 이후 3층 이적은 WCS 재고 밖에서 한다
- ⚠ 원문 불일치: 피킹 W/T는 이적 후 출고확정 때 확정한다
- 한 팔레트 ID에 인도처가 여럿이면 원팔레트ID-1~N으로 나눠 피킹 W/T 실적(PARTIAL 허용)을 보내는 규칙은 → P31 출고완료 확정 2-2·3-1·3-2에 있다. 직송 이적도 이 규칙을 그대로 따른다. 전달 완료 시점이 팔레트별로 다른 것만 이 문서 2절 4단계에 둔다
- ⚠ 원문 불일치: 직송 이적분도 예외 없이 3·4층 전달 완료 때 출고확정으로 WCS 재고에서 빠진다(출고 이력으로 제외)
- ⚠ 원문 불일치: 직송 이적분은 배출 재고 차감의 예외로 W/T 확정까지 WCS 재고를 유지한다
- 이적 후 새 팔레트 ID·HU 처리는 EWMS에서 한다
- 잔량은 GTP와 같이 전달 완료 때 이동 W/T 생성·확정을 한 번에 처리한다(→ P29 수작업 GTP 출고 3-4)

### 3-4. 출고 DOCK까지의 Workflow

- 출고 팔레트(AS/RS FULL, 1층 GANTRY MIXED, 3층 MIXED)를 1층 출고 DOCK까지 옮기는 Workflow는 현재 팔레트 유형과 배송 팔레트 유형이 다른지에 따라 경로가 달라진다
- 같으면 1층 출고 DOCK으로 바로 간다: 1층 출고대·GANTRY 출고대 → AMR·유인지게차 → 출고 DOCK / 3층 MIXED → 수직반송기 → AMR·유인지게차 → 출고 DOCK
- 다르면 3층 팔레트갈이 경로를 거친다

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| EWMS→WCS | 직송 피킹 W/T 생성 시 | W/T 번호, 제품, 수량, 인도처, FO, 출고 DOCK, 시간대 Type, 배송 팔레트 유형(EWMS가 직송 거래처별로 관리) |

- WCS는 직송 피킹 W/T의 FO·인도처·출고 DOCK·배송 팔레트 유형을 출고 프로세스(호기 할당, 팔레트 구성, 출고 DOCK 이동, 팔레트갈이 판단)에 쓴다
- 출고확정 실적(피킹 W/T 실적)의 항목은 → P31 출고완료 확정 4절에 있다.
