# [프로세스] GANTRY 장기 보관 재고 AS/RS 투입

> 키워드: EQP-GNT · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「GANTRY」, 「HU」, 「팔레트」, 「LOT·제조번호」, 「재고 수량」
> **이름만 쓰는 묶음**: 「AS/RS」, 「작업지시 체계」, 「재고 이력·관리단위」, 「W/T」, 「시스템」, 「단말」, 「설비 공통·설비사」, 「출고 업무 용어」, 「입고 업무 용어」
> **이어지는 프로세스**: 앞 → P38 재고조회(대상 고르기), → P18 GANTRY 호기 운영(보관호기 용량 초과 시 자동 생성) / 뒤 → P08 AS/RS 적치 / 관련 → P05 HU 확인·생성, → P45 네트워크 단절 대응

## 1. 범위
- 보관호기에 장기간 보관되는 제품을 팔레타이징해 AS/RS로 투입한다
- 사용자가 대상 BOX를 고르면 시작하고, 팔레트가 AS/RS 1층 입고대에 투입되면 끝난다. 적치는 → P08이다.
- 보관호기 용량 초과 때 WCS가 자동으로 만드는 팔레타이징도 이 프로세스를 쓴다(→ P18 §5).

## 2. 흐름
1. (WCS 사용자) 재고조회에서 GANTRY 보관일로 필터링해, 장기간 보관된다고 판단한 보관호기 BOX를 고른다
2. (WCS) 팔레타이징 Task를 만들고 전략 이력에 기록한다
   - 대상 BOX는 Task를 만들 때 작업중 재고로 묶어 출고 할당에서 제외한다
3. (WCS→EWMS) Task 생성 시점에 부착 팔레트 ID로 HU 확인을 먼저 요청한다. HU가 없으면 HU 생성까지 마쳐 「HU 확인 완료」로 둔다
4. (WCS→현대무벡스 ECS) 장기 보관 재고 팔레타이징·AS/RS 투입을 지시한다
5. (ECS) 보관호기 → 피킹호기로 옮긴다 → 1층 MIXED 팔레타이징로봇이 2316 팔레트로 구성한다 → 부착된 팔레트 ID를 재사용한다
6. (ECS) AS/RS 1층 입고대에 투입한다. 입고대에서 사이즈 체크·팔레트 유형 확인을 하고 1·2호기에 적치한다(→ P08)
7. (WCS) 재고는 BOX 출고 이력과 새 팔레트 입고 이력을 같은 변경 TASK번호로 남긴다

## 3. 조건·규칙
- 장기 보관 재고는 수작업으로 배출하지 않는다. 팔레타이징해 AS/RS로 투입한다
- 1층 MIXED 팔레타이징로봇에서는 출고 구성 작업이 장기 보관 재고 팔레타이징보다 먼저다
- 동일 LOT로만 팔레트를 구성한다
- 팔레트에 부착되어 있는 팔레트 ID를 재사용한다
- 부착 팔레트 ID를 재사용할 때 EWMS에 HU 확인·생성을 하는 것이 원칙이다
- AS/RS 투입은 내부 이동이므로 EWMS와 W/T 연동을 하지 않는다
- 장기 보관 재고 팔레타이징 팔레트는 AS/RS 2316 구역(1·2호기)에 적치한다

## 4. 주고받는 정보
| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→현대무벡스 ECS | 장기 보관 재고 팔레타이징·AS/RS 투입 지시 시 | 대상 BOX(셀, 동일 LOT), 팔레트 유형(2316), 부착 팔레트 ID, 목적(AS/RS 입고대). 출고 구성 다음 순위 |
| WCS→EWMS | 팔레타이징 Task 생성 시 | 부착 팔레트 ID로 HU 확인, 없으면 HU 생성 |

## 5. 예외 — EWMS 통신 단절과 HU 확인 비차단
- EWMS와 통신이 끊겨도 설비(팔레타이징·AS/RS 투입)가 멈추지 않게 한다
- HU 확인 결과를 설비 진행 조건으로 두지 않는다. W/T 없는 내부 이동이고 재고는 WCS가 이미 관리하기 때문이다
- 정해진 시간 안에 응답이 없으면 「HU 확인 보류」로 표시하고 팔레타이징·투입·적치는 계속한다. 복구 후 요청을 순서대로 다시 보낸다
- 보류 팔레트도 적치·위치·재고 관리와 출고 할당은 정상으로 한다. 다만 EWMS로 나가는 출고 실적(W/T 확정)을 보내기 전에 HU 확인을 먼저 끝낸다
- 재시도 결과 오류(다른 재고에 쓰이는 HU, 생성 실패 등)는 예외 목록에 올리고 파워유저에게 알람한다. HU SWAP 등 HU 작업으로 정리한다(→ P06)
- 「HU 확인 보류」 건수·경과 시간을 대시보드에 표시하고, 기준 시간을 넘으면 알린다

## 7. 미결
- [추가 협의] 장기 보관 재고 HU 확인 비차단 원칙과 응답 대기 시간 3초를 EWMS와 협의한다. 같은 비차단 원칙을 다른 HU 확인 흐름(일반입고, 디베닝 HU 생성)에도 적용할지 정한다(Q-161). §5의 비차단 처리 전체가 이 협의에 걸려 있다
