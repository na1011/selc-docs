# [프로세스] 재고조회

> 키워드: INV-QRY · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「WCS 위치」(셀 상태 — 이 화면에서 셀 상태를 바꾼다)
> **이름만 쓰는 묶음**: 「재고 수량」(재고수량·예약수량·가용수량·보류수량), 「조직·재고관리체계」(창고·화주), 「제품」(제품코드·제품명), 「팔레트」(팔레트 ID), 「GANTRY」(GANTRY 보관일), 「LOT·제조번호」(LOT·LOT 속성·Valuation Type), 「재고 이력·관리단위」(이력 유형 코드), 「작업지시 체계」(Task), 「시스템」(WCS)
> **이어지는 프로세스**: 화면에서 이어지는 처리 → P36 LOT 채번·속성 변경 / 보여 주는 값의 출처 → P33 재고 예약·보류, → P34 재고 반영·보정

## 1. 범위
- 사용자가 재고조회 화면에서 조건을 넣어 재고를 보고, 같은 화면에서 셀 상태·LOT 속성을 바꾸는 데까지다 〔K36-F00.01, K36-F00.02, REQ-INV-QRY-009, REQ-INV-QRY-013〕
- 이 문서는 화면 기능만 다룬다. 수량 구분의 뜻은 「재고 수량」 묶음에 있다.

## 2. 흐름
1. (사용자) 재고조회 화면에서 조회 조건을 넣는다: 창고, 존, 셀, 셀 상태, 설비, 화주, 모델ID, 팔레트 ID, GANTRY 보관일 등 〔K36-F00.01〕
2. (WCS) 재고와 위치(셀) 정보를 함께 보여, 기본 항목과 수량(재고·예약·가용·보류)을 표시한다 〔K36-F00.02〕
3. (사용자) 필요하면 같은 화면에서 셀 상태나 LOT 속성을 바꾼다(6-3) 〔REQ-INV-QRY-009, REQ-INV-QRY-013〕

## 3. 조건·규칙
- 조회 조건은 창고(필수)와 기본 항목으로 지정한다 〔REQ-INV-QRY-006〕
- 사용자 권한에 따라 접근할 수 있는 화주의 재고만 보인다 〔REQ-INV-QRY-006〕
- 장기 체류 재고조회 화면은 따로 두지 않는다. 재고조회에서 통합 관리하고, GANTRY 보관일 조회옵션으로 걸러 본다 〔BR-INV-QRY-009, REQ-INV-QRY-014, G024〕

## 6. 기능·화면

### 6-1. 표시 항목
- 기본 항목: 창고, 존, 셀, 셀 상태, 설비, 화주, 모델ID(제품코드), 모델명(제품명), 팔레트 ID, 재고수량, 예약수량, 가용수량, 보류수량 〔BR-INV-QRY-001, K36-OV02, REQ-INV-QRY-001〕
- LOT, LOT 속성도 함께 보여 준다 〔BR-INV-QRY-001, REQ-INV-QRY-001〕
- 셀 상태를 표시한다 〔G108, REQ-INV-QRY-002〕
- 수량은 재고수량·예약수량·가용수량·보류수량으로 나눠 표시한다 〔REQ-INV-QRY-003〕
- 예약수량에서 예약 상세(Task ID, 작업 유형, 수량, 생성 시각)를 볼 수 있다 〔REQ-INV-RSV-011〕
- 예약 작업 유형·보류 사유를 함께 보여, 가용에서 빠진 사유를 알 수 있게 한다 〔REQ-INV-UNT-030〕
- GANTRY 보관일 항목을 둔다 〔REQ-INV-QRY-014〕
- 화면에 GANTRY 보관일과 경과 일수를 표시한다 〔REQ-EQP-GNT-020〕

### 6-2. 조회옵션·집계
- GANTRY 보관일 조회옵션: 보관일 기간 또는 경과 일수 이상으로 걸러 장기 체류 재고를 본다 〔REQ-INV-QRY-014, G024, BR-INV-QRY-009〕
- 재고조회·이력 조회 화면에서 이력 유형 코드로 거른다 〔REQ-INV-UNT-023〕
- 제품별·존별·설비별 합계 보기를 제공한다 〔REQ-INV-QRY-006〕
- 엑셀 다운로드를 제공한다 〔REQ-INV-QRY-006〕

### 6-3. 화면에서 하는 처리
- 셀 상태 변경은 재고를 보면서 처리할 수 있도록 재고조회 화면에 통합한다 〔REQ-MST-LOC-030, REQ-INV-QRY-009〕
- 재고조회 화면에서 LOT 속성 변경(파손 등 사유로 Valuation Type 변경 등)을 처리할 수 있다. 처리 순서는 → P36 LOT 채번·속성 변경 〔REQ-INV-QRY-013〕

## 7. 미결
- 재료에 미결 기록은 없다.
