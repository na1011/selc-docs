# [프로세스] 제품마스터 수신·관리

> 키워드: MST-PRD · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「제품」, 「조직·재고관리체계」(PLANT → 화주)
> **이름만 쓰는 묶음**: 「시스템」, 「팔레트」(공팔레트), 「TRASH BIN」, 「에러·사유코드」(Reject), 「재고 수량」, 「작업지시 체계」(Task)
> **이어지는 프로세스**: 관련 → P47 기준정보 관리 · 뒤 → P03 디베닝입고(LEQ·Product Code 사용), P42 작업지시 생성·실행(경로 속성)

## 1. 범위
EWMS가 보낸 제품마스터를 받아 WCS 제품마스터에 반영하고 이력을 남기는 일과, WCS 자체 생성 제품을 화면에서 등록하는 일이다.

## 2. 흐름

### 2-1. EWMS 제품마스터 수신
1. (EWMS→WCS) 제품마스터를 일 1회 일괄 송신한다 〔BR-MST-PRD-011, K13-F01.01, REQ-MST-PRD-003, REQ-MST-PRD-011〕
2. (EWMS→WCS) EWMS에서 제품 정보가 바뀔 때마다 변경분을 송신한다 〔BR-MST-PRD-011, K13-F01.02, REQ-MST-PRD-003, REQ-MST-PRD-011〕
3. (WCS) 받은 제품마스터를 PLANT → 화주 맵핑으로 화주별 제품으로 등록한다 〔K06-F00.03, K06-IF01〕
4. (WCS) 제품(화주 + 제품코드) 단위로 신규 등록하거나 갱신한다 〔REQ-MST-PRD-013, K13-F01.03〕
5. (WCS) 바뀐 내용을 변경 이력으로 남긴다: 제품, 변경 속성, 변경 전·후 값, 수신 구분(일괄/변경), 수신 일시 〔K13-F01.03, REQ-MST-PRD-013〕
   - 값이 같으면 이력을 남기지 않는다 〔REQ-MST-PRD-013〕
6. (WCS) 수신 원문과 건수, 처리 결과(등록/갱신/오류), 오류 사유를 수신 이력으로 보관한다 〔REQ-MST-PRD-013〕

### 2-2. WCS 자체 생성 제품 등록
1. (WCS) EWMS에서 제품코드를 받지 않는 WCS 자체 생성 제품(공팔레트, TRASH BIN)을 WCS 제품관리 화면에서 직접 등록·수정한다 〔K13-F02.00, REQ-MST-PRD-007〕

## 3. 조건·규칙
| 조건 | 처리 | 출처 |
|---|---|---|
| 등록 출처가 WCS 자체인 제품 | EWMS 제품마스터 수신이 덮어쓰거나 삭제하지 않는다 | 〔REQ-MST-PRD-008, REQ-MST-PRD-013〕 |
| 일괄 송신에 없는 제품 | 삭제하지 않고 그대로 둔다(재고·이력 참조 유지) | 〔REQ-MST-PRD-013〕 |
| 경로를 정하는 속성(디베닝 대상·팔레트 입고 대상·GANTRY 작업여부 등)이 바뀜 | 이미 만든 Task는 기존 값으로 진행하고, 이후 생성하는 Task부터 새 값을 적용한다 | 〔REQ-MST-PRD-013〕 |
| LEQ가 바뀜 | 재고를 다시 환산하지 않는다(재고 수량 단위는 「재고 수량」 묶음). 변경은 제품마스터 변경 이력으로 남긴다 | 〔REQ-MST-PRD-018〕 |

## 4. 주고받는 정보
| 송신→수신 | 시점 | 업무 항목 | 출처 |
|---|---|---|---|
| EWMS→WCS | 일 1회 일괄 송신, EWMS 변경 시마다 | 제품코드, 속성값(Product Code, 디베닝 대상 구분값 등), LEQ(UOM 3레벨 수량) | 〔K13-IF02, K06-IF01〕 |

- ⚠ 원문 불일치: 제품마스터 수신 항목에 PLANT(→ 화주 맵핑)가 온다 〔K06-IF01〕
- ⚠ 원문 불일치: 제품마스터 수신 항목에 화주가 온다 〔K13-IF02〕
- 연동 속성 목록과 일괄 송신 시각은 미결이다(7절 Q-025) 〔REQ-MST-PRD-003〕

## 5. 예외
| 경우 | 처리 | 출처 |
|---|---|---|
| Product Code가 없는 제품 | 수신할 때 알람한다 | 〔K13-EX01, REQ-MST-PRD-002〕 |
| 〃 | 수신 오류로 남긴다(LEQ 누락과 같은 방식) | 〔REQ-MST-PRD-002〕 |
| EWMS 제품인데 3레벨 수량(LEQ)이 없거나 0 | 수신 오류로 남기고 알람한다 | 〔REQ-MST-PRD-018〕 |
| 일괄 송신이 들어오지 않음 | 알 수 있게 한다 | 〔REQ-MST-PRD-013〕 |

- Product Code가 비어 있으면 그 제품의 모든 BOX가 불일치로 Reject되어 입고가 막힌다 〔REQ-MST-PRD-002〕
- LEQ가 없으면 디베닝 팔레타이징 적재 수량 계산과 부분 팔레트 판정을 할 수 없어 그 제품의 입고가 막힌다 〔REQ-MST-PRD-018〕

## 6. 기능·화면
- 제품마스터 변경 이력을 화면에서 제품·기간·속성으로 조회한다 〔REQ-MST-PRD-013〕
- WCS 제품관리 화면에서 자체 생성 제품을 등록·수정한다(2-2) 〔REQ-MST-PRD-007〕

## 7. 미결
- [미결 Q-025] 제품마스터 연동 속성 목록 확정 — 규격, 중량, 팔레트 유형을 EWMS에서 받는지, 중포장 입수(UOM 2레벨 수량)를 받는지(다른 센터), 일괄 송신 시각. 이미 정한 것: 연동 주체 EWMS, 일 1회 일괄 + 변경 시 송신, 변경 이력은 WCS 관리 〔Q-025〕
