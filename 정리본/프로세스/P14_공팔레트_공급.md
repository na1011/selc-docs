# [프로세스] 공팔레트 공급

> 키워드: MST-EQP · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「팔레트」, 「AS/RS」, 「설비 공통·설비사」, 「GANTRY」, 「3층 디팔레타이징·MIXED」, 「로지스올 입고 설비」, 「할당 전략」(공팔레트 묶음 피킹은 할당 전략이 필터만 한다 — 필터 항목)
> **이름만 쓰는 묶음**: 「시스템」, 「작업지시 체계」, 「운반 설비」, 「단말」, 「HU」, 「출고 업무 용어」, 「입고 업무 용어」, 「LOT·제조번호」, 「TRASH BIN」, 「W/T」
> **이어지는 프로세스**: 앞 → P28 3층 출고 구성·P23 GANTRY 출고(디팔레타이징으로 공팔레트가 나옴) / 쓰는 공통 단계 → P09 AS/RS 인출, P08 AS/RS 적치(3층 입고대), P17 설비 접점 인계, P11 3층 출고대 도착 팔레트 처리 / 뒤 → P23 GANTRY 출고·P28 3층 출고 구성(공급한 공팔레트로 MIXED 출고 팔레트 구성), P03 디베닝입고(3층 입고 팔레타이징로봇이 공급받은 공팔레트로 팔레타이징) / 옆 → P05 HU 확인·생성(매거진 배출 묶음 검증)

## 1. 범위
팔레타이징 설비가 쓰는 공팔레트를 대 주는 일과, 디팔레타이징에서 나온 공팔레트를 모아 AS/RS에 다시 보관하는 일을 함께 다룬다.
- 공급: 설비가 매거진 재고로 부족해 WCS에 공팔레트를 요청할 때 시작해, AS/RS 공팔레트 묶음이 요청 설비의 공급라인·공급 위치에 투입될 때 끝난다.
- 회수·보관: 매거진이 꽉 차 설비가 배출을 요청할 때 시작해, 공팔레트 묶음이 AS/RS에 적치될 때 끝난다.

## 2. 흐름

### 2-1. 설비 요청 공급 (모든 층 공통)
1. (설비) 공팔레트가 필요하면 매거진 재고를 WCS 지시 없이 먼저 사용한다. 매거진·디스펜서의 관리 경계는 「팔레트」 묶음 3.5에 있다.
2. (설비 ECS→WCS) 매거진 재고로 부족해 추가로 필요한 경우에만 공팔레트 투입을 요청한다. 필요한 팔레트 유형을 보낸다.
3. (WCS) 요청 유형이 요청 설비의 허용 팔레트 유형인지 확인한다.
4. (WCS) 요청 유형의 AS/RS 공팔레트 여유를 확인한다. 여유가 없으면 피킹을 지시하지 않고 공급 불가를 리턴한다(5절).
5. (WCS) 요청 설비의 층으로 공급라인(1층 공팔레트 공급라인 / 3층 공팔레트 공급라인)을 정하고, 그 공급라인을 피킹 작업지시의 행선지로 한다.
6. (WCS→현대무벡스 ECS) 요청 설비의 허용 팔레트 유형 공팔레트 묶음을 AS/RS에서 피킹하도록 작업지시한다(→ P09 AS/RS 인출).
7. 공팔레트는 요청 설비까지 제품과 같은 경로로 이동한다. 설비 접점 처리도 제품과 같다(→ P17 설비 접점 인계).
8. (현대무벡스 ECS→WCS) 공팔레트 묶음 배출 완료를 보고한다.
9. (WCS) 공팔레트 재고(AS/RS 묶음·이동 중)를 갱신한다.

층마다 공급 경로가 다르다(2-2).

### 2-2. 층별 공급 경로

**1층 GANTRY (1층 MIXED 팔레타이징로봇)**
1. (WCS→현대무벡스 ECS) 1층 GANTRY의 추가 공팔레트 투입 요청을 받으면 AS/RS 2316 공팔레트 묶음 피킹을 지시한다.
2. 공팔레트 묶음은 보충과 같은 경로(Workflow)로 보충 컨베이어를 거쳐 1층 MIXED 팔레타이징 공팔레트 공급라인으로 간다. 이 경로와 공급라인(매거진과 별개)은 「GANTRY」 묶음 3-2에 있다.

**3층 MIXED 팔레타이징로봇 (1816)**
1. (WCS→현대무벡스 ECS) AS/RS 1816 공팔레트 묶음 피킹을 지시한다.
   - [미결 Q-216] 배출라인은 3층 출고대로 지정한다(설비 공급, TRASH BIN과 같은 라인).
2. [미결 Q-216] (작업자) 3층 출고대에서 MIXED 공팔레트 공급라인(「3층 디팔레타이징·MIXED」 묶음 3-2)까지 유인지게차로 옮긴다. WCS 작업지시는 없다.
3. (WCS PDA) 스캔하면 행선지(공팔레트 투입 위치)를 보여 준다(→ P11 3층 출고대 도착 팔레트 처리).
4. (WCS) EWMS 반영은 없고 위치 이력만 남긴다.

**3층 입고 팔레타이징로봇 (로지스올, 2316·1816·1960)**
1. [미결 Q-216] (WCS→현대무벡스 ECS) 요청 유형(2316·1816·1960)의 AS/RS 묶음을 3층 출고대로 배출해 공급한다. 3층 MIXED 팔레타이징로봇과 같은 방식이다.
2. [미결 Q-216] (작업자) 3층 출고대에서 로봇 공급 위치까지 유인지게차로 옮긴다.

**3층 투입 완료 (두 로봇 공통)**
1. (설비 ECS→WCS) 투입 완료는 설비 ECS(현대무벡스·로지스올)가 공급 위치에서 묶음을 인식하면 대표 팔레트 ID로 보고하는 것을 기본으로 한다.
2. (작업자→WCS PDA) 보고가 없으면 작업자가 PDA 투입 스캔으로 등록한다(보조).
   - [미결 Q-206] 설비 ECS가 투입 인식 보고를 지원하는지는 현대무벡스·로지스올 확인 대상이다.
3. (WCS) 투입 완료 시 공팔레트 재고에서 설비 투입으로 처리한다. EWMS 반영은 없다.
   - [미결 Q-216] 이때 3층 출고대 → 공급 위치 셀 이동 이력을 남긴다.

### 2-3. 매거진 스태킹
1. (설비) 디팔레타이징으로 빈 공팔레트는 매거진 라인을 타고 매거진에 스태킹된다. WCS 지시는 없다.

### 2-4. 매거진 배출(꽉 참) → AS/RS 보관

**공통**
1. (현대무벡스 ECS→WCS) 설비 투입 요청이 없는 상태에서 매거진이 꽉 차면 매거진 배출을 요청한다. 요청 여부와 세부 판단은 설비가 한다.
2. (현대무벡스 ECS→WCS) 요청에 대표 팔레트 ID(맨 밑)와 적재 팔레트 ID 전체를 같이 보낸다.
3. (WCS) 요청을 받아 받은 대표 팔레트 ID와 적재 팔레트 ID로 묶음 구성을 등록하고 이력 로그를 쌓는다.
4. 배출 묶음의 대표 팔레트 ID·적재 팔레트 ID 검증은 → P05 HU 확인·생성.
5. (WCS→현대무벡스 ECS) 해당 팔레트(대표 팔레트 ID 묶음)의 AS/RS 적치 작업지시를 보낸다. 설비 쪽의 별도 보관 투입 요청은 없다.
6. (현대무벡스 ECS→WCS) 적치 완료를 보고하면 WCS가 공팔레트 재고를 갱신한다.

**1층 매거진**
1. 1층 매거진 배출 묶음은 1층 AS/RS 입고대로 옮겨 투입해 보관한다. 매거진 → 1층 입고대 이동 구간은 Workflow로 정한다.
   - [미결 Q-202] 매거진 → 1층 입고대 이송 수단(AMR·유인지게차)은 정해지지 않았다(7절).
2. (WCS) 1층 매거진 배출 요청을 받으면 매거진 → 1층 AS/RS 입고대 이동을 팔레트 단위 Workflow로 만든다. 단계별 이송 수단은 Workflow 설정을 따른다.
3. (WCS→현대무벡스 ECS) 입고대 투입 후 적치 작업을 지시한다(→ P08 AS/RS 적치).

**3층 매거진**
1. (작업자) 매거진에서 3층 입고대까지 유인지게차로 옮긴다. WCS 작업지시는 없다.
2. (작업자) 공팔레트 묶음을 3층 입고대로 투입한다(→ P08 AS/RS 적치 2-2).
3. (WCS→현대무벡스 ECS) 3층 입고대 투입 시 W/T 없이 WCS가 자체 생성한 Work·Task로 해당 묶음의 AS/RS 적치를 지시한다.
4. (WCS) EWMS 반영 없이 위치 이력만 남긴다.

### 2-5. 공팔레트 이력
1. (WCS) 다음 이벤트마다 공팔레트 이력을 남기고 변경 TASK번호를 남긴다: AS/RS 보관 투입(묶음 구성 등록), 묶음 피킹·공급(설비 도착), 설비 사용(팔레타이징 실적의 팔레트 ID로 제품 팔레트(HU) 전환 연결), 다시 매거진 배출 후 보관 투입 시 재구성.
2. (WCS) 공급 후의 위치는 다음 보관 투입 통보나 팔레타이징 실적에서 다시 확정한다.

## 3. 조건·규칙

### 역할 분담


| 일 | 맡는 쪽 |
|---|---|
| 매거진 공팔레트 사용, 추가 공팔레트 투입 요청 | 설비 |
| 매거진 배출 요청 | 현대무벡스 |
| AS/RS 공팔레트 피킹 작업지시, 적치 작업지시 | WCS |

### 적용 설비
세 설비 모두 같은 방식이다: 매거진 우선 사용, 추가 필요 시 설비가 요청 → WCS가 AS/RS 공팔레트 묶음 피킹 지시.

설비별로 쓰는 팔레트 유형은 각 설비 묶음(「GANTRY」 3-3, 「3층 디팔레타이징·MIXED」, 「로지스올 입고 설비」)에 있다.

| 설비 | 요청 방식 |
|---|---|
| 1층 MIXED 팔레타이징로봇 | 추가 필요 시 요청 |
| 3층 MIXED 팔레타이징로봇 | 추가 필요 시 요청 |
| 3층 입고 팔레타이징로봇 | 추가 필요 시 유형을 지정해 요청 → WCS가 해당 유형 공팔레트를 공급 |

### 그 밖의 규칙

| 조건 | 처리 |
|---|---|
| 공팔레트 묶음 피킹의 할당 | 초기 전략 값 ⑥ 「대상 지정형」이다(뜻은 「할당 전략」 묶음 초기 전략 값). 대상은 사용자·설비 요청이 정한다 |
| 같은 설비·유형의 진행 중 요청이 있음 | 요청별 공급 진행 상태를 보고 중복 지시하지 않는다 |
| 공팔레트 묶음 공급·배출 작업의 출발·도착 위치(1층) | 1층 공팔레트 묶음 배출·공급 라인 셀을 쓴다 |
| 공팔레트의 AS/RS 3·4층 배출 | EWMS 반영 없이 위치 이력만 남긴다 |
| 매거진 배출 요청 수신 | 요청 여부는 설비가 판단하고, WCS는 받아서 처리한다 |

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| 설비 ECS→WCS | 매거진 재고로 부족해 추가 공팔레트가 필요할 때(투입 요청) | 요청 번호, 설비 ID, 팔레트 유형, 필요 수량(묶음 수) |
| WCS→현대무벡스 ECS | 추가 공팔레트 투입 요청 수신 시(피킹 지시) | 팔레트 유형, 공팔레트 묶음, 목적 설비 |
| WCS→설비 ECS | 추가 공팔레트 투입 요청 수신 시 AS/RS 공팔레트 여유 없음 | 요청 번호, 공급 불가 |
| 현대무벡스 ECS→WCS | 공팔레트 묶음 배출 완료 시 | 팔레트 ID(묶음), 배출 위치 |
| 현대무벡스·로지스올 ECS→WCS | [미결 Q-206] 3층 공팔레트 묶음 공급 위치 투입 인식 시 | 대표 팔레트 ID, 설비 ID, 공급 위치(보고 없으면 PDA 투입 스캔) |
| 현대무벡스 ECS→WCS | 매거진 꽉 참 + 투입 요청 없음(매거진 배출 요청) | 설비 ID, 대표 팔레트 ID(맨 밑), 적재 팔레트 ID 전체, 팔레트 유형, 수량(장수) |
| WCS→현대무벡스 ECS | 매거진 배출 요청 수신 후(AS/RS 적치 작업지시) | 대표 팔레트 ID(묶음), 팔레트 유형 |

## 5. 예외
- 공팔레트 요청 유형이 설비 허용 유형이 아니면 공급하지 않는다. 오류 처리 방식은 원문에서 정하지 않았다.
- 추가 요청한 유형의 AS/RS 공팔레트 여유가 없으면 피킹을 지시하지 않고 요청 설비에 공급 불가를 리턴한다.
- 묶음 재고 수량(장수)과 적재 팔레트 ID 수가 다르거나, 같은 팔레트 ID가 다른 묶음에 이미 있으면 알람을 보내고 수신값 기준으로 구성을 갱신한다. 물류 진행은 막지 않는다.

## 6. 기능·화면
- 3층 공급 위치 셀을 WCS PDA 행선지로 쓴다.
- 3층 투입 완료 보고가 없을 때 쓰는 WCS PDA 투입 스캔(2-2).

## 7. 미결
- [미결 Q-202] 1층 매거진 배출 묶음의 매거진 → 1층 AS/RS 입고대 이송 수단(AMR·유인지게차, AMR이면 설비 접점 등록). 정해진 것: 배출·공급 라인 별도 구성·10대 공용, 매거진 만재 묶음은 이 라인을 쓰지 않고 1층 입고대에서 AS/RS에 보관, 이동 구간은 Workflow, 공급 요청 시 행선지 = 해당 층 공급라인.
- [추가 협의] Q-206: 3층 MIXED 공팔레트 공급라인과 3층 입고 팔레타이징로봇 공급 위치의 물리 위치, 투입 인식 보고 지원 여부 — 현대무벡스·로지스올 확인. 정해진 것: 공급라인 투입, 설비 보고 기본·PDA 보조, 입고 팔레타이징로봇도 3층 출고대로 공급.
- [미결 Q-216] 3층 공팔레트 공급라인이 3층 출고대(TRASH BIN과 같은 라인)와 별도라면 AS/RS에서 3층 공급라인으로 바로 배출하는지. 그렇다면 3층 출고대 배출·유인지게차 운반(BR-MST-EQP-025·027, REQ-MST-EQP-031·033 ②④)을 바꾸고, 3층 입고 팔레타이징로봇(로지스올) 공급 위치도 같은 라인을 쓰는지 확인한다. 정해진 것: 1층·3층 공급라인은 별도다.
