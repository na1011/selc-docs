# [프로세스] 자동화 전환

> 키워드: INV-MVT · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「EWMS BIN 코드」(AMVT·MMVT), 「WCS 위치」(수작업 영역), 「W/T」(이동 W/T·W/T 생성·확정)
> **이름만 쓰는 묶음**: 「단말」(EWMS PDA), 「작업지시 체계」(Work·Workflow), 「운반 설비」(수직반송기·AMR), 「재고 이력·관리단위」(이력 유형 코드), 「AS/RS」, 「LOT·제조번호」(제조번호), 「팔레트」(팔레트 ID), 「출고 업무 용어」(GTP·이적), 「출고 오더」(직송), 「시스템」(EWMS)
> **이어지는 프로세스**: 앞 → P04 3층 수작업 이동, → P07 수작업 영역 팔레트 운반 / 함께 → P35 W/T 연동, → P29 수작업 GTP 출고, → P30 직송 이적 / 뒤 → P34 재고 반영·보정 / 관련 → P42 작업지시 생성·실행(W/T와 Work의 연결)

## 1. 범위
- 재고가 수작업 영역과 자동화 설비 사이를 넘나들 때, 그 이동을 WCS 재고에 들이거나 빼는 처리다. 수작업 → 자동화(AMVT)와 자동화 → 수작업(MMVT) 두 갈래와, EWMS PDA 작업 결과 수신이 있다

## 2. 흐름

### 2-1. 수작업 → 자동화 (AMVT)
1. (EWMS) 수작업 영역에서 시작하는 경계 이동(WCS 재고가 아닌 팔레트, 출고확정 후 운반 등)은 EWMS가 EWMS PDA로 선행작업을 한 뒤 W/T를 만든다
2. (EWMS→WCS) AMVT 이동 W/T를 보낸다(항목은 4절)
3. (WCS) W/T 맵핑 Work로 받아 입고로 등록한다. AS/RS 적치 W/T와 같은 방식이다
4. (WCS) 수작업 재고는 AMVT 로케이션을 거쳐 WCS에 입고한다
5. (WCS→설비) W/T를 받은 뒤 Workflow에 따라 필요한 작업지시(수직반송기·AMR 등)를 한다
- ⚠ 원문 불일치: [확인필요] WCS는 AMVT 위치셀에 들어온 재고를 자동화 입고로 처리한다 — 「EWMS BIN 코드」 묶음의 REQ-INV-MVT-004 ③(AMVT·MMVT는 EWMS BIN이므로 별도 재고 위치로 두지 않는다)과 어긋난다.

### 2-2. 자동화 → 수작업 (MMVT)
1. (WCS) 자동화 재고를 수작업으로 옮길 때는 MMVT 로케이션으로 위치를 전환한 뒤 출고한다
   - [확인필요] WCS는 자동화 배출 재고를 MMVT로 위치 전환한다
2. [확인필요] (WCS→EWMS) MMVT 전환을 EWMS에 연동한다(항목은 4절)
3. (WCS→EWMS) 이 갈래에서 WCS가 W/T 생성을 요청하는 것은 GTP·직송 이적 잔량이다(WCS가 생성을 요청하는 경우의 목록은 「W/T」 묶음에 있다). 3·4층 전달 완료 때 생성 요청과 확정을 한 번에 처리하고, WCS 재고에서 출고로 뺀다(3-2 불일치 참고)
4. 그 밖의 자동화 → 수작업 이동은 EWMS가 PDA 선행작업 후 만든 W/T를 받아 W/T 맵핑 Work로 처리하고, 배출 완료 때 확정한다

### 2-3. EWMS PDA 작업 결과 수신
1. (EWMS→WCS) 작업자가 EWMS PDA로 수작업 영역 ↔ 자동화 설비 작업을 하면, EWMS가 작업 직후 실시간으로 결과를 통보한다(항목은 4절)
2. (WCS) 받는 즉시 WCS 재고에 반영한다
3. (WCS) 반영은 W/T 맵핑 Work와 같은 방식으로 하고, 이력 유형 코드로 경계 이동을 구분한다
- ⚠ 원문 불일치: 수작업 영역 ↔ 자동화 설비 경계의 재고 변동은 EWMS PDA 작업 결과를 EWMS가 실시간 통보하고, WCS는 받는 즉시 재고에 반영한다 — 「W/T」 묶음의 BR-INV-WT-007(EWMS와 WCS 재고는 W/T 생성·확정으로만 동기화한다)과 어긋난다.

## 3. 조건·규칙

### 3-1. 경계 이동을 누가 만드나
- WCS는 수작업 영역에서 시작하는 경계 이동을 자체 판단으로 만들지 않는다. EWMS가 PDA 선행작업 후 만들어 보낸 W/T를 받아 처리한다

### 3-2. GTP·직송 이적 잔량
- ⚠ 원문 불일치: 자동화 재고를 수작업으로 옮길 때는 MMVT 로케이션으로 위치를 전환한 뒤 출고하며, GTP·직송 이적 잔량은 이 자동화 → 수작업(MMVT) 경로에서 WCS가 W/T 생성을 요청하는 경우다
- 반대쪽 기록은 → P29 수작업 GTP 출고에 있다: GTP·직송 이적 잔량 팔레트는 MMVT 전환 없이 출고 수작업 영역으로 보내고, DEST는 9013·RCV3 / 9014·RCV4다.
