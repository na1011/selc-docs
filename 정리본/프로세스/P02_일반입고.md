# [프로세스] 일반입고

> 키워드: INB-PLT · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「AS/RS」, 「W/T」, 「EWMS BIN 코드」, 「HU」, 「재고 수량」, 「에러·사유코드」, 「입고 오더」
> **이름만 쓰는 묶음**: 「시스템」, 「설비 공통·설비사」, 「운반 설비」, 「작업지시 체계」, 「팔레트」, 「제품」, 「LOT·제조번호」, 「단말」, 「창고 기초속성」, 「WCS 위치」, 「입고 업무 용어」, 「재고 이력·관리단위」, 「재고 운영 용어」
> **이어지는 프로세스**: 앞 → P01 EWMS 작업정보 수신, 뒤 → P08 AS/RS 적치, P10 AS/RS Bypass 이송, P12 AS/RS 용량 부족 배출, P11 3층 출고대 도착 팔레트 처리, P44 설비 에러·Reject 처리, P37 제조번호 수신·추적, 관련 → P04 3층 수작업 이동, P05 HU 확인·생성

## 1. 범위

1층에서 하역하거나 입고 수작업 영역에서 수작업 팔레타이징한 팔레트를 1층 AS/RS에 투입한다. 〔K26-OV01〕 투입 시점에 WCS가 EWMS 내역을 확인해 AS/RS 보관을 결정한다. 〔K26-OV02〕 적치 W/T 수신으로 시작해, 적치 W/T 확정(가용 전환) 또는 배출 건의 W/T 확정·재고 차감으로 끝난다.

**진입 조건**

| 조건 | 처리 | 출처 |
|---|---|---|
| WCS는 입고 오더 유형별로 투입 경로(1층 AS/RS / 3층)를 구분한다 | 1층 AS/RS는 이 프로세스, 3층은 → P04 3층 수작업 이동 | 〔REQ-MST-ORD-001〕 |
| 입고 유형 = 국내생산 / 해외생산 | 1층 AS/RS에 투입한다(이 경로 적용). (EWMS) 입고 오더 → 유형별 경로 결정 → 1층 AS/RS 투입 | 〔BR-MST-ORD-001, BR-INB-PLT-005, K16-F01.00〕 |
| 국내생산 입고 | 1층 하역장 하차 → 1층 AS/RS 투입 | 〔K16-F04.00, G180〕 |
| 해외생산(역수입) 입고 | 1층 하역장 하차 → 1층 AS/RS 투입 | 〔K16-F05.00, G181〕 |
| 제품마스터 「팔레트 입고 대상」 = Y(대형/일반) | 팔레트 입고 경로(이 프로세스)로 간다 | 〔BR-MST-PRD-002〕 |
| EWMS W/T 행선지 = 보관 | AS/RS에 적치한다 | 〔BR-INB-PLT-003〕 |

## 2. 흐름

### 2-1. 적치 W/T 수신과 재고 등록

1. (EWMS→WCS) EWMS가 입고 오더 기준으로 적치 W/T를 생성한 뒤 실시간으로 WCS에 보낸다. 〔K26-F00.01, BR-INB-PLT-013, BR-INB-PLT-020, REQ-INB-PLT-020, BR-INV-WT-010〕
2. (WCS) 적치 W/T를 저장하고, 같은 시점에 그 팔레트를 입고 이력으로 WCS 재고에 등록한다. 〔K26-F00.01, REQ-INB-PLT-020, BR-INV-WT-001, BR-INV-WT-010, BR-INB-PLT-014, BR-INB-PLT-026, REQ-INB-PLT-014, REQ-INB-PLT-025〕
   - 상태는 비가용(W/T 미확정)이다. 비가용 재고가 가용수량에서 빠진다는 것은 「재고 수량」 묶음에 있다. 〔BR-INV-WT-010, BR-INB-PLT-014, REQ-INB-PLT-014, REQ-INB-PLT-025, K26-F00.01〕
   - 위치는 1층 입고장 위치셀 RCV1(Stock Type 9011)이다. 〔K26-F00.01, BR-INV-WT-010, BR-INB-PLT-014, REQ-INB-PLT-014, REQ-INB-PLT-025〕
   - LOT를 채번한다. 〔K26-F00.01, REQ-INB-PLT-025〕
   - ⚠ 원문 불일치: [확인필요] WCS는 투입 시점에 실시간으로 팔레트 정보를 받아 입고 처리한다. 〔REQ-INB-PLT-005〕 — 입고 처리(재고 생성) 시점이 적치 W/T 수신 때(REQ-INB-PLT-025)와 다르다.

### 2-2. 하역·투입·목적지 결정

3. (작업자) 1층에서 하역하고, 필요하면 수작업 팔레타이징한다. 〔K26-F00.02〕
   - ATL로 하역한 팔레트는 (ATL→WCS) 하역 완료(팔레트 ID·DOCK)를 받으면 (WCS→AMR) 이송을 지시한다. 다음 이송은 항상 AMR로 한다. 〔REQ-EQP-VND-012〕
   - AMR의 목적지(AS/RS 1층 입고대 직접 / 대기존 경유)는 Workflow 설정을 따른다. 〔REQ-EQP-VND-012, BR-EQP-VND-024〕
4. (작업자) 1층 AS/RS에 투입한다. 〔K26-F00.03〕
5. (ECS) 사이즈 체크에서 규격을 넘으면 Reject한다 → 2-3. 〔BR-INB-PLT-001, K26-F00.04, REQ-INB-PLT-001〕
6. (ECS→WCS) 정상 팔레트는 팔레트 ID로 목적지(보관/Bypass)를 문의한다. 팔레트 ID, 팔레트 규격, 입고시각을 함께 보낸다. 이 문의는 W/T 생성 요청이 아니다. 〔K26-F00.05, BR-INB-PLT-002, REQ-INB-PLT-002, BR-INB-PLT-013〕
7. (WCS→EWMS) 목적지 문의를 받으면 즉시 팔레트 ID로 HU 내역(적재 내역·제조번호)을 조회한다. 〔K26-F00.06, BR-INB-PLT-021, REQ-INB-PLT-021, G119, G063, BR-INB-PLT-013〕
8. (WCS) 조회 결과를 미리 받아 둔 적치 W/T와 팔레트 ID로 연결하고, W/T DEST로 목적지를 정한다. 〔K26-F00.06, G119, BR-INB-PLT-013, BR-INB-PLT-024, REQ-INB-PLT-021, K26-OV02〕
9. (WCS) 이동 이력으로 위치를 1층 입고장(RCV1) → AS/RS 입고대로 옮긴다. Reject 배출 건도 같다(Reject도 적치 W/T 수신 후 토출한다). 〔K26-F00.08, BR-INV-WT-010, BR-INB-PLT-014, REQ-INB-PLT-014, REQ-INB-PLT-025〕
10. (WCS) HU 내역 조회로 받은 제조번호(S/N) 목록을 시리얼 이력에 남기고, 시리얼 마스터 생성·입고 이력 로그에 쓴다. → P37 제조번호 수신·추적 〔K26-F00.08, REQ-INB-PLT-022, REQ-INB-PLT-025〕
11. (WCS→ECS) 목적지(보관/Bypass/Reject)를 전달한다. 〔K26-F00.09, REQ-INB-PLT-004, K26-IF05〕
12. (ECS) AS/RS 적치 / 용량 부족 배출 / Reject 배출(ECS 판단, 에러 코드) / Bypass(AS/RS 경유 이송)를 한다. 배출된 팔레트는 유인지게차로 옮긴다. → P08 AS/RS 적치, P12 AS/RS 용량 부족 배출, P10 AS/RS Bypass 이송 〔K26-F00.10〕
13. (WCS) 결과별로 마무리한다. 〔K26-F00.11〕
    - 적치 완료: 이동 이력으로 위치를 적치 셀로 옮긴다. 적치 W/T 확정 후 가용이 된다. 〔K26-F00.11, BR-INB-PLT-014, REQ-INB-PLT-014, REQ-INB-PLT-025, BR-INV-WT-010〕
    - 용량 부족 배출·Reject: 출고대 도착 시 DEST BIN을 바꿔 적치 W/T를 확정하고, 3·4층 배출 완료 시 배출 이력으로 WCS 재고를 차감한다. 〔K26-F00.11, BR-INB-PLT-014, REQ-INB-PLT-014〕
    - Bypass(1층 → 3층, EWMS 지시): 3층 출고대 도착 시 적치 W/T를 확정한다. 〔K26-F00.11, BR-INB-PLT-018, REQ-INB-PLT-018〕

### 2-3. Reject 발생 시

1. 입고 과정(사이즈 체크 등)에서 Reject가 생긴다. 〔K26-F01.01〕
2. (ECS) Reject를 판단하고 에러 코드를 붙여 3층 출고대로 배출한다. (ECS→WCS) 에러 코드를 전달한다. Reject와 Bypass의 구분은 「에러·사유코드」 묶음에 있다. 〔K26-F01.02, BR-INB-PLT-016, G082, K26-OV02, K26-EX02〕
3. 배출된 Reject 팔레트는 유인지게차로 옮긴다. 보관하지 않고 사유코드를 달아 배출하는 규칙은 → 3. 조건·규칙 「Reject」. 〔K26-F01.03, BR-INB-PLT-009, REQ-INB-PLT-009〕
4. (WCS) ECS가 보낸 에러 코드를 Reject 사유로 기록한다. 〔REQ-INB-PLT-016〕
5. 3층 도착 시 현대무벡스가 Reject 사유를 WCS에 제공한다. 3층 배출라인 팔레트는 WCS PDA로 판단(출고 수작업 영역 이동 / 재투입 / 보류)하고 재고를 처리한다. → P11 3층 출고대 도착 팔레트 처리 〔BR-INB-PLT-012, K26-EX02〕
6. (WCS→EWMS) 1층 투입 때 HU 내역 조회로 연결해 둔 적치 W/T를 출고대 도착 시 확정한다. 확정할 때 DEST BIN을 바꾼다(→ 3. 조건·규칙). 〔BR-INB-PLT-012, REQ-INB-PLT-013, K26-IF08〕

## 3. 조건·규칙

### 목적지 결정

| 조건 | 처리 | 출처 |
|---|---|---|
| 1층 입고대 목적지 문의 | 연결된 적치 W/T의 DEST Stock Type·BIN으로 목적지(AS/RS 적치 / 3층 출고대 / 4층)를 정해 응답한다 | 〔BR-INB-PLT-034, REQ-INB-PLT-030, K26-IF02〕 |
| HU 내역 조회 응답의 행선지(층) | 쓰지 않는다. 경로는 적치 W/T DEST로 정한다 | 〔BR-INB-PLT-023, REQ-INB-PLT-021, REQ-INB-PLT-023, G063〕 |
| HU 내역 조회 ↔ 수신 W/T 연결 | 연결 키는 팔레트 ID다 | 〔BR-INB-PLT-024〕 |
| HU 내역 조회 | 제조번호(S/N)도 같이 받는다 | 〔BR-INB-PLT-022, K26-IF02〕 |
| 투입 팔레트의 팔레트 유형 | 목적지(유형별 크레인 호기·Bay 적치 / 3층 출고대 배출) 판단에 쓴다 | 〔REQ-INB-PLT-015〕 |
| 목적지 문의를 받았을 때 | 생성 요청이 아니라 수신한 적치 W/T와 연결하는 것이다. WCS가 자체 재고 변경으로 W/T 생성을 요청하는 경우는 별도다 | 〔BR-INB-PLT-013〕 |

### HU

- 입고 투입 시 HU 작업(확인·생성)은 EWMS가 선행한다. WCS는 HU 확인·생성을 하지 않는다. → P05 HU 확인·생성 〔BR-INB-PLT-023, REQ-INB-PLT-023, G063, K26-F00.06, K29-EX01〕

### W/T 확정과 재고

| 조건 | 처리 | 출처 |
|---|---|---|
| 재고 생성 시점을 적치 W/T 수신 때로 두는 근거 | EWMS가 W/T를 만들 때 재고가 이미 입고장(9011·RCV1)에 있으므로, 같은 시점·같은 위치(BIN)로 맞추면 재고대사가 단순해진다. 디베닝(RCV9 수신 시 재고 생성)과 같은 방식이다 | 〔REQ-INB-PLT-025〕 |
| 토출건(입고대 Reject·용량 부족 배출) | 적치 W/T를 받은 뒤 3·4층으로 토출한 것이다. W/T를 확정할 때 DEST BIN을 실제 도착 위치(3층 출고대 9013·RCV3 / 4층 입고장 9014·RCV4)로 바꾼다 | 〔BR-INB-PLT-017, REQ-INB-PLT-017, BR-INB-PLT-012, REQ-INB-PLT-013〕 |
| 팔레트 유형 불일치 Reject | W/T를 확정한다. DEST BIN을 3층 출고대 도착 위치(9013·RCV3)로 바꿔 EWMS에 확정한다 | 〔BR-INB-PLT-028, REQ-INB-PLT-027〕 |
| 적치 W/T 없음 Reject | W/T를 확정하지 않는다(EWMS 반영 없음) | 〔BR-INB-PLT-028, BR-INB-PLT-033, REQ-INB-PLT-027, REQ-INB-PLT-024〕 |
| 1층 투입 Bypass(1층 → 3층) | 적치 W/T로 처리한다. 4층 → 3층 Bypass는 이동 W/T로 별도다(→ P10) | 〔BR-INB-PLT-018, REQ-INB-PLT-018〕 |

### Reject

| 조건 | 처리 | 출처 |
|---|---|---|
| 입고 과정에서 Reject 발생 | Reject 사유코드(ECS 에러 코드)를 달고, AS/RS에 보관하지 않고 3층 출고대로 배출한다 | 〔BR-INB-PLT-009, REQ-INB-PLT-009〕 |
| AS/RS 투입 후 Reject | 3층 출고대 배출만 쓴다. 후진 배출 등 다른 방식은 쓰지 않는다 | 〔BR-INB-PLT-010, REQ-INB-PLT-011, G087, BR-INB-PLT-032〕 |
| 투입 전 오류 | 후진 배출한다(→ 5. 예외) | 〔BR-INB-PLT-010, BR-INB-PLT-032〕 |
| ECS가 찾은 Reject | ECS가 사유코드(에러 코드)를 WCS로 보내고, WCS가 받아 기록한다 | 〔REQ-INB-PLT-026, BR-INB-PLT-027, G082〕 |
| WCS가 찾은 Reject(적치 W/T 없음·팔레트 유형 불일치 등) | WCS가 ECS 목적지 문의에 대한 목적지 응답에 Reject와 사유코드를 담아 ECS로 보낸다 | 〔REQ-INB-PLT-026, BR-INB-PLT-027, BR-INB-PLT-030, G082〕 |
| 두 경우 모두 | Reject 이력에 사유코드와 판단 주체(ECS/WCS)를 남긴다 | 〔REQ-INB-PLT-026〕 |

- ⚠ 원문 불일치: 1층 입고대 Reject는 ECS가 판단해 에러 코드를 포함해 3층 출고대로 배출한다. 〔K26-OV02, BR-INB-PLT-016, G082〕
- ⚠ 원문 불일치: 적치 W/T 없음·팔레트 유형 불일치 Reject는 ECS가 찾는 경우와 WCS가 찾는 경우가 모두 있다. 〔BR-INB-PLT-027, REQ-INB-PLT-026〕
  - 앞 기록은 판단 주체를 ECS로만 적었고, 뒤 기록은 WCS 판단 Reject도 둔다(범위 차이).

## 7. 미결

- [추가 협의] [미결 Q-027] 1층 입고대 후진 배출 구조 가능 여부 — 현대무벡스 확인. 〔Q-027, K26-EX03〕
- Q-027의 정해진 처리: 투입 전 오류는 후진 배출한다, ECS 에러 코드 목록은 Q-169로 통합한다, 3층 출고대 배출 후 처리는 REQ-EQP-ASRS-016 기준이다, REQ-INB-PLT-010은 폐기한다. 〔Q-027, BR-INB-PLT-032〕
- [미결 Q-169] ECS가 보내는 에러 코드 목록. 〔K26-IF06〕
- [확인필요] 2-2 5·6·11단계와 4절의 목적지 문의·응답 줄에 같은 내용으로 출처를 단 요구사항 REQ-INB-PLT-001·002·004는 원문 상태가 확인필요다. 같은 줄의 규칙·흐름 기록(BR-INB-PLT-001·002, K26-F00.04·05·09, K26-IF01·05)은 상태 표시가 없다. 〔REQ-INB-PLT-001, REQ-INB-PLT-002, REQ-INB-PLT-004〕
