# [프로세스] 수작업 GTP 출고

> 키워드: OUB-MAN · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「EWMS BIN 코드」(DEST BIN·9013·RCV3·9014·RCV4·MMVT), 「W/T」(피킹 W/T·이동 W/T·W/T 확정), 「WCS 위치」(출고 수작업 영역·수작업 셀), 「재고 수량」(잔량), 「팔레트」(팔레트 ID·원팔레트ID-일련번호), 「운반 설비」(유인지게차·수직반송기·AMR), 「작업지시 체계」(Workflow·팔레트 작업 상태), 「할당 전략」(정렬 기준·초기 전략 값), 「LOT·제조번호」(입고월 FIFO)
> **이름만 쓰는 묶음**: 「출고 업무 용어」(GTP), 「AS/RS」, 「GANTRY」, 「시스템」, 「단말」, 「HU」, 「거래처·인도처」, 「출고 오더」, 「출고 배치」, 「설비 공통·설비사」, 「제품」, 「재고 이력·관리단위」(이동 이력·출고 이력)
> **이어지는 프로세스**: 앞 → P20 출고 배치 편성 · 뒤 → P31 출고완료 확정(전달 완료 자동 출고확정·인도처별 실적·PARTIAL 규칙의 주인) · 함께 → P41 자동화 전환, → P35 W/T 연동 · 관련 → P30 직송 이적(잔량·1층 이동 규칙은 이 문서가 주인이고 P30이 가리킨다), → P32 재고 할당(할당 공통 단계)

## 1. 범위

- 배치 확정된 피킹 W/T의 DEST BIN이 3·4층 출고 수작업 셀이면 시작한다.
- AS/RS 팔레트를 3층(또는 4층)으로 배출하고, 전달 완료 때 출고확정·잔량 처리를 한 뒤, 작업자가 출고 수작업 영역에서 작업한다.
- 출고 팔레트가 1층 출고 DOCK에 도착해 EWMS가 W/T를 확정하면 끝난다.

## 2. 흐름

### 2-1. 배출과 출고확정

1. (EWMS→WCS) 피킹 W/T를 받는다 → 출고 배치 확정 후 진행한다. DEST BIN이 3·4층 출고 수작업 셀(9013·RCV3 / 9014·RCV4)이면 GTP 출고로 처리한다
2. (WCS→현대무벡스 ECS) AS/RS 팔레트를 3층(또는 4층)으로 배출한다
3. (현대무벡스 ECS→WCS) 배출 완료를 알린다. 배출 완료가 곧 3·4층 전달 완료다
4. (WCS) 해당 층 수작업 셀(9013·RCV3 / 9014·RCV4)로 재고를 옮기고, 그 셀에서 출고확정한다
5. (WCS→EWMS) 피킹 W/T 실적을 보낸다. 한 팔레트에 인도처가 여럿이면 원팔레트ID-1~N으로 나눠 보낸다 → WCS 재고에서 뺀다
6. 잔량이 있으면 (WCS→EWMS) 3·4층 전달 완료 때 원팔레트ID-(N+1)로 자동화 → 수작업 이동 W/T 생성 요청과 확정을 한 번에 처리한다 → WCS 재고에서 뺀다(이후 EWMS 관리)

### 2-2. 출고 수작업 영역 작업

1. (작업자) AS/RS 출고대로 배출한 팔레트를 유인지게차로 출고 수작업 영역 로케이션까지 옮긴다. 3층 이송 컨베이어 없이 옮기며, WCS 작업지시는 없다
2. (작업자) 인도처별/FO별로 분류·분할한다. 이 작업은 EWMS 영역이다(WCS PDA 분할 없음)

### 2-3. 출고확정 후 1층 이동

- 이 절의 1층 이동 처리는 직송 이적 팔레트에도 같다(→ P30 직송 이적 2절 6단계)

1. (작업자) 3·4층 작업을 마친다 → (유인지게차) 수직반송기에 투입 → 1층 이동 → 출고 DOCK. 출고확정은 2-1에서 이미 처리했다
2. (EWMS) PDA로 선행작업을 한 뒤 W/T를 생성해 (EWMS→WCS) 알린다. W/T에는 팔레트 ID, 출발 층, 목적지 출고 DOCK이 있다
3. (WCS) 받은 W/T로 팔레트 단위 Workflow를 만들어 수직반송기·AMR에 작업지시한다. 유인지게차 단계는 작업지시 없이 PDA 스캔으로 처리한다
   - 경로: 출고 수작업 영역 → (유인지게차) 수직반송기 → 1층 → (AMR 또는 유인지게차, Workflow 설정) 출고 DOCK
4. (WCS) 이 팔레트는 WCS 재고로 등록하지 않고 운반으로 처리한다. 팔레트 작업 상태로만 관리한다
5. (WCS→EWMS) 완료되면 도착 정보를 보내 W/T를 확정한다

### 2-4. 예시

- 팔레트 1816J2323332, LEQ 4, 인도처 3곳으로 나뉜다
- 1816J2323332-1, -2, -3 → 3층 전달 완료 때 출고확정하고 인도처별 피킹 W/T 실적으로 EWMS에 보낸다 → 이후 3·4층 작업·1층 이동
- 잔량 1개 → 3층 전달 완료 때 1816J2323332-4로 이동 W/T 생성·확정 실적을 보낸다

## 3. 조건·규칙

### 3-1. GTP 대상

- AS/RS 보관 재고 중 GANTRY로 출고할 수 없는 건은 3층(또는 4층) 출고 수작업 영역으로 배출해 GTP로 출고한다
- GTP 여부는 피킹 W/T의 DEST BIN으로 정한다. DEST BIN이 3·4층 출고 수작업 셀(9013·RCV3 / 9014·RCV4)이면 GTP 출고로 보고 해당 층으로 AS/RS 배출을 지시한다(경로 = W/T DEST)
- WCS는 자체 기준으로 GANTRY 출고 불가나 GTP 여부를 판단하지 않는다. 자체 판단하면 W/T DEST와 배출 층·실적 BIN이 달라 W/T 확정이 실패한다
- 4층 출고 수작업 영역은 3층과 똑같이 운영한다(AS/RS 4층 배출 → 유인지게차 → 출고 수작업 영역 → GTP 작업 → 유인지게차 → 수직반송기 → 1층)
- 4층 GTP 출고는 3층과 같은 흐름·규칙(4층 전달 완료 때 출고확정·인도처별 원팔레트ID-n 실적)으로 처리한다

**팔레트 고르는 순서**
- ⚠ 원문 불일치: GTP는 수량 일치 팔레트를 먼저 고르고, 그다음 잔량 최소 → 부분 팔레트 → 입고월 FIFO 순을 쓴다
- ⚠ 원문 불일치: 초기 전략 값 ⑤ GTP — AS/RS 팔레트(수량 일치 팔레트 → 잔량 최소 → 입고월 FIFO). 「부분 팔레트」 단계가 없다

### 3-2. 출고 팔레트 구성

- GTP 출고 팔레트는 인도처별, 직송 차량(FO)별로 구성한다
- 3·4층 전달 완료 뒤의 분할·작업은 EWMS 영역이다. WCS PDA 분할, GTP PDA, PC 출고확정은 없다
- ⚠ 원문 불일치: [확인필요] WCS는 인도처별/FO별 팔레트 구성 지시를 제공한다
- ⚠ 원문 불일치: 실적 팔레트 ID는 「원팔레트ID-일련번호」로 정할 뿐, WCS PDA 분할과 분할 재고 이력(원팔레트 출고 + 분할 팔레트 입고)은 두지 않는다(위 「인도처별/FO별 팔레트 구성 지시」 줄과 분할 주체가 다르게 읽힌다)

### 3-3. 출고확정과 재고 차감

- 3·4층 전달 완료(AS/RS 배출 완료) 때 WCS가 자동으로 출고확정하고, 한 팔레트 ID에 인도처가 여럿이면 원팔레트ID-1~N으로 나눠 피킹 W/T 실적(PARTIAL 허용)을 보내는 규칙은 → P31 출고완료 확정 2-2·3-1·3-2에 있다. GTP도 이 규칙을 그대로 따른다
- 출고확정·잔량 이동 W/T 실적의 팔레트 ID는 「원팔레트ID-일련번호」(「팔레트」 묶음) 규칙으로 정한다. 인도처별은 1~N, 잔량은 N+1이다
- GTP 출고 팔레트는 EWMS가 생성한 피킹 W/T로 처리하며 새 W/T를 만들지 않는다. 인도처별 출고확정 실적도 이 피킹 W/T의 확정으로 요청한다
- AS/RS → 출고 수작업 영역 이동은 W/T 생성·확정으로 EWMS와 동기화한다
- ⚠ 원문 불일치: GTP 팔레트도 예외 없이 3·4층 전달 완료 때 출고확정으로 WCS 재고에서 빠진다(출고 이력으로 제외)
- ⚠ 원문 불일치: GTP 출고분은 배출 재고 차감의 예외로 W/T 확정까지 WCS 재고를 유지한다. GTP 작업 중인 팔레트는 W/T 확정 전까지 WCS가 관리한다(3·4층 배출 때 재고 차감의 예외)

**수작업 인계 재고 처리 순서**
1. 3·4층 배출 완료를 받으면 AS/RS 출고대 셀에서 해당 층 수작업 셀(9013·RCV3 / 9014·RCV4)로 이동 이력을 남긴다
2. 수작업 셀에서 인도처별 출고 이력(원팔레트ID-1~N)을 남기고 피킹 W/T 실적을 보낸다
3. 잔량은 같은 셀에서 이동 W/T 생성·확정 후 출고(제외) 이력을 남긴다
4. 셀 재고는 이 처리 안에서 바로 0이 된다

### 3-4. 잔량

- 이 프로세스의 잔량은 3·4층 전달 완료 때 팔레트에 남는, 피킹 W/T에 할당되지 않은 수량(팔레트 수량 − 할당 피킹 W/T 합계)이다
- 출고 팔레트에는 새 W/T를 만들지 않고, 잔량만 자동화 설비 → 수작업 이동 W/T를 만든다
- GTP·직송 이적 잔량의 자동화 → 수작업 이동 W/T는 3·4층 전달 완료 때 WCS가 EWMS에 생성을 요청하고 확정까지 한 번에 처리한다. 실적 팔레트 ID는 원팔레트ID-(N+1)이다
- 확정 후 잔량은 WCS 재고에서 뺀다(이후 EWMS 관리)
- 잔량의 HU 확인은 EWMS가 처리한다
- ⚠ 원문 불일치: GTP 잔량 팔레트는 출고 수작업 영역으로 보내며, AS/RS 재입고나 MMVT 전환은 하지 않는다. → P41 자동화 전환의 규칙(자동화 재고를 수작업으로 옮길 때 MMVT로 위치 전환 후 출고)·요구(GTP·직송 이적 잔량을 「자동화 → 수작업(MMVT)」으로 분류)와 어긋난다.
- ⚠ 원문 불일치: 잔량 이동 W/T의 DEST는 도착 층 「출고대」(9013·RCV3 / 9014·RCV4)로 한다. 위 「수작업 인계 재고 처리 순서」와 → P31 출고완료 확정은 같은 코드를 「출고 수작업 셀」이라 부르고 AS/RS 출고대 셀과 구분한다.

### 3-5. 1층 이동

- GTP 출고 팔레트는 3·4층에서 1층으로 수직반송기를 써서 옮긴다
- 3·4층 출고 수작업 영역 → 수직반송기 투입은 유인지게차가 하고, 1층 도착 후 출고 DOCK까지는 AMR 또는 유인지게차가 옮긴다
- 단계별 수단은 Workflow 설정을 따른다. Workflow가 무엇이고 왜 설정으로 두는지는 「작업지시 체계」 묶음에 있다
- GTP 출고 팔레트(분할 팔레트 ID)의 1층 이동 결과는 팔레트 작업 상태로 관리한다
- 출고확정 후라 WCS 재고가 아닌 운반으로 처리하고, EWMS W/T를 받았을 때 작업지시한다

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→현대무벡스 ECS | GTP 출고 지시 시 | 팔레트 ID, 배출층(3층/4층) |
| 현대무벡스 ECS→WCS | 배출 완료 시 | 팔레트 ID, 배출구 |
| WCS→EWMS | 3·4층 배출(전달) 완료 시 | 피킹 W/T 실적 — W/T 번호, 팔레트 ID(인도처가 여럿이면 원팔레트ID-1~N), 확정 수량, 확정 일시 |
| WCS→EWMS | 3·4층 배출(전달) 완료 시 잔량이 있으면 | 자동화 → 수작업 이동 W/T 생성 요청·확정 — 원팔레트ID-(N+1), 제품, 수량, DEST 9013·RCV3 / 9014·RCV4 |
| EWMS→WCS | EWMS PDA 선행작업 후 | 1층 이동 W/T — 팔레트 ID, 출발 층, 목적지 출고 DOCK |
| WCS→수직반송기 ECS / 수직반송기 ECS→WCS | 수직반송기 단계 | WCS가 지시하고, 출발 신호와 도착 신호를 따로 받는다 |
| WCS→생기연 ECS(AMR) | AMR 단계 | 이송 지시 |
| PDA→WCS | 유인지게차 단계 완료 시 | WCS 작업지시 없이 PDA 완료 스캔으로 위치 반영 |
| WCS→EWMS | 1층 이동 완료 시 | 도착 정보(W/T 확정용) |

## 5. 예외

- 한 팔레트에 할당된 피킹 W/T 합계가 팔레트 수량보다 크면 출고확정 실적을 보내지 않고 알람(재고 오류)을 띄운다
- 출고 팔레트 이동 중 오류 처리는 정해지지 않았다. 단계별 수단은 Workflow 설정이다
