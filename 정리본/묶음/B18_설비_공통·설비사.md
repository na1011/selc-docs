# [묶음] 설비 공통·설비사

> 유형: 설비(공통) · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 설비사, 설비사별 ECS, 설비 접점, 설비 기준정보 공통 칸에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 설비사가 누구인지, 설비사별 ECS와 「누가 누구에게 지시하나」, 설비 접점(P-NN) 목록과 그 이력, 같은 설비사 내부 인계 원칙, 설비 기준정보의 공통 칸을 다룬다.
- **각 설비의 설비사는 그 설비 묶음의 「설비사」 칸이 갖는다.** 이 묶음에는 설비별 설비사 맵핑표를 두지 않는다(결정로그 2절).
- 설비 유형별 속성의 내용은 각 설비 묶음에 있다. 접점에서 인계가 일어나는 순서는 → P17 설비 접점 인계, 설비 기준정보를 등록하는 기능은 → P47 기준정보 관리에 있다.
- 한 설비가 아니라 설비 전체에 걸친 묶음이라, 설비 유형의 확인할 칸(위치·투입·배출구…) 대신 위 다섯 가지를 절로 둔다.

## 3. 사실

### 3.1 설비사
- 설비사는 현대무벡스, 로지스올, 생기연이다.
- 설비별 설비사(수직반송기의 미정 포함):
  - 이 묶음에는 두지 않는다.
  - 「AS/RS」, 「BOX Shuttle」, 「GANTRY」, 「3층 디팔레타이징·MIXED」, 「로지스올 입고 설비」, 「운반 설비」 묶음의 설비사 칸을 본다.

### 3.2 설비사별 ECS와 「누가 누구에게 지시하나」
- 설비사별로 ECS가 따로 있다.
- WCS는 설비사별(현대무벡스, 로지스올, 생기연, 수직반송기 설비사) ECS 인터페이스를 각각 둔다.
- [확인필요] 설비마다 작업지시를 받는 ECS가 정해져 있다.
- [확인필요] 설비–설비사 맵핑은 기준정보로 관리하며, 이것으로 작업지시 대상 ECS를 정한다.

| WCS의 상대 | 주고받는 것 |
|---|---|
| 현대무벡스 ECS | 현대무벡스 설비의 작업지시·결과 |
| 로지스올 ECS | 로지스올 설비의 작업지시·결과 |
| 생기연 ECS | 생기연 설비의 작업지시·결과(AMR 이송 지시, AFL 이송 작업지시·결과는 Workflow 설정 구간) |
| 수직반송기 ECS (설비사 미정) | 수직반송기 작업지시 |

- 어느 설비가 어느 설비사(ECS) 소속인지는 각 설비 묶음의 「설비사」 칸이 갖는다(결정로그 2절).

운반 설비에 대한 지시:
- WCS는 AMR에 작업지시하고 결과를 받는다.
- WCS는 AMR 작업지시를 1층 구간(P-06·P-10·P-16·P-17)에만 내리고, 3층·4층 유인지게차 이동에는 작업지시를 내리지 않는다.
- ⚠ 원문 불일치: 1층 설비 접점 P-08(하차: ATL → AMR → AS/RS 1층 입고대·사이즈 체크 또는 대기존)에도 AMR이 있으나 위 구간 목록에는 P-08이 없다.
- AFL은 AMR처럼 생기연 ECS로 작업지시한다.
- 수직반송기도 WCS 작업지시 대상이다.
- 유인지게차 이동에는 WCS 작업지시가 없다. 유인지게차 단계는 작업지시 없이 WCS PDA 스캔으로 처리한다.

현대무벡스 설비별로 원문에 따로 적힌 것:
- WCS는 1층 출고 구성 지시와 완료 결과를 1층 MIXED 팔레타이징로봇 기준으로 현대무벡스 ECS와 주고받는다.
- WCS는 1층(GANTRY 입구) 디팔레타이징 지시를 따로 내리지 않고 현대무벡스의 디팔레타이징(적재) 실적만 받는다. AS/RS·보충 컨베이어·1층 디팔레타이징이 같은 현대무벡스 설비이기 때문이다.
- WCS는 3층 디팔레타이징 설비와 3층 MIXED 팔레타이징 설비에 작업을 지시하고 결과를 받는다. 지시 상대는 현대무벡스 ECS다.
- WCS는 잔량 BOX의 BOX Shuttle 투입과 부분 해체 팔레트의 AS/RS 재입고도 현대무벡스 ECS에 지시한다.
- WCS가 3층 디랩핑기에 작업을 지시하고, 설비가 완료를 보고한다.
- 3층 출고 구성에 쓰는 AS/RS 팔레트 구간은 현대무벡스 내부 인계지만, WCS는 각 단계 작업을 현대무벡스 ECS에 지시하고 결과를 받는다.

### 3.3 설비 접점 (P-NN)

#### 원칙
- 설비 접점은 설비사가 다른 설비 사이의 인계 지점이다. 모든 설비 접점은 WCS가 중간 처리한다.
- 설비사별로 ECS가 따로 있으므로, 설비 접점에서는 설비끼리 직접 연동하지 않는다.
- 수직반송기는 다른 설비사로 가정한다(설비사 미정은 「운반 설비」 묶음 설비사 칸). 그래서 수직반송기 투입·배출 인계 지점(P-06·P-10·P-14)을 모두 설비 접점으로 처리하고, WCS가 중간 처리하며 이 지점에서 작업지시한다. 이 가정은 설비사가 확정될 때까지 유지하고, 확정되면 접점을 다시 본다(Q-072).
- AFL의 설비 접점은 사용 구간이 정해지면 등록한다.

#### 살아 있는 접점

| 접점 | 층 | 송신(설비사) → 수신(설비사) | 발생 업무 |
|---|---|---|---|
| P-01 | 3층 | 3층 랩핑기(로지스올) → AS/RS 3층 입고라인(현대무벡스) | 디베닝입고 팔레트화 후 AS/RS 보관 |
| P-02 | 3층 | 디베닝 BCR 분기(로지스올) → BOX Shuttle 입구(현대무벡스) | 디베닝입고 BOX Shuttle 투입(경로 A) |
| P-06 | 1층 | AMR(생기연) → 수직반송기(설비사 미정) | 3층 수작업 이동(1층 → 3층) |
| P-08 | 1층 하역장·출고 DOCK | 하차: ATL(생기연) → AMR(생기연. ATL → AMR 구간은 「운반 설비」 묶음) → AS/RS 1층 입고대·사이즈 체크(현대무벡스) 또는 대기존(Workflow 설정). 상차: 출고 DOCK에 도착한 출고 팔레트(1층 출고대·GANTRY 출고대에서 AMR·유인지게차로 이송, AMR → ATL은 같은 생기연 내부) → ATL(생기연) | 입고 하차, 출고 상차 |
| P-10 | 1층 | 수직반송기(설비사 미정) → AMR(생기연) | 3층 출고 구성 완료 팔레트 이송(3층 → 수직반송기 → 1층 AMR → 1층 출고 DOCK). 유인지게차로 옮기면 접점 아님 |
| P-14 | 3층 | 3층 MIXED 팔레타이징(현대무벡스) → 수직반송기(설비사 미정) | 3층 출고 구성 완료 팔레트 1층 이동 |
| P-16 | 1층 | AS/RS 1층 출고대(현대무벡스) → AMR(생기연) | FULL 팔레트 출고 → 출고 DOCK 이동. 유인지게차로 옮기면 접점 아님 |
| P-17 | 1층 | GANTRY 출고대(현대무벡스) → AMR(생기연) | GANTRY 출고 구성 팔레트 → 출고 DOCK 이동. 유인지게차로 옮기면 접점 아님 |

- P-06·P-10·P-14는 수직반송기 설비사를 다른 설비사로 가정한 접점이다(3.3 원칙).
- P-03·P-04·P-05·P-15는 폐기됐다(6. 변경 이력). P-07·P-09·P-11·P-12·P-13은 원문에 없다.
- P-02 인계는 사전 지시 방식이다.
- 1층 출고대·GANTRY 출고대에서 출고 DOCK까지 AMR에 작업지시하고 결과를 받는 이동 구간이 있다(P-16·P-17).
- ⚠ 원문 불일치: 살아 있는 접점에는 P-16·P-17이 있다.
- ⚠ 원문 불일치: 「모든 설비 접점(P-01~P-14)」으로 범위를 적은 기록이 있다(→ P17 설비 접점 인계의 재료).

#### 포트와 접점
- [확인필요] 설비 포트마다 인계 상대 설비(연결 설비)와 설비 접점 번호가 있다. 예: 3층 입고 팔레타이징로봇, P-01.

### 3.4 같은 설비사 내부 인계 (설비 접점이 아닌 것)
- 같은 설비사 설비 사이의 인계는 설비 접점이 아니다. 해당 설비사 ECS 내부에서 처리한다. WCS는 작업지시·결과 수신을 한다.
- 이 절은 「어느 인계가 설비 접점이 아닌가」만 갖는다. 무엇이 무엇으로 이어지는지(이음매)는 그 부분을 가진 설비 묶음의 「투입·배출구」 칸에, 경로 전체의 순서는 프로세스에 있다(제안서 예 1).
- 1층 GANTRY 쪽: 「GANTRY」 묶음 3-2의 연결(AS/RS에서 보충 컨베이어로 들어오는 보충 경로, 보관호기 ↔ 피킹호기, 1층 MIXED 팔레타이징 → GANTRY 출고대, 보충 경로로 오는 1층 공팔레트·TRASH BIN)은 모두 현대무벡스 내부 인계이며 설비 접점이 아니다. AS/RS → GANTRY 보충도 설비 접점이 아니다. 경로 순서는 → P23 GANTRY 출고, → P22 GANTRY 사전·긴급 보충.
- AS/RS 1층: 「AS/RS」 묶음 3.2의 1층 연결(1층 사이즈 체크 → AS/RS, AS/RS FULL 팔레트 → 1층 출고대)은 현대무벡스 내부 인계다.
- 3층 출고 구성 쪽: 3층 출고 구성에 AS/RS 팔레트를 쓸 때 거치는 설비 사이 인계는 모두 현대무벡스 내부 인계이며 설비 접점이 아니다. 잔량 BOX → BOX Shuttle, 부분 해체 팔레트 → AS/RS 재입고도 같다. 이음매는 「AS/RS」 묶음 3.2(디팔레타이징 배출라인·재투입라인), 「3층 디팔레타이징·MIXED」 묶음 3-2, 「BOX Shuttle」 묶음 3.2에 있고, 경로 순서는 → P28 3층 출고 구성.
- ⚠ 원문 불일치: K20의 내부 인계 목록은 3층 디팔레타이징 로봇 → 3층 MIXED 팔레타이징을 바로 잇는 경로를 내부 인계로 적는다(Q-185 결정 이전 경로). 이 연결은 「3층 디팔레타이징·MIXED」 묶음 3-2에서 「해체 BOX는 BOX Shuttle로 가며 MIXED에 바로 투입할 수 없다」와 함께 ⚠로 있다.
- 로지스올 입고 설비 쪽: 「로지스올 입고 설비」 묶음 3-2의 연결(1층 하역 로봇부터 3층 랩핑기까지)의 이음매는 모두 로지스올 내부 인계다. 3층 이송 컨베이어 구간도 로지스올 내부 인계라 설비 접점이 아니다. 3층 랩핑기 → AS/RS는 P-01(3.3)이다.
- 유인지게차 이동(3층·4층 포함)은 설비 접점이 아니다.
- ⚠ 원문 불일치: BOX Shuttle ↔ 3층 MIXED 팔레타이징 사이 BOX 인계는 설비 접점이며 WCS가 중간 처리한다.
- ⚠ 원문 불일치: BOX Shuttle과 3층 디팔레타이징·MIXED 팔레타이징 설비는 같은 현대무벡스 설비라, 두 설비 사이 BOX 인계는 내부 인계이며 WCS가 작업을 지시한다.

### 3.5 설비 기준정보 공통 칸

#### 무엇이고 무엇에 쓰나
- WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다.
- 설비마다 장비 특성이 다르다(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등). 그래서 설비 기준정보는 공통 속성과 설비 유형별 속성으로 나눠 정의한다.
- 설비 기준정보는 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준이 된다.
- 설비 기준정보의 기준 속성은 다섯 묶음이다: 설비 마스터, 적재 제약, 포트, 설비 유형별 속성, 팔레트 유형 마스터. 팔레트 유형 마스터는 「팔레트」 묶음에 있다.
- [확인필요] 설비 유형별 추가 속성을 관리한다. 내용은 각 설비 묶음에 있다.

#### 설비 마스터(공통 속성)
- [확인필요] 공통 속성 목록: 설비 ID·유형·상위 설비·설비사·ECS(작업지시 대상)·층·구역·작업 단위·작업 용도·EWMS BIN 매핑·처리 능력·사용 여부·운영 상태. EWMS BIN 매핑의 내용은 「EWMS BIN 코드」 묶음에 있다.

| 칸 | 뜻·값 |
|---|---|
| 설비 ID | [확인필요] WCS 설비 식별 코드(호기 단위). 예: ASRS-01, GNT-G05, PLR-3F-IN |
| 설비 ID 형식 | 「유형-호기/층-용도」로 채번한다. 창고 안에서 중복을 허용하지 않는다. |
| 설비명 | [확인필요] 화면 표시명. 예: 3층 입고 팔레타이징로봇 |
| 설비 유형 | [확인필요] AS/RS, BOX Shuttle, GANTRY, 팔레타이징로봇, MIXED 팔레타이징로봇, 디팔레타이징, 수직반송기, AMR, AFL, ATL, 컨베이어, BCR, 사이즈 체크, 하역 로봇, 시퀀스 버퍼, 유인지게차(작업지시 없음, 도착 지연 기준 시간용) |

| 사용 여부 | [확인필요] 기준정보 사용/미사용. 배정 대상 여부를 정한다. |

| 도착 지연 기준 시간 | [확인필요] 출발 신호 후 도착 신호까지 허용 시간. 팔레트 작업 상태 오류 판단에 쓴다. 설비 마스터에 설비별로 둔다. 예: 수직반송기 1→3층 5분. 설비 유형별 세부는 「운반 설비」 묶음 |

- 설비 마스터에 설비사 설비 코드를 두어, ECS가 자기 코드로 보낸 실적·에러를 WCS 설비 ID로 맞춘다. 설비사 설비 코드가 없으면 ECS 보고를 설비와 연결할 수 없어 처리하지 못한다.
- 보관설비마다 사용하는 UOM 레벨(1 낱개 BOX / 2 중포장단위 / 3 팔레트 단위)을 관리한다. 확장성을 고려한 것이다. 중포장을 보관하는 설비가 생기면 그 설비의 UOM 레벨을 2로 설정해 확장한다.

## 6. 변경 이력
- 3층 디팔레타이징·MIXED 팔레타이징 설비의 설비사를 로지스올에서 현대무벡스로 바꿨다.
- 이에 따라 P-03·P-04·P-15는 현대무벡스 내부 인계가 되어 폐기했다. P-14는 송신 설비사를 현대무벡스로 했다.
- P-03(3층 출고 구성용 AS/RS 팔레트 경로)은 모두 현대무벡스 설비가 되어 설비 접점이 아니게 됐다.
- 경로 B 투입 P-04와 팔레타이징로봇 이송 P-05는 폐기했다.
