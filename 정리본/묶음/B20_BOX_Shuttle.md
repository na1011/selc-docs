# [묶음] BOX Shuttle

> 유형: 설비 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 BOX Shuttle에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 3층 BOX Shuttle 설비와 BOX 식별자를 다룬다.
- 디베닝 BCR 분기에서 들어오는 투입(P-02)은 「설비 공통·설비사」 묶음의 설비 접점이다. BOX를 받는 3층 MIXED 팔레타이징로봇은 「3층 디팔레타이징·MIXED」 묶음이 갖는다.
- 적치·인출 순서는 → P16 BOX Shuttle 적치·인출에 있다.

## 3. 사실

### 3.1 위치
- BOX Shuttle은 3층에 있다. 〔C01-3.05, G018, K22-OV01〕

### 3.2 투입·배출구
- BOX Shuttle 입고 경로는 A(디베닝 직접 투입)와 B(3층 출고 구성 후 잔량 보관) 두 가지다. 3층 사전 보충 BOX도 디팔레타이징 후 같은 방식으로 들어온다. 〔K22-OV02〕
- BOX Shuttle에서 인출한 BOX는 3층 MIXED 팔레타이징로봇으로 간다. 이 인계가 설비 접점이 아니라는 것(같은 설비사 내부 인계)은 「설비 공통·설비사」 묶음 3.4에 있다. 〔BR-EQP-VND-013, K20-F18.00, K22-OV05, BR-EQP-MIX-008, K24-OV03〕
- ⚠ 원문 불일치: 이 인계를 설비 접점으로 적은 기록이 있다. 두 기록은 「설비 공통·설비사」 묶음 3.4에 함께 두었다. 〔BR-EQP-BSH-005, K22-OV03〕

### 3.3 보관 단위·제약
- BOX Shuttle은 팔레트화 없이 BOX 그대로 입고·보관·피킹한다. 〔K22-OV01, G018〕
- BOX Shuttle은 UOM 1레벨(낱개 BOX)만 쓴다. 〔BR-MST-EQP-031, REQ-MST-EQP-037〕
- [확인필요] BOX Shuttle의 허용 제품 구분은 중소형이다. 〔K12-F26.00〕
- BOX Shuttle의 BOX 재고는 적치셀 단위로 관리된다. 〔BR-EQP-BSH-008〕
- BOX Shuttle 셀마다 피킹 우선순위가 있다. 셀 위치·피킹 우선순위를 두는 셀 마스터 칸은 「WCS 위치」 묶음에 있다. 〔BR-EQP-BSH-014〕
- BOX Shuttle 적치 위치는 BOX Shuttle이 자동 할당한다. WCS는 투입을 지시할 때 적치 위치를 지정하지 않는다(경로 A·B 공통). 〔BR-EQP-BSH-003, REQ-EQP-BSH-005〕
- WCS와 BOX Shuttle은 BOX 식별자(제조번호관리 상품은 제조번호(S/N), 그 외 상품은 제품코드)로 BOX를 주고받는다. 〔REQ-EQP-BSH-006, G019〕
- [확인필요] BOX Shuttle 설비 유형별 속성은 적치 위치 자동 할당(WCS 미지정), BOX 최대 규격·중량, 적치 단위(BOX 식별자)다. 〔K12-F37.00〕

### 3.4 설비사
- BOX Shuttle의 설비사는 현대무벡스다. 〔K22-OV04, C01-3.01, G044, BR-EQP-VND-001, K20-F03.00, K32-OV07〕

### 3.5 능력
- BOX Shuttle 적치율은 사용 셀 수 ÷ 전체 사용 가능 셀 수다. 〔REQ-EQP-BSH-008〕
- 셀 수·처리량 같은 실제 값은 원문에 없다.
