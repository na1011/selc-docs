# [묶음] HU

> 유형: 기준정보 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 HU에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- HU가 이 프로젝트에서 무엇인지(HU = 팔레트 ID)와, HU 확인·생성·삭제·PACK·UNPACK·SWAP을 누가 처리하는지를 다룬다.
- 팔레트 ID의 형식과 채번은 「팔레트」 묶음이 갖는다. HU 작업을 하는 순서는 → P05 HU 확인·생성, → P06 HU PACK·UNPACK·SWAP에 있다.
- HU는 SAP EWM 표준 용어다. (잠정 §9-8)

## 2. 용어

| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| HU | EWMS에서 채번하는 팔레트 단위 식별자. 팔레트 ID의 사용 가능 여부를 검증하는 기준이다. HU = 팔레트 ID다. | Handling Unit | EWM 표준 (잠정 §9-8) |
| HU 확인 | 사용하려는 팔레트 ID가 EWMS에 HU로 채번되어 있는지 확인하는 절차. | HU 검증, HU 조회, HU 스캔 | |
| HU 내역 조회 | 팔레트 ID로 EWMS에서 HU의 적재 내역과 제조번호(S/N)를 조회하는 것. | — | |
| HU 생성 | EWMS에 없는 팔레트 ID를 HU로 새로 채번하는 절차. | — | EWM 표준 (잠정 §9-8) |
| HU 삭제 | EWMS에 채번된 HU를 삭제하는 절차. | — | EWM 표준 (잠정 §9-8) |
| HU PACK | 자동화 설비 재고를 HU(팔레트)에 담는 작업. | HU 팩, 팩킹 | EWM 표준 (잠정 §9-8) |
| HU UNPACK | HU에 담긴 자동화 설비 재고의 전부 또는 일부를 HU에서 빼는 작업. | HU 언팩 | EWM 표준 (잠정 §9-8) |
| HU SWAP | 자동화 설비 재고가 담긴 HU를 다른 HU로 바꾸는 작업(팔레트 교체, HU 라벨 오류 등). | HU 스왑 | |

## 3. 사실

### 3.1 무엇을 식별하나 (식별 기준)
- HU는 팔레트 ID다(HU = 팔레트 ID). (잠정 §9-3)
- HU는 팔레트 단위 식별자다.

### 3.2 구성 항목
- HU에는 적재 내역과 제조번호(S/N)가 있고, 팔레트 ID로 EWMS에서 조회한다(HU 내역 조회).
- 그 밖의 구성 항목은 원문에 없다.

### 3.3 누가 만들고 어디서 오나
- HU는 EWMS가 채번한다.
- HU 검증과 HU 작업 반영(HU 조회·HU 생성·HU 삭제·PACK·UNPACK·SWAP)은 EWMS가 처리한다.

### 3.4 사용 여부·이력
원문에 없음.

### 3.5 그 밖의 사실
- WCS PDA의 HU PACK·UNPACK·SWAP은 HU 작업 가능으로 설정된 셀에서만 한다.

해당 없음.

## 5. 미결
원문에 없음.
