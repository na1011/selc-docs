# [묶음] 운반 설비

> 유형: 설비 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 AMR·유인지게차·수직반송기·ATL·AFL에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 층 안·층 사이에서 팔레트를 옮기는 설비 다섯(AMR, 유인지게차, 수직반송기, ATL, AFL)을 다룬다.
- 이 설비들이 다른 설비와 만나는 설비 접점(P-06·P-08·P-10·P-14·P-16·P-17)은 「설비 공통·설비사」 묶음이 갖는다. DOCK 자체는 「차량·도크」·「WCS 위치」 묶음이 갖는다.
- 어느 단계에 어떤 이송 수단을 쓸지는 Workflow 설정이며 「작업지시 체계」 묶음과 각 프로세스에 있다.

## 2. 용어

| 용어 | 뜻 | 동의어 | 비고 | 출처 |
|---|---|---|---|---|
| AMR | 자율주행 이동로봇. | Autonomous Mobile Robot | | 〔G031〕 |
| 유인지게차 | 작업자가 운전하는 지게차. | 지게차 | | 〔G032〕 |
| 수직반송기 | 층간 팔레트를 이송하는 수직 반송 설비. | — | | 〔G033〕 |
| ATL | 생기연이 담당하는 장비로, 팔레트 하역과 팔레트 상차를 담당한다. | — | | 〔G054, K20-F05.00, C01-3.03〕 |
| AFL | 생기연이 담당하는 설비. Workflow 이송 수단의 하나다. | — | 정식 명칭·설비 성격 설명이 원문에 없음 | 〔G055, BR-EQP-VND-025, K20-F05.00〕 |

## 3. 사실

### 3.1 위치
- AMR은 1층에서만 쓴다. 〔G031, C01-3.03, BR-EQP-VND-008, K26-OV03, K28-OV06, BR-OUB-MAN-006, K33-OV02, BR-INB-MAN-003〕
- 3·4층 팔레트 이동은 AMR 대신 유인지게차로 하며, WCS 작업지시가 없다(수직반송기·AS/RS 배출구 ↔ 수작업 영역. 3층 출고대 도착 팔레트, 수직반송기 도착 팔레트, AS/RS 3층 Bypass 팔레트 포함). 〔C01-3.06, G031, G032, BR-EQP-VND-008, BR-INB-MAN-009, BR-INB-MAN-003, K28-OV07, K26-OV03, G050, G048, BR-EQP-MIX-005, REQ-EQP-VND-006〕
- 1층에서도 수직반송기 투입이나 수직반송기 도착 팔레트를 출고 DOCK으로 옮기는 데 유인지게차를 쓸 수 있다(AMR 또는 유인지게차, Workflow 설정). 〔G032〕
- ATL은 1층 DOCK 22개 중 2개에 장착되어 있다. ATL DOCK은 입고·출고를 같이 한다. 〔G054, BR-EQP-VND-018, K20-F12.00, BR-YRD-VHC-023〕
- [확인필요] 수직반송기는 1·3·4층을 잇는다(설비 유형별 속성 「연결 층」). 〔K12-F42.00〕

### 3.2 투입·배출구 (운행 구간)
- AMR은 1층에서 수직반송기까지 팔레트를 운반한다. 또 3층 출고 구성 완료 후 수직반송기로 1층에 내려온 팔레트와, 1층 출고대·GANTRY 출고대의 출고 팔레트를 출고 DOCK까지 이송한다. 모두 유인지게차로도 할 수 있다(Workflow 설정). 〔G031, BR-EQP-VND-019〕
- 유인지게차는 3·4층에서 수직반송기·AS/RS 배출구와 수작업 영역 사이를 옮긴다. 〔G032, BR-EQP-VND-008〕
- ATL이 하역한 팔레트는 무조건 AMR로 이어진다(유인지게차 대체 없음). ATL → AMR은 생기연 내부 인계다. 〔BR-EQP-VND-024, G054〕
- ATL에서 이어받은 AMR이 AS/RS 1층 입고대까지 갈지 대기존까지 갈지는 Workflow로 설정한다. 〔G054〕
- ⚠ 원문 불일치: 수직반송기는 1층→3층 수작업 이동과 3층 출고 구성 완료 팔레트의 1층 이동에 쓴다. 〔G033〕
- ⚠ 원문 불일치: 수직반송기 층간 이동은 1층 → 3·4층 수작업 이동, 3층 출고 구성 팔레트·GTP 출고 팔레트의 1층 이동이다. 〔REQ-EQP-VND-007〕
- AFL의 실제 사용 구간은 Workflow 설정으로 정한다. AFL은 Workflow 단계별 이송 수단(AMR·유인지게차·AFL)의 하나로 설정할 수 있다. 〔BR-EQP-VND-025, G055, K20-F05.00, REQ-EQP-VND-013〕

### 3.3 보관 단위·제약
- 생기연(AMR)은 재고를 보관하지 않는다. 〔BR-INV-SYNC-011〕
- [확인필요] 설비 유형별 속성은 다음과 같다. 〔K12-F42.00, K12-F43.00, K12-F44.00, K12-F45.00〕

  | 설비 | 유형별 속성 |
  |---|---|
  | 수직반송기 | 연결 층(1·3·4층), 층별 정지 포트, 1회 적재 수 |
  | AMR | 운행 층(1층만), 대수, 스테이션(출발·도착 지점) 목록 |
  | AFL | Workflow 이송 수단(사용 구간은 Workflow 설정), 운영 층, 대수 |
  | 유인지게차 | 운영 층, 층별 도착 지연 기준 시간(ECS 인터페이스 없음, 작업지시 여부 N) |

### 3.4 설비사
- AMR·ATL·AFL의 설비사는 생기연이다. 〔C01-3.03, K20-F05.00, G046, BR-EQP-VND-001, K28-OV05, G054, G055〕
- [미결 Q-072] 수직반송기의 설비사는 미정이다. 다른 설비와 설비사가 다르다고 보고(다른 설비사로 가정) 그 접점을 WCS가 중간 처리한다. 〔C01-2.05, C01-3.04, G033, K24-OV04, K28-OV05, K20-F06.00, REQ-OUB-MAN-011, BR-EQP-VND-001〕
- 유인지게차의 설비사: 원문에 없음.
- [확인필요] 유인지게차는 ECS 인터페이스가 없다. 〔K12-F45.00〕

### 3.5 능력
- 수직반송기 층간 이동에서 WCS는 수직반송기로부터 출발 신호와 도착 신호를 따로 받는다. 〔BR-EQP-VND-016, REQ-EQP-VND-007〕
- [확인필요] 도착 지연 기준 시간은 설비 유형마다 다르게 둔다: 수직반송기는 호기별·출발층→도착층 조합별, AMR은 스테이션 구간(출발→도착)별이다. 작업지시가 없는 유인지게차 단계는 설비 유형 「유인지게차」(작업지시 여부 N)로 층별 등록하고, 출발 스캔(없으면 이전 단계 완료)부터 도착 스캔까지 기준 시간을 둔다. 〔REQ-MST-EQP-034〕
- ⚠ 원문 불일치: 수직반송기 도착 지연 기준 시간은 설비 마스터의 호기별 값이다(층 조합 구분 언급 없음). 〔REQ-EQP-VND-008〕
- 대수·처리량 같은 실제 값은 원문에 없다.

### 3.6 운영 상태 — WCS 작업지시 여부
- AMR은 WCS가 작업지시하고 결과를 받는다. 〔G031, BR-OUB-GNT-026〕
- WCS는 AMR 작업지시를 1층 구간(P-06·P-10·P-16·P-17)에만 내린다. 〔REQ-EQP-VND-006〕
- ⚠ 원문 불일치: 1층 설비 접점 P-08(하차: ATL → AMR → AS/RS 1층 입고대·사이즈 체크 또는 대기존)에도 AMR이 있으나 위 구간 목록에는 P-08이 없다. 〔K20-F12.00, REQ-EQP-VND-006〕
- 수직반송기도 WCS 작업지시 대상이다. 〔BR-EQP-VND-020, G033〕
- AFL은 AMR처럼 생기연 ECS로 작업지시한다. 〔G055, BR-EQP-VND-025〕
- 유인지게차 단계는 작업지시 없이 WCS PDA 스캔으로 처리한다(작업지시가 없다는 사실은 3.1의 한 줄에 모았다). 〔REQ-OUB-GNT-031〕

## 4. 상태 값
해당 없음.

## 5. 미결

- [미결 Q-147] [추가 협의] AFL 실제 도입 여부와 사용 구간(후보: ATL 대기존 → 1층 AS/RS 입고대, 3·4층 운반), 생기연 ECS 인터페이스 항목. AFL을 Workflow 이송 수단으로 두는 것은 정했다. 〔Q-147〕
