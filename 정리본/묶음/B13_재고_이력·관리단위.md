# [묶음] 재고 이력·관리단위

> 유형: 기준정보 (잠정 §9-1) · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 재고 관리단위(재고를 무엇 단위로 구분하나)와 재고 이력에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 재고 관리단위(팔레트·중포장·BOX/셀 단위, 개체화), 이동과 관리단위 전환, 재고 이력 3종과 이력 유형 코드, 반대 이력 정정을 다룬다.
- 재고 수량(재고·예약·보류·가용)의 뜻은 「재고 수량」 묶음이 갖는다. 이 묶음은 그 이름만 쓴다. (잠정 §9-4)
- 이력을 쌓아 재고에 반영하는 순서는 → P34 재고 반영·보정, 자동화 구역 전환은 → P41 자동화 전환.

## 2. 용어

| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| 재고 관리단위 | 재고를 담는 논리적 관리단위(UOM 관리단위)다. BOX 또는 팔레트일 수 있다. | 논리적 관리단위 | UOM 레벨별 구분은 3-1 |
| 개체화 | 재고가 위치한 셀 단위로 식별된 상태다. | | |

| 입출고 이력 | LOT별 재고 증감(입고·출고)을 남기는 이력이다. | 재고 입출고 이력, 수불 이력 | |

## 3. 사실

### 3-1. 무엇을 식별하나(식별 기준) — 관리단위
- 재고의 논리 관리단위는 보관 단위다. 팔레트 ID로, 또는 BOX 단위 설비에서는 셀 코드로 식별한다.
- 재고 관리단위는 BOX(1레벨, 셀) / 중포장(2레벨) / 팔레트(3레벨) 중 보관 단위다.
- 재고 관리단위는 아이템 UOM 레벨에 따라 다음으로 구분한다.

| 아이템 UOM 레벨 | 보관 단위 | 관리단위 |
|---|---|---|
| 1 | 낱개 BOX | 현재 셀 |
| 2 | 중포장단위 | 중포장 ID |
| 3 | 팔레트 단위 | 팔레트 ID |

- 재고는 보관하는 UOM 단위로 관리한다.
- 팔레트 재고의 관리단위는 팔레트 ID다.
- 팔레트·중포장에 담기지 않은 BOX는 1레벨이므로 늘 셀(설비 셀·스테이징 셀·이송 중 셀)에 둔다.
- GANTRY·BOX Shuttle 등 BOX 단위 설비(보관설비 UOM 레벨 1)에서는 BOX를 적재된 셀 단위로 관리한다. 별도 채번은 하지 않는다.
- 셀 단위로 식별된 BOX(개체화)는 그 셀로 위치를 알 수 있다.
- 개체화는 GANTRY·BOX Shuttle 등 BOX 단위 설비에 적용한다.
- 재고는 UOM 기준 중포장 단위로도, 팔레트 단위로도 보관할 수 있다.
- WCS는 중포장 단위 보관 재고와 팔레트 단위 보관 재고를 모두 관리한다.
- 평택 CDC는 중포장(UOM 2레벨)을 쓰지 않는다. 그래서 중포장 단위 재고가 생기지 않는다.
- 존·로케이션·셀은 물리적 위치이고, 재고 관리단위는 논리적 관리단위다. 둘을 구분해 관리한다.

### 3-2. 구성 항목

**재고가 갖는 것**
- 재고는 관리단위에 담긴 LOT별 수량이다. 팔레트 ID·제품코드·수량을 갖는다.
- 위치는 재고 관리단위의 현재 위치(셀)다.
- 한 팔레트에 여러 LOT(제품)의 재고를 둘 수 있다.
- 팔레트에 여러 제품이 담기면 팔레트 ID, 제품코드, 수량, 위치(셀)로 관리한다.
- BOX 단위 설비에서는 셀 하나에 여러 상품(LOT)과 수량이 들어갈 수 있다.

**재고 이력의 종류**
- 재고 이력은 입출고 이력·재고 이동 로그·재고 상태 이력 세 가지다.
- 이력 구분은 입출고 / 이동 / 상태다.
- 예약수량·보류수량·재고 상태의 변경은 재고 상태 이력으로 남는다.
- 예약의 생성·소진·해제·이전은 사유·변경 TASK번호·시각과 함께 이력으로 남는다.
- ⚠ 원문 불일치: 재고 상태 이력이 남기는 「재고 상태」에는 W/T 미확정·작업중·셀 할당불가 등이 있다.
- ⚠ 원문 불일치: 재고 상태는 따로 두지 않는다. W/T 미확정은 재고에 따로 표시하지 않고 예약으로 표현한다(「재고 수량」 묶음).

**이력이 담는 것**
- 모든 재고 이력에는 이력 유형 코드를 붙여 발생 원인을 구분한다.
- 모든 재고 이력에는 변경 TASK번호가 붙는다.
- 이력 공통 항목은 이력 유형 코드, 변경 TASK번호, 사유 코드(보정·LOT 속성 변경·보류 등 필요한 유형만), 작업자(시스템 처리면 시스템 ID), 일시, 변경 전·후 값이다.
- 재고 관리단위의 위치 변경 이력은 이전 셀, 이후 셀, 변경 TASK번호, 시각을 남긴다.

**이력 유형 코드의 규칙**
- 이력 유형 코드마다 규칙을 기준정보로 둔다. 규칙 항목은 다음과 같다.
  - 증감 방향
  - 사유 코드 필수 여부
  - 영향 수량(재고·예약·보류·가용)
  - 보류 재고 처리 가능 여부(재고 보정 유형만 허용)
  - 후속 연계 대상(EWMS 실적·W/T, 시리얼 이력 로그)
- 전환 이력 유형 코드에는 팔레트갈이(이적)·GTP 분할·HU PACK·UNPACK을 각각 둔다.

### 3-3. 누가 만들고 어디서 오나
- 재고의 모든 변경은 이력으로 남는다.
- 이력으로 남는 변경에는 수량·위치·관리단위·LOT·예약·보류·상태가 모두 든다.
- 재고(관리단위·LOT·수량·위치)의 변동은 입출고 이력 또는 이동 이력(재고 이동 로그)으로 남는다.
- 이력이 쌓이면 재고에 바로 반영된다. 이력과 재고 사이에 시차가 없다.
- 자동화 BIN 안에서 일어나는 관리단위 전환은 W/T를 만들지 않고 WCS 이력으로만 처리한다.

### 3-4. 사용 여부·이력 — 정정과 추가
- 이력은 지우거나 고치지 않는다.
- 잘못 쌓인 이력은 원래 이력을 참조한 반대 이력(취소 이력)을 쌓아 정정한다.
- 정정 이력은 사유 코드가 필수다.
- 이력으로 언제든 재고의 변경 과정을 추적할 수 있다.
- 새 프로세스가 생기면 이력 유형 코드와 그 규칙을 추가한다.
- 새 관리단위 전환이 생기면 전환 이력 유형 코드를 계속 추가한다.

### 3-5. 그 밖의 사실

**이동과 관리단위**
- 팔레트 단위로 이동(적치·배출·설비 간 이송)하면 재고는 바뀌지 않고 위치(셀)만 바뀐다.
- 팔레트 단위 이동도 이동 이력(재고 이동 로그)으로 남는다.
- 팔레트를 이동해도 관리단위는 그대로다.
- BOX 단위 설비의 BOX는 셀을 옮기면 관리단위(셀)도 바뀐다.
- 같은 UOM 레벨 안의 위치 변경은 이동이다.
- 재고를 이동할 때 to 쪽에 같은 재고(관리단위·LOT)가 있으면 수량을 합산한다.
- 합산 결과가 마이너스가 되는 경우만 막는다.

**관리단위 전환**
- 관리단위 전환은 UOM 레벨이 바뀌는 처리다.

| 전환 | UOM 레벨 |
|---|---|
| 팔레타이징 · MIXED 출고 구성 | 1 → 3 |
| 디팔레타이징 | 3 → 1 |
| (중포장 사용 센터) 중포장 해체 | 2 → 1 |
| (중포장 사용 센터) 중포장 팔레타이징 | 2 → 3 |
| (중포장 사용 센터) 팔레트에서 중포장 분리 | 3 → 2 |

- 팔레타이징·디팔레타이징 같은 관리단위 전환은 출고 이력 + 입고 이력으로 남긴다.
- 관리단위 전환에서 LOT·화주는 그대로 두고 수량만 옮긴다.
- 팔레타이징·MIXED 출고 구성으로 새로 생긴 팔레트의 관리단위는 팔레트 ID(HU)다.
- BOX ↔ 팔레트 관리단위 전환이 일어나는 곳은 다음 여섯이다. 모두 이력으로 남는다.
  1. GANTRY 디팔레타이징(팔레트 → BOX)
  2. 1층 MIXED 출고 구성(BOX → 출고 팔레트)
  3. 디베닝 팔레타이징(BOX → 팔레트)
  4. 3층 디팔레타이징(팔레트 → BOX, BOX Shuttle·MIXED)
  5. 3층 MIXED 출고 구성(BOX → 출고 팔레트)
  6. 수작업 GTP 분할(팔레트 → 원팔레트ID-n. W/T 확정 전이라 WCS 재고다)

## 4. 상태 값 — 이력 유형 코드

| 이력 구분 | 이력 유형 코드 |
|---|---|
| 입출고 | 입고 적치(디베닝·AS/RS 입고·재입고) |
| 입출고 | 출고(출고완료 확정·3·4층 배출 차감) |
| 입출고 | 관리단위 전환 출고·입고 |
| 입출고 | LOT 속성 변경 출고·입고 |
| 입출고 | 재고 보정 증가·감소(재고대사·재고실사 차이) |
| 입출고 | WCS 자체 재고 생성(TRASH BIN 팔레트 등록 등) |
| 입출고 | 화주 변경 출고·입고 |
| 이동 | 팔레트 위치 이동 |
| 이동 | BOX 셀 간 이동 |
| 상태 | 예약 생성·소진·해제(예약 작업 유형별) |
| 상태 | 보류 생성·해제 |
| 상태 | 셀 상태 변경(할당불가 등) |
| (전환) | 팔레트갈이(이적) · GTP 분할 · HU PACK · UNPACK — 각각 따로 둔다 |

## 5. 미결
- [미결 Q-218] [추후 정리] 중포장단위(UOM 2레벨)를 쓰는 센터의 처리가 정해지지 않았다: 중포장 ID 채번 주체(EWMS·설비·WCS)와 스캔, 중포장 ID와 EWMS HU의 관계, 중포장 입수 EWMS 연동, 전환 지점. 평택 CDC는 쓰지 않는다.
