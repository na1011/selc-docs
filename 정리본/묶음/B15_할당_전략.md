# [묶음] 할당 전략

> 유형: 기준정보 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 할당 전략이 무엇이고 어떤 칸을 갖는지만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 할당 전략과 위치 규칙이 무엇인지, 전략의 구성 항목, 누가 바꾸는지, 버전, AI 결과를 받는 틀을 다룬다.
- 모든 할당에 공통인 단계와 위치 규칙의 판정 순서는 → P32 재고 할당에 있다. 프로세스마다 다른 할당 순서는 각 프로세스에 있다.
- 가용수량·예약·보류의 뜻은 「재고 수량」 묶음, 셀 유형·셀 상태는 「WCS 위치」 묶음, 출고 체크 속성은 「LOT·제조번호」 묶음의 이름이다.

## 2. 용어
| 용어 | 뜻 | 동의어 | 비고 | 출처 |
|---|---|---|---|---|
| 할당 전략 | 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 통합한 WCS 설정 관리 | WCS 할당전략, 재고 할당 전략 | | 〔G220, BR-MST-ALC-001, K10-OV01, REQ-MST-ALC-001〕 |
| 위치 규칙 | 할당 전략마다 등록하는 존·로케이션·셀의 포함/제외 목록 | 전략별 위치 규칙 | | 〔G110, BR-MST-ALC-007, REQ-MST-ALC-011〕 |

## 3. 사실

### 무엇을 식별하나 (식별 기준)
- 원문에 없음. (전략이 어느 작업에 쓰이는지는 구성 항목 ① 적용 조건이 정한다.)
- 프로세스 유형마다 적용 조건이 없는 기본 전략을 반드시 하나 둔다. 새 화주·출고 유형이 생겨도 할당이 멈추지 않게 하기 위해서다 〔BR-MST-ALC-010〕

### 구성 항목
| 구성 요소 | 내용 | 출처 |
|---|---|---|
| ① 적용 조건 | 창고, 화주, 프로세스 유형, 출고 유형(STO/직송), 시간대 Type, 제품군·설비(층) | 〔REQ-MST-ALC-002〕 |
| ② 후보 범위 | 대상 설비·존(GANTRY 피킹호기·보관호기, BOX Shuttle, AS/RS 등) | 〔REQ-MST-ALC-002〕 |
| ③ 필터 | 화주 일치, LOT 출고 체크 속성, 가용수량, 셀 유형·셀 상태 할당불가 제외(존·로케이션 값 함께 확인), W/T 미확정·작업 잠금 제외. 유효기한·제조일은 별도 필터 없이 LOT 속성의 출고 체크로 처리한다 | 〔REQ-MST-ALC-002〕 |
| ④ 정렬 | 입고월 FIFO, 설비 보관일, 잔량 최소, 부분 팔레트 우선, 수량 일치 팔레트 우선 중에서 순서를 지정 | 〔REQ-MST-ALC-002〕 |
| ⑤ 보충원 순위 | 1순위·2순위 … 재고원(예: 3층 BOX Shuttle → AS/RS 팔레트) | 〔REQ-MST-ALC-002〕 |
| ⑥ 수량 규칙 | FULL 팔레트 분리 기준, 분할 허용 여부 | 〔REQ-MST-ALC-002〕 |
| ⑦ 부족 시 동작 | 다음 순위, 긴급 보충, 출고 대기, 파워유저 선택(부분 출고/출고 대기) | 〔REQ-MST-ALC-002〕 |

- LOT 혼합은 할당 전략의 설정 항목으로 두지 않는 고정 규칙이다 〔BR-MST-ALC-003, REQ-MST-ALC-002〕
- 출고 체크 속성이 같으면 LOT를 섞어 쓴다 〔REQ-MST-ALC-002〕
- 출고 체크 속성 필터가 비교하는 오더 조건은, WCS가 출고예정·W/T에서 가공한 Work의 LOT 속성이다 〔BR-MST-ALC-004〕
- 서로 다른 화주(별도 재고 관리 PLANT)의 재고가 섞이지 않도록 출고 할당 때 화주를 체크한다. 평택 CDC에도 적용한다 〔REQ-MST-STK-003〕

#### 위치 규칙
- 할당 전략마다 특정 존·로케이션·셀의 포함/제외를 등록·삭제해 후보 범위를 정한다 〔BR-MST-ALC-007, REQ-MST-ALC-011, G110〕
- 위치 규칙은 위치 마스터의 셀 유형을 기본값으로 함께 쓰고, 그 기본값을 덮어써 그 전략의 후보 범위를 정한다 〔G110, BR-MST-ALC-007, REQ-MST-ALC-011〕
- 비보관 위치처럼 여러 전략에 반복되는 범위는 공통 위치 그룹으로 등록하고, 전략은 그룹 단위로 포함·제외한다 〔REQ-MST-ALC-012〕
- Work 값과 맞춰 정해지는 동적 범위도 위치 규칙의 한 유형이다. 「Work 할당 호기 로케이션」 한 줄로 표현할 수 있다(GANTRY 호기 = 로케이션) 〔REQ-MST-ALC-012, REQ-MST-LOC-030〕

### 누가 만들고 어디서 오나
- 할당 전략은 파워유저만 변경한다 〔REQ-MST-ALC-006〕
- 위치 규칙은 운영 중 바뀌지 않는 고정 설정이다 〔G110, BR-MST-ALC-008, REQ-MST-ALC-011, BR-MST-ALC-012〕
- 고정 설정은 운영 시간 외에 파워유저가 바꿀 수 있다 〔BR-MST-ALC-012〕
- 화주는 PLANT–화주 맵핑(맵핑 데이터)으로 지정하고, LOT는 할당 전략으로 찾아 작업지시에 맞는 LOT를 지시한다(출고예정·피킹 W/T에 LOT가 없다는 것은 「출고 오더」 묶음) 〔BR-MST-ALC-002, K10-OV03, G220〕

#### AI 결과 수용
- 할당 전략은 AI(외부 최적화) 결과를 받아 반영할 수 있는 틀을 갖춘다 〔BR-MST-ALC-005, REQ-MST-ALC-009〕
- 수용 대상은 두 가지다: 전략 설정값 제안(정렬 기준·순위·허용 편차·사전 보충 범위 등)과 할당·보충 결과 제안(Work별 선택 재고·수량·시각) 〔BR-MST-ALC-011, REQ-MST-ALC-010〕
- 적용 방식(파워유저 승인 / 자동)은 전략별로 고르고, 기본값은 파워유저 승인이다 〔BR-MST-ALC-011, REQ-MST-ALC-010〕
- 파워유저 승인 적용은 시뮬레이션 비교 후에 한다 〔REQ-MST-ALC-010〕

### 초기 전략 값 (구성 항목의 처음 설정값)
- 초기 전략 값은 지금 확정된 할당 규칙을 할당 전략 설정으로 옮긴 처음 설정값이다. 번호마다 대상이 정해져 있다 〔REQ-MST-ALC-004〕
- 각 값의 후보·순서·보충원 내용은 그 대상 프로세스에 있다(제안서 §7: 「어떤 순서로 재고를 고르나」는 프로세스). 〔REQ-MST-ALC-004〕

| 번호 | 대상 | 내용이 있는 프로세스 | 출처 |
|---|---|---|---|
| ① | 1층 GANTRY 출고·보충 | → P23 GANTRY 출고 | 〔REQ-MST-ALC-004〕 |
| ② | 3층 출고 구성 | → P28 3층 출고 구성 | 〔REQ-MST-ALC-004〕 |
| ③ | 사전 보충 | → P22 GANTRY 사전·긴급 보충, → P27 3층 사전·긴급 보충 | 〔REQ-MST-ALC-004〕 |
| ④ | 재할당 | → P13 설비 출고 불가 재할당 | 〔REQ-MST-ALC-004〕 |
| ⑤ | FULL 팔레트 출고 · GTP · 직송 이적 | → P24 FULL 팔레트 출고, → P29 수작업 GTP 출고, → P30 직송 이적 | 〔REQ-MST-ALC-004〕 |
| ⑥ | 재고실사 배출 · 공팔레트 묶음 피킹 | → P40 재고실사, → P14 공팔레트 공급 | 〔REQ-MST-ALC-004〕 |

- ⑥은 대상 지정형이다. 대상 지정형은 사용자·설비 요청이 대상을 정하고, 할당 전략은 필터만 하는 방식이다. 〔REQ-MST-ALC-004〕

### 사용 여부·이력
- 할당 전략은 버전과 적용 시작 시각을 둔다 〔REQ-MST-ALC-006〕

### 그 밖의 사실
- 재고를 쓰는 모든 프로세스는 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다 〔G220, K10-OV02, REQ-MST-ALC-001〕
- 그런 프로세스: 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 〔K10-OV02, G220〕

## 5. 미결
- 재료에 이 묶음의 미결 기록은 없다.
