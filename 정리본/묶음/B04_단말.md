# [묶음] 단말

> 유형: 시스템 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 현장·관리 단말(EWMS PDA, WCS PDA, PC·대시보드, 키오스크)과 사용자 역할(파워유저)에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 단말마다 무엇을 맡는지, EWMS PDA와 WCS PDA의 경계, WCS PDA 기능 항목, 대시보드 구성, 사용자 권한을 다룬다.
- 화면을 쓰고 알림을 받는 순서는 → P46 단말 화면·알림에 있다. DOCK IN·DOCK OUT은 「차량·도크」 묶음의 이름이다.
- 「사용자 권한」은 따로 집이 없는 개념이라 잠정으로 이 묶음에 둔다(§3 「사용자 권한」).

## 2. 용어
| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| EWMS PDA | EWMS가 제공하는 작업자용 PDA. 수작업 영역과 자동화 설비 사이에서 주고받는 작업을 처리한다 | PDA | 소속 (잠정 §9-3) |
| WCS PDA | WCS가 제공하는 작업자용 PDA. 단순 조회보다 현장 작업 수행과 예외 조치 중심이다 | | |
| 대시보드 | 입출고 예정·진행 현황 등 관리 목적 정보를 보여 주는 WCS 화면 | | |
| 파워유저 | 예외 상황 알람을 받고 조치하는 WCS 운영 관리자급 사용자 | 파워 유저 | 사용자 역할이라 이 묶음에 둔다(제안서 예 7) |
| 키오스크 | 차량 운전자 또는 작업자가 DOCK IN·DOCK OUT을 등록하는 현장 단말 | | |

## 3. 사실

### 역할
- 단말 역할: WCS PDA는 현장 작업·예외 조치(스캔, Reject 처리 등), PC·대시보드는 관리·조회를 맡는다
- WCS PDA는 현장 작업 수행과 예외 상황 조치 중심으로 구성하고, 단순 정보 조회 기능은 최소화한다
- WCS PDA의 핵심 기능은 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치다
- WCS PDA는 출고완료 확정도 수행한다
- 출고 검수도 현장 작업이므로 WCS PDA에 둔다
- 입출고 예정 정보 등 관리 목적 조회는 PC·대시보드 중심으로 검토해 제공한다
- 키오스크는 WCS PDA와 함께 쓴다

### 책임 경계 (무엇을 관리하고 무엇을 안 하나)
- 수작업 영역과 자동화 설비 사이의 작업은 작업자가 EWMS PDA로 한다
- 자동화 설비 구역의 현장 조치는 WCS PDA로 한다
- 단, 수작업 영역 팔레트 운반(재고 비관리) 요청은 WCS PDA로 한다
- 출고완료 확정은 EWMS PDA가 아니라 WCS가 제공한다
- WCS가 제공하는 출고완료 확정은 PDA 스캔과 PC 일괄 확정이다

### 누가 누구에게 지시하나
- EWMS PDA의 작업 결과는 EWMS가 WCS에 실시간 통보한다

### 그 밖의 사실

#### WCS PDA 기능 상세
| 기능 | 항목 |
|---|---|
| 스캔 대상 | 팔레트 ID·HU·BOX 바코드·셀 |
| 상태 확인 | 현재 위치, 셀 상태, 보류 여부, 진행 중 Task·Action, Reject 사유 |
| 작업 추적 | 팔레트 ID 기준 Task → Workflow → Action 진행 이력 |
| Reject 처리 | 사유코드 확인, 조치 결과 입력, 재투입 요청 |
| 긴급 조치 | 작업 보류·해제, 우선순위 상향, 수동 완료·취소, 파워유저 알람 |

- Reject 사후 처리 화면은 모든 Reject를 다루는 통일된 화면을 쓴다

#### 사용자 권한
- 긴급 조치는 권한별로 제한한다
- 수동 완료·취소는 파워유저만 하며, 사유 입력이 필수다
- 수동 완료·취소 처리 내역은 전략 이력에 남긴다
- 수동 완료는 설비 실적 없이 다음 단계로 넘기는 것이다
- 수동 완료를 해도 W/T 확정은 기존 규칙을 따른다

#### 대시보드 구성
- 대시보드는 센터 관제실 대형 화면 1개와 PC 웹 화면으로 제공하며, 같은 화면을 표시 크기만 달리한다
- 현장 표시판은 DOCK 현황판만 따로 둔다

| 표시 항목 | 내용 |
|---|---|
| 입출고 예정·진행률 | |
| 설비 운영 상태 | |
| 오류 모니터링 | 거래처 정보 오류, 보류 오류, Reject, 인터페이스 실패, 재고대사 불일치 |
| 팔레트 작업 상태 오류 | 도착 지연·신호 불일치·미지시 신호 |
| 자동 전환·자동 생성 | 이송 수단 전환·용량 초과 재입고 |
| 공팔레트 | 수량·ID 불일치 |
| 프로세스 통합 모니터링 | 프로세스 유형별 작업 요구·할당·진행·완료·부족 건수, 재할당·긴급 보충 건수 |

- 전략별 지표 대시보드(입고월 FIFO 준수율 등)는 두지 않는다

## 5. 미결
- 재료에 이 묶음의 미결 기록은 없다.
