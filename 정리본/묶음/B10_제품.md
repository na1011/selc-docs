# [묶음] 제품

> 유형: 기준정보 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 제품(제품마스터·UOM 마스터)에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 제품을 무엇으로 구분하나, 제품마스터와 UOM 마스터가 무엇을 갖나, 제품이 어디서 오나(EWMS 연동 / WCS 자체 생성)를 다룬다.
- 제조번호 자체와 시리얼 추적은 「LOT·제조번호」 묶음이 갖는다. 이 묶음은 제품마스터의 제조번호 관리여부(S/N 관리 여부)만 갖는다(제안서 예 3).
- 재고를 UOM 레벨별로 무엇 단위로 구분하나는 「재고 이력·관리단위」 묶음이 갖는다. 제품마스터를 받고 고치는 순서는 → P48 제품마스터 수신·관리.

## 3. 사실

### 3.1 무엇을 식별하나(식별 기준)
- 제품은 화주사별로 관리한다.
- 제품은 화주 + 제품코드로 구분한다.
- 같은 제품코드라도 화주가 다르면 별도 제품이다.
- 운영 속성(디베닝 대상·OUT EQUIPMENT 등)도 제품(화주 + 제품코드) 단위로 설정한다.

### 3.2 구성 항목

**제품마스터**
- [확인필요] 제품마스터에는 디베닝 대상, 팔레트 입고 대상, OUT EQUIPMENT(GANTRY/BOX), 제조번호 관리여부 속성이 있다.
- 제품마스터에 팔레트 유형(2316·1816·1960) 속성을 관리한다.
- 제품마스터에 등록 출처(EWMS / WCS 자체)를 둔다.
- 제품마스터(EWMS 수신)에는 치수(폭·길이·높이)·중량과 적재 관련 속성이 있다. 적재 관련 속성은 원문에 TIER·LAYER·MAXLAYER·SIDE_CLAMP로만 적혀 있고, 업무 이름은 원문에 없다.
- Product Code는 별도 관리 대상(별도 마스터·키워드)이 아니라 제품마스터의 하위 속성이다.
- 제품(화주 + 제품코드)마다 Product Code 값을 가지며, 제품마스터 연동으로 함께 받는다.
- 제품명은 재고조회 등 화면에서 모델명으로 표기한다.
- ⚠ 원문 불일치: 제품마스터 속성은 입고 경로, 보관설비, 출고설비를 결정한다.
- ⚠ 원문 불일치: 디베닝 경로는 제품마스터 디베닝 대상 속성이 아니라 디베닝 입고정보(디베닝 하역 대상) 수신과 W/T의 목적지로 정한다(→ P03 디베닝입고).

**OUT EQUIPMENT**
- 출고 구성 층은 제품마스터의 OUT EQUIPMENT(GANTRY/BOX)로 정한다. 값의 뜻은 4절이다.
- OUT EQUIPMENT는 제품마스터로 받아 관리한다.
- 피킹 W/T 할당과 사전 보충 대상 산출에서 이 값으로 출고 구성 층을 정한다.
- GANTRY 대상은 OUT EQUIPMENT = GANTRY인 제품이다.
- OUT EQUIPMENT = BOX인 제품은 중소형 제품이다.

**UOM 마스터·아이템 UOM 레벨**
- 제품의 UOM은 3레벨(낱개·중포장단위·팔레트 단위)까지 UOM 마스터로 관리한다. 레벨 값은 4절이다.
- UOM 마스터는 제품(화주 + 제품코드)마다 아이템 UOM 레벨별 수량(1레벨 환산 수량)을 가진다.
- UOM 1레벨(수량 1)은 모든 제품에 자동으로 생기고 수정하지 않는다.
- 평택 CDC는 중포장단위를 사용하지 않는다. 그래서 2레벨 수량을 1로 둔다.
- 다른 센터는 중포장단위를 사용할 것으로 예상된다.
- 제품의 특성상 BOX = EA를 룰로 한다. BOX는 EA(개체, 아이템 UOM 레벨 1)로 간주한다.
- EWMS는 다른 UOM으로 수량을 보내지 않는다. EWMS와 주고받는 수량(W/T·실적·재고대사)은 모두 1레벨(BOX) 수량이다.
- EWMS와 주고받는 수량에는 UOM 환산을 하지 않는다.

**LEQ**
- UOM 3레벨(팔레트 단위) 수량은 LEQ다.
- LEQ는 EWMS 제품마스터의 값을 받아 쓴다.
- [미결 Q-025] LEQ를 받는 연동 속성은 정해지지 않았다(5절).
- WCS는 LEQ를 디베닝 팔레타이징 지시에 쓴다.

### 3.3 누가 만들고 어디서 오나
- EWMS 제품의 제품마스터는 EWMS가 WCS로 보낸다.
- EWMS에서 받는 제품은 EWMS 연동으로 관리한다.
- 디베닝 대상 여부는 상위 시스템(EWMS)이 정해 제품마스터 구분값으로 WCS에 내려준다.

**WCS 자체 생성 제품**
- WCS 자체 생성 제품은 공팔레트와 TRASH BIN이다.
- 공팔레트는 EWMS에서 제품코드를 받지 않아, WCS 제품관리 화면에서 자체 생성한 제품으로 관리한다.
- TRASH BIN은 EWMS에서 제품코드를 받지 않아, WCS 제품관리 화면에서 자체 생성한 제품으로 재고 관리한다.
- 자체 생성 제품의 제품코드는 EWMS 제품코드와 겹치지 않도록 접두어 등 별도 채번 규칙을 둔다. 실제 값은 제품관리 화면에서 등록할 때 정한다.
- 자체 생성 제품의 화주는 화주 마스터에 등록한 내부 화주 하나(예: 000 'WCS 자체')다. 화주는 LOT 필수 속성이라, 화주가 없으면 LOT를 채번할 수 없다.
- 공팔레트 제품은 팔레트 유형(2316·1816·1960 등)마다 하나씩 만든다.
- 자체 생성 제품은 제조번호 미관리, 디베닝 대상 N, GANTRY 작업여부 N으로 둔다.
- TRASH BIN 제품은 하나만 둔다(재고 수량을 무엇으로 세나는 「TRASH BIN」 묶음).
- TRASH BIN 제품의 팔레트 유형은 비워 둔다(「제약 없음」). 그래서 팔레트 유형 불일치 Reject 대상이 아니다.
- 자체 생성 제품은 UOM 1레벨만 필수다. 3레벨이 없으면 LEQ를 쓰는 처리의 대상이 아니다.
- 자체 생성 제품의 재고는 EWMS가 그 제품을 모르므로 W/T 생성요청·실적 보고 대상이 아니다. WCS 이력으로만 처리한다.

### 3.4 사용 여부·이력
- WCS는 제품마스터 변경 이력을 관리한다.
- 제품의 사용 여부(사용/미사용 구분): 원문에 없음.

## 4. 상태 값

**OUT EQUIPMENT**

| 값 | 뜻 |
|---|---|
| GANTRY | 1층 GANTRY(1층 MIXED)에서 출고 구성한다. |
| BOX | 3층 BOX Shuttle·3층 MIXED 팔레타이징에서 출고 구성한다. |

**아이템 UOM 레벨**

| 값 | 뜻 |
|---|---|
| 1 | 낱개(BOX). EA로 간주한다. 1레벨 환산 수량은 항상 1이다. |
| 2 | 중포장단위. 1레벨 환산 수량은 중포장 입수다(평택 CDC 1, 미사용). |
| 3 | 팔레트 단위. 1레벨 환산 수량은 LEQ다. |

## 5. 미결
- [미결 Q-025] LEQ를 EWMS 제품마스터의 어느 연동 속성으로 받는지 정해지지 않았다.

## 6. 변경 이력
- GANTRY 대상 규칙(OUT EQUIPMENT = GANTRY)은 예전 규칙을 대체했다.
