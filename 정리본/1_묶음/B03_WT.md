# [묶음] W/T

> 유형: 시스템 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 W/T의 종류·상태와 이 프로젝트에서의 고유 의미만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- W/T가 무엇인지, 종류(적치·피킹·이동)와 종류별 생성 주체, W/T 생성·확정이 재고에 갖는 뜻, WCS 연계 상태, W/T 취소의 뜻을 다룬다.
- 가용재고·가용수량·예약의 뜻은 「재고 수량」 묶음이 갖는다. 이 묶음은 그 이름만 쓴다.
- W/T를 주고받는 순서는 → P35 W/T 연동, 취소를 요청하는 순서는 → P26 W/T 취소 요청에 있다.

## 2. 용어
| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| W/T | EWMS가 생성·확정하는 창고 작업 지시. EWMS 작업 단위다. 유형은 적치 W/T(입고), 피킹 W/T(출고), 이동 W/T(BIN 간 이동)이다 | Warehouse Task, WT | EWM 표준 (잠정 §9-8) |
| 적치 W/T | 입고 재고를 AS/RS 등 자동화 설비에 적치하기 위한 W/T. 입고 W/T는 모두 적치 W/T로 부른다 | 입고 W/T(쓰지 않는 표기) | |
| 피킹 W/T | 출고를 위한 W/T. 출고 W/T는 모두 피킹 W/T로 부른다 | 출고 W/T(쓰지 않는 표기) | |
| 이동 W/T | 출발 BIN과 도착 BIN을 지정해 재고 위치를 옮기는 W/T | BTB W/T(쓰지 않는 표기), BIN to BIN W/T | |
| W/T 생성 | W/T가 생성된 상태. 그 재고는 WCS 재고로 잡히지만 가용재고는 아니다 | | 프로젝트 고유 의미 |
| W/T 확정 | 작업 완료로 W/T가 확정된 상태. 재고가 가용재고가 되어 출고지시가 가능하다 | | |
| W/T 취소 | EWMS가 생성한 피킹 W/T를 오픈오더 기준으로 전량 취소하는 처리. 수량 일부를 지정해 취소할 수 없다 | | |

## 3. 사실

### 3-1. 역할
- WCS는 W/T 생성·확정으로 EWMS와 재고를 동기화한다
- EWMS(로케이션 단위)와 WCS(상세 위치 단위)의 재고는 W/T 생성·확정으로만 동기화한다
- 자동화 설비 구역의 재고 변동(진입·이동·배출)은 W/T 생성·확정으로 EWMS와 동기화한다
- 재고는 W/T 상태(생성/확정)에 따라 비가용/가용으로 구분된다

### 3-2. 책임 경계 (무엇을 관리하고 무엇을 안 하나)
- W/T는 EWMS가 생성·확정하고, WCS는 이를 연동해 재고를 관리한다
- WCS가 EWMS에 W/T 생성을 요청하는 경우는 디베닝 적치 W/T와, GTP·직송 이적 잔량의 자동화 → 수작업 이동 W/T뿐이다
- WCS가 적치 W/T 생성을 요청하는 경우는 디베닝뿐이다
- 층간 이동과 수작업 영역에서 시작하는 이동은 EWMS가 W/T를 생성해 보낸다. WCS는 W/T 생성을 요청하지 않고, 받은 W/T로 작업지시한다

#### W/T 종류별 생성 주체
| W/T | 쓰는 이동 | 생성 |
|---|---|---|
| 적치 W/T | 일반 입고(AS/RS 입고) | EWMS가 생성해 WCS에 실시간 전송 |
| 적치 W/T | 1층 → 3층 Bypass | EWMS 생성·WCS 수신 |
| 적치 W/T | 디베닝 입고 | WCS 요청으로 EWMS가 생성 |
| 피킹 W/T | 출고 | EWMS가 생성해 WCS에 보냄 |
| 이동 W/T | 4층 → 3층 Bypass | EWMS 생성·WCS 수신 |
| 이동 W/T | 층간 이동(1층 → 3·4층 수작업 이동) | EWMS가 생성해 보냄. WCS는 생성을 요청하지 않음 |
| 이동 W/T | GTP·직송 이적 잔량의 자동화 설비 → 수작업 이동 | WCS 요청으로 EWMS가 생성. 생성 요청과 확정을 함께 한다 |

### 3-3. 누가 누구에게 지시하나
- W/T 취소 기능은 EWMS가 제공하고, WCS가 EWMS에 취소를 요청한다

### 3-4. 그 밖의 사실

#### W/T 확정과 HU
- W/T 확정은 대상 팔레트의 HU 생성이 끝난 뒤에만 한다. HU 생성이 끝나기 전에는 WCS가 EWMS에 W/T 확정 요청을 보내지 않는다
- [확인필요] WCS는 HU 생성이 끝나지 않은 팔레트의 W/T 확정을 차단한다

#### W/T 취소의 결과
- W/T가 취소되면 EWMS는 새 W/T를 만들지 않고 오더가 종료되어 재작업할 수 없다
- 그래서 W/T 취소는 주의해서 쓴다

#### 출고확정 실적과 PARTIAL
- EWMS는 피킹 W/T의 출고확정 실적을 PARTIAL(W/T 수량 일부)로 받아도 수용한다. GTP뿐 아니라 GANTRY·3층 출고 구성·센서 확정 등 모든 출고확정 실적에 같다

#### 직송 피킹 W/T
- 직송 피킹 W/T에 담겨 오는 정보는 「출고 오더」 묶음 3-3에 있다.
