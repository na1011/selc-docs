# [묶음] AS/RS

> 유형: 설비 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 AS/RS에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.
> AS/RS는 입출고 라인과 셀·보관 구조를 한 장으로 둔다(잠정 §9-5). 셀·보관 구조는 3-3에 있다.

## 1. 범위
- AS/RS 본체와 그 일부인 입고대·출고대·3층 입고라인·재투입라인·3층 디팔레타이징 배출라인, 크레인 호기·Bay, 사이즈 체크, Bypass를 다룬다.
- 배출라인이 이어지는 3층 디랩핑기부터는 「3층 디팔레타이징·MIXED」 묶음이 갖는다. 설비 접점(P-NN)은 「설비 공통·설비사」 묶음이 갖는다. 적치셀이라는 셀 개념은 「WCS 위치」 묶음이 갖는다. 팔레트 ID 앞 4자리 = 팔레트 유형은 「팔레트」 묶음이 갖는다.
- 적치·인출·Bypass 이송·용량 부족 배출의 순서는 → P08 AS/RS 적치, → P09 AS/RS 인출, → P10 AS/RS Bypass 이송, → P12 AS/RS 용량 부족 배출에 있다.

## 2. 용어

| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| AS/RS | 팔레트 단위로 재고를 보관·입출고하는 자동화 창고 설비. | Automated Storage and Retrieval System | |
| 입고대 | AS/RS에 팔레트를 투입하는 위치. | AS/RS 투입구(쓰지 않는 표기), 투입구 | |
| 출고대 | AS/RS가 팔레트를 그대로 배출하는 곳. 1층에서 AS/RS FULL 팔레트 출고를 배출하는 지점을 1층 출고대라 하며, 1층 GANTRY 출고 구성 팔레트를 배출하는 GANTRY 출고대와 구분한다. | 1층 출고대, 3층 출고대, 3층 팔레트 배출라인(쓰지 않는 표기), 팔레트 배출라인 | GANTRY 출고대 정의는 「GANTRY」 묶음 |
| AS/RS 3층 입고라인 | 디베닝 입고 후 3층 입고 팔레타이징로봇이 팔레타이징하고 3층 랩핑기로 랩핑한 중소형제품 팔레트가 AS/RS에 입고되는 라인. 3층 입고대와 구분한다. | 3층 입고라인 | |
| AS/RS 재투입라인 | 3층 부분 해체에서 작업자가 피킹량만 작업한 뒤 남은 팔레트를 AS/RS에 다시 넣는 라인. 3층 입고대·AS/RS 3층 입고라인과 구분한다. | 재투입라인 | |
| 3층 디팔레타이징 배출라인 | AS/RS 3층 배출라인 중 하나(나머지는 3층 출고대 2개). AS/RS에 보관된 중소형제품 팔레트를 디팔레타이징하기 위해 배출하는 AS/RS 3층 출고라인이다. | 디팔레타이징 라인, AS/RS 3층 출고라인 | |
| 크레인 호기 | AS/RS 안에서 팔레트를 적치·인출하는 크레인 단위(1~16호기). | 스태커 크레인 | |
| Bay | AS/RS 랙의 구획 단위(1~32 Bay). | — | |
| 사이즈 체크 | AS/RS 입구에서 팔레트 크기·높이·중량을 측정해 규격 초과 시 Reject하는 절차. | 사이즈체커 | |
| Bypass | 화물을 AS/RS를 통해 옮기고자 할 때 쓰는 처리(AS/RS를 이송 경로로 사용). | 바이패스, BYPASS | |

## 3. 사실

### 3-1. 위치
- 2층 AS/RS: 원문에 2층 기술 없음 (§9-6).
- AS/RS의 투입·배출구는 1·3·4층에 있다. 층별 구성은 3-2에 있다.
- [추가 협의] AS/RS 재투입라인의 물리 위치는 정해지지 않았다(→ 5. 미결 Q-207).

### 3-2. 투입·배출구

#### 층별 구성
- AS/RS는 1·3·4층에 입고대·배출구가 있다.
- 입고대는 1·3·4층에 있으며 모든 크레인 호기에 접근할 수 있다.
- ⚠ 원문 불일치: 층별 역할상 1층에 AS/RS 입고대, 3층에 출고대가 있다.
- ⚠ 원문 불일치: 출고대는 1층에도 있다(1층 출고대).

#### 1층
- AS/RS FULL 팔레트는 1층 출고대로 배출한다.
- 1층 출고대는 AS/RS FULL 팔레트 출고와 재고실사 배출을 배출하는 곳이다.
- 위치(셀) 마스터에 1층 출고대를 3층 출고대·GANTRY 출고대와 구분해 관리한다.
- 1층 사이즈 체크는 AS/RS로 이어진다.
- 위 1층 연결이 같은 설비사 내부 인계라는 것은 「설비 공통·설비사」 묶음 3-4에 있다.
- 사이즈 체크는 AS/RS 입구에서 ECS가 팔레트 크기·높이·중량을 측정하는 것이다.

#### 3층 투입 (3개)
- 3층에는 투입 지점이 따로 셋 있다: ① 3층 입고대(1개 포트) ② AS/RS 3층 입고라인(디베닝 팔레타이징 팔레트) ③ AS/RS 재투입라인(3층 부분 해체 잔량 재입고).
- 3층 입고대는 3층에서 AS/RS 투입이 필요한 경우에 쓴다: 3층 출고대 팔레트 재투입, 3층 출고 수작업 영역 팔레트, 3층 매거진 배출 공팔레트 묶음, TRASH BIN 보관.
- AS/RS 3층 입고라인은 로지스올 설비(3층 랩핑기)에서 팔레트를 받는다. 이 인계는 설비 접점 P-01이며, 접점은 「설비 공통·설비사」 묶음이 갖는다.
- 3층 부분 해체 후 남은 팔레트는 AS/RS 재투입라인으로 들어간다.
- AS/RS 재투입라인으로 재투입할 때 사이즈 체크를 한다.

#### 3층 배출 (3개)
- 3층 배출라인은 3개다: ① 3층 디팔레타이징 배출라인 1개 ② 3층 출고대 2개.
- AS/RS 3층 디팔레타이징 배출라인은 3층 디랩핑기로 직접 이어진다. 컨베이어 라인이며 유인지게차 구간이 없다.
- 3층 디팔레타이징 배출라인은 3층 출고 구성에 쓸 팔레트를 디팔레타이징할 때 쓴다.
- 3층 출고대 2개는 Bypass·Reject·GTP 팔레트 등을 디팔레타이징 없이 팔레트 그대로 수작업 영역 쪽으로 배출한다. Bypass 팔레트, Reject 팔레트(AS/RS 만재로 인한 용량 부족 배출 포함), 출고 수작업 영역(GTP 출고)으로 보내는 팔레트가 이 라인으로 나온다.
- 3층 TRASH BIN 공급은 AS/RS 출고대로 배출한다.
- 3층 출고 구성 경로·재투입라인 연결이 같은 설비사 내부 인계(설비 접점 아님)라는 것은 「설비 공통·설비사」 묶음 3-4에 있다.
- 3층 출고대 2개 중 어느 출고대로 배출할지는 현대무벡스 ECS가 정한다.

#### 투입·배출구의 기준정보 등록
- 3층 AS/RS 라인 6개(3층 입고대, AS/RS 3층 입고라인, AS/RS 재투입라인, 3층 디팔레타이징 배출라인 1개, 3층 출고대 2개)는 서로 구분해 설비 기준정보(투입·배출 포트)와 위치(셀) 마스터에 각각 등록한다.
- 입고대는 투입 후 적치 완료 전 팔레트 재고의 위치가 된다(입고대를 층별 셀로 두는 것은 「WCS 위치」 묶음).

### 3-3. 보관 단위·제약
- AS/RS 보관 단위는 팔레트다(팔레트화 필수).
- AS/RS는 팔레트 단위 핵심 자동화 보관 설비로, 일반·디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다.
- AS/RS는 TRASH BIN도 팔레트에 태워 보관한다.
- [확인필요] 사이즈 체크의 설비 유형별 속성은 규격 임계값(크기·높이·중량)이다.

#### 셀·보관 구조
- AS/RS는 팔레트 유형에 따라 크레인 호기와 Bay가 다르다. 그래서 팔레트를 AS/RS에 투입할 때 팔레트 유형이 중요한 값이다.

  | 팔레트 유형 | 크레인 호기 | Bay |
  |---|---|---|
  | 2316 | 1·2호기 | 1~4 Bay |
  | 1960 | 3·4호기 | 5~8 Bay |
  | 1816 | 5~16호기 | 9~32 Bay |

- 크레인 호기별 담당 Bay와 수용 팔레트 유형은 AS/RS 설비 기준정보로 관리한다.
- [확인필요] AS/RS 설비 유형별 속성은 셀 구성(열·연·단), 셀 크기 등급, 층별 투입·배출구, 공팔레트 보관 구역, 셀 코드, 크레인 호기별 담당 Bay·수용 팔레트 유형이다. 셀 구성·셀 코드의 실제 값만 [미결 Q-034]다(5절).
- AS/RS 셀 구성(호기·Bay·열·연·단)과 셀 코드 포맷은 현대무벡스 설비 자료를 그대로 받아 셀 마스터에 등록한다. 별도 WCS 셀 코드나 맵핑은 없다.
- 셀 코드의 호기·Bay로 팔레트 유형별 구역을 판단한다.
- 공팔레트 보관 구역은 따로 두지 않는다. 공팔레트 묶음도 팔레트 유형별 Bay 구역 안에서 AS/RS가 셀을 정한다. TRASH BIN도 같은 방식이다.
- 공팔레트 묶음과 재입고(재고실사·부분 해체) 팔레트도 같은 기준으로 유형별 호기에 적치한다.

#### 셀을 누가 정하나
- 적치셀은 AS/RS(현대무벡스)가 자동으로 정한다. WCS가 지정할 수도 있다(선택 기능, OPTIONAL).
- 적치 가능 여부는 적치셀을 자동 할당하는 AS/RS(현대무벡스)가 판단한다.
- 출고 피킹셀은 WCS가 지정한다.

### 3-4. 설비사
- AS/RS의 설비사는 현대무벡스다.
- AS/RS 재투입라인의 설비사는 현대무벡스다.
- 사이즈 체크 설비는 현대무벡스 담당이다.

### 3-5. 능력
원문에 없음. 셀 구성 실제 값(호기별 Bay·열·연·단 수, 셀 크기 등급)은 미결이다(Q-034).

### 3-6. 운영 상태
원문에 없음.

### 3-7. 그 밖의 사실 — Bypass
- Bypass 지시는 EWMS로부터 받는다.
- Bypass를 어떤 업무(OEM·쉽백 등)에 지시할지는 EWMS가 정하며 WCS는 관여하지 않는다.
- Bypass 경로는 1층 → 3층과 4층 → 3층이 기본이다. 경우에 따라 1층 → 4층(적치 W/T DEST 9014·RCV4)도 생길 수 있다.

## 4. 상태 값
해당 없음.

## 5. 미결
- [미결 Q-034] [추후 정리] AS/RS 셀 구성 실제 값(호기별 Bay·열·연·단 수, 셀 크기 등급)과 셀 코드 포맷은 현대무벡스 설비 자료를 받은 뒤 셀 마스터에 등록한다. 설비사 체계 그대로 등록하고 공팔레트 별도 구역은 두지 않기로 정했다.
- [미결 Q-207] [추가 협의] AS/RS 재투입라인의 물리 위치.
- [미결 Q-107] [추가 협의] 디베닝 팔레트(P-01, AS/RS 3층 입고라인)에 사이즈 체크를 하는지 — 현대무벡스 확인.
