# [묶음] 재고 운영 용어

> 유형: 업무 용어 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 재고 운영 업무(재고대사·재고실사·재고 보정·재고 스냅샷)의 이름과 그에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- 재고를 맞추고 확인하는 운영 업무의 정의를 다룬다. 「어떻게 하나」는 → P39 재고대사, → P40 재고실사, → P34 재고 반영·보정에 있다.
- 재고 수량의 뜻은 「재고 수량」 묶음, 재고 보정 이력 유형은 「재고 이력·관리단위」 묶음이 갖는다.

## 2. 용어

| 용어 | 뜻 | 동의어 | 비고 |
|---|---|---|---|
| 재고대사 | WCS 재고를 설비사(ECS) 재고, EWMS 재고(RCV9·WCS1 로케이션)와 비교해 일치시키는 작업이다. | | 불일치 유형은 4절 |
| 재고실사 | 자동화 설비 재고를 유인 영역으로 배출하여 실물 수량을 확인하는 작업이다. | 재고조사 | |
| 재고 보정 | 재고대사·재고실사 차이 등으로 WCS 재고를 맞추는 처리다. | | |
| 재고 스냅샷 | 특정 시점의 재고를 그대로 복사해 둔 기록이다. | 스냅샷, 시점재고 스냅샷 | |

## 3. 사실 — 그 밖의 사실

**재고 보정의 책임 경계**
- 재고 보정은 EWMS 등 외부 시스템과 연동하지 않고 WCS만 단독으로 처리한다.
- 재고대사 불일치는 WCS만 단독으로 보정한다. 이 보정은 EWMS와 연동하지 않는다.
- 재고실사 차이 보정은 WCS만 단독으로 한다. 이 보정은 EWMS와 연동하지 않는다.
- 재고 보정 등 WCS 단독 재고 변경은 EWMS에 W/T 생성 요청·확정을 보내지 않는다.

**재고 스냅샷의 구성**
- 재고 스냅샷 항목은 스냅샷 ID, 기준 일시, 설비사·설비, 위치(셀), 팔레트 ID/BOX, 제품코드, 수량이다.
- 재고대사 스냅샷에는 예약수량도 함께 담는다.
- 스냅샷은 보관해 이력으로 조회한다.
