# [묶음] LOT·제조번호

> 유형: 기준정보 · 확인 담당: 미정(§9-2) · 원문 기준일 2026-11-02
> 이 묶음은 LOT와 제조번호(시리얼)에 대해 늘 참인 것만 담는다. 흐름·조건·순서는 프로세스 문서에 있다.

## 1. 범위
- LOT가 무엇이고 무엇으로 채번되나(LOT 생성 전략·LOT 속성), 보관·출고 때 LOT를 섞는 기준, 제조번호를 시리얼 마스터·이력 로그로 추적하는 것의 사실을 다룬다.
- 제품마스터의 제조번호 관리여부(S/N 관리 여부)와 Product Code 자체는 「제품」 묶음이 갖는다.
- LOT를 채번하고 속성을 바꾸는 순서는 → P36 LOT 채번·속성 변경, 제조번호를 받아 로그를 쌓는 순서는 → P37 제조번호 수신·추적.

## 2. 용어

## 3. 사실

### 3-1. LOT

#### 무엇을 식별하나(식별 기준)
- LOT는 창고별 로트번호로 식별한다.
- 로트번호는 L로 시작하는 12자리 일련번호다(L + 숫자 11자리).
- 일련번호는 단순 일련번호(단순 시퀀스)로 채번한다.
- 로트번호 일련번호는 창고 구분 없이 하나로 이어진다. 숫자는 0으로 채운다(예: L00000000001).
- 창고코드·화주·제품코드는 모든 LOT 생성 전략에 늘 포함되며 선택 해제할 수 없다. 그래서 LOT 하나는 한 창고·화주·제품을 가리킨다.
- 화주가 다른 재고는 LOT로 구분되어 섞이지 않는다.

#### 구성 항목 — LOT 생성 전략과 LOT 속성
- LOT 생성 전략은 창고별로 정한다. 후보 속성 중 사용할 속성을 골라, 그 조합으로 LOT를 채번한다.
- LOT 생성 전략의 후보 속성은 다음과 같다.
  - 필수: 창고코드, 화주, 제품코드
  - 선택: 제조번호, 입고일자, Storage Location, 기타 LOT 속성 1~5(예비 항목, 입고정보 항목 맵핑)
- LOT 생성 전략은 별도 관리 화면에서 관리한다.
- LOT 생성 전략에서 선택한 속성마다 보관 체크·출고 체크 사용 여부를 둔다.
- 각 후보 속성의 보관 체크·출고 체크는 전략에 따른다.
- 창고코드는 LOT 필수 속성이다. 창고코드(창고정보)가 다르면 LOT를 따로 채번한다.
- LOT 속성의 창고코드는 창고와 같은 항목이다.
- 화주는 LOT 필수 속성이다. 화주정보가 다르면 LOT를 채번한다.
- 제품코드는 LOT 필수 속성이다. 제품코드가 다르면 LOT를 채번한다.
- Storage Location(WCS 맵핑 기준)은 선택 속성이다. 전략에서 선택하면 값이 다를 때 LOT를 채번한다.
- 입고일자는 선택 속성이다. 전략에서 선택하면 입고일자가 다를 때 LOT를 채번한다. 기준 시점은 고정하지 않는다.
- 기타 LOT 속성 1~5는 예비 항목이다. 전략에서 선택하면 값이 다를 때 LOT를 채번한다.
- Valuation Type을 기타 LOT 속성으로 맵핑해 선택하면, 값이 다를 때 LOT를 채번한다.
- 제조번호는 LOT 생성 전략의 후보 속성으로 제공한다(기능 뼈대만 둔다).
- LOT 생성 전략에서 선택하지 않은 속성은 값이 달라도 LOT를 새로 채번하지 않는다.
- 제조번호를 선택하지 않은 창고에서는 제조번호로 LOT를 새로 채번하지 않는다.
- LOT는 생성 시점에 적용된 전략의 속성값을 LOT 속성으로 보관한다.
- 입고월은 입고일자와 별개 속성이다.

**기타 LOT 속성의 속성명**
- 기타 LOT 속성에는 속성명(표시명)을 따로 관리해 맵핑된 이름을 붙인다(예: 1 = Storage Location, 2 = Valuation Type, 3 = 입고월).
- 화면·조회에는 맵핑된 속성명을 표시한다.
- 기타 LOT 속성의 속성명과 입고정보 항목 맵핑은 창고별로 관리한다.
- 속성명·입고정보 맵핑은 LOT 생성 전략과 한 화면에서 관리한다.

**평택 CDC**
- 평택 CDC LOT 생성 전략은 필수 속성(창고코드·화주·제품코드)에 기타 LOT 속성 1~3(Storage Location·Valuation Type·입고월)을 더한 것이다.
- 평택 CDC는 제조번호·입고일자·기타 LOT 속성 4~5를 선택하지 않는다.
- 평택 CDC 입고정보 맵핑: Storage Location → 기타 LOT 속성1, Valuation Type → 기타 LOT 속성2, 입고월 → 기타 LOT 속성3.
- 평택 CDC는 입고일자 대신 입고월을 LOT 속성으로 쓴다.
- 평택 CDC는 제조번호를 LOT 속성으로 선택하지 않는다.
- 제조번호를 선택하지 않는 이유는 물류 작업지시 효율 저하 우려다.

#### 누가 만들고 어디서 오나
- LOT는 WCS가 채번한다.
- Valuation Type 값은 EWMS로부터 받아 사용한다.
- Storage Location은 적치 W/T의 값을 WCS 기준으로 맵핑한 것이다.
- 기타 LOT 속성에는 입고정보 항목을 맵핑한다.
- ⚠ 원문 불일치: [미결 Q-175] 입고월은 EWMS로부터 받은 입고예정정보를 WCS가 가공해 만든다.
- ⚠ 원문 불일치: 입고예정정보는 입고 PLAN을 수립하는 용도로만 쓴다(「입고 오더」 묶음).
- ⚠ 원문 불일치: 입고월은 입고정보(입고예정정보·적치 W/T)의 입고일자로 WCS가 가공한다(→ P36 LOT 채번·속성 변경).

#### 사용 여부·이력
- LOT 생성 전략을 바꿔도 기존 LOT는 그대로 유지된다.
- 새 전략은 변경 이후 신규 채번부터 적용된다.
- LOT 속성 변경은 원 LOT의 속성값을 직접 고치지 않는다.
- LOT 속성 변경은 파손 등 여러 사유로 생긴다.
- LOT의 사용 여부(사용/미사용 구분): 원문에 없음.

#### 보관 체크·출고 체크 — LOT를 섞는 기준
- 「보관 체크 = 사용」인 속성이 다른 재고는 같은 팔레트·번들에 섞지 않는다.
- 속성이 다른 재고도 같은 셀(로케이션)에는 섞어 보관할 수 있다.
- 보관 체크에서 BOX는 EA로 간주한다.
- 출고 할당 때는 「출고 체크 = 사용」 속성이 출고 오더 조건과 일치하는 LOT만 할당한다.
- 같은 제품의 다른 LOT라도 출고 체크 속성이 같으면 섞어 출고해도 된다. 이런 LOT는 한 W/T·한 출고 팔레트에 섞어 할당한다.
- 출고 체크 속성이 다른 LOT는 섞지 않는다.
- LOT 혼합 여부는 출고 체크 속성만으로 판단한다. 유효기한·제조일 등 LOT 속성도 출고 체크가 되어 있지 않으면 혼합 대상이다(별도 혼합 기준을 두지 않는다).

### 3-2. 시리얼 추적

#### 무엇을 식별하나(식별 기준)
- 제조번호는 제품 개체 하나를 가리킨다. 시리얼은 유니크하므로 시리얼당 수량은 1이다.

#### 구성 항목
**시리얼 마스터**
- 시리얼 마스터는 제조번호의 최신 상태를 갖는다: 현재 위치, UOM 레벨별 상위 단위 ID, 최종 TASK번호.

**시리얼 이력 로그**
- 시리얼 이력 로그에는 로그를 발생시킨 변경 TASK번호를 함께 기록한다. 어떤 작업으로 로그가 생겼는지 추적하기 위해서다.
- 변경 TASK번호는 작업지시 체계의 Task 번호다. Task는 변경 TASK번호로 시리얼 이력 로그와 이어진다.
- 시리얼 이력 로그에는 아이템 UOM 레벨(1~3)별 항목을 기록한다.
- 이 UOM 레벨 항목으로 팔레타이징(하위 → 상위 단위 적재)과 디팔레타이징(상위 → 하위 단위 해체) 전후의 단위 관계를 추적한다.
- 팔레트 단위로 보관한 재고 안의 중포장 구성도 시리얼 이력 로그의 UOM 레벨 항목으로 추적한다.
- 시리얼 이력 로그 항목은 다음과 같다: 제조번호, 제품코드, 이벤트 구분(입고 생성/설비 실적/출고 검수), 변경 TASK번호·TASK 유형, 상위 W/T 번호, 설비 ID, FROM/TO 위치, UOM 레벨 1~3 항목의 변경 전/후 값, 발생 시각·수신 시각, 송신 시스템, 처리 결과(정상/누락/중복).
- 이력 로그가 쌓이는 이벤트는 세 가지다: 시리얼번호가 입고되어 처음 생성될 때, 설비로부터 시리얼번호 단위 결과 실적을 받을 때, 출고하면서 시리얼번호 단위 검수 결과를 받을 때.

#### 누가 만들고 어디서 오나
- 제조번호는 EWMS가 관리하는 제품 속성인 Product Code를 앞자리로 써서 만들어진다.
- WCS는 시리얼 마스터를 관리한다.

#### 사용 여부·이력
- 시리얼 마스터와 시리얼 이력 로그는 삭제하지 않고 영구 보관한다(자동 정리 없음).

#### 그 밖의 사실 — 시리얼 추적과 LOT의 관계
- 제조번호는 시리얼 마스터에 등록해 이력 로그로 추적한다.
- 재고·작업지시는 LOT 단위로 처리하고, 시리얼번호는 로그로만 추적한다.
- 평택 CDC에서 WCS는 제조번호를 재고·작업지시 단위(LOT)로 쓰지 않고 추적 로그 용도로만 쓴다.
- 제조번호 미관리 상품은 시리얼 마스터·이력 로그 대상에서 제외한다.
- 제조번호에는 필수 조건이 없다. 누락되어도 진행한다.
- 제조번호 누락·중복이 있어도 물류 프로세스(입고·적치·출고)를 막지 않고 정상 진행한다.
- 로그는 수신된 정보를 기준으로 쌓는다.
- ⚠ 원문 불일치: 조회 화면의 「누락」은 입고됐으나 출고 검수 이력이 없는 제조번호이고, 「중복」은 같은 제조번호가 두 번 이상 입고된 경우다.
- ⚠ 원문 불일치: 물류 진행 규칙의 「누락」은 제조번호를 받지 못한 경우다(누락 시 로그 없이 진행한다).

## 4. 상태 값
- 시리얼 이력 로그의 이벤트 구분·처리 결과 값은 3-2 「시리얼 이력 로그」 항목에 있다.

## 5. 미결
- [미결 Q-175] 입고월을 무엇으로 만드나(입고예정정보인지 적치 W/T인지)가 확인 중이다. 3-1의 원문 불일치 세 줄을 함께 본다.
- [미결 Q-081] [추후 정리] 시리얼 이력 로그에 Action ID를 함께 기록할지 정해지지 않았다.
