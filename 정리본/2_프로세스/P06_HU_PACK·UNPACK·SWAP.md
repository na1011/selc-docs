# [프로세스] HU PACK·UNPACK·SWAP

> 키워드: HU-VAL · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「HU」, 「WCS 위치」, 「재고 수량」
> **이름만 쓰는 묶음**: 「시스템」, 「단말」, 「재고 이력·관리단위」, 「LOT·제조번호」, 「팔레트」, 「작업지시 체계」, 「출고 업무 용어」
> **이어지는 프로세스**: 앞·뒤 → 없음(작업자 요청으로 시작해 재고 이력 반영으로 끝난다), 관련 → P05 HU 확인·생성, P29 출고 수작업 영역 출고, P34 재고 반영·보정

## 1. 범위

WCS는 자동화 설비 재고에 대해 HU PACK, HU UNPACK, HU SWAP 기능을 제공한다. 작업자가 WCS PDA에서 특정 셀의 재고현황을 조회해 처리한다. 셀 스캔으로 시작해, EWMS 처리 성공 뒤 WCS 재고 이력과 작업 이력을 남기면 끝난다.

## 2. 흐름

### 2-1. 공통 절차

1. (작업자, WCS PDA) 접근 가능한 셀을 스캔한다. (WCS) 셀 재고현황(HU, 제품, LOT, 수량, 상태)을 보여 준다.
2. (WCS) 작업 가능 여부를 점검한다. 예약수량·작업 잠금(진행 중 Task)·보류가 있으면 작업할 수 없다.
3. (작업자) 작업(PACK / UNPACK / SWAP)과 대상 재고·수량을 고른다.
4. (작업자) HU를 스캔한다. (WCS→EWMS) HU 조회로 검증하고, 새 HU면 HU를 생성한다.
5. (WCS→EWMS) PACK / UNPACK / SWAP을 요청한다.
6. (WCS) EWMS 처리가 성공한 뒤 결과를 재고 이력으로 반영한다. HU가 바뀌는 수량은 원 HU 출고 이력 + 대상 HU 입고 이력을 같은 변경 TASK번호로 남긴다(출고 수작업 영역 출고 분할과 같은 방식). 시리얼 관리 제품은 시리얼 이력 로그에도 남긴다.
7. (WCS) 작업자·시각·작업 유형·전후 HU를 작업 이력으로 남긴다.

### 2-2. 작업별 처리

- **HU PACK:** 셀 재고(HU 없는 재고 또는 다른 HU에서 UNPACK한 재고)와 수량을 고르고 대상 HU를 스캔한다. HU 조회 결과가 없으면 HU 생성 후 PACK을 요청한다. 이미 재고가 담긴 HU에도 추가로 담을 수 있다. WCS는 대상 HU 입고 이력으로 반영한다.
- **HU UNPACK:** 셀의 HU를 스캔해 확인하고 뺄 재고·수량을 고른다. 재고 전부 또는 일부를 뺄 수 있다. UNPACK을 요청하고, WCS는 원 HU 출고 이력으로 반영한다.
- **팔레트갈이:** 원 HU에서 HU UNPACK하고 대상 HU에 HU PACK하는 것으로 처리한다. 두 작업을 한 작업(같은 변경 TASK번호)으로 묶는다. 원 HU가 비면 해당 재고를 종료한다.
  - [미결 Q-154] 원 HU가 빈 뒤 HU 삭제 여부는 정해지지 않았다(→ 7. 미결).
- **HU SWAP:** 기존 HU와 새 HU를 차례로 스캔한다. 새 HU는 HU 조회 결과가 없거나 비어 있어야 하며, 다른 재고가 담겨 있으면 거부한다. 새 HU가 없으면 HU 생성 후 SWAP을 요청한다. WCS는 기존 HU 출고 + 새 HU 입고 이력으로 바꾸고, 수량·LOT·위치는 그대로다.

## 3. 조건·규칙

| 조건 | 처리 |
|---|---|
| HU 작업 셀 범위 | 작업자가 접근할 수 있는 셀로 한정한다. 접근 가능 여부는 셀 기준정보 설정을 기준으로 한다 |
| 셀 기준정보의 「HU 작업 가능」 표시 | WCS PDA는 이 표시가 있는 셀만 조회·작업할 수 있게 한다. 표시가 없는 셀을 스캔하면 작업 불가 안내를 띄운다 |
| 예약수량·작업 잠금(진행 중 Task)·보류가 있는 재고 | 작업 불가 |
| SWAP의 새 HU에 다른 재고가 담겨 있음 | 거부한다 |

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |

## 5. 예외

| 상황 | 처리 |
|---|---|
| HU 작업 중 EWMS 처리 실패 | 해당 PACK·UNPACK·SWAP을 처리하지 못하게 막는다. WCS 재고에 반영하지 않는다 |
| [미결 Q-154] 팔레트갈이처럼 이어서 요청하다 중간에 실패(UNPACK 성공 후 PACK 실패) | EWMS와 WCS 상태를 어떻게 맞출지 정하지 않았다 |

## 6. 기능·화면

- WCS PDA는 셀 재고현황 조회와 HU PACK·UNPACK·SWAP 처리 기능을 제공한다.

## 7. 미결

- [미결 Q-154] HU PACK·UNPACK·SWAP 남은 정리
  - [추후 정리] (1) PACK·UNPACK·SWAP 항목·응답, 빈 HU의 HU 삭제 여부
  - (2) 팔레트갈이처럼 이어서 요청하다 중간에 실패한 경우(UNPACK 성공 후 PACK 실패) EWMS·WCS 상태 정합 방법
- Q-154의 정해진 처리: 팔레트갈이 = UNPACK + PACK, 접근 가능 셀 = 셀 기준정보 설정 기준, 실패 시 처리 불가 제어, HU 작업 공통 절차·PACK·UNPACK·SWAP 호출·접근 가능 셀 관리.
