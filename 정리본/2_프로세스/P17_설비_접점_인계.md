# [프로세스] 설비 접점 인계

> 키워드: EQP-VND · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「설비 공통·설비사」, 「운반 설비」, 「작업지시 체계」
> **이름만 쓰는 묶음**: 「시스템」, 「팔레트」, 「WCS 위치」, 「W/T」, 「단말」, 「출고 업무 용어」
> **이어지는 프로세스**: 앞·뒤 → 설비 접점을 지나는 모든 프로세스(입고·출고·공팔레트 공급 등) / 옆 → P43 팔레트 작업 상태 추적, P42 작업지시 생성·실행

## 1. 범위
설비 접점에서 송신 설비가 완료·배출을 알려 올 때 시작해, WCS가 수신 설비에 작업을 지시할 때 끝난다. 수직반송기 층간 이송의 출발·도착 신호 처리를 함께 다룬다.
접점 번호(P-NN)의 목록과 뜻은 「설비 공통·설비사」 묶음에 있다. 이 문서는 접점에서 WCS가 중간 처리하는 흐름만 둔다.

## 2. 흐름

### 2-1. 접점 인계 (공통)
1. (송신 설비 ECS→WCS) 송신 설비가 완료·배출 정보를 보낸다.
2. (WCS→수신 설비 ECS) WCS가 수신 설비에 작업을 지시한다. 모든 설비 접점(P-01~P-14)에서 이렇게 한다.
3. [확인필요] (WCS) 설비 접점 구간에서 인계 중인 BOX의 위치·상태를 관리해 재고가 누락되지 않게 한다.

### 2-2. 수직반송기 인계
수직반송기로 들어가고 나오는 인계(P-06·P-10·P-14)가 설비 접점인 까닭(수직반송기 설비사 미정)은 「설비 공통·설비사」 묶음 3-3 「원칙」에 있다. 이 접점에서도 2-1처럼 송신 설비 완료를 받아 수신 설비에 작업을 지시한다.

1. (WCS→수직반송기 ECS) 층간 이송을 작업지시(Action)로 내린다(팔레트 ID, 출발 위치(층), 도착 위치(층)).
2. (수직반송기 ECS→WCS) 출발 시 센싱으로 출발 신호를 보낸다.
3. (WCS) 출발 신호를 받으면:
   - 작업 상태를 이송 중으로 바꾼다.
   - WCS 재고 팔레트(출고 수작업 영역 출고 팔레트 등)는 위치를 출발층 포트에서 수직반송기(이송 중 셀)로 옮긴다.
   - 출발층 포트는 비운 것으로 보고 다음 투입 지시를 낼 수 있게 한다.
4. (수직반송기 ECS→WCS) 도착 시 센싱으로 도착 신호를 보낸다.
5. (WCS) 도착 신호를 받으면:
   - 작업 상태를 도착으로 바꾼다.
   - 위치를 도착층 포트로 반영한다.
6. (WCS) Workflow에 따라 후행 작업을 잇는다: 1층 AMR 이송 지시(P-10) 또는 유인지게차, 3·4층 도착 시 W/T 확정, PDA 행선지 표시 등.

## 3. 조건·규칙

| 조건 | 처리 |
|---|---|
| 수직반송기 출발·도착 신호 | 작업지시의 결과로 받아 팔레트 작업 상태에 반영한다(→ P43 팔레트 작업 상태 추적) |
| 출발·도착 신호 처리의 작업 상태 판단 | 통합 모델을 따른다(→ P43 팔레트 작업 상태 추적) |
| 수직반송기 센싱 결과를 받은 뒤 | 후행 작업이 이어지도록 Workflow를 구성한다 |

## 4. 주고받는 정보

수직반송기와 주고받는 신호의 주요 항목은 출발 위치(층), 도착 위치(층), 팔레트 ID다.

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→수직반송기 ECS | 작업지시 시 | 팔레트 ID, 출발 위치(층), 도착 위치(층) |
| 수직반송기 ECS→WCS | 출발 시 — 센싱(출발 신호) | 팔레트 ID, 출발 위치(층), 도착 위치(층) |
| 수직반송기 ECS→WCS | 도착 시 — 센싱(도착 신호) | 팔레트 ID, 출발 위치(층), 도착 위치(층) |
| (공통) | 수직반송기 신호 모두 | 팔레트 ID, 출발 위치(층)·도착 위치(층) + 포트, 신호 시각 |

## 5. 예외
- 수직반송기 도착 지연·신호 불일치는 통합 모델 ⑤를 따른다(→ P43 팔레트 작업 상태 추적).
- [추후 정리] 설비 접점(P-01~P-14) 인계 중 한쪽 설비 장애·수량 불일치 시 처리는 추후 정리 대상이다(Q-055). 접점 P-14·P-10도 여기에 걸린다.
