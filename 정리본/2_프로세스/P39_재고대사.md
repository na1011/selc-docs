# [프로세스] 재고대사

> 키워드: INV-SYNC · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「재고 운영 용어」(재고대사·재고 스냅샷·재고 보정), 「EWMS BIN 코드」(BIN·BIN 마스터·RCV9·WCS1·Stock Type), 「조직·재고관리체계」(PLANT·화주·Storage Location 맵핑)
> **이름만 쓰는 묶음**: 「설비 공통·설비사」(현대무벡스·로지스올·생기연), 「AS/RS」, 「BOX Shuttle」, 「GANTRY」, 「운반 설비」(AMR), 「로지스올 입고 설비」(시퀀스 버퍼), 「제품」(WCS 자체 생성 제품·아이템 UOM 레벨), 「재고 수량」(예약수량), 「재고 이력·관리단위」(이력 유형), 「W/T」, 「작업지시 체계」(Action), 「창고 기초속성」, 「단말」(파워유저), 「WCS 위치」(셀), 「시스템」(EWMS·ECS)
> **이어지는 프로세스**: 앞 → P35 W/T 연동, → P33 재고 예약·보류(실물 부족 등록), → P37 제조번호 수신·추적(HU 시리얼 수 차이 등록) / 뒤 → P34 재고 반영·보정

## 1. 범위
- 정기(일 1회) 또는 수동으로 재고대사를 시작해, 불일치 건을 조회하고 처리(보정 또는 설비 재확인)할 때까지다
- 갈래는 둘이다. 설비사와는 같은 시점의 재고 스냅샷으로 비교하고, EWMS와는 BIN별 합산으로 대사한다

## 2. 흐름

### 2-1. 설비사 스냅샷 재고대사
1. (WCS→설비사 ECS) 재고정보를 요청한다(정기 일 1회·수동)
2. (설비사 ECS→WCS) 요청 시점의 재고 스냅샷을 만들어 WCS로 보낸다
3. (WCS) 같은 시점의 WCS 재고 스냅샷을 만든다
4. (WCS) 스냅샷을 기준으로 비교해 불일치 건을 조회·처리한다(2-3)
- 정기 재고대사는 같은 시점의 재고 스냅샷으로 한다

### 2-2. EWMS 재고대사
1. (EWMS↔WCS) EWMS와도 스냅샷 재고 기준으로 대사한다
   - [추가 협의] EWMS 대사 방식은 Q-219에서 정한다(7절)
2. (WCS) EWMS RCV9 + WCS1 로케이션 수량을 집계한다
3. (WCS) WCS 전체 재고를 집계한다(맵핑 기준으로 변환)
4. (WCS) 비교해 차이 내역을 낸다

### 2-3. 불일치 처리
1. (WCS) 스냅샷 기준 불일치 건을 조회한다
2. (파워유저) 불일치 건을 처리한다. 처리는 WCS 재고 보정 또는 설비 재확인 요청이다
3. (파워유저) 보정은 사유를 등록하고 재고대사 보정 유형의 이력으로 한다(→ P34 재고 반영·보정)
4. (WCS) 보정에는 사유·작업자·이력을 남긴다

## 3. 조건·규칙

### 3-1. 비교 기준
- W/T 연동으로 재고대사가 가능하도록 한다(→ P35 W/T 연동)
- 비교 단위는 PLANT/Storage Location ↔ 화주/WCS Storage Location 맵핑 기준이다
- 제품 단위로 대사한다(예정). LOT·제조번호 단위가 아니다
- 설비사·EWMS 재고대사 모두 1레벨(BOX = EA) 수량으로 비교한다. UOM 환산은 없다
- EWMS와 대사할 때 WCS 재고를 BIN 마스터로 BIN별 합산해 EWMS BIN 재고와 비교한다
- EWMS의 PLANT별 재고를 PLANT 관리 맵핑으로 화주별로 합산한 뒤 WCS 화주 재고와 비교한다
- 화주별 합산은 BIN별 합산과 함께 쓴다. 화주·BIN·제품이 같은 것끼리 비교한다
- WCS 자체 생성 제품 재고는 EWMS 재고대사에서 뺀다. 설비사·WCS 스냅샷 재고대사에는 넣는다

### 3-2. 주기·대상·권한
- 설비사 재고대사는 일 1회 정기 실행하고, 수동 실행도 둔다
- EWMS 재고대사의 주기:
  - ⚠ 원문 불일치: EWMS 재고대사도 일 1회 정기 실행하고, 수동 실행도 둔다
  - ⚠ 원문 불일치: EWMS와 주고받는 대사의 주기는 미정이다
- 실행 시각은 창고 기초속성으로 둔다. 기본값은 업무 마감 후다
- 설비사 대사 대상:
  - ⚠ 원문 불일치: 대상은 재고를 보관하는 현대무벡스 설비(AS/RS·BOX Shuttle·GANTRY)이고, 생기연(AMR)은 뺀다
  - ⚠ 원문 불일치: 현대무벡스(AS/RS·BOX Shuttle·GANTRY)는 반드시 넣는다. 로지스올(디베닝 시퀀스 버퍼)은 스냅샷을 줄 수 있으면 넣는다([추가 협의] Q-219). 생기연(AMR)은 뺀다
- 불일치 보정은 파워유저만 한다

### 3-3. 이동 중 재고와 시점 차이
- 스냅샷 시점에 진행 중인 Action(이동 중 재고)은 따로 표시해 오탐을 줄인다
- EWMS 대사는 WCS 스냅샷과 같은 기준 시각의 EWMS BIN 재고와 비교한다
- [추가 협의] 그 EWMS BIN 재고를 EWMS가 기준 시각 스냅샷으로 만드는지, WCS가 조회하는지는 Q-219다
- 기준 시각 전후로 확정되거나 미확정인 W/T는 시점 차이로 따로 표시한다
- 이동 중 재고와 시점 차이 W/T는 반드시 구분한다. 구분하지 않으면 정상 재고가 불일치로 잡히고, 보정하면 맞던 재고가 틀어진다

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→설비사 ECS | 정기 재고대사 때 | 재고정보 요청(기준 시각) |

## 5. 예외
- 스냅샷 기준 불일치 건은 조회한 뒤 처리한다. 불일치 유형별로 보정하거나 설비를 재확인한다(2-3)
- 이동 중·시점 차이 재고는 따로 표시한다(3-3)

## 6. 기능·화면
- [확인필요] EWMS RCV9·WCS1 재고와 WCS 재고를 비교하는 재고대사 기능을 제공한다
- 재고대사 결과 차이 내역을 조회할 수 있다
- 스냅샷 기준으로 불일치 건을 조회하고 처리하는 기능을 제공한다
- 스냅샷 항목(예약수량 포함)과 스냅샷 보관·이력 조회는 「재고 운영 용어」 묶음(재고 스냅샷)에 있다

## 7. 미결
- [추가 협의] Q-219: 로지스올 디베닝 시퀀스 버퍼의 재고 스냅샷 제공 여부, EWMS 대사 방식(EWMS가 기준 시각 스냅샷을 만드는지 / WCS가 EWMS BIN 재고를 조회하는지)
- Q-219에서 이미 정한 것: 일 1회 정기·수동 실행, 현대무벡스 설비는 반드시 대상, 보정은 파워유저, 스냅샷 대사 상세 채택(2·3·6절)
