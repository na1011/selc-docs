# [프로세스] 출고완료 확정

> 키워드: OUB-CFM · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「W/T」(피킹 W/T·W/T 확정), 「작업지시 체계」(Workflow), 「단말」(PDA·PC), 「LOT·제조번호」(제조번호·시리얼 이력 로그), 「출고 오더」(STO·ORG DO·SPLIT DO)
> **이름만 쓰는 묶음**: 「WCS 위치」, 「EWMS BIN 코드」, 「운반 설비」, 「팔레트」(원팔레트ID-일련번호), 「시스템」, 「재고 운영 용어」, 「재고 이력·관리단위」, 「출고 업무 용어」, 「재고 수량」(마이너스 불가), 「거래처·인도처」(인도처), 「AS/RS」, 「GANTRY」
> **이어지는 프로세스**: 앞 → P23 GANTRY 출고, → P24 FULL 팔레트 출고, → P25 출고 DOCK 이송, → P28 3층 출고 구성, → P29 출고 수작업 영역 출고, → P30 직송 이적 · 함께 → P34 재고 반영·보정(확정 뒤 재고 차이 정정), → P37 제조번호 수신·추적 · 관련 → P35 W/T 연동(W/T 확정 실적 공통 규칙)

## 1. 범위

- 출고 팔레트 Workflow에서 출고확정을 일으키는 단계가 끝나면 시작한다.
- WCS가 피킹 W/T를 확정해 EWMS에 출고확정 실적을 보내고, EWMS가 W/T를 확정하면 끝난다.

## 2. 흐름

### 2-1. 확정 시점

- 수작업 영역으로 인계하는 건(출고 수작업 영역 출고·직송 이적)만 인계 시점(3·4층 전달 완료)에 출고확정한다. 나머지(AS/RS FULL 팔레트, 1층 GANTRY MIXED, 3층 MIXED 등)는 설비 Flow의 끝 부분에서 출고확정한다
- 출고 팔레트 Workflow마다 출고확정을 일으키는 단계를 설정할 수 있다. 수작업 인계 건은 3·4층 전달 완료 단계, 그 외는 설비 Flow의 마지막 단계로 두고, 해당 단계 완료를 받으면 피킹 W/T 실적을 EWMS에 보낸다

### 2-2. 출고 수작업 영역 출고·직송 이적 — 전달 완료 때 자동 확정

1. (WCS) 3·4층 배출 완료(전달 완료)를 받는다
2. (WCS) 수작업 인계 건은 해당 층 출고 수작업 셀(3층 9013·RCV3, 4층 9014·RCV4)로 재고를 옮긴 뒤 그 셀에서 출고확정한다
3. (WCS→EWMS) 피킹 W/T 실적을 자동으로 보낸다. 한 팔레트에 인도처가 여럿이면 원팔레트ID-일련번호로 나눠 보낸다 → WCS 재고에서 빠진다
- 세부 흐름은 → P29 출고 수작업 영역 출고, → P30 직송 이적에 있다. 직송 이적의 전달 완료 시점(AS/RS FULL·1층 GANTRY MIXED·3층 MIXED별)은 → P30 2절 4단계에 있다.
- ⚠ 원문 불일치(안내): 3단계 「전달 완료 때 WCS 재고에서 빠진다」와 「출고 수작업 영역 출고·직송 이적분은 배출 재고 차감의 예외로 W/T 확정까지 WCS 재고를 유지한다」가 서로 다르다. 두 내용은 → P09 AS/RS 인출 3절(재고 차감), → P29 3-3, → P30 3-3에 있다

### 2-3. 설비 Flow 끝 — 센서·PDA·PC

1. 센서: 출고 센서가 출고 팔레트의 팔레트 ID를 인식하면 해당 팔레트 ID의 피킹 W/T를 확정한다
   - [확인필요] WCS는 출고 센서 스캔 결과로 피킹 W/T를 확정해 EWMS에 보낸다
2. PDA: 작업자 PDA 스캔 시점에 피킹 W/T를 확정한다
3. PC 일괄: 미확정 출고 대상을 조회한 뒤 선택한 건을 일괄 확정한다

### 2-4. 실적 전송과 EWMS 확정

1. (WCS→EWMS) 출고 작업 실적을 보낸다 → (EWMS) W/T를 확정한다. STO는 SPLIT DO 기준으로 확정한다
2. WCS 실적은 ORG DO(W/T) 기준으로 보내고, SPLIT DO 기준 W/T 확정은 EWMS가 내부에서 처리한다

## 3. 조건·규칙

### 3-1. 확정 수단

- 확정 수단은 센서, PDA, PC 일괄이다
- 설비 Flow 끝 부분의 확정 수단
  - 마지막 이송이 AMR이면 AMR의 출고 DOCK 도착 보고로 출고확정한다
  - 마지막 이송이 유인지게차이면(WCS 작업지시 없음) 출고 DOCK에서 PDA 스캔 또는 출고 센서 인식으로 출고확정한다
  - OEM 3층 논리 출고 DOCK은 PDA/PC로 확정한다
- 출고 수작업 영역 출고·직송 이적은 3·4층 전달 완료 때 자동 출고확정하므로 PDA·PC 확정 대상이 아니다. OEM 3층 논리 출고 DOCK 등은 대상이다
- 출고 수작업 영역 출고·직송 이적 실적의 팔레트 ID는 인도처가 하나면 원팔레트 ID, 여럿이면 인도처별 원팔레트ID-1~N이다

### 3-2. 실적 단위

- 출고확정 실적은 PARTIAL(피킹 W/T 수량 일부)로도 EWMS에 보낼 수 있다. EWMS가 이를 수용한다는 것과 그 범위(모든 출고확정 실적)는 「W/T」 묶음에 있다
- WCS는 실적마다 팔레트 ID(출고 수작업 영역 출고는 분할 팔레트 ID = 원팔레트ID-n)를 정확히 넣는다
- 출고확정 실적도 LOT 단위가 아니라 수신한 W/T 단위로 취합한다(W/T 확정 실적 공통 규칙 → P35 W/T 연동 3-3). 한 W/T·출고 팔레트에 여러 LOT가 섞여도 W/T 기준 수량으로 합산한다
- LOT별 수량은 WCS 재고 이력에만 남긴다

## 4. 주고받는 정보

| 송신→수신 | 시점 | 업무 항목 |
|---|---|---|
| WCS→EWMS | 출고 확정 시 | W/T 번호, 팔레트 ID(출고 수작업 영역 출고는 분할 팔레트 ID), 확정 수량, 확정 일시 (PARTIAL 확정 허용) |
| WCS→EWMS | 출고 작업 실적 시 | W/T 번호, 제품, 수량 (STO는 ORG DO 기준. SPLIT DO 기준 W/T 확정은 EWMS 내부 처리) |

## 5. 예외

- 중복 확정: 같은 팔레트(분할 팔레트 ID 포함)가 수단과 관계없이 다시 확정되면(센서·PDA 중복 등) 재고 차감·EWMS 실적을 다시 하지 않고 「이미 확정」으로 응답한다
  - 이유: 다시 차감하면 마이너스 방지에 걸려 오류가 나고, EWMS에 실적이 두 번 간다
- 오스캔: 확정 대기 대상이 아닌 팔레트 ID는 확정하지 않고, 사유(출고 대상 아님 / 다른 DOCK / 미완료 작업)를 PDA에 표시한다
- 확정 취소: 실적을 보낸 뒤에는 되돌릴 인터페이스가 없으므로 WCS는 확정 취소 기능을 두지 않는다. EWMS 쪽 정정은 EWMS가 한다(W/T 취소 인터페이스 Q-117). WCS 재고 차이는 재고 보정 유형으로 정정한다(→ P34 재고 반영·보정)

## 6. 기능·화면

- WCS는 출고완료 확정(PDA 스캔·PC 일괄 확정) 기능을 직접 제공한다. 출고 수작업 영역 출고·직송 이적 팔레트는 대상에서 뺀다
- 출고 검수 실적은 외부 시스템에서 받지 않고, WCS의 PC 또는 PDA에서 처리한다
- WCS는 출고 검수를 시리얼번호 단위로 처리하는 PC·PDA 기능을 제공한다
- (작업자) PDA·PC 출고완료 확정 화면에서 시리얼번호 단위 출고 검수를 함께 처리해, 피킹 W/T 확정과 시리얼 이력 로그 적재(검수 실적 → 시리얼 이력 로그)를 한 번에 수행한다
