# [프로세스] 단말 화면·알림

> 키워드: SYS-UI · 원문 기준일 2026-11-02
> **기대는 묶음** (사실을 알아야 이해되는 것): 「단말」(WCS PDA·PC·대시보드)
> **이름만 쓰는 묶음**: 「작업지시 체계」(전략 이력), 「AS/RS」(출고대), 「운반 설비」(유인지게차), 「에러·사유코드」(Reject), 「팔레트」(팔레트 ID)
> **이어지는 프로세스**: 관련 → P43 팔레트 작업 상태 추적, P44 설비 에러·Reject 처리, P11 3층 출고대 도착 팔레트 처리, P42 작업지시 생성·실행(Task 화면)

## 1. 범위
현장 작업자와 관리자가 단말로 정보를 보고 조치하는 일 중, 다른 프로세스 하나에 속하지 않는 화면을 다룬다. 전략 이력 조회가 여기에 있다.
- 팔레트 작업 추적 화면 → P43, 통합 Reject·에러 조치 화면 → P44, Task 화면 → P42

## 2. 흐름
1. (작업자) WCS PDA로 화물 바코드를 스캔해 화물 상태와 진행 중 작업을 확인한다
2. (작업자) 필요하면 WCS PDA에서 Reject 처리·긴급 조치를 한다 → P44 설비 에러·Reject 처리
3. (관리자) PC·대시보드에서 입출고 예정·진행 현황 등 관리 목적 정보를 조회한다

## 3. 조건·규칙
- 원문에 이 문서만의 조건·규칙은 없다.

## 4. 기능·화면

### 4-1. 3층 출고대 도착 팔레트 판단 (WCS PDA)
- 3층 배출라인(출고대)에 도착한 팔레트는 WCS PDA로 판단하고 재고 처리한다
- 배출 행선지가 여러 곳이므로, 유인지게차 작업자가 배출 팔레트 ID를 스캔하면 WCS PDA가 행선지를 보여 준다
- 판단·재고 처리의 순서와 조건은 → P11 3층 출고대 도착 팔레트 처리, 행선지 표시 방식은 → P43 팔레트 작업 상태 추적

### 4-2. 전략 이력 조회 (PC 화면 1개)
- 조회 조건: 기간, 프로세스, 전략 종류, 결정 주체(시스템/사용자), Task ID
- 결과: 이력 목록에서 Task 진행 이력(Task → Workflow → Action)으로 연결한다. 엑셀로 내려받는다
- 팔레트 작업 추적 화면에서 이 조회로 바로 들어오는 것은 → P43 6-2
- 전략별 지표 대시보드는 두지 않는다. 운영 데이터가 쌓인 뒤 검토한다

## 5. 미결
- 원문에 이 문서만의 미결 항목은 없다.
