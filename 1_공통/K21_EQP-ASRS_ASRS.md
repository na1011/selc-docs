## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K12 MST-EQP 설비 기준정보 · 팔레트 유형**: WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.

## 1. 개요
팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다. 적치셀 할당, 적치 통보, 피킹 지시·완료 이벤트를 정의한다. 설비사는 현대무벡스이며, AS/RS 3층 입고라인(3층 입고 팔레타이징로봇 → 3층 랩핑기 → AS/RS, P-01)은 로지스올 설비와의 설비 접점이다. 3층 디팔레타이징 배출라인(AS/RS → 3층 디랩핑기 → 3층 디팔레타이징)과 3층 부분 해체 잔량 팔레트 재입고(AS/RS 재투입라인)는 모두 현대무벡스 설비 사이의 내부 인계다 (EQP-VND). 3층 배출라인은 3층 디팔레타이징 배출라인과 팔레트를 그대로 수작업 영역 쪽으로 내보내는 출고대 2개다. 크레인 호기와 Bay는 팔레트 유형별로 나뉘며(2316 = 1~4 Bay(1·2호기), 1960 = 5~8 Bay(3·4호기), 1816 = 9~32 Bay(5~16호기)), 팔레트 투입 시 팔레트 유형이 중요한 값이다.

## 3. 프로세스 흐름
입고:
1. (ECS) 입구 처리, 사이즈 체크
2. (ECS/WCS) 적치셀 할당 — 팔레트 유형에 맞는 크레인 호기·Bay 안에서 할당(BR-EQP-ASRS-020). 기본은 AS/RS 자동 할당, WCS 지정은 선택(OPTIONAL) (BR-EQP-ASRS-023). 입고대는 모든 호기에 접근 가능
3. (ECS) 적치
4. (ECS→WCS) 적치셀 통보 → (WCS) 이동 이력으로 위치를 입고대 → 적치 셀로 반영 (WCS 재고는 적치 W/T 수신 시 1층 입고장 위치로 생성되고 투입 시 입고대로 이동, INB-PLT BR-INB-PLT-014)
5. (WCS→EWMS) 적치 결과 전달 → 적치 W/T 확정(가용재고화)

출고:
1. (WCS) 피킹셀 지정 및 피킹 작업지시 (팔레트 ID, 피킹 위치 → ECS)
2. (ECS) 팔레트 인출 → 배출 위치로 이송
3. (ECS→WCS) 피킹 완료 결과 통보
4. (ECS→WCS) 출고 작업 불가 시 불가 사유 전달 (현대무벡스)
5. (WCS) 대체 재고 선정 → 재할당 → 새 피킹 작업지시

## 6. 인터페이스
| 송신→수신 | 시점 | 주요 항목 |
| --- | --- | --- |
| WCS→ECS | 입고 목적지 결정 시 | 팔레트 ID, 목적지, 팔레트 유형, (선택, OPTIONAL)적치셀 — 유형별 호기·Bay 범위 안 |
| ECS→WCS | 적치 완료 시 | 팔레트 ID, 적치셀 |
| WCS→EWMS | 적치 통보 수신 후 | W/T 번호, 팔레트 ID, 적치 위치 |
| EWMS→WCS | 4층 → 3층 Bypass 지시 시 | 이동 W/T: W/T 번호, 팔레트 ID, 제품, 수량, 출발 BIN·도착 BIN |
| WCS→EWMS | 4층 → 3층 Bypass 도착 시 | 이동 W/T 확정: W/T 번호, 팔레트 ID, 도착 위치 |
| WCS→EWMS | 1층 → 3층 Bypass 3층 출고대 도착 시 | 적치 W/T 확정: W/T 번호, 팔레트 ID (DEST BIN은 EWMS 지정 9013·RCV3 그대로) |

| WCS→EWMS | 3·4층 배출 완료 시 (W/T가 있었던 건, GTP·직송 이적 제외) | W/T 확정: W/T 번호, 팔레트 ID, DEST BIN(토출건은 실제 도착 위치 3층 출고대 9013·RCV3 / 4층 입고장(9014·RCV4)으로 변경) |

| ECS→WCS | 피킹 완료 시 | 팔레트 ID, 완료 결과 |

| ECS→WCS | 용량 부족 배출·Reject 팔레트 출고대 도착 시 | 팔레트 ID, 배출 사유(용량 부족) 또는 Reject 에러 코드(ECS 판단), 도착 배출구 (현대무벡스 상황판에도 표시) |

## 7. 예외 처리
- 출고 작업 불가: 현대무벡스가 불가 사유 전달 → WCS가 대체 재고 선정·재할당 (BR-EQP-ASRS-005)
- AS/RS 용량 부족: 투입건 3층 출고대 배출 (REQ-EQP-ASRS-009), 3층 도착 시 사유 정보 제공 (REQ-EQP-ASRS-011), 적치 W/T DEST BIN 변경 확정 (REQ-EQP-ASRS-033)
- 적치 실패/셀 이상: 재적치 보고 위치 반영, 최종 실패 시 3층 출고대 Reject 배출, 셀 이상은 이동/할당불가·재고 보류·재고대사 등록·재할당 (REQ-EQP-ASRS-052)

## 8. 미결 사항
- Q-162: [추가 협의] 현대무벡스 ECS 인쇄물 출력 — 인쇄물 종류(팔레트 라벨·출고 라벨 등)와 출력 위치·시점, 출력에 필요한 인터페이스 항목 목록(REQ-EQP-ASRS-029 후보), FULL 팔레트 출고지시·MIXED 팔레타이징 작업지시(1층 GANTRY·3층) 메시지에 추가하는 방식, 출력 실패·재출력 처리 (인터페이스 항목 추가 원칙 결정)
- Q-034: [추후 정리] AS/RS 셀 구성 실제 값(호기별 Bay·열·연·단 수, 셀 크기 등급)과 셀 코드 포맷 — 현대무벡스 설비 자료 수령 후 셀 마스터 등록 (설비사 체계 그대로 등록·공팔레트 별도 구역 없음 결정)
- Q-207: [추가 협의] 3층 부분 해체 시 작업자가 피킹하는 위치, AS/RS 재투입라인의 물리 위치 (재투입라인 설비사 현대무벡스·피킹 BOX는 BOX Shuttle 적치·재투입 시 사이즈 체크·피킹 실적 = 설비 HMI 입력 후 현대무벡스 ECS 보고 결정)
