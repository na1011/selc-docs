## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K23 EQP-GNT GANTRY**: 1층 대형제품 출고 전용 설비. AS/RS에서 FULL 팔레트로 출고할 수 없는 잔여 제품을 디팔레타이징하여 BOX 단위로 출고 구성(MIXED 팔레타이징)한다.
- **K24 EQP-MIX 3층 디팔레타이징 · MIXED 팔레타이징**: 3층에서 AS/RS 배출 팔레트를 디팔레타이징하고, 출고 주문에 따라 출고 구성(MIXED 팔레타이징)하는 설비. BOX Shuttle과 다른 설비이므로 별도 키워드로 관리한다.

## 1. 개요
디팔레타이징 전에 팔레트의 랩핑 비닐을 제거하는 방식과, 제거한 비닐을 담는 TRASH BIN의 보관·공급을 정의한다. 3층은 디랩핑기가 비닐을 제거하고, 1층은 작업자가 직접 제거한다. TRASH BIN은 팔레트에 태워 AS/RS에 보관하며, 1층·3층 모두 현대무벡스 ECS를 통해 보충 요청을 받으면 WCS가 AS/RS에서 요청 위치로 이동시킨다(WCS PDA 호출 없음). TRASH BIN 공급은 현대무벡스 ECS 요청으로만 시작하며 3층 랩핑 제거 지시와 별개로 움직인다. TRASH BIN은 WCS 자체 생성 제품으로 재고 관리한다(MST-PRD).

## 3. 프로세스 흐름
랩핑 비닐 제거:
- 3층: (WCS→현대무벡스 ECS) 랩핑 제거 지시 → (디랩핑기) 3층 디팔레타이징 전 팔레트의 랩핑 비닐 제거 → TRASH BIN에 담음 → (현대무벡스 ECS→WCS) 완료 보고
- 1층: (작업자) GANTRY 디팔레타이징 전 랩핑 비닐 직접 제거 → TRASH BIN에 담음

TRASH BIN 공급 (랩핑 제거 지시와 별개 프로세스, 가득 찬 통의 회수·비우기는 현대무벡스 자체 처리 — BR-EQP-TRB-018):
1. (작업자) TRASH BIN이 가득 찼는지 육안으로 판단해 설비 내 버튼 클릭 → (현대무벡스 ECS→WCS) 1층·3층 TRASH BIN 보충 요청 — WCS PDA 호출 없음, 랩핑 제거 지시·완료 보고로 시작하지 않음 (BR-EQP-TRB-016·017)
2. (WCS) AS/RS에 보관된 TRASH BIN 선정·예약 → (WCS→AS/RS ECS) 출고 지시
3. (AS/RS → 요청 위치) TRASH BIN 이동 — 이동 단계·수단은 Workflow 설정(SYS-ARC). 1층은 보충 컨베이어 → GANTRY, 3층은 3층 출고대 배출까지이며 출고대 → 디랩핑기는 작업자가 유인지게차로 옮김(WCS 작업지시 없음, REQ-EQP-TRB-005 ④)
4. (ECS→WCS) 도착 알림 → (WCS) 요청 종료, 재고 위치를 요청 위치 로케이션으로 반영 (REQ-EQP-TRB-022 ③)

TRASH BIN 팔레트는 EWMS HU 확인·생성 대상이 아니다(자체 생성 제품, MST-PRD REQ-MST-PRD-010). ① 새 TRASH BIN 팔레트는 WCS 화면에서 팔레트 ID를 먼저 등록(TRASH BIN 제품 수량 1로 재고 생성)한 뒤 3층 입고대에 투입한다. 등록하지 않은 팔레트 ID는 3층 입고대에서 TRASH BIN으로 판별되지 않아(EQP-ASRS REQ-EQP-ASRS-044 ①) Reject된다. ② 이미 등록된 팔레트 ID는 다시 투입되어도 같은 invn_id로 적치한다(REQ-EQP-TRB-017). ③ 도착 알림을 받으면 재고 위치를 요청 위치 로케이션으로 옮긴다(REQ-EQP-TRB-022 ③). | WCS | 확정 |
| REQ-EQP-TRB-010 | WCS는 3층 디랩핑기(현대무벡스 ECS)에 팔레트별 랩핑 제거 작업을 지시하고 완료 보고를 받아야 한다. | WCS | 확정 |
| REQ-EQP-TRB-012 | WCS는 TRASH BIN 공급을 현대무벡스 ECS 보충 요청 단위의 별도 작업으로 생성·처리하고, 3층 랩핑 제거 지시(Workflow 단계)와 연결하지 않아야 한다. | WCS | 확정 |
| REQ-EQP-TRB-013 | WCS는 1층·3층 현대무벡스 ECS의 TRASH BIN 보충 요청을 받아 AS/RS에 보관된 TRASH BIN을 선정·출고 지시하고 요청 위치까지 이동 작업을 생성해야 한다. WCS PDA 호출 기능은 두지 않는다. | 현대무벡스 ECS→WCS | 확정 |
| REQ-EQP-TRB-015 | WCS는 가득 찬 TRASH BIN의 회수·비우기 흐름을 지시하거나 관리하지 않는다. 해당 흐름은 현대무벡스가 자체 처리한다. | 현대무벡스 | 확정 |
| REQ-EQP-TRB-016 | WCS는 1층 TRASH BIN 보충 요청을 받으면 AS/RS TRASH BIN 팔레트를 보충 컨베이어로 배출해 GANTRY 입구로 공급하는 보충 경로로 이동시켜야 한다(현대무벡스 내부 인계, AMR·유인지게차 단계 없음). | WCS | 확정 |
| REQ-EQP-TRB-017 | WCS는 3층 입고대에 투입된 TRASH BIN 팔레트를 W/T 없이 자체 생성한 Work·Task로 AS/RS 적치 지시하고(EQP-ASRS BR-EQP-ASRS-048), WCS 자체 품목으로 EWMS 반영 없이 위치 이력만 남겨야 한다. | WCS | 확정 |
| REQ-EQP-TRB-018 | TRASH BIN 요청 위치 목록은 1층 GANTRY 디팔레타이징 작업장(GANTRY 호기별 10곳)과 3층 디랩핑기 1곳으로 하고, 로케이션으로 등록해 현대무벡스 요청 위치(설비) 코드와 맵핑한다(REQ-EQP-TRB-005). 최소 보유 수량 알람(BR-EQP-TRB-021)과 빈 통 없음 처리(BR-EQP-TRB-022)를 적용한다. | WCS | 확정 |
| REQ-EQP-TRB-020 | WCS는 TRASH BIN 팔레트의 유형을 제한하지 않고 2316·1816·1960 어느 유형이든 보관·공급해야 한다. AS/RS 적치 셀은 팔레트 유형별 크레인 호기·Bay 구역(MST-EQP BR-MST-EQP-021)을 따른다(BR-EQP-TRB-023). | WCS | 확정 |
| REQ-EQP-TRB-021 | 팔레트 유형 무제약에 따른 흐름 보완: TRASH BIN 제품은 제품마스터 팔레트 유형을 "제약 없음"으로 두고, 투입 시 팔레트 유형 불일치 Reject(EQP-ASRS REQ-EQP-ASRS-027) 대상에서 뺀다(빼지 않으면 3층 입고대 투입 통이 Reject되어 보관이 막힘). 1층 GANTRY 입구는 모든 유형을 받으므로 경로별 유형 제외는 없다. | WCS | 확정 |
| REQ-EQP-TRB-022 | TRASH BIN 보충 요청 인터페이스: ① 요청(현대무벡스 ECS→WCS) — 요청 번호, 요청 위치(설비·호기 코드), 요청 시각 ② 응답(WCS→현대무벡스 ECS, 수신 직후) — 요청 번호, 결과(접수 / 공급 불가·대기 / 진행 중(같은 위치 중복 요청, REQ-EQP-TRB-005 ③)) ③ 도착 알림(ECS→WCS, 도착 시) — 요청 번호, 팔레트 ID, 도착 위치, 도착 시각 → WCS는 요청을 종료하고 도착 위치로 위치 이력을 남긴다. 1층·3층 같고 PDA 도착 스캔은 두지 않는다(BR-EQP-TRB-025). | 현대무벡스 ECS↔WCS | 확정 |
| REQ-EQP-TRB-014 | WCS는 작업자가 TRASH BIN 만재를 육안으로 판단해 설비 내 버튼을 클릭했을 때 현대무벡스 ECS가 보내는 보충 요청을 받아 TRASH BIN 공급 작업을 시작해야 한다. | 현대무벡스 ECS→WCS | 확정 |
| REQ-EQP-TRB-011 | 랩핑 제거 지시 방식: 랩핑 제거를 3층 배출 Workflow(AS/RS 3층 배출 → 디랩핑기 → 3층 디팔레타이징 로봇)의 한 단계로 설정한다. 완료 보고를 받은 뒤에 다음 단계(디팔레타이징 지시)를 진행하고, 실패를 보고받으면 알람을 띄우고 해당 팔레트 작업을 보류한다. 지시·보고 내역은 작업 이력으로 남긴다. | WCS | 확정 |

## 7. 예외 처리
- AS/RS에 빈 TRASH BIN이 없을 때 처리 미정 (Q-139)
- 같은 위치 중복 요청: 새 요청을 만들지 않고 '진행 중'으로 응답한다. 진행 중 요청이 도착 지연 기준을 넘으면 알람을 띄운다(REQ-EQP-TRB-005 ③).
- 등록하지 않은 TRASH BIN 팔레트 ID 투입: 3층 입고대에서 Reject된다. 화면에서 등록한 뒤 다시 투입한다(REQ-EQP-TRB-009 ①).
