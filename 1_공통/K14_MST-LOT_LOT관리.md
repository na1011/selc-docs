## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K05 MST-CTR 창고(CDC) 마스터**: 창고(CDC)를 화주(MST-OWN)와 함께 WCS 관리의 최상위 단위로 관리한다. 로케이션·설비 등 기준정보와 재고·작업지시 관리는 창고 아래에, 제품·재고관리체계(화주·Storage Location 맵핑)는 화주 아래에 속한다.
- **K06 MST-OWN 화주(화주사) 마스터**: 화주(화주사)를 창고(CDC)와 함께 WCS 관리의 최상위 레벨로 관리한다. 제품은 화주사별로 관리한다.
- **K07 MST-STK 재고관리체계 (PLANT · Storage Location · 화주 매핑)**: EWMS는 PLANT와 Storage Location 조합으로 Stock Type을 관리하고, WCS는 이를 화주·WCS Storage Location으로 맵핑하여 별도 관리한다. 맵핑 기준과 PLANT별 재고 혼용 정책을 정의한다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.

> 상태: 일부확정

## 1. 개요
WCS는 보관재고가 섞이지 않도록 LOT 생성 전략에 정한 LOT 속성 조합으로 LOT를 채번하여 재고를 구분한다. 창고코드·화주·제품코드는 필수 속성으로 항상 포함하고, 나머지 속성은 창고별로 선택한다. 선택하지 않은 속성은 값이 달라도 LOT를 새로 채번하지 않는다. 제조번호는 후보 속성으로 기능 뼈대만 두고, 평택 CDC는 물류 작업지시 효율 저하 우려로 선택하지 않으며(평택 전략 = 필수 + 기타 LOT 속성1~3: Storage Location·Valuation Type·입고월) 시리얼 마스터·이력 로그로 별도 추적한다(MST-SN). LOT 속성별 채번 규칙과 보관/출고 체크 여부를 정의한다.

## 3. 프로세스 흐름
1. (EWMS→WCS) 입고정보(입고예정정보·적치 W/T) 수신 — 인터페이스 정의는 INB-PLT·INB-DVN §6. 이 중 LOT 속성에 쓰는 항목: 창고코드, PLANT(→ 화주), 제품코드, Storage Location, Valuation Type, 입고일자(→ WCS가 입고월 가공)
2. (WCS) 해당 창고의 LOT 생성 전략에서 선택된 속성 추출 (후보: 필수 = 창고코드, 화주, 제품코드 / 선택 = 제조번호, 입고일자, Storage Location, 기타 LOT 속성 1~5(예비 항목, 입고정보 항목 맵핑)) — 필수 속성은 항상 포함, 선택하지 않은 속성은 채번에 영향 없음, 평택 CDC는 제조번호 미선택 — 화주·Storage Location은 MST-STK 맵핑 기준
3. (WCS) 재고 생성 시 동일 속성 조합 LOT가 있으면 사용, 없으면 그때 신규 채번 — LOT를 미리 만들지 않음, 로트번호는 L로 시작하는 12자리 일련번호 (BR-MST-LOT-031·032)

LOT 속성 변경 (파손 등 사유 발생 시):
1. (WCS) 재고조회 화면에서 대상 재고·수량·변경할 속성(Valuation Type 등)·사유 입력
2. (WCS→EWMS) WCS 재고 처리 전에 변경 내용 통보
3. (WCS) 인터페이스 성공 시 대상 수량을 변경된 속성 조합의 LOT로 이동(없으면 신규 채번), 원 LOT 차감, 이력 기록 / 실패 시 WCS 재고 처리 안 함
