# [K18/40] [INV-WT] W/T 상태 · 가용재고

## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.

## 머리말
> 분류: 업무=재고 / 설비=공통
> 관련 시스템: EWMS, WCS | 관련 키워드: INV-SYNC, EQP-ASRS, EQP-BSH, OUB-CFM, HU-VAL, MST-LOC
> 상태: 일부확정

## 1. 개요
EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): W/T, W/T 생성, W/T 확정, 가용재고, EWMS, WCS, HU 생성, AS/RS, 적치셀, HU, 팔레트 ID, 수작업 영역, OEM생산 입고, 쉽백, EWMS PDA, 입고대, HU 내역 조회, 디베닝, 팔레타이징, 이적, GTP, 잔량, LOT, 제조번호, WCS1, RCV9, 직송, Work, Bypass, 이동 W/T, 파워유저, 적치 W/T, 피킹 W/T, 재고 보정, 창고 기초속성, 통합 에러관리, 재고대사

## 3. 프로세스 흐름
1. W/T 생성 → WCS 재고(비가용)
2. 작업 완료(예: AS/RS 최종 적치) → WCS → EWMS 완료 통보
3. W/T 확정 → 가용재고(출고지시 가능)
