# [K37/40] [INV-SYNC] 재고대사 (설비 · WCS · EWMS)

## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K05 MST-CTR 창고(CDC) 마스터**: 창고(CDC)를 화주(MST-OWN)와 함께 WCS 관리의 최상위 단위로 관리한다. 로케이션·설비 등 기준정보와 재고·작업지시 관리는 창고 아래에, 제품·재고관리체계(화주·Storage Location 맵핑)는 화주 아래에 속한다.
- **K07 MST-STK 재고관리체계 (PLANT · Storage Location · 화주 매핑)**: EWMS는 PLANT와 Storage Location 조합으로 Stock Type을 관리하고, WCS는 이를 화주·WCS Storage Location으로 맵핑하여 별도 관리한다. 맵핑 기준과 PLANT별 재고 혼용 정책을 정의한다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K36 INV-QRY 재고조회**: WCS가 관리하는 자동화 설비 구역 재고를 조회하는 기본 화면의 항목과 수량 구분을 정의한다. 재고조회는 창고, 존, 셀, 셀 상태, 설비, 화주, 모델ID(제품코드), 모델명(제품명), 팔레트 ID, 재고수량, 예약수량, 가용수량, 보류수량을 기본으로 관리한다.

## 머리말
> 분류: 업무=재고 / 설비=공통
> 관련 시스템: EWMS, WCS, ECS | 관련 키워드: INV-WT, MST-LOC, MST-STK, INV-QRY, SYS-ARC
> 상태: 일부확정

## 1. 개요
EWMS의 RCV9·WCS1 로케이션 수량과 WCS 전체 재고 수량이 일치해야 한다. W/T 연동으로 재고대사가 가능하도록 한다. 정기 재고대사는 같은 시점의 재고 스냅샷으로 한다. WCS가 설비사에 재고정보를 요청하면 설비사가 재고 스냅샷을 만들고, WCS도 시점 재고 스냅샷을 만들어 스냅샷 기준 불일치 건을 조회·처리한다. EWMS와도 스냅샷 재고 기준으로 대사한다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): 재고대사, WCS1, W/T, Stock Type, 화주, EWMS, WCS, PLANT, Storage Location, LOT, 제조번호, ECS, 설비사, 재고 스냅샷, 팔레트 ID, 제품코드, Action, BIN, BIN 마스터, RCV9, 재고 보정, 디베닝, AS/RS, BOX Shuttle, GANTRY, 시퀀스 버퍼, AMR, 창고 기초속성, 현대무벡스, 로지스올, 생기연, 파워유저

## 3. 프로세스 흐름
1. EWMS RCV9 + WCS1 로케이션 수량 집계
2. WCS 전체 재고 집계 (맵핑 기준 변환)
3. 비교 → 차이 내역 산출

정기 스냅샷 재고대사:
1. (WCS→설비사 ECS) 재고정보 요청 (정기 일 1회·수동, REQ-INV-SYNC-013)
2. (설비사 ECS) 요청 시점 재고 스냅샷 생성 → WCS로 전송
3. (WCS) 같은 시점의 WCS 재고 스냅샷 생성
4. (WCS) 스냅샷 기준 비교 → 불일치 건 조회·처리
5. (EWMS↔WCS) EWMS와도 스냅샷 재고 기준으로 대사
