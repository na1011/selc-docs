# [K39/40] [INV-MVT] 자동화 전환 (AMVT / MMVT)

| 항목 | 내용 |
|---|---|
| 대분류 | 기타업무 — 재고 운영·차량·야드 (폴더 4_기타업무) |
| 입력 순서 | 39 / 40 (묶음 H: 재고 운영) |
| 선행 키워드 | K11 MST-LOC, K18 INV-WT, K33 OUB-MAN |
| 후행 키워드 | 없음 |
| 상태 | 일부확정 · BR 3 · REQ 확정 2 / 확인필요 2 · 미결 0 |

> 읽는 규칙은 C01 공통 컨텍스트 §1을 따른다. 용어 정의는 C02 GLOSSARY를 따른다(이 문서에는 §2 용어를 넣지 않음). 확정만 설계 기준, 확인필요·미결(Q)은 가정으로 표시.

## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K33 OUB-MAN 수작업 GTP 출고 (AS/RS 출고 후 분할)**: AS/RS 보관 재고 중 GANTRY로 출고할 수 없는 건은 3층(또는 4층) 출고 수작업 영역으로 배출하여 GTP 방식으로 출고한다. AS/RS 출고대로 배출한 뒤 유인지게차로 출고 수작업 영역 로케이션까지 이동하며 WCS는 작업지시를 내리지 않는다 (AMR은 1층만 사용).

## 머리말
> 분류: 업무=재고 / 설비=공통
> 관련 시스템: EWMS, WCS | 관련 키워드: MST-LOC, INV-WT, OUB-MAN
> 상태: 일부확정

## 1. 개요
수작업 구역과 자동화 구역 간 재고 이동을 EWMS 전환 로케이션(AMVT, MMVT)으로 처리한다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): AMVT, MMVT, W/T, EWMS, WCS, 위치셀, W/T 생성, 팔레트 ID, 수작업 영역, EWMS PDA, 제조번호, Work, AS/RS, BIN, BIN 마스터, GTP, 잔량, 이력 유형 코드, 이동 W/T, 적치 W/T, 이적, 직송

## 3. 프로세스 흐름
- 수작업 → 자동화: AMVT 로케이션으로 WCS 입고
- 자동화 → 수작업: MMVT 로케이션으로 WCS 위치 전환 후 출고

| BR-INV-MVT-002 | 자동화 재고를 수작업으로 이동 | MMVT 로케이션으로 위치 전환 후 출고 |
| BR-INV-MVT-003 | 수작업 영역 ↔ 자동화 설비 간 주고받는 정보 | 작업자가 EWMS PDA로 작업 → EWMS가 WCS로 실시간 통보 → WCS는 수신 즉시 WCS 재고에 반영 (단, 출고완료 확정은 WCS 제공 — BR-OUB-CFM-005) |
