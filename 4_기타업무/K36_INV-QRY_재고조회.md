## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K05 MST-CTR 창고(CDC) 마스터**: 창고(CDC)를 화주(MST-OWN)와 함께 WCS 관리의 최상위 단위로 관리한다. 로케이션·설비 등 기준정보와 재고·작업지시 관리는 창고 아래에, 제품·재고관리체계(화주·Storage Location 맵핑)는 화주 아래에 속한다.
- **K06 MST-OWN 화주(화주사) 마스터**: 화주(화주사)를 창고(CDC)와 함께 WCS 관리의 최상위 레벨로 관리한다. 제품은 화주사별로 관리한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K12 MST-EQP 설비 기준정보 · 팔레트 유형**: WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K14 MST-LOT WCS LOT 관리**: WCS는 보관재고가 섞이지 않도록 LOT 생성 전략에 정한 LOT 속성 조합으로 LOT를 채번하여 재고를 구분한다. 창고코드·화주·제품코드는 필수 속성으로 항상 포함하고, 나머지 속성은 창고별로 선택한다.
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.

## 머리말
> 분류: 업무=재고 / 설비=공통
> 관련 시스템: WCS | 관련 키워드: INV-UNT, INV-WT, MST-CTR, MST-LOC, MST-OWN, MST-PRD, MST-EQP, MST-LOT
> 상태: 일부확정

## 1. 개요
WCS가 관리하는 자동화 설비 구역 재고를 조회하는 기본 화면의 항목과 수량 구분을 정의한다. 재고조회는 창고, 존, 셀, 셀 상태, 설비, 화주, 모델ID(제품코드), 모델명(제품명), 팔레트 ID, 재고수량, 예약수량, 가용수량, 보류수량을 기본으로 관리한다. 재고 구조(재고 키 wh_id + invn_id + lot_id, 위치 별도 테이블)는 INV-UNT를 따른다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): WCS, 재고 관리단위, 창고코드, W/T, W/T 생성, 셀 상태, 재고수량, 예약수량, 가용수량, 보류수량, 팔레트 ID, 기타 LOT 속성, 화주, LOT, 제품코드, 제품명, EWMS, PLANT, Storage Location, Valuation Type, 입고월, LOT 속성 변경, GANTRY 보관일, Task, 재고실사, 재고 보정

## 3. 프로세스 흐름
1. (WCS) 재고조회 화면에서 조회 조건 입력 (창고, 존, 셀, 셀 상태, 설비, 화주, 모델ID, 팔레트 ID, GANTRY 보관일 등)
2. (WCS) 재고(invn_id·LOT)와 위치(셀) 정보를 결합해 기본 항목과 수량(재고·예약·가용·보류) 표시

보류수량 반영:
1. (EWMS→WCS) 보류재고 전환·해제 정보 수신
2. (WCS) 대상 LOT 식별 (기준 추가 협의, Q-104)
3. (WCS) 보류 전환 수량이 가용수량보다 크면 재고 처리 오류 → 반영하지 않음 → (WCS→EWMS) 보류 오류 통보
4. (WCS) 해당 제품의 LOT별 재고정보에서 보류수량 업데이트(전환 = 증가, 해제 = 감소) → 가용수량 재계산
5. (WCS) 해당 LOT가 하나라도 속한 팔레트·셀 전체를 보류 대상으로 처리

| WCS→EWMS | 보류 처리 오류 시 | 원 수신 건 식별값, 제품코드, 요청 수량, 가용수량, 오류 사유 |

## 7. 예외 처리
- 보류 전환 수량 > 가용수량: 반영하지 않고 재고 처리 오류, EWMS에 오류 통보 (REQ-INV-QRY-011·012)
- 보류 대상 invn_id의 다른 LOT 행: 동반 보류로 할당 제외, 원 보류 해제 시 함께 해제 (REQ-INV-QRY-015)

## 8. 미결 사항
- Q-104: [추가 협의] 보류재고 전환·해제 수신 시 대상 LOT를 찾는 기준 — EWMS는 WCS LOT 번호를 모르므로 화주·제품코드·LOT 속성값(Storage Location·Valuation Type·입고월 등) 중 무엇으로 찾을지 (해제 수신·보류 범위·상한 오류 결정)
