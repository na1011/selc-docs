# [K38/40] [INV-CNT] 자동화 설비 재고실사

## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K22 EQP-BSH BOX Shuttle**: 3층의 중소형 제품 대상 BOX 단위 보관 설비. 팔레트화 없이 BOX 그대로 입고·보관·피킹한다.
- **K23 EQP-GNT GANTRY**: 1층 대형제품 출고 전용 설비. AS/RS에서 FULL 팔레트로 출고할 수 없는 잔여 제품을 디팔레타이징하여 BOX 단위로 출고 구성(MIXED 팔레타이징)한다.
- **K37 INV-SYNC 재고대사 (설비 · WCS · EWMS)**: EWMS의 RCV9·WCS1 로케이션 수량과 WCS 전체 재고 수량이 일치해야 한다. W/T 연동으로 재고대사가 가능하도록 한다.

## 머리말
> 분류: 업무=재고 / 설비=AS/RS, BOX Shuttle, GANTRY
> 관련 시스템: WCS, ECS | 관련 키워드: EQP-ASRS, EQP-BSH, EQP-GNT, INV-SYNC, INV-UNT, INV-WT, SYS-ARC
> 상태: 일부확정

## 1. 개요
자동화 설비는 무인 영역으로 출입이 제한되므로, 실사 대상 재고를 유인 영역으로 배출하여 확인 후 재입고한다. AS/RS 재고실사는 무조건 1층으로 배출한 뒤 재입고한다(BOX Shuttle·GANTRY 실사 방식은 협의 필요). WCS가 실사 배출 지시를 생성해 설비에 전달하며, 생성 시점에 대상 재고를 작업중 재고로 바꿔 가용재고에서 제외하고, 설비가 실사 후 재입고를 완료하면 작업을 완료하고 재고를 가용화한다. 재입고 위치가 바뀌어도 수용한다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): 재고실사, AS/RS, BOX Shuttle, GANTRY, EWMS, WCS, ECS, BOX 식별자, Workflow, W/T, 가용재고, 작업중 재고, 예약수량, 재고 이동 로그, 설비사, 팔레타이징, 재고 스냅샷, 출고대, 재고 관리단위

## 3. 프로세스 흐름
1. (WCS) 재고조사 대상 선정
2. (WCS) 실사 배출 지시 생성 → 생성 시점에 대상 재고를 작업중 재고로 전환(가용재고에서 제외)
3. (WCS→ECS) 실사 배출 지시 전달 — AS/RS는 무조건 1층 출고대로 배출 (BOX Shuttle·GANTRY는 협의 필요, Q-127)
4. (ECS) 1층 출고대 배출 → (작업자) 바로 실사
5. (작업자) 실사 후 바로 재입고 투입 → (ECS) AS/RS 적치(팔레트 위치가 원래와 달라질 수 있음) → (ECS→WCS) 재입고 실적(적치 위치)
6. (WCS) 작업 완료 처리 → 재고 가용화. 재입고 위치가 원래와 다르면 통보된 위치로 이동 이력을 쌓아 반영

## 7. 예외 처리
- 실사 차이: 사유 등록 후 재고실사 보정 유형으로 WCS만 보정, EWMS 연동 없음 (BR-INV-CNT-008, REQ-INV-CNT-007)
- 보류 재고가 있는 팔레트도 실사 배출·재입고 이동을 막지 않는다(BR-INV-CNT-010)
