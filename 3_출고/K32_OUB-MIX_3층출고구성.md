## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K22 EQP-BSH BOX Shuttle**: 3층의 중소형 제품 대상 BOX 단위 보관 설비. 팔레트화 없이 BOX 그대로 입고·보관·피킹한다.
- **K24 EQP-MIX 3층 디팔레타이징 · MIXED 팔레타이징**: 3층에서 AS/RS 배출 팔레트를 디팔레타이징하고, 출고 주문에 따라 출고 구성(MIXED 팔레타이징)하는 설비. BOX Shuttle과 다른 설비이므로 별도 키워드로 관리한다.
- **K25 EQP-TRB 랩핑 비닐 제거 · TRASH BIN**: 디팔레타이징 전에 팔레트의 랩핑 비닐을 제거하는 방식과, 제거한 비닐을 담는 TRASH BIN의 보관·공급을 정의한다. 3층은 디랩핑기가 비닐을 제거하고, 1층은 작업자가 직접 제거한다.
- **K30 OUB-BAT 출고배치관리**: WCS는 출고배치관리 화면에서 출고 오더를 출고 배치로 묶는다. 배치는 자동으로 생성·처리하는 것이 아니라 차수(배치 차수)를 두고, 차수마다 속성(오더유형 TC/직송, 포함할 거래처 거리유형(장거리·중거리·인근, WCS 거래처 마스터에서 관리), 거리유형별 오더타입(A~D))을 정해 그 속성 기준으로 오더를 묶는 개념이다.
- **K31 OUB-GNT GANTRY 출고 / 사전보충**: 대형제품 출고 중 FULL 팔레트로 출고할 수 없는 건을 GANTRY에서 BOX 단위로 출고 구성(MIXED 팔레타이징)한다. 보관호기 잔량을 먼저 피킹호기로 이동해 사용하고, 부족분은 AS/RS 팔레트를 배출·디팔레타이징하여 보충한다.

## 1. 개요
3층에서 중소형 제품을 BOX 단위로 모아 출고 팔레트를 구성(MIXED 팔레타이징)하는 출고 흐름. 피킹 W/T를 할당할 때는 재고 할당 우선순위로 재고를 가져다 쓴다: 1순위 BOX Shuttle 재고, 2순위 AS/RS 팔레트(3층 배출 → 디팔레타이징 → BOX Shuttle 적치 후 인출). 중소형 BOX의 낱개 오더 출고를 위해 출고예정 기반 사전 보충을 한다. 사전 보충 수요는 AS/RS FULL 팔레트로 출고할 수 있는 수량을 팔레트 출고로 빼고 남은 수량으로 계산한다. 사전 보충은 새벽에 1회 받은 출고예정 중 당일 출고예정·시간대 A타입 오더만 추려 보충 대상 자료를 만든다. 피킹 W/T 할당·피킹지시 시 재고가 부족하면 긴급 보충을 한다. 디팔레타이징한 BOX는 2순위 할당·보충 모두 MIXED에 바로 넣지 않고 BOX Shuttle에 적치한 뒤 쓰며, BOX Shuttle 적치율 임계치에 도달하면 사용자 알람으로 사전 조치한다. 출고 구성 후 남은 BOX는 BOX Shuttle에 보관한다(1층 GANTRY의 보관호기와 같은 역할). 출고 구성 설비에는 인도처별 스테이션 매핑이 없다. AS/RS·BOX Shuttle·3층 디랩핑기·3층 디팔레타이징·MIXED 팔레타이징은 모두 현대무벡스 설비라 3층 출고 구성 경로는 현대무벡스 내부 인계이며, WCS가 단계마다 작업을 지시한다. 피킹지시 시점에 재고가 부족할 수 있어 부족 유형과 처리를 정의한다.

## 3. 프로세스 흐름
사전 보충 (중소형 BOX 낱개 오더):
1. (EWMS→WCS) 새벽 시간에 출고예정 1회 수신 → (WCS) 당일 출고예정 대상·시간대 A타입 오더만 추려 보충 대상 자료 생성(BR-OUB-MIX-019) → 중소형 제품 출고예정 수량 중 AS/RS FULL 팔레트 출고분을 빼고 남은 수량으로 3층 사전 보충 수요 계산 (BR-OUB-MIX-014)
2. (WCS→현대무벡스 ECS) AS/RS 팔레트 3층 배출 → 랩핑 제거 → 3층 디팔레타이징 → BOX Shuttle 적치 (피킹 W/T 수신 전)
3. BOX Shuttle 적치율 임계치 도달 시 (WCS→대시보드·파워유저) 알람 → 사용자 사전 조치 (BR-OUB-MIX-018)

출고 구성:
1. (EWMS→WCS) 피킹 W/T 수신 → (WCS 사용자) 배치 편성·확정(OUB-BAT BR-OUB-BAT-010), 이후 단계는 배치 확정 후 진행
2. (WCS) BOX Shuttle 재고 우선 할당
3. (WCS→BOX Shuttle ECS) BOX 인출 지시 → 3층 MIXED 팔레타이징로봇으로 이송 (현대무벡스 내부 인계)
4. 2순위 할당분: (WCS→현대무벡스 ECS) AS/RS 팔레트 3층 배출(3층 디팔레타이징 배출라인) → 3층 디랩핑기 랩핑 제거(WCS 지시·완료 보고, EQP-TRB) → (현대무벡스 내부 인계) → (WCS→현대무벡스 ECS) 3층 디팔레타이징 — 해체 범위는 옵션(BR-OUB-MIX-009, 현재 기본 = 전량 해체)
 - 전량 해체(기본): 팔레트 전부 해체 → 해체 BOX 전량 BOX Shuttle 적치 → 필요 BOX 인출 → MIXED (MIXED 직투입 불가, BR-OUB-MIX-021), 공팔레트는 매거진
 - 부분 해체: 디팔레타이징하지 않고 작업자가 피킹량만 작업 → BOX Shuttle 적치 → 인출 → MIXED(BR-OUB-MIX-021), 남은 팔레트는 AS/RS 재투입라인으로 재입고(사이즈 체크 기본, HU 확인 안 함, 상세 Q-207). 적용·피킹 수량은 사용자 판단
5. (로딩 옵티마이저) 인도처별 적재 방법·출고 팔레트 분할 결정 — SDS 수행 시 (SDS→WCS) 결과 수신 → 출고 구성 지시와 함께 전달 / 설비사 수행 시 자체 처리
 → (WCS→현대무벡스 ECS(3층 MIXED 팔레타이징)) 출고 구성 지시 → MIXED 팔레타이징
6. (현대무벡스 ECS→WCS) 3층 MIXED 출고 구성 완료·잔량 BOX 통보 → 잔량은 BOX Shuttle 투입 지시 (현대무벡스 내부 인계, EQP-BSH 경로 B)
7. 출고 팔레트 수직반송기로 1층 이동(P-14) → AMR(P-10) 또는 유인지게차로 1층 출고 DOCK 이송 → 출고완료 확정 (OUB-CFM)

부족 발생 시(할당 우선순위 2순위 = 긴급 보충, BR-OUB-MIX-022): 감지(W/T 할당 / 피킹지시 전 / 출고 구성 중 설비 보고) → 긴급 보충(BR-OUB-MIX-015, MIXED 직투입 안 함 BR-OUB-MIX-017) → 마감 내 해소 불가 시 파워유저가 부분 출고·출고 대기 선택 (§7)

| S5 재고 상태 변경 | 보류 전환, LOT 속성 변경(파손 등), 셀 상태 할당불가 | W/T 할당(배치 확정) | 가용 재고에서 제외 후 재할당 |
| S6 보충 미완료 | 사전 보충분이 아직 BOX Shuttle에 적치·확정되지 않음(디팔레타이징·적치 진행 중·지연) (BR-OUB-MIX-013) | 피킹지시 전 확인 | 적치 완료 대기 또는 AS/RS 팔레트로 재할당 |
| S7 실물 수량 차이 | BOX Shuttle 적치·인출 수량 차이, BOX 파손·Reject, 디팔레타이징 실적 부족 | 출고 구성 중 설비 보고 | 재고 처리 오류 표시·재고대사 등록, 재할당 |
| S8 설비 출고 불가 | BOX Shuttle 이상으로 BOX를 인출할 수 없음 | 설비 보고 | 불가 사유 수신 후 재할당 (EQP-ASRS BR-EQP-ASRS-005 방식, REQ-EQP-ASRS-008) |
| B1 적치 진행 중 | 경로 B 잔량 BOX가 BOX Shuttle로 인계 중이라 아직 BOX Shuttle 적치 완료 전 | W/T 할당(배치 확정) | 가용에서 제외, 적치 완료 대기 또는 재할당 |
| B2 W/T 미확정 | 경로 A(디베닝)로 적치했으나 BOX 단위 적치 W/T 확정 전이라 가용재고 아님 (EQP-BSH BR-EQP-BSH-016, 경로 B는 Q-016) | W/T 할당(배치 확정) | 확정 대기 또는 재할당 |
| B3 인계 손실 | BOX Shuttle → 3층 MIXED 팔레타이징로봇 이송 중 BOX 누락·Reject | 출고 구성 중 설비 보고 | 재고 처리 오류 표시·재고대사 등록, 재할당 |
| B4 처리능력 부족 | 재고는 있으나 BOX Shuttle 인출 처리량 때문에 마감 내 인출 불가 | 피킹지시 전 확인 | 인출 우선순위 재조정, 불가 시 마감 내 해소 불가 처리 |

- 위 표의 '재할당'은 긴급 보충으로 수행한다 (BR-OUB-MIX-015). 보충 BOX는 BOX Shuttle 적치 후 사용(BR-OUB-MIX-017)
- 마감 내 해소 불가 시 파워유저가 부분 출고 / 출고 대기 선택, 부분 출고 잔량은 W/T 취소 요청 (REQ-OUB-MIX-007)
- 수요 감소로 사전 보충 소요량이 0 이하: Action 전송 전 작업 취소, 전송 후 작업은 완료하고 남는 BOX는 BOX Shuttle 미예약 재고 (REQ-OUB-MIX-028)
