## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K02 SYS-JOB 작업지시 체계 (Batch · Work · Task · Workflow · Action)**: WCS는 프로세스별로 작업지시를 Batch → Work → Task의 계층으로 관리하고, Task는 WCS Planning이 생성하고, WCS Execution이 Task를 받아 Workflow에 따라 실제 설비 단위 작업지시인 Action을 생성한다(SYS-ARC). Action 이후 설비 인터페이스는 오픈솔루션의 통신표준화 솔루션이 처리한다.
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K09 MST-CUS 거래처 마스터**: WCS는 TC센터만 거래처로 관리한다. EWMS와 같은 거래처코드로 TC센터 거래처 정보를 만들어 두고, TC센터에 GANTRY 호기를 지정할 때 쓴다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…

## 1. 개요
WCS는 출고배치관리 화면에서 출고 오더를 출고 배치로 묶는다. 배치는 자동으로 생성·처리하는 것이 아니라 차수(배치 차수)를 두고, 차수마다 속성(오더유형 TC/직송, 포함할 거래처 거리유형(장거리·중거리·인근, WCS 거래처 마스터에서 관리), 거리유형별 오더타입(A~D))을 정해 그 속성 기준으로 오더를 묶는 개념이다. 차수는 출고예정일이 당일인 오더만 처리하며, 전일 잔여건이 있으면 당일 오더에 포함한다(운영상 전일 잔여건은 없도록 운영). 한 오더는 한 차수에만 속한다. 사용자는 차수에 오더를 추가하거나 수작업으로 포함·제외할 수 있고, 화면은 드래그앤드롭 등 사용자 편의 기능을 제공한다. 배치의 오더는 피킹 W/T이며(출고예정은 사전 보충에만 쓰고 배치 대상이 아님), 출고예정일은 EWMS가 W/T에 내려준다. 배치 확정이 작업지시의 관문으로, 피킹 W/T는 배치 확정 후에만 할당·작업지시(Work·Task)가 생긴다. 작업지시 체계 Batch와의 관계 등은 확인 중이다(Q-150).

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): EWMS, WCS, Batch, Work, Task, 전략 이력, W/T, W/T 생성, 화주, FO, 인도처, 거래처, 출고 DOCK, 출고예정, 시간대별 출고 Type, 출고 배치, 거리유형, 거래처 마스터, 배치 차수, STO, 직송, TC, ORG DO, 피킹 W/T, 대시보드, 파워유저, 사전 보충, 긴급 보충

## 3. 프로세스 흐름
1. (EWMS→WCS) 출고 오더(피킹 W/T) 수신 — 인도처(거래처), 출고 오더 유형(STO·직송), 출고예정일, 시간대별 출고 Type (MST-ORD). 출고예정은 사전 보충에만 쓰고 배치 대상이 아니다
2. (WCS 사용자) 배치 차수 생성 — 차수 속성(오더유형 TC/직송, 포함할 거리유형, 거리유형별 오더타입 A~D) 설정
3. (WCS) 출고예정일이 당일인 미배치 오더(전일 잔여건 포함) 중 차수 속성에 맞는 오더를 해당 차수에 묶음
4. (WCS 사용자) 출고배치관리 화면에서 배치에 오더 추가, 오더를 수작업으로 포함·제외 — 현재 차수의 포함 오더를 조회해 선택 제거, 당일자 오더를 팝업으로 조회해 선택 포함 (드래그앤드롭 등)
5. (WCS 사용자) 배치 확정 → (WCS) 확정된 차수의 피킹 W/T를 할당하고 작업지시(Work·Task)를 생성 (BR-OUB-BAT-010). 확정 전 W/T는 작업지시를 만들지 않는다

- 거리유형이 '미지정'인 TC센터 거래처의 오더(MST-CUS BR-MST-CUS-011): 어떤 차수 속성에도 맞지 않아 묶이지 않고 미배치 목록에 남아 사용자가 수작업으로 포함한다
- 미등록 거래처의 피킹 W/T: 작업지시를 생성하지 않으므로 배치 대상에서도 제외한다 (MST-CUS BR-MST-CUS-008)
- 배치 확정 전 피킹 W/T: 할당·작업지시를 만들지 않음(BR-OUB-BAT-010), 마감 리드타임 안에 미배치·미확정이면 알람(REQ-OUB-BAT-017, 추천)

## 8. 미결 사항
- Q-150: 출고 배치 정의 — (1) 작업지시 체계(SYS-JOB)의 출고 Batch와 같은 것인지 (2) "오더타입(A~D)"을 시간대별 출고 Type으로, 오더유형 TC/직송을 출고 오더 유형 STO/직송으로 본 해석이 맞는지 (3) 하루 차수 수, 배치 구분 단위(창고·화주·출고 DOCK·설비 등) (4) 추천 항목(REQ-OUB-BAT-007~009·017) 채택 여부, 할당(예약) 시점도 배치 확정으로 본 해석 (배치 확정 = 작업지시 관문·배치 오더 = 피킹 W/T·출고예정은 사전 보충만·출고예정일 EWMS 제공 결정)
