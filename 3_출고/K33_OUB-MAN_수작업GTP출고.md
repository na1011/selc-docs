## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K09 MST-CUS 거래처 마스터**: WCS는 TC센터만 거래처로 관리한다. EWMS와 같은 거래처코드로 TC센터 거래처 정보를 만들어 두고, TC센터에 GANTRY 호기를 지정할 때 쓴다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K29 HU-VAL 공팔레트 · HU 확인/생성**: 팔레트 ID의 WCS 사용 가능 여부를 판단하기 위해 EWMS HU를 확인·생성한다. 공팔레트는 묶음 단위로 AS/RS에 재고 보관하여 관리한다.
- **K30 OUB-BAT 출고배치관리**: WCS는 출고배치관리 화면에서 출고 오더를 출고 배치로 묶는다. 배치는 자동으로 생성·처리하는 것이 아니라 차수(배치 차수)를 두고, 차수마다 속성(오더유형 TC/직송, 포함할 거래처 거리유형(장거리·중거리·인근, WCS 거래처 마스터에서 관리), 거리유형별 오더타입(A~D))을 정해 그 속성 기준으로 오더를 묶는 개념이다.
- **K31 OUB-GNT GANTRY 출고 / 사전보충**: 대형제품 출고 중 FULL 팔레트로 출고할 수 없는 건을 GANTRY에서 BOX 단위로 출고 구성(MIXED 팔레타이징)한다. 보관호기 잔량을 먼저 피킹호기로 이동해 사용하고, 부족분은 AS/RS 팔레트를 배출·디팔레타이징하여 보충한다.

## 1. 개요
AS/RS 보관 재고 중 GANTRY로 출고할 수 없는 건은 3층(또는 4층) 출고 수작업 영역으로 배출하여 GTP 방식으로 출고한다. AS/RS 출고대로 배출한 뒤 유인지게차로 출고 수작업 영역 로케이션까지 이동하며 WCS는 작업지시를 내리지 않는다 (AMR은 1층만 사용). 출고 수작업 영역은 OEM 3층 논리 출고 DOCK과 같이 쓰며, 출고 수작업 영역 재고는 WCS가 관리하지 않는다(EWMS 관리). 3·4층 전달 완료(AS/RS 배출 완료) 시 WCS가 출고확정하고 피킹 W/T 실적을 EWMS에 보낸다. 한 팔레트에 인도처가 여럿이면 원팔레트ID-1~N을 붙여 인도처별로 보내고, 잔량은 원팔레트ID-(N+1)로 자동화 → 수작업 이동 W/T 생성 요청·확정을 한 번에 처리한다. 이 시점에 WCS 재고에서 빠지며, 이후 분할·작업은 EWMS 영역이다(WCS PDA 분할·GTP PDA·PC 출고확정 없음). 출고확정 후 1층 이동은 EWMS가 PDA 선행작업 후 생성한 W/T를 받아 WCS가 운반 작업지시한다(BR-OUB-MAN-025).

## 3. 프로세스 흐름
수작업 영역 위치:
| 층 | 수작업 영역 용도 |
| --- | --- |
| 1층 | 입고 수작업 영역: AS/RS 입고 투입 전 수작업 팔레타이징 구역만 존재 (INB-PLT) |
| 3층·4층 | 출고 수작업 영역: GTP 출고, OEM 3층 논리 출고 DOCK. GTP 출고와 OEM 3층 논리 출고 DOCK은 같은 출고 수작업 영역을 사용하며, 위치가 포함된 로케이션 약 3개로 운영 예정 |

GTP 출고 흐름:
1. (EWMS→WCS) 피킹 W/T 수신 → 배치 확정(OUB-BAT BR-OUB-BAT-010) 후 진행 — DEST BIN이 3·4층 출고 수작업 셀(9013·RCV3 / 9014·RCV4)이면 GTP 출고로 처리(BR-OUB-MAN-026)
2. (WCS→현대무벡스 ECS) AS/RS 팔레트 3층(또는 4층) 배출
3. (현대무벡스 ECS→WCS) 배출 완료 = 3·4층 전달 완료 → (WCS) 해당 층 수작업 셀(9013·RCV3 / 9014·RCV4)로 재고 이동 → 그 셀에서 출고확정(BR-OUB-MAN-024) → (WCS→EWMS) 피킹 W/T 실적 전송, 한 팔레트에 인도처가 여럿이면 원팔레트ID-1~N으로 나눠 전송 → WCS 재고에서 제외 (BR-OUB-MAN-022)
4. (작업자) 유인지게차로 출고 수작업 영역 로케이션으로 팔레트 이송 (WCS 작업지시 없음)
5. (작업자) 인도처별/FO별 분류·분할 — EWMS 영역(WCS PDA 분할 없음)
7. 출고 팔레트: (작업자) 3·4층 작업 완료 → (유인지게차) 수직반송기 투입 → 1층 이동 → 출고 DOCK — 출고확정은 3단계에서 이미 처리, 1층 이동은 (EWMS PDA 선행작업 → EWMS→WCS W/T) 수신 후 WCS 작업지시(BR-OUB-MAN-025)
8. 잔량 팔레트: (WCS→EWMS) 3·4층 전달 완료 시 원팔레트ID-(N+1)로 자동화 → 수작업 이동 W/T 생성 요청·확정을 한 번에 처리 → WCS 재고에서 제외(이후 EWMS 관리) (BR-OUB-MAN-023)

예시: 팔레트 1816J2323332, LEQ 4, 인도처 3곳 분기
- 1816J2323332-1, -2, -3 → 3층 전달 완료 시 출고확정, 인도처별 피킹 W/T 실적으로 EWMS 전송 → 이후 3·4층 작업·1층 이동
- 잔량 1개 → 3층 전달 완료 시 1816J2323332-4로 이동 W/T 생성·확정 실적 전송

| BR-OUB-MAN-023 | GTP·직송 이적 잔량 처리 | 3·4층 전달 완료 시 팔레트에 남는 잔량(피킹 W/T에 할당되지 않은 수량)은 WCS가 EWMS에 자동화 → 수작업 이동 W/T 생성을 요청하고, W/T 확정도 한 번에 처리한다. 실적에는 팔레트 일련번호(원팔레트ID-(N+1))를 넣어 보낸다 |
| BR-OUB-MAN-024 | 수작업 인계 셀 | 수작업 출고완료 처리를 위해 출고 수작업 영역 셀 정보를 WCS에 둔다. 셀은 EWMS BIN 단위(3층 9013·RCV3, 4층 9014·RCV4)로 하고, 수작업 인계 건(GTP·직송 이적)은 해당 셀로 재고를 이동한 뒤 그 셀에서 출고확정한다 |
| BR-OUB-MAN-025 | GTP·직송 이적 출고확정 후 3·4층 → 1층 이동 | EWMS가 PDA로 선행작업을 한 뒤 W/T를 생성해 WCS에 알린다. WCS는 수신 후 필요한 작업지시(수직반송기·AMR)를 한다. 출고확정 후라 WCS 재고가 아닌 운반으로 처리한다 (MST-LOC BR-MST-LOC-035) |
| BR-OUB-MAN-026 | GTP 출고 판단 | WCS가 자체 기준으로 GANTRY 출고 불가를 판단하지 않는다. 피킹 W/T의 DEST BIN이 3·4층 출고 수작업 셀(9013·RCV3, 9014·RCV4)이면 GTP 출고로 처리한다(경로 = W/T DEST, MST-LOC BR-MST-LOC-033). GANTRY 실물 부족·설비 이상은 GTP가 아니라 재할당·긴급 보충으로 처리한다(OUB-GNT REQ-OUB-GNT-015) |
