## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K12 MST-EQP 설비 기준정보 · 팔레트 유형**: WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K15 MST-SN 제조번호(S/N) 관리**: 평택 CDC는 LOT 생성 전략에서 제조번호를 LOT 속성으로 선택하지 않는다(물류 작업지시 효율 저하 우려, 후보 속성으로는 존재, MST-LOT). 대신 시리얼 마스터를 두어, 시리얼번호가 입고되어 최초 생성될 때, 설비로부터 시리얼번호 단위 결과 실적을 받을 때, 출고하면서 시리얼번호 단위 검수 결과를 받을 때 이력 로그를 쌓아 추적한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K22 EQP-BSH BOX Shuttle**: 3층의 중소형 제품 대상 BOX 단위 보관 설비. 팔레트화 없이 BOX 그대로 입고·보관·피킹한다.

> 분류: 업무=입고 / 설비=하역 로봇(1층), 디베닝라인, BCR, 시퀀스 버퍼, 팔레타이징로봇, BOX Shuttle

> 상태: 일부확정

## 1. 개요
디베닝 대상 중소형 BOX 제품을 1층에서 로봇으로 하역해 3층으로 이동하고, BCR 스캔 후 입고정보 속성값에 따라 팔레타이징(→AS/RS) 또는 BOX Shuttle로 분기한다. EWMS 재고위치는 EWMS 디베닝 작업지시 시 1층 입고장(9011·RCV1)에서 디베닝설비 입고장(Stock Type 9015·BIN RCV9)으로 전환되며, WCS도 이 시점 위치셀 RCV9에 자동화 설비 재고로 잡는다. 디베닝 장비 설비사는 로지스올이며, 팔레트화 후 AS/RS 투입(P-01)과 BOX Shuttle 투입(P-02)은 현대무벡스 설비와의 설비 접점이다 (EQP-VND).

## 3. 프로세스 흐름
1. (EWMS→WCS) 하역 작업 전 디베닝 하역 대상 전송 — EWMS가 디베닝 작업지시를 하면 재고를 1층 입고장(9011)에서 디베닝설비 입고장(9015·RCV9)으로 전환하면서 디베닝 대상만 구분해 보낸다 (BR-INB-DVN-015·016·032) → (WCS) 수신 후 팔레트 ID가 없는 재고로 등록 — invn_id = WCS 위치셀(RCV), LOT 채번 (BR-INB-DVN-017·020)
1-1. (WCS→로지스올 ECS) 수신한 디베닝 하역 대상 정보를 디베닝 장비에도 전달
2. (하역 로봇) 1층 하역 → 3층 이송 컨베이어로 3층 BCR까지 이동 (로지스올 내부 인계)
3. (로지스올 ECS→WCS) BCR 검수 결과 전송 — BOX 제품코드/제조번호, 예정정보 대조 결과(정상/REJECT), REJECT 사유 (검수·REJECT 판정은 로지스올)
4. (WCS) REJECT 건 → WCS PDA 현장 조치(통합 Reject 처리) 대상으로 등록해 해당 건만 사후 처리 — 작업자가 REJECT BOX를 확인한 뒤 재투입 / 정상 건 → 입고정보 속성값 확인
5. 분기
 - 팔레타이징 대상: 시퀀스 버퍼 → 팔레타이징로봇(동일 제품, LEQ 기준) → 3층 랩핑기(로지스올, 랩핑, WCS 관여 없음 BR-INB-DVN-024) → AS/RS 3층 입고라인(P-01) → AS/RS 보관
 - BOX Shuttle 대상: BOX Shuttle 투입 → 적치 (EQP-BSH 경로 A)
6. (팔레타이징로봇 ECS→WCS) 팔레타이징 결과(팔레트 ID, 제조번호(S/N)) 수신 → (WCS→EWMS) 그 정보로 HU 생성·PACK API 호출 (BR-INB-DVN-018·022)
7. (WCS→EWMS) HU 생성·PACK이 성공하면 해당 팔레트 ID로 적치 W/T 생성 요청 → (EWMS→WCS) 적치 W/T 생성 응답(W/T 번호) → AS/RS 적치 → 적치 W/T 확정 (BR-INB-DVN-019·022)

## 7. 예외 처리
- BCR 스캔 제품이 디베닝 하역 대상 정보(예정정보)에 없으면 로지스올이 REJECT 판정하고, WCS는 검수 결과를 받아 해당 건만 WCS PDA 통합 Reject 화면에서 사후 처리한다. BCR 스캔 실패 등 다른 사유도 로지스올이 판정하며, 작업자가 REJECT BOX를 확인한 뒤 재투입한다 (BR-INB-DVN-010~013).
- REJECT BOX 재고는 수신 위치셀(RCV9)에 두고 PDA에 배출 위치만 표시하며, BCR 앞으로 재투입해 재검수한다 (BR-INB-DVN-026). 배출구·재투입구 물리 위치는 협의 대상 (Q-029), 사유코드 목록은 공통 사유코드 맵핑 (INB-PLT Q-169)
- LEQ 미달 잔량: 마지막 팔레트를 미달 팔레트로 마감해 AS/RS에 적치, 미도착 시 미도착 확정 시점에 마감 지시 (BR-INB-DVN-031). 로봇의 적재 수량 지정·마감 지시 지원은 로지스올 확인 (Q-030)

## 8. 미결 사항
- Q-163: [추후 정리] 디베닝 하역 대상 취소·변경 처리 — 하역 시작 전·후 처리, 로지스올 예정정보 취소 지원 여부 (프로세스에 포함하지 않음)
- Q-029: [추가 협의] 디베닝 REJECT 배출구·재투입구(BCR 앞) 물리 위치와 배출 위치 코드 전달 방식 — 로지스올 확인 (REJECT BOX 재고 RCV9 위치셀 유지·배출 위치 표시만·BCR 앞 재투입 재검수·사유코드 목록 INB-PLT Q-169 통합 결정, BCR 스캔 실패 등)·작업자 확인 후 재투입·PDA 통합 Reject 화면 사후 처리 결정)
- Q-030: [추가 협의] 3층 입고 팔레타이징로봇이 팔레트별 적재 수량 지정과 마감 지시를 지원하는지 — 로지스올 확인 (LEQ 미달 팔레트로 마감·AS/RS 적치·WCS 사전 계산 결정)
