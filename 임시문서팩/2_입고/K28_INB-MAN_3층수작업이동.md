# [K28/40] [INB-MAN] 팔레트 3층 수작업 이동

| 항목 | 내용 |

| 입력 순서 | 28 / 40 (묶음 F: 입고·HU) |

| 후행 키워드 | K40 YRD-VHC |
| 상태 | 일부확정 · BR 9 · REQ 확정 6 / 확인필요 2 · 미결 0 |

## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K26 INB-PLT 팔레트 입고 (일반입고 / 대형)**: 1층에서 하역 또는 입고 수작업 영역에서 수작업 팔레타이징한 팔레트를 1층 AS/RS에 투입한다. 투입 시점에 WCS가 EWMS 내역을 확인하여 AS/RS 보관을 결정하며, AS/RS 용량이 부족하면 3층 출고대로 배출한다(용량 부족 배출, Bypass와 별개). 1층 입고대 Reject는 Bypass와 구분하며, ECS가 판단해 에러 코드를 포함해 3층 출고대로 배출한다.

## 머리말
> 분류: 업무=입고 / 설비=AMR, 수직반송기, 유인지게차, AS/RS(1층)
> 관련 시스템: EWMS, WCS | 관련 키워드: INB-PLT, MST-ORD, EQP-VND, YRD-VHC
> 상태: 일부확정

## 1. 개요
1층에서 하역 또는 수작업 팔레타이징한 팔레트(국내OEM·해외OEM 등, 쉽백은 WCS 프로세스 대상 아니나 3층 수작업 이동 작업지시 필요 여부 협의 중 — MST-ORD Q-165)를 3층·4층으로 이동한다. W/T상 행선지가 3층인 입고가 대상이다. WCS는 이동 작업지시(AMR·수직반송기)를 처리하고 WCS 재고로는 등록하지 않는다. EWMS가 PDA 선행작업 후 생성한 W/T를 받아 이동 작업을 만들고, 도착하면 도착 정보를 EWMS에 보내 W/T를 확정한다. AMR 설비사는 생기연, 수직반송기는 설비사 미정(다른 설비사로 가정)이므로 AMR → 수직반송기 인계(P-06)는 설비 접점으로 WCS가 중간 처리한다. AMR은 1층만 사용한다. 3층 도착 팔레트(수직반송기 도착·AS/RS 3층 Bypass)는 유인지게차가 옮기며 WCS는 작업지시를 내리지 않는다.

## 3. 프로세스 흐름
이동 작업 생성 전: (작업자) EWMS PDA 선행작업 → (EWMS→WCS) W/T 생성·전송 → (WCS) 이동 작업 생성 (BR-INB-MAN-015)

이동 방식 2가지 (OEM 3층 이동은 AS/RS를 통하지 않음, BR-INB-MAN-013). 수단은 Workflow 설정(기본·대체)으로 정하고, AMR 가동 불가 시 대체 수단으로 전환한다(BR-INB-MAN-014):
1. AMR 라인: AMR 호출 → 수직반송기까지 이동 → 3층
2. 유인지게차: 지게차가 직접 수직반송기로 이동 → 3층

도착 후 (공통):
3. 수직반송기 목적층(3층·4층) 도착(수직반송기 ECS→WCS) → (WCS) 이동 작업 완료 처리 (WCS 재고 등록 없음) → (WCS→EWMS) 도착 정보 전송 → W/T 확정
4. (작업자) 유인지게차로 3층 도착 팔레트 이동 (WCS 작업지시 없음, WCS 처리 범위 밖)
