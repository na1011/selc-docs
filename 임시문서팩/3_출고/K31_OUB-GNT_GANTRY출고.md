## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.
- **K09 MST-CUS 거래처 마스터**: WCS는 TC센터만 거래처로 관리한다. EWMS와 같은 거래처코드로 TC센터 거래처 정보를 만들어 두고, TC센터에 GANTRY 호기를 지정할 때 쓴다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K22 EQP-BSH BOX Shuttle**: 3층의 중소형 제품 대상 BOX 단위 보관 설비. 팔레트화 없이 BOX 그대로 입고·보관·피킹한다.
- **K23 EQP-GNT GANTRY**: 1층 대형제품 출고 전용 설비. AS/RS에서 FULL 팔레트로 출고할 수 없는 잔여 제품을 디팔레타이징하여 BOX 단위로 출고 구성(MIXED 팔레타이징)한다.
- **K24 EQP-MIX 3층 디팔레타이징 · MIXED 팔레타이징**: 3층에서 AS/RS 배출 팔레트를 디팔레타이징하고, 출고 주문에 따라 출고 구성(MIXED 팔레타이징)하는 설비. BOX Shuttle과 다른 설비이므로 별도 키워드로 관리한다.
- **K25 EQP-TRB 랩핑 비닐 제거 · TRASH BIN**: 디팔레타이징 전에 팔레트의 랩핑 비닐을 제거하는 방식과, 제거한 비닐을 담는 TRASH BIN의 보관·공급을 정의한다. 3층은 디랩핑기가 비닐을 제거하고, 1층은 작업자가 직접 제거한다.
- **K30 OUB-BAT 출고배치관리**: WCS는 출고배치관리 화면에서 출고 오더를 출고 배치로 묶는다. 배치는 자동으로 생성·처리하는 것이 아니라 차수(배치 차수)를 두고, 차수마다 속성(오더유형 TC/직송, 포함할 거래처 거리유형(장거리·중거리·인근, WCS 거래처 마스터에서 관리), 거리유형별 오더타입(A~D))을 정해 그 속성 기준으로 오더를 묶는 개념이다.

> 상태: 일부확정

## 1. 개요
대형제품 출고 중 FULL 팔레트로 출고할 수 없는 건을 GANTRY에서 BOX 단위로 출고 구성(MIXED 팔레타이징)한다. 보관호기 잔량을 먼저 피킹호기로 이동해 사용하고, 부족분은 AS/RS 팔레트를 배출·디팔레타이징하여 보충한다. 디팔레타이징한 BOX 중 피킹호기로 보내고 남은 잔량은 보관호기에 보관하며(GANTRY 진입 시점에만), 출고 구성을 마친 팔레트는 GANTRY 출고대로 배출한다. AS/RS FULL 팔레트는 1층 출고대로 배출한다. 출고예정 정보로 사전 보충하여 출고라인 병목을 줄인다.

## 3. 프로세스 흐름
1. (EWMS→WCS) 출고예정 수신 → (WCS) 사전 보충 계획
2. (EWMS→WCS) 피킹 W/T 수신 → (WCS 사용자) 배치 편성·확정(OUB-BAT) → (WCS) 할당·출고 작업지시
3. (WCS→ECS) 보관호기에 해당 제품 재고가 있으면 피킹호기로 이동
4. 부족분: (WCS→ECS) AS/RS 팔레트 배출 → 보충 컨베이어로 GANTRY 입구 이송 → 디팔레타이징(팔레트 → BOX, 별도 지시 없음·실적만 수신 EQP-GNT BR-EQP-GNT-036) → 인도처 매핑 피킹호기로 이송, 남은 잔량 BOX → 보관호기로 이동하여 보관(GANTRY 진입 시점에만)
5. (로딩 옵티마이저) 인도처별 적재 방법·출고 팔레트 분할 결정 — SDS 수행 시 (SDS→WCS) 결과 수신 → (WCS→현대무벡스 ECS) 전달 / 현대무벡스 수행 시 설비사 자체 처리
 → 피킹호기에서 1층 MIXED 팔레타이징로봇이 출고 구성(MIXED 팔레타이징)
6. (ECS) 출고 구성을 마친 팔레트를 GANTRY 출고대로 배출 — MIXED 팔레타이징 후 피킹호기에 남은 BOX는 그대로 둔다 → (WCS→생기연 ECS) AMR 이송 지시 또는 유인지게차(Workflow 설정)로 출고 DOCK 이동
7. (ECS→WCS) 출고 구성 완료 통보 → 출고완료 확정 (OUB-CFM)

사전 보충 알고리즘 (REQ-OUB-GNT-008~010·012, 리드타임·처리능력 값은 설비 값 수신 후 설정):
1. GANTRY 수요 산출: 출고예정 중 당일 출고예정·시간대 A타입 오더(BR-OUB-GNT-021)의 OUT EQUIPMENT = GANTRY 제품을 (인도처, 화주, 제품)별로 모아, AS/RS 실제 팔레트 수량 기준 FULL 팔레트 출고분을 먼저 빼고 남은 수량을 GANTRY 수요로 본다.
2. 피킹호기별 순소요량: 인도처 매핑(TC센터) 또는 출고예정 FO 기준 직송 GANTRY 호기 임시 할당(직송, 사전 보충 대상 포함 BR-OUB-GNT-019, REQ-OUB-GNT-028)으로 피킹호기별로 합산. 합산 시(같은 호기의 인도처 N개 동일 제품은 묶음). 순소요량 = GANTRY 수요(W/T 미할당분) − 피킹호기 미예약 현재고(현재고 − 예약수량) − 도착예정 수량(진행 중 보충량). 출고예정과 개별로 짝짓지 않고 피킹호기·제품 단위 합계로 계산한다 (소프트 예약 없음).
3. 보관호기 재고 우선 배정: 같은 화주·LOT 조건을 충족하는 보관호기 재고로 먼저 채운다(내부 이송, 보충 컨베이어 부하 없음). GANTRY 보관일·LOT가 오래된 BOX부터 쓴다 (BR-OUB-GNT-018).
4. AS/RS 팔레트 선택: 남은 소요를 제품별로 합산해 팔레트를 고른다(팔레트 1개를 여러 피킹호기에 분배 가능). 우선순위 ① 잔량 최소 조합(best-fit, 보관호기 용량 절약) ② 부분 팔레트 우선(AS/RS 셀 비움) ③ LOT 순서(입고월 FIFO). 가용재고만 사용(보류·할당불가 셀 제외, 화주 체크). 디팔레타이징 후 잔량은 보관호기로.
5. 시간 배치: 작업별 최종 완료 시각 = 시간대 Type 마감 − (출고 구성 + 상차 리드타임). 여유시간이 적은 작업부터 보충 라인 시간당 처리능력 안에서 배치하고, 초과 구간은 앞쪽 저부하 구간(A 이전 야간, 시간대 사이)으로 당긴다. 보충 대상은 당일·A타입 오더로 한정하고(BR-OUB-GNT-021) 피킹호기·보관호기 용량을 넘지 않게 자른다.
6. 예약·재계산: 사전 보충 BOX는 출고예정에 예약하지 않고 피킹호기 재고로 두며, W/T를 받아 할당할 때 예약(예약수량)한다(INV-RSV). 출고예정 변경·취소 시 다음 재계산에서 수요가 줄고, Action 전송 전 사전 보충 작업은 취소하고 이미 보충된 재고는 피킹호기 미예약 재고로 둔다(REQ-OUB-GNT-034). 재계산 시점: 출고예정 수신·변경, W/T 수신, 설비 실적 수신, 주기 실행.

예시: 인도처 X(G01 매핑), 제품 P 수요 130 BOX, AS/RS에 48 BOX 팔레트 다수와 30 BOX 부분 팔레트 1개 → FULL 팔레트 2개(96) 출고, GANTRY 수요 34 → G01 현재고 0 → G05 보관호기 10 BOX 이동, 남은 소요 24 → 48 BOX 팔레트(잔량 24) 대신 30 BOX 부분 팔레트(잔량 6) 선택, 잔량 6은 보관호기로 → 시간대 B(~12시) 마감에서 역산해 보충 라인 빈 구간에 배치.

## 7. 예외 처리
- 디팔레타이징 전 DeWrapping 체적정보 요청은 미결 과제 (EQP-MIX Q-107)
- 사전 보충 후 출고예정 취소/변경으로 소요량이 0 이하: Action 전송 전 작업 취소, 전송 후 작업은 완료하고 남는 BOX는 피킹호기 미예약 재고 (REQ-OUB-GNT-034)
- 출고 유형별 마감시간 미구체화 — 사전 보충 시간 배치·긴급 보충 우선순위·마감 내 해소 불가 판정의 기준이 정해지지 않음 (MST-ORD Q-123, 추가 협의)
- 사전 보충 후 실제 피킹지시 시 GANTRY 재고 부족 (BR-OUB-GNT-008, 처리 REQ-OUB-GNT-013~016):

| 유형 | 원인 | 감지 시점 | 처리 |
| --- | --- | --- | --- |
| S1 수량 증가·신규 | W/T 수량이 출고예정보다 많거나, 출고예정 없이 W/T가 들어옴 | W/T 할당(배치 확정) | 부족분 긴급 보충 |
