## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K15 MST-SN 제조번호(S/N) 관리**: 평택 CDC는 LOT 생성 전략에서 제조번호를 LOT 속성으로 선택하지 않는다(물류 작업지시 효율 저하 우려, 후보 속성으로는 존재, MST-LOT). 대신 시리얼 마스터를 두어, 시리얼번호가 입고되어 최초 생성될 때, 설비로부터 시리얼번호 단위 결과 실적을 받을 때, 출고하면서 시리얼번호 단위 검수 결과를 받을 때 이력 로그를 쌓아 추적한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K31 OUB-GNT GANTRY 출고 / 사전보충**: 대형제품 출고 중 FULL 팔레트로 출고할 수 없는 건을 GANTRY에서 BOX 단위로 출고 구성(MIXED 팔레타이징)한다. 보관호기 잔량을 먼저 피킹호기로 이동해 사용하고, 부족분은 AS/RS 팔레트를 배출·디팔레타이징하여 보충한다.
- **K32 OUB-MIX 3층 출고 구성 (BOX Shuttle · MIXED 팔레타이징)**: 3층에서 중소형 제품을 BOX 단위로 모아 출고 팔레트를 구성(MIXED 팔레타이징)하는 출고 흐름. 피킹 W/T를 할당할 때는 재고 할당 우선순위로 재고를 가져다 쓴다: 1순위 BOX Shuttle 재고, 2순위 AS/RS 팔레트(3층 배출 → 디팔레타이징 → BOX Shuttle 적치 후 인출).
- **K33 OUB-MAN 수작업 GTP 출고 (AS/RS 출고 후 분할)**: AS/RS 보관 재고 중 GANTRY로 출고할 수 없는 건은 3층(또는 4층) 출고 수작업 영역으로 배출하여 GTP 방식으로 출고한다. AS/RS 출고대로 배출한 뒤 유인지게차로 출고 수작업 영역 로케이션까지 이동하며 WCS는 작업지시를 내리지 않는다 (AMR은 1층만 사용).

## 머리말
> 분류: 업무=출고 / 설비=출고 센서, PDA, PC
> 관련 시스템: WCS, EWMS | 관련 키워드: INV-WT, OUB-GNT, OUB-MAN, MST-ORD, MST-SN
> 상태: 일부확정

## 1. 개요
자동화 설비에서 출고된 팔레트의 피킹 W/T를 확정하는 방식을 정의한다. 출고확정 시점은 수작업 영역으로 인계하는 건(GTP·직송 이적)은 인계 시점(3·4층 전달 완료), 나머지는 설비 Flow의 끝 부분이다. 확정 수단은 센서, PDA, PC 일괄이며, OEM 3층 논리 출고 DOCK은 PDA/PC로 확정한다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): W/T, W/T 확정, 팔레트 ID, 출고 DOCK, EWMS, WCS, GTP, 수작업 영역, OEM생산 입고, EWMS PDA, 시리얼 이력 로그, 출고 수작업 영역, GANTRY, MIXED 팔레타이징, Valuation Type, LOT, 피킹 W/T, AS/RS, 이적, 직송, 인도처, Workflow, GANTRY 출고대, AMR, 유인지게차, 수직반송기, 출고대, 팔레트 유형, 재고 보정, W/T 취소

## 3. 프로세스 흐름
- 센서: 출고 팔레트 스캔(센서) → 해당 팔레트 ID의 피킹 W/T 확정
- PDA: 작업자 PDA 스캔 시점에 피킹 W/T 확정
- PC 일괄: 대상 조회 → 선택 건 확정
- PDA·PC 확정 화면에서 시리얼번호 단위 출고 검수를 함께 처리 → 피킹 W/T 확정과 시리얼 이력 로그 적재(MST-SN)를 한 번에 수행
