## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K12 MST-EQP 설비 기준정보 · 팔레트 유형**: WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.
- **K22 EQP-BSH BOX Shuttle**: 3층의 중소형 제품 대상 BOX 단위 보관 설비. 팔레트화 없이 BOX 그대로 입고·보관·피킹한다.

> 분류: 업무=출고/보관 / 설비=3층 디팔레타이징 설비, 3층 MIXED 팔레타이징 설비
> 관련 시스템: WCS, ECS, EWMS | 관련 키워드: EQP-BSH, EQP-ASRS, EQP-VND, OUB-GNT, OUB-MIX, MST-ORD
> 상태: 일부확정

## 1. 개요
3층에서 AS/RS 배출 팔레트를 디팔레타이징하고, 출고 주문에 따라 출고 구성(MIXED 팔레타이징)하는 설비. BOX Shuttle과 다른 설비이므로 별도 키워드로 관리한다. 설비사는 현대무벡스(3층 디팔레타이징·MIXED 팔레타이징)로 AS/RS·3층 디랩핑기·BOX Shuttle과 같다. 그래서 AS/RS 3층 디팔레타이징 배출라인 → 디랩핑기 → 디팔레타이징 → BOX Shuttle → MIXED 팔레타이징(디팔레타이징 BOX는 MIXED 직투입 불가, OUB-MIX BR-OUB-MIX-021), 잔량 → BOX Shuttle은 모두 현대무벡스 내부 인계이며(부분 해체는 디팔레타이징 없이 작업자가 피킹하고 잔량은 AS/RS 재투입라인으로 재입고, Q-207)(설비 접점 아님), WCS는 단계마다 작업을 지시하고 결과를 받는다. 수직반송기는 설비사 미정으로 다른 설비사로 보므로, 출고 구성 완료 팔레트의 MIXED 팔레타이징 → 수직반송기(P-14)와 수직반송기 → AMR(P-10)도 설비 접점이다.

## 3. 프로세스 흐름
출고 구성 (AS/RS → 3층):
1. (WCS→현대무벡스 ECS) AS/RS 보관 팔레트 3층 배출(3층 디팔레타이징 배출라인) → (WCS→현대무벡스 ECS) 3층 디랩핑기 랩핑 제거 지시 → 완료 보고 수신(EQP-TRB) → 디랩핑기 → 디팔레타이징 로봇(현대무벡스 내부 인계), WCS가 랩핑 제거 완료 수신 후 디팔레타이징 지시
2. (WCS→현대무벡스 ECS) 3층 디팔레타이징 지시 → BOX 단위 해체 결과 WCS 수신 — 해체 범위는 옵션(전량 해체 기본 / 부분 해체 — 디팔레타이징 없이 작업자 피킹, 잔량 AS/RS 재투입라인 재입고, OUB-MIX BR-OUB-MIX-009·010)
2-1. (WCS→현대무벡스 ECS) 해체 BOX 전량 BOX Shuttle 투입 → 적치 완료 → 피킹 W/T 할당 → BOX Shuttle 인출 → MIXED 팔레타이징로봇 (MIXED 직투입 불가, OUB-MIX BR-OUB-MIX-021)
3. (WCS→현대무벡스 ECS) 3층 MIXED 팔레타이징 출고 구성 지시 → 출고분 MIXED 팔레타이징
4. (현대무벡스 ECS→WCS) 3층 MIXED 출고 구성 완료 및 잔량 BOX 정보 통보

출고 구성 완료 팔레트 이송:
4-1. (WCS→수직반송기 ECS) 출고 팔레트 수직반송기로 1층 이동 지시 — 설비 접점 P-14, WCS 중간 처리
4-2. (수직반송기 ECS→WCS) 3층 출발 신호 → 1층 도착 신호를 따로 통보 (출발 위치·도착 위치·팔레트 ID, EQP-VND REQ-EQP-VND-007)
4-3. (WCS→생기연 ECS) AMR 이송 지시 — 설비 접점 P-10, WCS 중간 처리
4-4. AMR 또는 유인지게차(Workflow 설정)가 1층 출고 DOCK으로 이송 → AMR은 (생기연 ECS→WCS) 이송 완료 통보, 유인지게차는 WCS PDA 스캔

잔량 BOX → BOX Shuttle (현대무벡스 내부 인계, WCS 작업지시):
5. (WCS) 잔량 BOX 정보를 BOX Shuttle 투입 작업으로 변환
6. (WCS→BOX Shuttle ECS) 잔량 BOX 투입 지시
7. (BOX Shuttle ECS→WCS) 투입·적치 완료 → WCS가 MIXED 팔레타이징 설비 쪽 인계 완료 처리
