## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K02 SYS-JOB 작업지시 체계 (Batch · Work · Task · Workflow · Action)**: WCS는 프로세스별로 작업지시를 Batch → Work → Task의 계층으로 관리하고, Task는 WCS Planning이 생성하고, WCS Execution이 Task를 받아 Workflow에 따라 실제 설비 단위 작업지시인 Action을 생성한다(SYS-ARC). Action 이후 설비 인터페이스는 오픈솔루션의 통신표준화 솔루션이 처리한다.
- **K07 MST-STK 재고관리체계 (PLANT · Storage Location · 화주 매핑)**: EWMS는 PLANT와 Storage Location 조합으로 Stock Type을 관리하고, WCS는 이를 화주·WCS Storage Location으로 맵핑하여 별도 관리한다. 맵핑 기준과 PLANT별 재고 혼용 정책을 정의한다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.

## 1. 개요
프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다. 출고예정·피킹 W/T에는 LOT·화주가 지정되지 않으므로 화주는 맵핑 데이터로 지정하고 LOT는 할당 전략으로 찾는다(MST-ORD BR-MST-ORD-024). 할당 결과는 예약(INV-RSV)으로 이어지고, 적용한 전략은 전략 이력(SYS-ARC)으로 남는다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): WCS, Task, Workflow, 전략 이력, Planning, AS/RS, BOX Shuttle, GANTRY, 피킹호기, 보관호기, GANTRY 보관일, 창고 기초속성, MIXED 팔레타이징, 체적정보, 이적, GTP, 대시보드, 잔량, 재고실사, W/T, 재할당, 셀 상태, 가용수량, 작업 잠금, HU, 공팔레트 공급, 공팔레트 묶음, PLANT, 입고월, 화주, LOT, 이력 유형 코드, 재고 처리 표준 메소드, STO, 직송, 파워유저, 사전 보충, 긴급 보충, 출고예정, 할당 전략, Work, 재고 스냅샷, 가용재고, 셀 유형, 위치 규칙, 피킹 W/T

## 3. 프로세스 흐름
1. (WCS 사용자·파워유저) 프로세스 유형별 할당 전략 등록·변경 — 적용 조건, 후보 범위, 필터, 정렬, 보충원 순서, 부족 시 동작 (상세 구성 추천 REQ-MST-ALC-002)
2. (WCS Planning) 작업 요구 발생 — 피킹 W/T 수신, 사전 보충 계획, 긴급 보충, 설비 출고 불가에 따른 재할당, 재고실사 배출, 공팔레트 공급 요청 등
3. (WCS Planning) 화주 지정(PLANT–화주 맵핑, MST-STK) → 프로세스 유형·조건으로 적용할 할당 전략 조회
4. (WCS Planning) 할당 전략에 따라 후보 재고 필터 → 정렬 → 보충원 순위대로 수량 배분
5. (WCS Planning) 할당과 예약을 한 트랜잭션으로 처리하고 Task 생성 (INV-RSV REQ-INV-RSV-002)
6. (WCS) 적용 전략·선택 근거를 전략 이력으로 기록 (SYS-ARC REQ-SYS-ARC-012)

- 적용할 할당 전략이 없는 프로세스·조건: 프로세스 유형별 기본 전략을 적용한다. 기본 전략도 없으면 할당을 보류하고 파워유저에게 알람 (BR-MST-ALC-010)
