## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K02 SYS-JOB 작업지시 체계 (Batch · Work · Task · Workflow · Action)**: WCS는 프로세스별로 작업지시를 Batch → Work → Task의 계층으로 관리하고, Task는 WCS Planning이 생성하고, WCS Execution이 Task를 받아 Workflow에 따라 실제 설비 단위 작업지시인 Action을 생성한다(SYS-ARC). Action 이후 설비 인터페이스는 오픈솔루션의 통신표준화 솔루션이 처리한다.
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K05 MST-CTR 창고(CDC) 마스터**: 창고(CDC)를 화주(MST-OWN)와 함께 WCS 관리의 최상위 단위로 관리한다. 로케이션·설비 등 기준정보와 재고·작업지시 관리는 창고 아래에, 제품·재고관리체계(화주·Storage Location 맵핑)는 화주 아래에 속한다.
- **K09 MST-CUS 거래처 마스터**: WCS는 TC센터만 거래처로 관리한다. EWMS와 같은 거래처코드로 TC센터 거래처 정보를 만들어 두고, TC센터에 GANTRY 호기를 지정할 때 쓴다.

## 1. 개요
WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다. 설비별 사용 팔레트 유형은 1층 MIXED 팔레타이징로봇(GANTRY 소속, 10대) = 2316(1층 GANTRY 디팔레타이징 입구는 유형 제한 없음), 3층 MIXED 팔레타이징로봇 = 1816, 3층 입고 팔레타이징로봇 = 2316·1816·1960이며, 공팔레트가 필요하면 설비가 매거진 재고를 먼저 쓰고, 추가로 필요한 경우에만 필요한 팔레트 유형을 WCS에 요청하며 WCS가 AS/RS에서 공급한다. 속성 항목(§3 표)은 1차 추천안으로 확인필요 상태다.

공팔레트 공급 (공팔레트 = 제품과 동일하게 관리):
1. (설비) 공팔레트가 필요하면 매거진 재고를 먼저 사용 — WCS 지시 없이 설비가 자체 처리 (디스펜서 동작 WCS 미관여)
2. (설비 ECS→WCS) 매거진 재고로 부족해 추가로 필요한 경우에만 공팔레트 투입 요청 — 필요한 팔레트 유형 전송
3. (WCS) 요청 유형이 설비 허용 팔레트 유형인지 확인
4. (WCS→현대무벡스 ECS) AS/RS 공팔레트 묶음 피킹 작업지시 → 요청 설비까지 제품과 같은 경로로 이동, 설비 접점도 제품과 동일하게 WCS 중간 처리
5. (WCS) 공팔레트 재고(AS/RS 묶음·이동 중) 갱신 — 매거진 재고는 WCS 재고로 관리하지 않음

매거진 스태킹:
6. (설비) 디팔레타이징에서 나온 공팔레트가 매거진 라인을 타고 매거진에 스태킹
7. (설비) 매거진 재고·사용은 설비가 관리하며 WCS는 재고로 관리하지 않음

매거진 배출 (설비 투입 요청 없음 + 매거진 꽉 참):
8. (현대무벡스 ECS→WCS) 매거진 배출 요청 — 설비 투입 요청이 없는 상태에서 매거진이 꽉 찬 경우 현대무벡스가 요청하며, 대표 팔레트 ID(맨 밑)와 적재 팔레트 ID 전체를 같이 보낸다
9. (WCS) 요청 수신 → 묶음 구성 등록·이력 (HU-VAL BR-HU-VAL-009~011)
9-1. (WCS→현대무벡스 ECS) 해당 팔레트(대표 팔레트 ID 묶음) AS/RS 적치 작업지시
10. (현대무벡스 ECS→WCS) 적치 완료 → WCS 공팔레트 재고 갱신

## 6. 인터페이스
| 송신→수신 | 시점 | 주요 항목 |
| --- | --- | --- |
| 설비 ECS→WCS | 매거진 재고로 부족해 추가 공팔레트 필요 시 (투입 요청) | 요청 번호, 설비 ID, 팔레트 유형, 필요 수량(묶음 수) |
| WCS→현대무벡스 ECS | 추가 공팔레트 투입 요청 수신 시 | 팔레트 유형, 공팔레트 묶음, 목적 설비 (피킹 지시) |
| WCS→설비 ECS | 추가 공팔레트 투입 요청 수신 시 AS/RS 공팔레트 여유 없음 | 요청 번호, 공급 불가 |
| 현대무벡스 ECS→WCS | 공팔레트 묶음 배출 완료 시 | 팔레트 ID(묶음), 배출 위치 |
| 현대무벡스·로지스올 ECS→WCS | 3층 공팔레트 묶음 공급 위치 투입 인식 시 | 대표 팔레트 ID, 설비 ID, 공급 위치 (REQ-MST-EQP-033, 보고 없으면 PDA 투입 스캔) |
| 현대무벡스 ECS→WCS | 매거진 꽉 참 + 투입 요청 없음 (매거진 배출 요청) | 설비 ID, 대표 팔레트 ID(맨 밑), 적재 팔레트 ID 전체, 팔레트 유형, 수량(장수) |
| WCS→현대무벡스 ECS | 매거진 배출 요청 수신 후 (AS/RS 적치 작업지시) | 대표 팔레트 ID(묶음), 팔레트 유형 |

## 7. 예외 처리
- 추가 요청한 팔레트 유형의 AS/RS 공팔레트 여유가 없으면 요청 설비에 공급 불가를 리턴한다 (BR-MST-EQP-018).

## 8. 미결 사항
- Q-074: [추후 정리] 팔레트 유형 코드(2316·1816·1960)별 실제 규격(가로×세로 mm)·재질·최대 적재 높이/중량 (코드 체계는 직송 이적과 동일로 결정)
- Q-202: 1층 매거진 배출 묶음의 매거진 → 1층 AS/RS 입고대 이송 수단(AMR·유인지게차, AMR이면 설비 접점 등록) (배출·공급 라인 별도 구성·10대 공용, 매거진 만재 묶음은 이 라인 미사용·1층 입고대에서 AS/RS 보관·이동 구간 Workflow 결정, 공급 요청 시 행선지 = 해당 층 공급라인 결정)
- Q-206: [추가 협의] 3층 MIXED 공팔레트 공급라인과 3층 입고 팔레타이징로봇 공급 위치의 물리 위치, 투입 인식 보고 지원 여부 — 현대무벡스·로지스올 확인 (공급라인 투입·설비 보고 기본·PDA 보조·입고 팔레타이징로봇도 3층 출고대 공급 결정)
- Q-216: 3층 공팔레트 공급라인이 3층 출고대(TRASH BIN과 같은 라인)와 별도라면 AS/RS에서 3층 공급라인으로 바로 배출하는지 — 그렇다면 3층 출고대 배출·유인지게차 운반(BR-MST-EQP-025·027, REQ-MST-EQP-031·033 ②④)을 바꾸고, 3층 입고 팔레타이징로봇(로지스올) 공급 위치도 같은 라인을 쓰는지 확인 (1층·3층 공급라인 별도 결정)
