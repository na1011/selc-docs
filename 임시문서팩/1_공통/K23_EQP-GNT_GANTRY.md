## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K09 MST-CUS 거래처 마스터**: WCS는 TC센터만 거래처로 관리한다. EWMS와 같은 거래처코드로 TC센터 거래처 정보를 만들어 두고, TC센터에 GANTRY 호기를 지정할 때 쓴다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K12 MST-EQP 설비 기준정보 · 팔레트 유형**: WCS는 자동화 설비를 기준정보(설비 기준정보)로 관리한다. 설비마다 장비 특성(작업 단위, 처리 능력, 적재 제약, 투입·배출 포트, 사용 팔레트 유형 등)이 다르므로, 공통 속성과 설비 유형별 속성을 정의하여 작업지시 대상 ECS 결정, 설비 배정, 설비 접점 처리, 공팔레트 공급의 기준으로 사용한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K19 INV-RSV 재고 예약(할당) 관리**: 설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.

> 상태: 일부확정

## 1. 개요
1층 대형제품 출고 전용 설비. AS/RS에서 FULL 팔레트로 출고할 수 없는 잔여 제품을 디팔레타이징하여 BOX 단위로 출고 구성(MIXED 팔레타이징)한다. 출고 구성은 GANTRY 소속 설비인 1층 MIXED 팔레타이징로봇이 수행하고, 출고 구성을 마친 팔레트는 GANTRY 출고대로 배출한다. 총 10개 호기로, 피킹호기 8개(출고 구성)와 보관호기 2개(G05, G10 — GANTRY 진입 시 디팔레타이징 잔량 보관)로 구성된다. 설비사는 현대무벡스로 AS/RS와 같아, AS/RS → GANTRY 보충은 설비 접점이 아니다 (보충 컨베이어·1층 디팔레타이징도 현대무벡스).

호기 운영:
1. 출고 시 보관호기에 해당 제품 재고가 있으면 피킹호기로 먼저 이동 — GANTRY 보관일·LOT가 오래된 BOX부터 (BR-EQP-GNT-022)
2. 부족분은 AS/RS 팔레트 배출 → 디팔레타이징(현대무벡스 자체 진행, WCS는 실적만 수신 BR-EQP-GNT-036) → 인도처 매핑 피킹호기(TC센터) 또는 FO 임시 할당 호기(직송)로 이송, 피킹호기로 보내고 남은 잔량 BOX는 보관호기로 이동하여 보관
3. 피킹호기에서 1층 MIXED 팔레타이징로봇이 출고 구성(MIXED 팔레타이징) → 출고 구성을 마친 팔레트는 GANTRY 출고대로 배출
4. 보관호기 잔량은 2번 GANTRY 진입 시점에만 생기며, MIXED 팔레타이징과는 무관하다 (보관호기 재고는 다음 출고 시 1번에서 사용)
5. 장기간 보관되는 보관호기 재고: (WCS 사용자) 재고조회에서 GANTRY 보관일로 필터링해 판단 → (WCS→현대무벡스 ECS) 1층 MIXED 팔레타이징로봇으로 동일 LOT만 팔레타이징(출고 구성 작업이 먼저, 부착된 팔레트 ID 재사용) → AS/RS 입고대 투입 — 내부 이동이라 EWMS W/T 연동 없음, 수작업 배출 불가 (BR-EQP-GNT-023~026)

## 7. 예외 처리
- 인도처 매핑 없는 출고분: 거래처 정보 오류로 보류, 매핑 등록 시 자동 재처리 (MST-CUS REQ-MST-CUS-018)
- 피킹호기 고장·부족: 파워유저가 인도처 매핑을 다른 피킹호기로 변경, Action 전 W/T 재할당 (REQ-EQP-GNT-039)
- 보관호기 적재 공간 부족: 사전 보충 단계에서 예상 잔량이 여유를 넘는 팔레트는 뒤로 미루고, 그래도 넘치면 잔량을 팔레타이징해 AS/RS에 재입고하고 알람 (BR-EQP-GNT-046)
- 장기 보관 재고를 수작업으로 배출하지 않는다. 팔레타이징해 AS/RS로 투입한다 (BR-EQP-GNT-020·021)
- 장기 보관 재고 팔레타이징 중 EWMS 통신 단절: 설비는 멈추지 않고 HU 확인을 보류했다가 복구 후 처리 (BR-EQP-GNT-028, 제어 방식 추천 REQ-EQP-GNT-023)
