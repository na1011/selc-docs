## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K01 SYS-ARC WCS 구성 (Planning · Execution)**: WCS 시스템 계층을 Planning과 Execution 둘로 나누고, 각각 별도 인스턴스로 분리한다. Planning은 SCP에 설치하고, Execution은 각 센터별 로컬에 설치한다.
- **K02 SYS-JOB 작업지시 체계 (Batch · Work · Task · Workflow · Action)**: WCS는 프로세스별로 작업지시를 Batch → Work → Task의 계층으로 관리하고, Task는 WCS Planning이 생성하고, WCS Execution이 Task를 받아 Workflow에 따라 실제 설비 단위 작업지시인 Action을 생성한다(SYS-ARC). Action 이후 설비 인터페이스는 오픈솔루션의 통신표준화 솔루션이 처리한다.
- **K08 MST-OPT 창고 기초속성**: 창고별로 제어해야 하는 옵션을 변수로 담아 창고 기초속성으로 관리한다. 각 프로세스는 필요한 시점에 해당 창고의 기초속성 변수를 읽어 동작을 제어한다.
- **K10 MST-ALC 할당 전략**: 프로세스별로 어떤 재고를 작업 대상으로 쓸지 정하는 규칙을 '할당 전략'이라는 설정 관리로 통합한다. 출고 할당(FULL 팔레트·GANTRY·3층 출고 구성·GTP·직송 이적), 사전 보충·긴급 보충, 재할당, 재고실사 배출, 공팔레트 묶음 피킹 등 재고를 쓰는 모든 프로세스는 각자 규칙을 코드로 갖지 않고 할당 전략 설정을 참조해 후보 재고를 거르고 순서를 정한다.
- **K17 INV-UNT 재고 관리단위(invn_id) · 위치 관리**: WMS 기본 사상에 따라 물리적 위치(존·로케이션·셀)와 논리적 관리단위(UOM 관리단위)를 분리한다. 논리적 관리단위는 invn_id로 식별하며 BOX일 수도, 팔레트일 수도 있다.
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.

## 1. 개요
설비 작업지시(Task·Action)를 만들 때 진행 중인 작업이 쓰고 있는 재고를 예약수량으로 관리해, 다음 작업이 진행 중 작업을 감안해 생성되도록 하는 제어 방법을 정의한다. 예약의 생성·소진·해제 시점, 동시 생성 경합 방지, 팔레트 이동 중 작업 잠금, 목적지 도착예정 수량, 정합성 점검을 다룬다. 재고 구조와 이력 반영 원칙은 INV-UNT, 수량 구분과 조회는 INV-QRY를 따른다.

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): WCS, ECS, Work, Task, Action, Workflow, 전략 이력, Planning, Execution, GANTRY, 재고 관리단위, 창고코드, 디팔레타이징, 대시보드, 재고대사, 재고 스냅샷, 재고실사, W/T, 재할당, 셀 상태, 재고수량, 예약수량, 가용수량, 작업 잠금, 도착예정 수량, 보류수량, 공팔레트 묶음, LOT, 재고 이동 로그, 변경 TASK번호, 순소요량, EWMS, AS/RS, 피킹호기, 보관호기, 잔량, 공팔레트, 화주, 인도처, 사전 보충, 긴급 보충, 출고예정, 창고 기초속성, BOX Shuttle, W/T 생성, 가용재고, 입고월, 할당 전략, 이적

## 3. 프로세스 흐름
1. (WCS Planning) 재고를 쓰는 Task(출고 할당·보충·이송·실사 등) 생성 시 후보 재고 조회: 가용수량 > 0, 셀 상태 정상, invn_id 작업 잠금 없음
2. (WCS Planning) 할당과 예약을 한 트랜잭션으로 처리: 예약 레코드 생성(Task ID, invn_id, lot_id, 수량, 작업 유형), 팔레트 이동이면 invn_id 작업 잠금, 목적 셀 적치 예약과 도착예정 수량 등록
3. (WCS Planning→WCS Execution) 예약된 invn_id·LOT·수량을 담아 Task 전달
4. (WCS Execution→설비 ECS) Workflow에 따라 Action 지시. Action 전송 후에는 예약을 회수(선점)하지 않음
5. (설비 ECS→WCS Execution→WCS Planning) 실적 수신 → 출고·이동 이력과 예약 소진을 같은 변경 TASK번호로 처리, 도착예정 수량을 재고로 전환, 작업 잠금 해제
6. (WCS) 부분 실적·실물 부족: 실적 수량만 소진, 남은 예약은 Task 상태에 따라 유지 또는 해제, 부족분은 재고 처리 오류 표시 후 재할당
7. (WCS) Task 취소·실패: 예약 즉시 해제. 재할당은 원 예약 해제와 새 예약을 한 트랜잭션으로 처리
