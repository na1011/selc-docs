## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K02 SYS-JOB 작업지시 체계 (Batch · Work · Task · Workflow · Action)**: WCS는 프로세스별로 작업지시를 Batch → Work → Task의 계층으로 관리하고, Task는 WCS Planning이 생성하고, WCS Execution이 Task를 받아 Workflow에 따라 실제 설비 단위 작업지시인 Action을 생성한다(SYS-ARC). Action 이후 설비 인터페이스는 오픈솔루션의 통신표준화 솔루션이 처리한다.
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K14 MST-LOT WCS LOT 관리**: WCS는 보관재고가 섞이지 않도록 LOT 생성 전략에 정한 LOT 속성 조합으로 LOT를 채번하여 재고를 구분한다. 창고코드·화주·제품코드는 필수 속성으로 항상 포함하고, 나머지 속성은 창고별로 선택한다.

## 머리말
> 분류: 업무=기준정보 / 설비=공통
> 관련 시스템: EWMS, WCS | 관련 키워드: MST-PRD, MST-LOT, INB-DVN, INB-PLT, OUB-CFM
> 상태: 일부확정

## 1. 개요
평택 CDC는 LOT 생성 전략에서 제조번호를 LOT 속성으로 선택하지 않는다(물류 작업지시 효율 저하 우려, 후보 속성으로는 존재, MST-LOT). 대신 시리얼 마스터를 두어, 시리얼번호가 입고되어 최초 생성될 때, 설비로부터 시리얼번호 단위 결과 실적을 받을 때, 출고하면서 시리얼번호 단위 검수 결과를 받을 때 이력 로그를 쌓아 추적한다. 입고 유형별 제조번호 수신 방식을 함께 정의한다. 제조번호는 EWMS가 관리하는 제품 속성인 Product Code를 앞자리로 사용해 만들어진다(MST-PRD).

## 2. 용어
이 문서에서 쓰는 용어(정의는 C02 GLOSSARY): 제조번호, 제조번호 미관리 상품, BCR, 디베닝입고, 일반입고, LOT, EWMS, WCS, AS/RS, BOX Shuttle, GANTRY, 디베닝, W/T, 팔레트 ID, ECS, 팔레타이징, MIXED 팔레타이징, EWMS PDA, 시리얼 마스터, 시리얼 이력 로그, 디팔레타이징, 변경 TASK번호, 아이템 UOM 레벨, Task, LOT 생성 전략, CDC, 제품코드, Product Code, HU, HU 내역 조회, 피킹 W/T, 중포장단위

## 3. 프로세스 흐름
제조번호 수신:
- 디베닝입고: (BCR) 스캔 → (WCS) 제조번호 수신
- 일반입고: (EWMS) 제조번호 생성 → (WCS→EWMS) 입고장 투입 시 HU 내역 조회 → (EWMS→WCS) HU 내역과 함께 제조번호(S/N) 수신 (INB-PLT BR-INB-PLT-022)

시리얼 마스터 · 이력 로그 (모든 로그에 변경 TASK번호와 아이템 UOM 레벨 1~3 항목 기록):
1. 입고 최초 생성: 시리얼번호가 처음 수신되면 (WCS) 시리얼 마스터 생성 + 이력 로그(입고 생성)
2. 설비 결과 실적: 시리얼번호 단위 변경 작업이 발생하면 (ECS→WCS) 실적 수신 즉시 실시간으로 모두 이력 로그 적재 (특정 설비로 한정하지 않음)
3. 출고 검수: (작업자) WCS가 제공하는 PC 또는 PDA의 출고완료 확정 화면에서 시리얼번호 단위 출고 검수를 함께 처리(OUB-CFM) → (WCS) 검수 실적 발생 즉시 이력 로그 적재
- 제조번호 미관리 상품은 시리얼 마스터·이력 로그 대상에서 제외
- 제조번호 누락·중복은 물류 프로세스를 막지 않음 — 작업은 그대로 진행하고, 로그는 수신된 정보 기준으로 적재
- 재고·작업지시는 LOT 단위로 처리하며, 시리얼번호는 로그로만 추적한다
