# [C02] 평택 CDC WCS 요구사항 — GLOSSARY (용어집)

> C01 공통 컨텍스트 다음에 모든 세션에서 한 번 입력한다. 키워드 문서(K01~K40)는 §2에 용어 이름만 적고 정의는 이 문서를 따른다.
> 기준일: 2026-11-02 · 용어 224개 · 같은 용어는 모든 키워드에서 같은 뜻이다. '동의어/약어'로 적힌 표현도 같은 용어로 읽는다.

| 용어 | 정의 | 동의어/약어 | 관련 키워드 |
|---|---|---|---|
| EWMS | WCS의 상위 시스템(개발 범위 외). 수작업 영역과 자동화 설비 영역 전체 재고를 관리하고(자동화 설비 영역은 BIN으로 크게 묶어 관리), 입출고 오더, W/T 생성·확정, HU 채번, 도크 배정을 담당하며 WCS에 작업 정보, 입고예정정보, 국내생산·국내OEM 차량 입문계획, 출고 차량정보를 내려준다. | WMS (이전 문서 표기), ERP (용어 통일 전 표기) | 전체 |
| 게이트 관리 시스템 | CDC 정문의 차량 입차·출차를 관리하는 시스템. 아마노시스템을 사용하며 WCS에 입차·출차 정보를 연동한다. | 아마노시스템 | YRD-VHC |
| WCS | 개발 대상 시스템. 상위 EWMS와 하위 설비 시스템(ECS) 사이에서 자동화 설비 작업을 지시·제어하고, LOT 단위로 자동화 설비 구역 재고를 관리한다(제조번호는 시리얼 마스터·이력 로그로 추적). 수작업 영역 재고는 관리하지 않으며, EWMS BIN 안의 설비 내 상세 재고·위치를 관리하고 W/T 생성·확정으로 EWMS와 재고를 동기화한다. | Warehouse Control System | 전체 |
| ECS | WCS의 하위 설비 시스템(개발 범위 외). WCS의 지시를 받아 개별 자동화 설비(AS/RS, BOX Shuttle, GANTRY 등)를 직접 제어한다. 설비사별로 별도 ECS가 존재한다. | 설비 시스템, Equipment Control System | INB-PLT, EQP-ASRS |
| FIS | 역수입(해외생산·해외OEM) 입고의 차량 입문계획을 WCS로 push하는 시스템. WCS와 연동 개발 대상이다 (정식 명칭 확인필요, Q-011). |  | MST-ORD, YRD-VHC |
| CDC | 물류센터(Distribution Center). 본 문서 대상은 평택 CDC. |  | 전체 |
| Batch | 프로세스별 작업지시 체계의 최상위 묶음 단위. 하위에 Work를 둔다 (세부 구체화 예정). | 배치 | SYS-JOB |
| Work | Batch 아래의 작업 단위. 출고예정·W/T를 수신하면 원본(EWMS 수신 원본)을 별도로 보관하고, WCS가 화주·LOT 속성 등을 붙여 만든 가공 데이터가 Work다. W/T에 맵핑되어 실적을 반영하는 Work와, W/T와 무관하게 작업지시를 위해 WCS가 생성하는 Work(보충·내부 이송 등)가 있다. 하위에 Task를 둔다 (세부 구체화 예정). | 워크 | SYS-JOB |
| Task | Work 아래의 작업 단위. WCS Planning이 생성하며, WCS Execution이 Task를 받아 Workflow에 따라 Action을 만든다. 변경 TASK번호로 시리얼 이력 로그와 연결된다 (세부 구체화 예정). | 태스크, TASK | SYS-JOB, MST-SN |
| Action | WCS Execution이 Task를 받아 Workflow에 따라 생성하는 실제 설비 단위 작업지시. Action 이후 설비 인터페이스는 통신표준화 솔루션이 처리한다 (세부 구체화 예정). | 액션, 설비 작업지시 | SYS-JOB |
| Workflow | WCS Execution이 Task를 설비 작업지시용 Action으로 만드는 처리 흐름. Execution은 Workflow에 따라 Action을 생성한다. 팔레트 단위 흐름(이송 단계·수단: 설비, AMR, 유인지게차 등)은 상황에 따라 달라지므로 Workflow로 설정할 수 있게 하고, 설정된 대로 작업이 이어진다 (세부 구체화 예정). | 워크플로 | SYS-JOB, SYS-ARC |
| 전략 이력 | 모든 프로세스에서 작업에 적용한 작업방식·전략(옵션 값, Workflow, 할당·보충 전략, 사용자 판단 등)을 남기는 이력. 나중에 어떤 방식으로 처리했는지 추적·비교하는 데 쓴다. | 작업방식 이력 | SYS-ARC, SYS-JOB, MST-OPT |
| Planning | WCS를 둘로 나눈 계층 중 계획 부분. 별도 인스턴스로 SCP에 설치하며, Task를 생성해 각 센터의 Execution에 전달한다. | WCS Planning, 플래닝 | SYS-ARC, SYS-JOB |
| Execution | WCS를 둘로 나눈 계층 중 실행 부분. 별도 인스턴스로 각 센터(창고)별 로컬에 설치하며, Task를 받아 Workflow에 따라 설비 작업지시용 Action을 생성하고 설비 실적을 받는다. 네트워크 단절 시 독립 수행 방안을 검토한다. | WCS Execution | SYS-ARC, SYS-JOB |
| SCP | WCS Planning 인스턴스를 설치하는 클라우드 플랫폼(정식 명칭 확인필요). |  | SYS-ARC |
| 통신표준화 솔루션 | 오픈솔루션이 제공하는 설비 통신 표준화 솔루션. Action 이후 WCS와 설비(ECS) 사이 인터페이스를 처리한다(접점 설계 중). |  | SYS-ARC, SYS-JOB, EQP-VND |
| AS/RS | 팔레트 단위로 재고를 보관·입출고하는 자동화 창고 설비. 1·3·4층에 입고대·배출구가 있다. 1층 FULL 팔레트 출고는 1층 출고대로 배출한다. 3층에는 투입용으로 3층 입고대(1개 포트), 디베닝 팔레타이징 팔레트가 들어가는 AS/RS 3층 입고라인, 부분 해체 잔량을 다시 넣는 AS/RS 재투입라인이 따로 있고, 배출라인은 디팔레타이징용 3층 디팔레타이징 배출라인 1개와 팔레트를 그대로 배출하는 3층 출고대 2개다. | Automated Storage and Retrieval System | EQP-ASRS, INB-PLT |
| BOX Shuttle | 3층에 위치한 중소형 제품 대상 BOX 단위 자동화 보관 설비. | 박스셔틀 | EQP-BSH, INB-DVN |
| BOX 식별자 | BOX Shuttle에서 BOX를 식별하는 키. 제조번호관리 상품은 제조번호(S/N), 그 외 상품은 제품코드를 사용한다. | BOX ID | EQP-BSH, EQP-MIX, MST-SN |
| GANTRY | 1층에 위치한 대형제품 출고 전용 설비(10개 호기). AS/RS에서 FULL 팔레트로 출고할 수 없는 잔여 제품을 디팔레타이징하여 BOX 단위로 출고 구성(MIXED 팔레타이징)하고, 출고 구성을 마친 팔레트는 GANTRY 출고대로 배출한다. GANTRY 진입 시 디팔레타이징한 BOX 중 피킹호기로 보내고 남은 잔량은 보관호기에 보관한다(MIXED 팔레타이징과 무관). 출고 구성은 GANTRY 소속 설비인 1층 MIXED 팔레타이징로봇이 수행한다(설비사 현대무벡스). | 갠트리 | EQP-GNT, OUB-GNT |
| 피킹호기 | GANTRY 각 행 왼쪽 4개 호기(G01~G04, G06~G09). 인도처와 매핑되며, 1층 MIXED 팔레타이징로봇이 이곳에서 출고 구성(MIXED 팔레타이징)을 수행한다. MIXED 팔레타이징 후 남은 BOX는 피킹호기에 그대로 둔다. |  | EQP-GNT, OUB-GNT |
| 보관호기 | GANTRY 각 행 가장 오른쪽 호기(G05, G10). GANTRY 진입 시 디팔레타이징한 BOX 중 피킹호기로 보내고 남은 잔량을 보관하고(MIXED 팔레타이징과 무관), 다음 출고 시 피킹호기로 이동시켜 출고 구성에 사용한다. | 보충호기 | EQP-GNT, OUB-GNT |
| GANTRY 출고대 | 1층 GANTRY에서 1층 MIXED 팔레타이징로봇이 출고 구성(MIXED 팔레타이징)을 마친 출고 팔레트를 배출하는 곳. AS/RS FULL 팔레트를 배출하는 1층 출고대와 구분한다. 배출된 팔레트는 AMR 또는 유인지게차로 출고 DOCK까지 옮긴다. |  | EQP-GNT, OUB-GNT |
| GANTRY 보관일 | BOX가 GANTRY(피킹호기·보관호기)에 보관된 기준 일자. 장기 보관의 정의(기준 기간)는 두지 않고, 사용자가 이 값을 보고 장기 보관 여부를 판단한다. 재고조회 조회옵션으로 필터링하며, 보관호기 재고를 우선 사용할 때 오래된 BOX부터 쓰는 기준이 된다. |  | EQP-GNT, OUB-GNT, INV-QRY |
| 하역 로봇 | 1층에서 디베닝 대상 BOX를 차량/컨테이너에서 하역하는 로봇 설비. |  | INB-DVN |
| BCR | 바코드 리더. 디베닝 후 3층에서 BOX의 제품코드/제조번호를 스캔하여 WCS로 전송한다. | Barcode Reader | INB-DVN |
| 시퀀스 버퍼 | BCR 이후 3층 입고 팔레타이징로봇 진입 전 BOX를 순서대로 대기시키는 버퍼 설비. 설비사는 로지스올이다. | S/B (약어 용법 확인필요, Q-006) | INB-DVN |
| 팔레타이징로봇 | 시퀀스 버퍼를 거친 BOX를 동일 제품·LEQ 기준으로 팔레트화하는 3층 로봇 설비(3층 입고 팔레타이징로봇). 팔레트 유형 2316·1816·1960 중 필요한 유형을 요청하면 WCS가 공팔레트를 공급한다. | 3층 입고 팔레타이징로봇 | INB-DVN, MST-EQP |
| 1층 MIXED 팔레타이징로봇 | 1층 GANTRY 소속 설비(현대무벡스)로, 피킹호기에서 출고 주문에 따라 BOX를 혼적해 출고 팔레트를 구성(출고 구성)하는 로봇. 장기간 보관되는 보관호기 재고를 동일 LOT로 팔레타이징해 AS/RS로 보낼 때도 쓰며, 출고 구성 작업이 먼저다. 호기당 1대(피킹호기·보관호기 포함 10대) 있으며 2316 팔레트를 사용한다. | 1층 MIXED 팔레타이징 설비 | EQP-GNT, OUB-GNT, MST-EQP, EQP-VND |
| 3층 MIXED 팔레타이징로봇 | 3층에서 출고 주문에 따라 BOX를 혼적해 출고 팔레트를 구성하는 로봇 설비. 3층 입고 팔레타이징로봇과 별도 설비이며 1816 팔레트를 사용한다. 설비사는 현대무벡스다. | 3층 MIXED 팔레타이징 설비 | EQP-MIX, MST-EQP |
| AMR | 자율주행 이동로봇. 1층에서만 사용하며, 1층에서 수직반송기까지 팔레트를 운반하고 3층 출고 구성 완료 후 수직반송기로 1층에 내려온 팔레트와, 1층 출고대·GANTRY 출고대의 출고 팔레트를 출고 DOCK까지 이송한다(모두 유인지게차도 가능, Workflow 설정). WCS가 작업지시하고 결과를 받는다. 3층·4층은 AMR 대신 유인지게차를 사용한다. | Autonomous Mobile Robot | INB-MAN, EQP-VND, OUB-GNT |
| 유인지게차 | 작업자가 운전하는 지게차. 3층·4층에서 AMR 대신 팔레트를 운반하며(수직반송기·AS/RS 배출구 ↔ 수작업 영역), WCS는 작업지시를 내리지 않는다. 1층에서도 수직반송기 투입이나, 수직반송기 도착 팔레트를 출고 DOCK으로 옮기는 데 쓸 수 있다(AMR 또는 유인지게차, Workflow 설정). | 지게차 | INB-MAN, OUB-MAN, EQP-VND |
| 수직반송기 | 층간 팔레트를 이송하는 수직 반송 설비. 1층→3층 수작업 이동과 3층 출고 구성 완료 팔레트의 1층 이동에 사용한다. 설비사는 미정이며, 다른 설비와 설비사가 다르다고 보고 모든 인계 지점을 설비 접점으로 WCS가 작업지시한다. 수직반송기도 WCS 작업지시 대상이며, 층간 이동 시 WCS는 수직반송기로부터 출발 신호와 도착 신호를 따로 받고, 주요 항목은 출발 위치(층)·도착 위치(층)·팔레트 ID다. 수직반송기 센싱으로 결과를 받으면 WCS가 Workflow에 따라 후행 작업을 잇는다. |  | INB-MAN, EQP-MIX, EQP-VND |
| 위치셀 | WCS가 관리하는 물리적 위치 단위. EWMS가 BIN으로 관리하는 자동화 설비 구역 안의 상세 위치이며, 'F00-001-001-01' 형식의 자리수 포맷을 따른다. |  | MST-LOC |
| BIN | EWMS가 재고위치를 묶어 관리하는 단위(EWMS BIN: RCV1·RCV3·RCV9·WCS1·AMVT·MMVT). EWMS는 BIN과 Stock Type 두 기준으로 재고위치를 관리한다. AS/RS·GANTRY 등 자동화 설비 재고는 자동화구역(Stock Type 0050·BIN WCS1)이고, 1층 입고장·3층 출고대(9011·RCV1, 9013·RCV3)은 설비 재고 영역이 아니라 설비를 태워 이동시킬 작업지시에 쓴다. AS/RS에 넣으라는 입고는 자동화구역으로 지정하고, 적치하지 못하고 다른 프로세스로 가는 경우에만 입고장(9011·9013)을 쓴다. EWMS BIN은 층 개념을 포함하므로 WCS는 셀을 EWMS Stock Type·BIN과 매핑하고, 출발 셀과 목적 셀의 BIN이 다르면 BIN 변경 이동(층간 이동 포함)으로 본다. BIN 변경 이동은 W/T로만 EWMS에 반영하고 층간이동지시는 쓰지 않는다. | EWMS 로케이션, Storage Bin | MST-LOC, INV-UNT |

| 사전 보충 | 피킹 W/T 수신 전에 출고예정 정보로 출고 구성용 BOX를 미리 보충하는 작업. 층 구분 없이 당일 출고예정·시간대 A타입 오더만 대상으로 하며, 출고예정 수신 시점(EWMS가 새벽 1회 PUSH)에 만든다("수시 보충"). | 긴급 보충 | 피킹 W/T 할당이나 피킹지시 시점에 출고 구성 재고가 부족할 때 즉시 생성하는 보충 작업. 사전 보충보다 우선한다. 부족 수량에서 진행 중 보충량(사전·긴급 보충의 도착예정 수량)을 빼고 만들며, 같은 제품의 시작 전 사전 보충은 긴급으로 전환한다. 1층 GANTRY는 보관호기 → AS/RS 팔레트 순으로 피킹호기를 채우고, 3층은 AS/RS 팔레트를 3층 디팔레타이징해 BOX Shuttle에 적치한 뒤 쓴다(MIXED 직투입 안 함, OUB-MIX). 3층의 할당 우선순위 2순위(AS/RS 팔레트 3층 배출·디팔레타이징)는 긴급 보충과 같은 개념이다. |  | OUB-GNT, OUB-MIX |
