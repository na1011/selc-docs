## 0. 선행 맥락 (앞 순서 관련 키워드 요약)
- **K03 SYS-UI 단말 역할 (PDA · PC · 대시보드)**: WCS PDA는 단순 정보 조회보다 현장 작업 수행과 예외 상황 조치 중심으로 기능을 재정의한다. 바코드 스캔을 통한 화물 상태 확인, 작업 추적, Reject 처리, 긴급 조치 기능을 중심으로 요구사항을 보완한다.
- **K04 SYS-ERR 통합 에러관리**: 설비사·설비마다 다른 에러코드를 WCS가 취합해 통합 에러코드로 관리한다. 에러마다 작업자 전달 메시지, 처리방법 메시지, 후행 API를 연결해 두고, 에러가 들어오면 연결된 메시지를 작업자에게 전달하고 후행 API로 후속 처리(Reject 등록, 재고 오류 표시, 재할당, Task 보류 등)를 잇는다.
- **K11 MST-LOC 로케이션 / 위치코드**: EWMS BIN 코드(RCV9, WCS1, AMVT, MMVT)와 WCS 위치셀 사이의 매핑 기준, 설비 물리 위치 코드 포맷을 정의한다. EWMS는 수작업 영역과 자동화 설비 영역 전체 재고를 관리하며, 자동화 설비 영역은 BIN(로케이션) 단위로 크게 묶어 관리한다.
- **K13 MST-PRD 제품마스터**: 입고 경로, 보관설비, 출고설비를 결정하는 제품마스터 속성을 정의한다. Product Code는 제품마스터의 하위 속성이며, 이를 이용한 제조번호 정합성 체크도 여기서 다룬다.
- **K15 MST-SN 제조번호(S/N) 관리**: 평택 CDC는 LOT 생성 전략에서 제조번호를 LOT 속성으로 선택하지 않는다(물류 작업지시 효율 저하 우려, 후보 속성으로는 존재, MST-LOT). 대신 시리얼 마스터를 두어, 시리얼번호가 입고되어 최초 생성될 때, 설비로부터 시리얼번호 단위 결과 실적을 받을 때, 출고하면서 시리얼번호 단위 검수 결과를 받을 때 이력 로그를 쌓아 추적한다.
- **K16 MST-ORD 입출고 오더 유형**: EWMS 입고 오더 유형(해외생산·국내생산·국내OEM·해외OEM, 쉽백은 WCS 프로세스 제외), 출고 오더 유형(STO/직송), 출고 정보 유형(출고예정/피킹 W/T/시간대별 Type)과 각 유형이 WCS 처리 경로에 주는 영향을 정의한다. 출고 작업지시 단위는 출고 유형별로 다르다: 직송은 SO→DO→FO로 만들어 FO 단위로, STO는 동일 TC 기준 총량피킹이 가능하도록 DO를 ORG DO로 묶어 OR…
- **K18 INV-WT W/T 상태 · 가용재고**: EWMS가 W/T를 생성·확정하고 WCS는 이를 연동하여 재고 상태를 관리한다. W/T 생성 시 WCS 재고로 잡히지만 가용재고가 아니며, W/T 확정 후 가용재고가 되어 출고지시가 가능하다.
- **K20 EQP-VND 설비사 맵핑 · 설비 접점**: 자동화 설비별 설비사를 정의하고, 설비사가 다른 설비 사이에서 BOX/팔레트가 인계되는 설비 접점의 발생 위치를 정리한다. 설비사별로 ECS가 따로 있으므로 설비 접점에서는 설비끼리 직접 연동하지 않고 WCS가 중간 처리한다.
- **K21 EQP-ASRS AS/RS**: 팔레트 단위 핵심 자동화 보관 설비로, 일반/디베닝입고 완료 팔레트와 공팔레트 묶음을 보관한다. 1·3·4층에 입고대·배출구가 있으며, 1층에서 FULL 팔레트 출고를 배출하는 곳을 출고대(1층 출고대)라 한다.

## 머리말
> 분류: 업무=입고 / 설비=AS/RS(1층), 사이즈 측정 설비
> 관련 시스템: EWMS, WCS, ECS | 관련 키워드: EQP-ASRS, HU-VAL, INV-WT, MST-ORD, INB-MAN, YRD-VHC
> 상태: 일부확정

## 1. 개요
1층에서 하역 또는 입고 수작업 영역에서 수작업 팔레타이징한 팔레트를 1층 AS/RS에 투입한다. 투입 시점에 WCS가 EWMS 내역을 확인하여 AS/RS 보관을 결정하며, AS/RS 용량이 부족하면 3층 출고대로 배출한다(용량 부족 배출, Bypass와 별개). 1층 입고대 Reject는 Bypass와 구분하며, ECS가 판단해 에러 코드를 포함해 3층 출고대로 배출한다. EWMS BIN은 WCS1. 3층 출고대 배출 후에는 유인지게차로 이동하며 WCS는 작업지시를 내리지 않는다 (AMR은 1층만 사용). 1층 수작업 영역은 AS/RS 입고 투입건 수작업 구역만 있다. ATL(생기연) 하차 후 AS/RS 투입도 설비 접점이다 (P-08, ATL 미구체화).

하위 유형 (프로세스·HU 처리 모두 동일, 구분 불필요):
- (a) 팔레트화 입고: 팔레트 상태로 입고되어 그대로 투입
- (b) 수작업 팔레타이징 후 투입: 1층에서 수작업으로 팔레트화한 뒤 투입 (별도 프로세스 아님)

## 3. 프로세스 흐름
0. (EWMS→WCS) 적치 W/T 수신 — EWMS가 입고 오더 기준으로 생성한 뒤 실시간으로 WCS에 전송 → WCS 저장, 같은 시점에 WCS 재고 생성(비가용, 위치 = 1층 입고장 위치셀 RCV1, LOT 채번) (BR-INB-PLT-020·026)
1. (작업자) 1층 하역, 필요 시 수작업 팔레타이징
2. (작업자) 1층 AS/RS 투입
3. (ECS) 사이즈 체크 — 크기·높이·중량 측정, 규격 초과 시 Reject. 팔레트 유형은 적치할 크레인 호기·Bay를 정하는 중요한 값 (EQP-ASRS BR-EQP-ASRS-020·021)
4. (ECS→WCS) 정상 팔레트에 대해 팔레트 ID로 목적지(보관/Bypass) 문의 (W/T 생성 요청이 아님)
5. (WCS→EWMS) 입고장 투입 시 팔레트 ID로 HU 내역 조회(적재 내역·제조번호) → 수신해 둔 적치 W/T와 팔레트 ID로 연결하고 W/T DEST로 목적지 결정(응답 지연 시 W/T DEST로 먼저 응답, REQ-INB-PLT-032) (BR-INB-PLT-021·023·024) — WCS는 HU 확인·생성을 하지 않음
 - 수신한 W/T가 없으면 Reject 라인(3층 출고대)으로 토출 (BR-INB-PLT-025)
 - (WCS) 이동 이력으로 위치를 1층 입고장(RCV1) → AS/RS 입고대로 반영, 제조번호를 시리얼 이력에 남김 (재고는 0단계 W/T 수신 시 생성) (Reject 배출 포함 — Reject도 적치 W/T 수신 후 토출)
6. (WCS→ECS) 목적지 전달
7. (ECS) AS/RS 적치 / 용량 부족 배출 / Reject 배출(ECS 판단, 에러 코드) / Bypass(AS/RS 경유 이송) → 유인지게차로 이동 (WCS 작업지시 없음, 이송 컨베이어 없음)
8. (WCS) 적치 완료: 이동 이력으로 위치를 적치 셀로 반영 → 적치 W/T 확정 후 가용 (EQP-ASRS) / 용량 부족 배출·Reject: 출고대 도착 시 적치 W/T를 DEST BIN 바꿔 확정·배출 이력으로 WCS 재고 차감 (BR-INB-PLT-017, EQP-ASRS BR-EQP-ASRS-018) / Bypass(1층 → 3층, EWMS 지시): 3층 출고대 도착 시 적치 W/T 확정 (BR-INB-PLT-018)

Reject 발생 시:
1. 입고 과정(사이즈 체크 등)에서 Reject 발생
2. (ECS) Reject 판단·에러 코드 부여 → 3층 출고대 배출, (ECS→WCS) 에러 코드 전달 (BR-INB-PLT-016)
3. AS/RS에 보관하지 않고 3층 출고대로 배출 → 유인지게차로 이동

| BR-INB-PLT-035 | 적치 W/T 변경·취소 수신 | 투입(목적지 문의) 전이면 W/T 수신 때 만든 재고를 입고 취소 이력(반대 이력)으로 없애고, 변경은 취소 + 새로 수신으로 처리한다. 투입 후면 '작업 진행 중'으로 거부한다 |
| BR-INB-PLT-036 | HU 내역 조회 응답 지연 | 적치 W/T가 있으면 HU 내역 조회 응답을 기다리지 않고 W/T DEST로 목적지를 응답해 투입을 진행하며, HU 내역은 백그라운드로 다시 조회한다. W/T도 없으면 Reject 라인 토출 |

| EWMS→WCS | HU 내역 조회 응답 | HU 적재 내역(제품·LOT·수량), 제조번호(S/N) 목록 |

## 7. 예외 처리
- 디팔레타이징 전 DeWrapping 체적정보 요청은 미결 과제 (EQP-MIX Q-107)
- 입고 과정 Reject(사이즈 체크 규격 초과 등): ECS가 판단해 에러 코드를 포함해 3층 출고대로 배출 (BR-INB-PLT-009·016, Bypass와 구분). 3층 도착 후 처리는 WCS PDA 판단(출고 수작업 영역 이동 / 재투입 / 보류, EQP-ASRS REQ-EQP-ASRS-016)
- AS/RS 투입 전 오류(BCR 리딩 실패 등 팔레트 ID 미확인): 1층 입고대에서 후진 배출, WCS는 오류 이력만 기록 (BR-INB-PLT-032, 후진 구조 확인 Q-027)
- HU 내역 조회 응답 지연·내역 없음: W/T DEST로 먼저 응답해 투입 진행, 백그라운드 재조회, 계속 실패 시 알람·적치 확정 보류 (REQ-INB-PLT-032)
- 적치 W/T 변경·취소 수신: 투입 전이면 입고 취소 이력으로 재고 삭제, 투입 후면 거부 (REQ-INB-PLT-031)
