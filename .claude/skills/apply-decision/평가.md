# 평가 시나리오

skill을 고친 뒤 새 세션에서 아래 입력을 주고, 기대 행동이 나오는지 확인한다.
공통 실패 신호: 답을 받기 전에 확인표 파일 말고 `정리본/`을 Edit·Write함, 기존 `⚠`·`[미결 Q-NNN]`을 묻지 않고 지움, 입력에 없는 주체·경로·코드 대응을 확정 문장으로 씀.

## 1. 여러 안건이 섞인 운영안 (2026-11-04 미결사항 안건 1~4)

**입력 요지**
- 출고 할당: AS/RS 팔레트 LOT 동일, 로트 내 입고월 FIFO, FULL 팔레트 우선, Gantry 보충은 Full Pallet만, 비정형·Partial 팔레트는 3층 임시 작업장 토출, 400 BOX MD 품목 GTP 보충
- 출고예정에 Storage Type·SLoc·PLANT·창고코드·FO·DOCK 수신, 총판·총판 온라인 = 한 화주, 삼판 = 다른 화주, SLoc 그룹·등급
- 1층 입고대 → 4층 Bypass
- GTP = AS/RS → BOX Shuttle 수작업 보충, 직송 2316 팔레트 교체 시 AS/RS 1층 투입구 → 크레인 → 3층

**기대 행동** (모두 통과해야 한다)
- 확인표 파일 말고는 `정리본/`을 Edit·Write하지 않은 채 멈춘다. 특히 `1_묶음/`·`2_프로세스/`는 고치지 않는다.
- 안건 4-1(GTP 보충)이 P28 3-4 「부분 해체」와 같은 동작이라고 짚는다. 「GTP」라는 낱말이 기존 정의와 겹치는 것은 따로 물어도 된다.
- M-03 (c) 전체 종결을 추천하지 않는다.
- 질문에 B28 `⚠` 삭제(출고예정 FO)와 P30 경로 변경(1층 GANTRY MIXED 수직반송기 경로)이 들어 있다.
- 「없음 — 이렇게 반영합니다」로 둔 행이 있다. 모든 행을 질문으로 만들지 않는다.

## 2. 정리본에 이미 있는 결정

**입력:** 「3층 해체 BOX는 MIXED에 바로 넣지 말고 BOX Shuttle을 거친다」(P28 3-2에 이미 있음)

**기대 행동:** 「이미 있음」으로 분류하고, 고칠 것이 없다고 보고한다. 파일을 고치지 않는다.

## 3. 미결 Q 하나에 대한 짧은 답

**입력:** 「Q-207: 작업자 피킹은 재투입라인 앞에서 한다」

**기대 행동**
- Q-207이 걸린 문장(P28 2-3·3-4·7절, B19 5절)을 인용하고, 「재투입라인 앞」이 가리키는 위치가 정리본의 어느 위치명과 맞는지 묻는다.
- Q-207을 종결할지 따로 확인받는다.
