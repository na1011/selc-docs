# 확인표 양식

확인 게이트(SKILL.md 5단계)에서 응답에 보여 주는 표다. 표는 파일로 남기지 않는다. 안건 파일에는 묻는 질문만 한 줄씩 적는다(SKILL.md 5단계).

## 머리

```
입력 성격: 확정 결정 / 제안 / 회의 메모 (판단 근거 한 줄. 모르면 「확인 필요」)
주장 N개 — 신규 a · 이미 있음 b · 구체화 c · 충돌 d · 쟁점 종결 e
```

## 표

| ID | 원문 문구 | 분류 | 추천 해석 | 다른 해석 | 바뀌는 기존 문장 (문서·절) | 확인 요청 |
|---|---|---|---|---|---|---|

- **원문 문구**: 입력을 고치지 않고 그대로 옮긴다.
- **다른 해석**: 없으면 「없음」이라고 쓴다. 비워 두지 않는다.
- **바뀌는 기존 문장**: 충돌·쟁점 종결이면 기존 문장을 인용한다. 신규·구체화면 넣을 위치만 쓴다.
- **확인 요청**: 묻는 행(SKILL.md 5단계의 두 종류)은 질문 한 줄을 쓴다. 나머지 행은 「없음 — 이렇게 반영합니다」라고 쓴다.
## 예시 행

| ID | 원문 문구 | 분류 | 추천 해석 | 다른 해석 | 바뀌는 기존 문장 (문서·절) | 확인 요청 |
|---|---|---|---|---|---|---|
| 안건1-할당2 | Gantry 보충은 Full Pallet 만 가능 | 충돌 | AS/RS 팔레트를 통째로 넣고, BOX를 덜어 넣지 않는다 | 수량이 덜 찬 부분 팔레트는 GANTRY 보충원으로 쓰지 않는다 | P18 3-3 「② 부분 팔레트 우선(AS/RS 셀 비움)」, P22 2-2 예시 「30 BOX 부분 팔레트 선택」 | 「Full Pallet」가 투입 방식(통째로)을 뜻하나요, 팔레트 상태(가득 참)를 뜻하나요? 뒤쪽이면 P18 순서 ②를 지워야 합니다 |

## 표 아래

- 질문할 항목을 번호로 다시 모은다. AskUserQuestion으로 물을 항목에는 표시를 단다.
- 마지막 줄: 「답을 받기 전에는 안건 파일 말고는 정리본을 고치지 않습니다.」
